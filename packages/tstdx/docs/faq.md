# 常见问题

## 连接

### 所有请求都超时

公共节点会失效。先确认是节点问题还是代码问题：

```ts
import { pingAll } from "tstdx";
console.table(await pingAll());
```

全部 `connected: false` 就是节点或网络的问题。内置 `TDX_HOSTS` 只是起点，不是稳定基础设施。

### 握手成功，但 K 线和五档都是空的

这是公共节点最常见的形态。`pingAll` 测不出来，要用业务探测：

```ts
import { probeHosts } from "tstdx";
const rows = await probeHosts();
console.table(
  rows.map((r) => ({ host: r.host, usable: r.usable, bars: r.bars.status })),
);
```

`status` 为 `"empty"` 表示连上了但正文为空，`"error"` 才是协议或网络错误。用 `fromBestHost({ requireMarketData: true })` 可以直接跳过这类节点。

如果你在自己拼协议帧，还要检查第三条握手帧的末字节是不是 `0x05`——用 `0x02` 时握手有应答但行情没正文。

### 请求发出去了，服务器既不回也不报错

请求帧**整包长度**不对。服务器对长度不符的请求是静默超时。K 线少 6 字节、除权和财务各多 2 字节都出现过。测试里锁死了每种请求的长度，改 `build*` 时不要绕过。

### 关闭后还能用吗

能。`close()` 释放连接池并停止心跳，下次请求会重新建连。

## 数据口径

### 价格差了 10 倍或 100 倍

多半是小数位。股票与指数是两位小数，ETF 等证券要看证券目录里的 `decimalPoint`。客户端会自动处理；**直接调低层 `parseQuotes` / `parseMinutes` / `parseTransactions` 时必须自己传 `decimals`**，它们的默认值只对股票和指数正确。

### 财务金额比真实财报大 10 倍

你在用修正前的版本。协议金额单位是**千元**，不是万元。升级后重算所有缓存值。见[实网边界](./limits.md#2026-09-15财务字段口径修正)。

### `finance` 的股本结构子项对不上

那几个槽位（国家股、发起人股、法人股、B 股、H 股、职工股）**语义已被复用或错位**，不要用。实测 sh600519 的"法人股"大于总股本、sz000002 的"发起人股"为负、"职工股"槽位的值实际是每股收益。包内保留协议原值不换算，就是为了让这个异常显形而不是被换算掩盖。

### 怎么知道财务快照是哪一期的

`updatedDate` **不是报告期**，它是快照更新日（实测均非季末）。要拿到报告期，用本地财务包反查：把快照的 `totalAssets` / `mainRevenue` / `netProfit` 拿到 `gpcw*.dat` 里匹配，命中唯一的那一期就是。做法见[本地财务包](./api/affair.md#一个可复现的核验方法)。

### 成交量到底是手还是股

**未核验。** 分时、K 线与报价的量额不保证同一单位。没有独立证据前不要换算，也不要用 `amount / volume` 当均价。同一条记录内部的比值（委比、外盘占比）不受影响，可以放心用。

### 复权价和行情软件对不上

本包的前复权锚定**查询区间的末日**，后复权锚定首日，而且只使用截止日之前的除权事件。行情软件通常显示的是"随未来除权自动改写的最新前复权"。换一个 `end` 会得到不同的因子——这是设计，不是 bug。

### 涨跌停价和交易所不一样

`priceLimits` 是**本地规则参考值**，不是交易所下发价格。规则表覆盖 2023-04-10 起的常规 A 股板块与首次上市窗口；更早日期返回 `unsupported`。重新上市、退市整理等特殊状态未建模。

### 分时能当分钟 K 线用吗

不能。分时是 `{ price, volume }` 序列，没有 OHLC。指数分时的量字段尤其不能当成股数。

## 分页与批量

### 逐笔的 start 是从哪边数的

**从最新一笔往回数。** `start=0` 是当前最新成交，`start` 越大越早。这是在真实服务器上实测的，和直觉相反。

### 能不能把多页拼起来再截断

不能。五档、K 线、逐笔的价格是**页内**差分或累加编码，整页一起解才对。跨页拼接后再截断会得到错值。

### 批量里有一只失败，整批就废了吗

不会。`barsBatch` / `kBatch` 逐项返回 `data` / `empty` / `error`，并保留输入顺序：

```ts
for (const row of rows)
  if (row.status === "error") console.warn(row.symbol, row.error);
```

### 分页时报"重复记录"

逐笔只有分钟级时间，分页边界上可能出现无法区分的相同记录。本包**抛错而不是去重**——去重会静默丢掉真实成交。遇到这个错误需要调用方决定怎么处理。

## 数量口径

### stocks、allStocks、blockMembers 数量对不上

三种不同口径：

- `stocks(market)` — 该市场的**全部证券**（含基金、债券等）
- `allStocks()` — 只承诺**沪深 A 股**；北交所要单独调 `stocks("bj")`
- `blockMembers()` — 板块的**扁平成分条数**，一只股票可以属于多个板块

不要互相校验。

## 打包与发布

### 为什么装不上

`package.json` 里 `"private": true` 是刻意的防误发。现在只能走 workspace 或本地 tarball，见[安装与开发](./setup.md#安装)。

### 改了协议解码，已打包的应用要重新打包吗

要。任何改变解码结果的改动（尤其是单位换算）都会让旧产物与新产物的数字不一致。财务金额倍率修正就是这类改动。
