# quant-rps

独立纯 TypeScript RPS 计算模块，无应用、数据库、文件、网络或 UI 依赖。

公开入口为 `quant-rps`，应用消费者直接从包根导入，无兼容再导出层：

- `calculateRps`：传入已后复权价格、成交量、明确交易日历与证券元数据，返回逐周期收益、排名、缺失、剔除和用于宿主计算证据哈希的原始收益输入。
- `rankRps`：同周期横截面排名，并列取从 1 开始的平均名次；`RPS=(1-rank/N)*100`。
- `aggregateGroupRps`：按有效成分股收益等权聚合，再对行业/概念分别排名，不能平均成分股 RPS。
- `rpsPeriods`、`rpsPolicy`、相关类型：计算周期及统一规则。

默认周期为 **1（当日）、3、5、10、20、50、120** 个交易日。收益为 `当日后复权价 / N 个交易日前后复权价 - 1`。当日是相对前一交易日的收益，盘中批次用既有观测价，收盘用已完成日线。每个周期独立分母，缺任一成交端点留空，不填价、不填零。参考日历不足最长窗口时拒绝计算。

应用负责通达信取数/复权、成分快照校验、证据哈希、调度、发布和存储。既有日表及观测按各自 `periods` 解码，旧六周期结果不改写；新增周期从新计算批次生效。

独立验证：`pnpm --filter quant-rps test`（根入口 `pnpm rps:test`）及 `pnpm --filter quant-rps typecheck`。包内 `tests/rps.test.ts` 覆盖并列排名、独立分母、证券资格、多周期、等权组聚合、缺失和非法输入，只导入包源码与 Vitest，不依赖应用、数据库或 UI。应用集成验证由宿主单独维护，不作为本包测试入口。

本轮交付范围为基础包及统一策略侧所需接入，不包含原 RPS 应用适配与 UI 周期迁移。
