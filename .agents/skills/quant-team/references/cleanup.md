# quant-team 清理与保留

清理遵循仓库根 AGENTS 的授权流程：管理者提供精确清单和默认预演脚本，交给 Claude 在正常权限下执行，再核验回执与实际剩余项。

- 不按目录名、文件年龄或 `TEMP` 通配符推断归属，不自动回收历史运行。
- 每次清理只接受明确的绝对目标和保留项。先核对目标位于本任务范围、所有路径组件无链接/联接、运行已终止、无相关进程和锁；任一条件无法确认就保留并报告。
- 默认保留 `run.json`、冻结定义、结果、失败/恢复记录及复现需要的输入引用。管理者完成审阅并明确授权后，才可把整轮证据加入清单。
- 临时夹具应由创建它的测试清理。旧的系统临时目录无法确认归属时，不在本轮批量删除。
- 清理脚本无参数时只预演；`-Apply` 只删除同一精确清单中的已核实目标，输出逐项回执。执行前重新检查路径和进程，不能用旧预演替代。
- 清理失败或审批拒绝时记录具体目标；不扩大权限、不更换代理重试、不把已交接写成已删除。

操作结束后，交付记录列出已清理的一次性工件与仍保留证据的位置。本技能不提供基于年龄的自动删除规则。
