# 观澜 · 本地量化研究工作台

Next.js / T3 Stack 全栈 TypeScript 应用。Electron 仅提供窗口、托盘和本机 Node 服务生命周期。

## 启动

开发环境：Windows x64、Node.js 22、pnpm 9。

```powershell
pnpm install
pnpm dev
```

打开 http://127.0.0.1:3000 。默认读取 `E:\new_tdx64`，可在“数据与连接”更改。点击“扫描本地数据”建立证券目录；无需全市场导入后才能看图。

生产网页与桌面：

```powershell
pnpm build
pnpm desktop:prepare
pnpm start
# 或打开 Electron
pnpm exec electron .
# 构建 Windows 解压即用目录
pnpm desktop:pack
```

产物：`release/win-unpacked/GuanlanQuant.exe`。分发时保留整个 `win-unpacked` 目录。内置 Electron、Node 运行时及 SQLite 二进制，无需用户安装 Node/Python。点击窗口右上角 × 直接退出应用并停止后台服务与监控；也可通过托盘“退出并停止监控”退出。电脑关机、休眠或应用退出期间无法监控。

首次下载 Electron 如遇代理环境，可在当前终端设置 `$env:ELECTRON_GET_USE_PROXY='true'` 后运行 `node node_modules/electron/install.js`，使用已有 HTTP(S)_PROXY。

## 数据与研究

- 本地 A 股日线 `.day`、五分钟线 `.lc5` 只读解析；支持旧分钟线的 32 年年份回绕与当前 360 字节 TNF 名称目录。其他 TNF 版本保留证券代码，不猜名称。
- 仅按 A 股价格单位解析。北交所支持相应证券代码；ETF、指数、期货尚未进入本地筛选池。
- 日线和分钟线不是同一覆盖范围，页面明确标注来源和最后日期。旧文件不会触发今日通知。
- “MCP 最新行情”使用通达信服务，独立保留快照，不把不同来源拼成不明口径的历史序列。成交量归一为原始股数；缺少原始量时拒绝解析。
- MCP 配置可从本机 `%USERPROFILE%\.codex\config.toml` 的 `tdx-finance` 项导入，识别远程 URL 和 token-file，使用 Node MCP Client 直接连接；不执行原配置里的 Python/refresh 命令。令牌过期后更新原认证并重新导入。也可配置 `TDX_MCP_URL` / `TDX_MCP_TOKEN`。
- 腾讯适配为后续扩展点，当前交付接通本地通达信和通达信 MCP。

## 研究模型（默认 Codex）

在“数据与连接 → 研究模型”选择 Codex、Claude Code 或 DeepSeek。旧配置升级后默认使用 Codex。所有研究环节使用当前选择，调用失败不会自动回退到 DeepSeek。

自动选股研究采用量价批量快评：最多 Top 10，分两批各 5 只，正常输出时共两次模型调用；每批结构错误最多修复一次。保留原量化排名，逐股记录确认/证伪条件、风险、缺口、引用及技能版本。后续批次失败时保留已有报告并暂停，任务中心显示失败原因。批次 token 用量共享展示，不冒充逐股精确用量。

“数据与连接 → 研究技能”显示 54 项技能的安装与登记状态；目前仅量价快评接通应用方法流程，其他登记项不表示完整策略已实现。方法从本机 `~/.agent-skills/skills` 读取（可通过服务端 `QUANT_SKILLS_DIR` 更换根目录），不执行技能里的脚本；报告保存主文件与参考文件 hash。缺少依赖文件时明确失败，不伪造技能版本。

“数据与连接 → 财联社新闻存档”只读本机 CLS SQLite，可配置路径、按北京时间截止点及关键词翻页。历史模式同时限制发布时间和采集时间，避免后来补采的新闻进入当时已知信息。自动快评共用最近七天最多十二条当前新闻，标注其与旧行情的时点差异；尚未做行业自动分类，也不把新闻摘要当作市场强弱指标。

“条件选股”提供本地可复现规则和通达信在线自然语言筛选。在线每页 20 条，保存原问句、源字段日期、单位/复权、工具 schema 和数据指纹，可导出本页或将有效代码填入本地池。在线服务可能采用与问句不同的区间解释，结果不代表本地规则已经通过；本地覆盖只表示最近扫描索引，不保证行情已更新。翻页时实时结果可能变化。

行情页“核验证券身份”使用本机腾讯 westock-data Node 搜索并由通达信 lookup 交叉核验，展示双源一致、单源确认或来源冲突。冲突不会补入主档；已确认名称可供搜索、标题和选股使用，本地名称优先，其他名称保留为别名。该操作不确认停复牌状态。需要本机已安装 westock-data 技能；不会执行其他任意子命令或使用模型 API。

- Codex：本机安装 Codex CLI，并通过 `codex login` 登录 ChatGPT 账号。应用复用 CLI 登录，要求 ChatGPT 认证，不使用 API key。模型留空使用 CLI 默认模型。
- Claude Code：本机安装 Claude Code，并通过 `claude auth login` 登录订阅账号。调用采用 `claude -p`，关闭工具、Hooks、额外 MCP 和会话持久化；不使用跳过订阅登录的 bare 模式。
- DeepSeek：仅在选择它时使用用户环境变量 `DEEPSEEK_API_KEY`。不要放到 `NEXT_PUBLIC_*`。修改密钥后重启应用。

CLI 程序不随应用分发，需在本机安装；默认自动查找 PATH、用户安装目录和 npm 安装目录。CLI 负责认证，应用不复制登录令牌。研究仍由云端模型完成，会使用对应套餐额度，不代表离线或无限额度。界面的 CLI“已安装”只表示找到程序，不代表已登录或剩余额度充足。报告 token 为用量记录，不表示 API 扣费金额。

调用在临时工作目录通过 stdin 传递证据，Codex 使用只读模式并关闭 shell、网页搜索及多代理；结果仍须通过相同的结构和引用校验。超时或取消会停止当前 CLI；退出桌面应用会结束后台服务及其 CLI 子进程。

参考：[Codex 非交互调用](https://developers.openai.com/codex/noninteractive)、[Claude Code 程序化调用](https://code.claude.com/docs/en/headless)。

- 自然语言生成受限策略草案，明确不支持的条件，用户确认后才运行。
- 选股默认分析前 10 只，逐股分析后形成候选对比。可关闭自动分析或减少数量。
- 个股研究可补查当前行情/财务和公告，证据带来源与时间；资料失败时如实标注缺失。
- 回测后自动复盘，只输入固定回测结果，不补入当前财务公告冒充历史已知信息。
- 输出经 Zod 及证据 ID 校验；最多修复一次。记录模型、提示词版本、token 用量，缓存相同证据请求，支持取消和导出报告。

## 策略与回测边界

首期是**双均线研究模拟**：收盘价高于短均线、短均线高于长均线，并满足涨幅和量比条件。卖出条件为规则不再满足。

下一根开盘成交，100 股一手、T+1，无量及一字 K 线不成交；固定佣金 0.03%（最低 5 元）、卖出印花税 0.05%、单边滑点 0.05%。这些是可追溯实验参数，不是历史税费还原。资金不足以买入一手会单独计数。

**不复权，未完整建模除权分红、涨跌停排队、流动性与退市，不能用作正式策略业绩。** 单只 A 股、有限模板，未实现实盘下单、任意 JS 策略执行和 LLM 历史信号回测。后续正式引擎需单独确定公司行动与成交规则。

## 信号与聊天推送

在“数据与连接”添加渠道，再在“信号与通知”选择证券池、规则、周期、数据源和目标。支持：

| 渠道 | 所需配置 |
| --- | --- |
| 飞书群机器人 | Webhook，可选签名密钥 |
| 企业微信群机器人 | 官方群机器人 Webhook |
| Telegram | Bot Token、Chat ID，可选话题 ID；私聊先联系机器人 |
| Discord | Incoming Webhook，可选 Thread ID |

保存渠道不发消息。“发送测试通知”才向目标发送明确标注的测试内容。渠道和监控都启用后自动投递订阅信号。首期为单向推送，没有个人微信桥接或聊天远程控制。

监控每 60 秒检查已完成 K 线，首次/重启/休眠恢复建立基线；只有新 K 线上的“不满足→满足”才产生事件。日线等待 15:05 后，并验证交易日。默认交易日来自上证指数数据，也可输入明确交易日期覆盖。MCP 源主动查询；本地源需要通达信更新文件。

规则信号先发送，AI 解读成功后追加。SQLite outbox 记录每渠道投递，支持限流等待、最多 5 次尝试、过期丢弃、暂停与明确标注的手动重发。日线信号有效期 24 小时，五分钟信号 10 分钟。响应丢失后的重试可能重复，使用信号编号识别；“平台已接受”不等于已读。

凭证通过 Windows DPAPI 加密，保存在用户数据目录 `credentials` 下，不写入业务数据库。默认仅连接四个平台的官方 HTTPS 主机；渠道出站代理可选。

## 存储与测试

桌面打包统一使用 `pnpm desktop:pack`，固定输出到 `release/win-unpacked`。打包成功后自动清理旧版本，只保留最新一套程序及其依赖资源；构建失败保留旧版。打包前先退出桌面应用，占用时会停止打包，不再创建其他版本目录。

浏览器和桌面默认共用 `%LOCALAPPDATA%\QuantWorkbench`，可通过 `QUANT_DATA_DIR` 覆盖。SQLite WAL、递增事务迁移、数据快照、任务与报告均在此处。升级不会写通达信目录。当前迁移版本见 `src/server/db/migrations.ts`；不使用 `db:push` 修改用户数据库。

共用数据目录时仅一个存活进程负责监控与推送；该进程退出后其他实例自动接管，并重新建立监控基线，避免同时打开网页版和桌面版造成重复信号。

```powershell
pnpm typecheck
pnpm test
pnpm build
pnpm desktop:prepare
pnpm desktop:smoke
node scripts/desktop-smoke.mjs --packaged
pnpm smoke:data
# 以下会使用本机 MCP 认证及产生一次小额模型调用
pnpm exec tsx scripts/smoke.ts --mcp --llm
```

自动测试覆盖二进制格式、时间/价格异常、确定性计算、未来数据隔离、信号新鲜度、事务回滚、四渠道格式、错误分类与恢复、LLM 结构/引用/取消及本机 API 访问限制。真实聊天投递需用户配置目标，自动测试不会向第三方发消息。

第三方图表采用 [TradingView Lightweight Charts](https://www.tradingview.com/)，保留页面归属标识；分发许可证见 `THIRD_PARTY_NOTICES.md`。
