### 1.1 策略验证分层

允许按 E3 开发本地事件研究并评估既有交易自检工具。聚宽仍是历史交易验证的优先候选，不是唯一永久选择。正式业绩需要数据时点、历史证券池、公司行动、交易限制、成交与资金约束的证据；现有自检不能用作正式策略业绩。跨系统结果先逐项对齐，不直接互相替代。

### 1.2 指标本地计算

本地通达信行情由 TypeScript 计算，共享指标位于 `packages/trading-strategy-core`，规则维护于 `packages/trading-strategies`。应用负责来源与可知时点，回测及绩效分别复用独立包；运行约束见 [invariants](invariants.md)。

### 1.3 缠论原生边界

应用现有专用 worker 使用 koffi 绑定 czsc-tdx 的 API v22，冻结实际 DLL 摘要及配置；契约与验证见 [v22交付](deliveries/2026-11-08-czsc-v22.md)。策略包只消费中性结构事实，不加载 DLL。

每个应用宿主使用单一专用子进程串行 DLL 调用，台账任务线程转发到同一队列；不得并发进入或另开 DLL 工作池。Float32Array、库对象存活与 golden 权威规则见 [invariants §6](invariants.md#6-缠论原生边界)。无法加载则汇报，不换 FFI、不移植算法。

DLL 由管理者重建并预置；执行者不需要自行安装编译工具或依赖。旧“本机无工具链/旧 build DLL 可直接用”的前提已被实际重建推翻。对外捆绑分发仍需用户确认许可义务，见 [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md)；不由执行者作法律或分发决定。

改动级运行相关测试与typecheck；子任务运行pnpm test；有意义的应用交付运行build，桌面交付运行desktop:prepare。浏览器/桌面按受影响行为和实际环境验证，不按固定角色禁止；打包仍需授权。纯文档检查内容、链接和diff。完整步骤见 [operations](operations.md)。

### 4.3 决策日志取代进度日志

### 4.4 范围与权限

M1–M5是历史完成记录，不限制新需求修订。当前E阶段按可验收增量推进，局部细节自行决定，范围外想法记入待议；未授权提交不阻断可隔离开发。
