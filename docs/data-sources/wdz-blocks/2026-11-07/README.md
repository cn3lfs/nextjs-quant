## 排行口径

地区与风格均不进入板块概念排行及其排名分母。通达信类别 3/5 和 FG 继续提供地区/风格定义；WDZ 名单中不同命名和额外风格由 [wdz-block-ranking-exclusions.json](../../../../src/server/data/wdz-block-ranking-exclusions.json) 明确补充，并与来源一起进入分类哈希。

复核发现仅按通达信名称精确匹配会漏掉大盘/中盘/小盘、低价、高派息、QFII持股等。补充名单按市值/估值/股息、强弱/活跃度、机构持股、资本运作/分配、上市阶段/风险属性分类，共 23 项；不靠“包含地名”判断地区，上海国资、福建国资、海南自贸区等产业或政策主题继续保留。原始概念文件继续完整保存，过滤发生在计算入口。

来源限制：这里是当前收到的名单快照，不能倒推所有历史日期的成分，也不能将市场/指数分类当作产业定义。原图 `Readme01.png` 是 WDZ 安装说明，不是地区/风格分类说明。更新时新建日期快照、逐项复核分类，不覆盖本快照。
