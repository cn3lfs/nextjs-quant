# 公开财务组合基线来源与本地适配

核对日期：2026-11-11。本轮有限接入4项基础组合，不用缺失字段凑Piotroski九因子或Graham净净值，也不把负债/资产冒称Bhandari负债/市值。所有输入复用项目既有 `classicFinancialFeatures` 与已有B/P计算，不新增另一套财务公式、排序算法或组合引擎。

- [Novy-Marx原作者论文](https://mysimon.rochester.edu/novy-marx/research/OSoV.pdf)：毛利/资产盈利能力及与价值结合的研究来源，不复制论文正文，不将其历史表现作为沪深策略业绩。

## 四项可执行组合及字段映射

| ID                                | 输入键                          | 已有源特征                   | 方向与规则                                                                |
| --------------------------------- | ------------------------------- | ---------------------------- | ------------------------------------------------------------------------- |
| portfolio-gross-profitability     | grossProfitability              | gross-profit-assets          | 最新可见非金融年报(收入FN74-成本FN75)/同年正资产FN40；高优先TopK等权      |
| portfolio-cash-accruals           | cashAccrualQuality              | cash-quality                 | (经营现金流FN107的TTM-合并净利润FN95的TTM)/最近正资产FN40；高优先TopK等权 |
| portfolio-conservative-investment | assetGrowth                     | asset-growth                 | 本期资产/上一年同报告期正资产-1，要求两期正资产；低优先TopK等权           |
| portfolio-profitability-value     | grossProfitability、bookToPrice | gross-profit-assets及已有B/P | 共同有效样本内分别平均并列百分位，平均后高优先TopK等权；B/P须正           |

TopK默认10，不按样本收益调参。新增3个因子全部为比例ratio，不是百分数；period为null、skip为0，报告组成期由财务证据说明，不能误当固定行情根数。BookToPrice沿用已有单位统一，不用倒数PE或EPS估计代替。

## 时点和口径边界

- 财务只允许决策日已可见的报告及其组成期；公告当日不提前可见，下一已知观测交易日起可用。财务数据下载版本的历史修订限制保留，不能声称拥有首次披露版本。
- 毛利/资产使用同一个年报的资产分母，不能用最近季报资产；金融企业或行业分类未知不套用普通企业毛利。负毛利是真实亏损，可排名；缺成本不能当0。
- 现金质量是本项目既有现金流法/期末资产变体，和Sloan原资产负债表差额、折旧、平均资产公式不相同。负值有效，CFO缺失不填0，TTM组成期任一不可见则留空。
- 保守增长允许资产收缩；缺上一年同报告期、前期/本期资产非正均留空。采用年报/季报同比与公告后可见时点，不宣称原美国年度分组、六月持有或固定6个月滞后。
- 盈利能力/价值组合排除非正B/P，其他真实负盈利不自动剔除；分母不正或字段未知不能制造极大排序值。统一排名器对每因子并列值分配平均名次，合成后并列以证券代码稳定排序。只保留全部所需因子有效的共同样本；分母0和空样本不分配虚构仓位。
- 默认只做多、周度再平衡、TopK等权，是沪深可执行基础适配，不复刻原多空、NYSE断点、市值加权或原历史证券池。组合撮合、费用、现金、T+1继续委托现有统一执行链。

## 验证

包内专项测试以真实字段投影构建财报，检查年度毛利/同年资产、TTM现金法、同报告期资产增长、金融排除、缺失/非正分母、未来公告不可见、因子ratio单位、来源hash和完整许可。统一排名及实际历史组合接线由应用集成测试与独立验收覆盖，来源文档不替代运行验收。

## 统一候选单位与消费者核对

本轮发现并修复应用候选适配边界的百分数/比例不一致：共享行情因子的动量、短期反转、收益波动，财务同比增速以及E/P、B/P、CF/P均以百分数输出；统一candidate元数据声明ratio，因此只在新候选适配器对这7个键除100。ROE、毛利资产、现金应计、资产同比和Beta本来是比例，不重复换算；总市值保留元。底层因子及冻结源证据仍保存原始单位和值。

调用链仅为策略中心本地求权重和周度组合任务，最终消费端使用逐因子排名，反波动配置使用最小波动/各股波动的比例；共同缩放不会改变排名或目标权重。日线目标波动策略独立从完成行情计算波动和年化目标，不消费这些candidate值，因此不调整其风险阈值。本修复纠正接口和冻结值单位，不改已有共享公式或历史记录。

`tests/strategy-signals/portfolio-classics-integration.test.ts`已以12只合成股票和真实字段投影财报验证4项本地取数、排名、周度共享资金实际成交、原字段冻结、未来披露不影响结果、当前零/负资产排除和缺TTM留空，并独立手算三估值比例、同比增速以及反波动缩放等价；新9项与原候选9项定向18项通过。全仓最终结果由本轮交付记录单独登记，不以该定向结果代替。
