# 本地候选池RPS七周期组合

周期仅为项目已经维护的1/3/5/10/20/50/120。7个目录入口属于同一个相对强弱家族的周期预设，不能宣传为7个独立alpha。

策略输入为完成日线的 `C[t]/C[t-N]-1` 比例值，应用取数复用共享ROC并在候选边界由百分数转比例；端点必须有成交量，缺失不前填。策略模块复用统一排名和TopK等权执行，不复制 `quant-rps` 算法，也不新增对它的生产依赖。

[现有quant-rps](../../../packages/quant-rps/README.md)的同池平均并列排名与收益排序同序。本入口只对用户明确的本地候选集合排序，当前使用未复权价格，不继承主RPS的后复权、ST、上市年限、名称和长期停牌资格过滤。因此它是明确的本地研究基线，不称全市场RPS，不宣称和主RPS结果数值相同。除权跳变和当前证券池偏差继续披露。

本地目标权重允许共享证券分类确认的沪深场内基金（含ETF）与股票混池，限纯行情及等权策略；财务和市值策略拒绝基金候选。ETF可计算本地目标权重，历史撮合仍有品种规则、费用及公司行动模型缺口，继续保留原股票执行范围，不套用股票税费模拟ETF成交。

`tests/strategy-signals/portfolio-rps-integration.test.ts`直接比较7周期定义与 `quant-rps.rpsPeriods`，以既有 `rankRps` 验证同池排序同序，覆盖端点零量、预热不足、并列稳定排序、实际周度组合任务及未来价格不影响结果；16项定向验证通过。完整交付结果由主控登记。
