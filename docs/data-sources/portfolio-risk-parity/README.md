# 协方差风险平价基础配置

核对日期：2026-11-11。

算法参考 [Griveau-Billion、Richard、Roncalli 原论文](https://arxiv.org/abs/1311.4057)与 [riskparity.py 官方仓库](https://github.com/convexfi/riskparity.py)。后者 README 与 MIT 许可按固定提交保存，版本、字节数与 SHA256 见 [manifest](manifest.json)。运行时未复制、导入上游 Python/C++ 代码，纯 TypeScript 求解器在 `packages/trading-strategies/src/portfolio-risk-parity.ts`。

规则使用决策日及以前、完全对齐的 60 个日简单收益率。以样本协方差为基础，给对角线加入平均样本方差的百万分之一作为固定正则项，通过循环坐标下降求解等风险贡献的只做多配置，最后归一化为总权重 1。不估计预期收益，不使用杠杆，不以反波动权重替代协方差求解。

输入最多 200 个候选，在构建协方差矩阵之前检查；手工 API 对该策略使用同样上限，普通因子排序不受此专用限额影响。历史不足、缺少决策日、零波动的证券明确排除；日期不一致、未来输入、非法收益及重复证券拒绝。风险份额最大绝对误差必须不超过 `1e-8`，最多 10,000 轮；未收敛则失败，不自动降级。风险贡献针对含正则项的协方差矩阵，不能称为未经正则化的精确解。

组合撮合、费用、现金约束、公司行动及 T+1 沿用既有执行器。数据适配冻结实际输入行情和收益；当前证券池与历史修订限制仍然存在，这个基础配置的工程验收不构成策略业绩证明。
