# 数据源验收要求

东方财富mx-ds-mcp是独立自然语言资料查询，按用户确认不属于图表源；采用[独立查询验收](mx-data-adapter.md)，不得把其表格返回计入下述K线矩阵成功数。

适用于本地文件（vipdoc）、tstdx、westock-data、东方财富。各源独立填写支持矩阵，不能用自动换源的成功替代手动源成功。尚未测试、明确不支持、请求失败、数据错误和通过必须区分。

## 最低覆盖矩阵

固定样本见 [sourceAcceptanceSamples](../tests/data-source-acceptance.ts)：沪市主板 sh600000、深市主板 sz000001、创业板 sz300750、科创板 sh688981、北交所 bj920002、指数 sh000001、申万二级行业 pt01801081、ETF sh510300。每类检查日线、周线、5分钟线；每次要求3根，记录请求时刻、真实末根时刻和形成中状态。

每个数据源必须披露以下验收结果：

1. 身份：正确市场、品种类型、代码和名称；搜索近似命中或跨市场同数字代码不能混入。
2. 单品种：日期合法、顺序递增、无重复、OHLC自洽、成交量和额非负；不得用零值填缺。
3. 复权与单位：记录真实请求参数，不复权不得默默改成默认前复权；不同品种/周期的量额单位须分别核验，未确认不得拼接。
4. 批量：逐一核对请求代码，返回非空不代表全部成功；股票/指数/板块/ETF混合请求和子组合均需核验，不得静默遗漏。
5. 错误：结构化错误即使退出码为0也不得当成功；不支持必须明确说明，手动选择不得静默切源。
6. 应用链路：供应商能返回不等于页面能使用。单独验证API入参、快照保存、周期切换、来源显示和错误重试；缓存读取不能冒充新的供应商实取。
7. 本地文件只读，验证隔离QUANT_DATA_DIR；不得调用已停用付费MCP，不发送通知或交易。

“验收完成”可以包含明确披露的不支持项；“全覆盖可用”要求所有矩阵项通过。测试仅证明样本在该次请求的可用性，不保证全部证券和未来服务状态。

## 可重复执行

离线防回归：

```powershell
pnpm exec vitest run tests/data-source-acceptance.test.ts
```

真实接口验收（会发起免费skill查询；测试框架自动隔离数据目录）：

```powershell
$env:QUANT_WESTOCK_ACCEPTANCE = '1'
pnpm exec vitest run tests/westock-acceptance-live.test.ts
Remove-Item Env:QUANT_WESTOCK_ACCEPTANCE
```

默认测试不访问外网，真实验收必须显式运行；其他三源仍需分别执行本矩阵，当前不冒充已通过。

## 除品种覆盖外的验收维度

以下是四源共同要求；“应测试”不等于本轮全部已完成。

| 优先级 | 维度 | 必须验证的行为 |
| --- | --- | --- |
| P0 | 身份与代码 | 同数字跨市场、旧代码/更名、北交所新旧代码、搜索歧义；指数不能误当股票 |
| P0 | 复权与单位 | 除权日前后比较原始价/前复权/后复权；量的股/手、金额元/万元、ETF份额单位；ETF行情与基金净值分开 |
| P0 | 时间与新鲜度 | 时区、交易日/周末/节假日、集合竞价/午休/收盘、当日及当周未完成K线；明确末根时间，旧缓存不得冒充今日数据 |
| P0 | 数据完整性 | 重复/乱序/非法日期、OHLC矛盾、缺字段/非有限数、批量遗漏/串码/部分失败；空结果区别于请求失败 |
| P0 | 范围与深度 | 起止日边界、首尾包含规则、每种分钟周期、最大根数及截断、历史不足；不得把未满请求量等同于全历史 |
| P0 | 运行失败 | 超时、取消、断网、限流、结构化错误但退出码0、服务端格式变化；重试次数有界，不支持项不循环请求 |
| P0 | UI与缓存 | 手动源不暗换、切源/切周期/快速切股不串回包，缓存按来源/证券/周期/复权隔离，来源和失败原因可见 |
| P1 | 特殊证券状态 | 停牌、复牌、新上市不足N根、退市历史、涨跌停且零成交；不补造交易记录 |
| P1 | 聚合与跨源对照 | 日转周/月和各分钟周期的边界、未完成周期；相同时间和复权口径比OHLC，差异保留而非强行覆盖 |
| P1 | 本地与协议边界 | vipdoc截断/损坏/缺文件及更新中读取；tstdx拆包/粘包/压缩/断连/响应数量与实际字节不符；本地目录始终只读 |
| P1 | 持续可用度 | 多交易日多时段记录成功率、延迟、数据滞后、失败分类；据真实观察调整自动优先级，不能仅凭一次成功排序 |

当前adapter离线用例覆盖入参、日期和数量边界、批量补查、错误响应、身份/OHLC校验及取消；实网覆盖固定矩阵。停牌、新股、除权、单位独立核验、全周期与真实UI交互等仍需专门样本和环境验收。
