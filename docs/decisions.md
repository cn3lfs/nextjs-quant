## 2026-09-09 · 重定项目范围

**背景**：前一轮 19 小时无人值守执行产出 1,159 行进度日志、545 个 `output/` 一次性脚本
（27 MB，0 个被 git 跟踪）、148 个测试文件、32,942 行源码，但几乎每条日志都以
"A–H 整体目标仍未完成"结尾。

**判定为打转，根因四条**：

1. A–H 是能力覆盖清单，没有终止条件——54 技能 × 每技能 N 项可无限细分。
2. 验证成本绑死在每个微改动上（全量测试 + 构建 + 桌面冒烟 + Playwright ×130 次）。
3. 性能目标早已超额达成（40.84s → 165ms，250 倍）后仍在打磨序列化与 UI 计时。
4. 8 条流派线并行铺开，全部停在"诊断基础/完整方法待接入"，无一条闭环。

**决策**

- 项目定位收敛为**自用精简量化平台**：看得见（图表指标）/ 算得出（缠论、双突破）/
  推得到（信号推送）。
- **放弃自建回测引擎**，策略验证外包给聚宽。理由：公司行动因子链、停复牌、涨跌停排队、
  退市、历史证券池、官方交易日历，聚宽已做好且数据质量更高，自建是在最弱维度上硬拼。
  原计划中最重的一块（约占剩余工作量一半）就此删除。
- 冻结 8 条流派线、性能优化、组合风控、多品种扩展。见 `docs/roadmap.md` §2。
- 里程碑改为 M1–M5 严格串行，每个都有二值验收条件。

**放弃了什么**：`docs/optimization-progress.md` 中 A–H 的逐项完成审计。
该目标结构本身是打转的成因，不再作为验收标准。

## 2026-09-09 · 缠论用 FFI 调 DLL，不移植算法

**背景**：用户要求迁移 `D:\github\czsc-tdx` 的缠论指标作为交易策略。

**调查事实**

- 该仓库 7,243 行 C++，实现分型/笔/线段/中枢/走势类型/三类买卖点 + MACD 背驰 + 均线吻，
  注释标注 108 课课文编号可溯源。
- 导出为干净 C ABI：`Func30(int, float*, float*, float*, float*)` 单一入口覆盖 58 种输出；
  `Func40` 旁路注册真实 C/V 供 MACD 相关输出使用。
- `build/CZSC64.dll`（802 KB）已交叉编译并静态链接 MinGW 运行时，自包含。
- `tests/` 自带 golden 数据：上证指数 2038 根前复权日线（2018-01-26 ~ 2026-06-26）
  与完整期望输出（157 笔 / 15 线段 / 18 笔中枢 / 17 笔买卖点），另有人工复核过的
  中枢锚点表。
- **本机无 C++ 工具链**（无 g++/MinGW，原构建在 WSL2 完成）。

**决策**：FFI 调用现成 DLL，不移植。缠论的包含处理与笔/线段划分对细节极度敏感，
重写 5,000+ 行的出错概率远高于收益，且 golden 数据使 FFI 路径可被严格验证。

**与预期不符的事实**：原路线图把缠论列入冻结清单，判断依据是"现有 `chan-*` 模块
停在 LLM 解读层"。实际上 `czsc-tdx` 是独立的成熟计算资产，与仓库内 `chan-*` 无关。
已将缠论提升为 M3，并把自研难度更高的双突破推到 M5——先落地确定的东西。

**待办**：DLL 为 GPL v3（Copyright 2016, Martin Tang），而其 README 声明"免费分享使用，
没有任何限制"。自用不分发无义务；若捆绑进 `GuanlanQuant.exe` 对外分发需先确认义务。
**该决策留给用户，执行者不得自行决定。**

## 2026-09-09 · M1 三项存疑口径的独立佐证

**背景**：M1 §3.3 列出三项由管理者认定、无法从 `tdx-doc` 直接查证的口径，
原计划全部交由 B 层人工对着通达信定案。

**做法**：改用两个独立来源交叉验证，不依赖通达信软件。

**结论（三项全部佐证，实现无需修改）**

1. **BOLL 的 STD 分母 N−1**：`tdx-doc examples/专家系统.md` 的 BOLL 写作
   `STD(CLOSE,N)` 且注释为"估算标准差"；`functions/统计函数.md` 明确
   `VAR`="估算样本方差" 对 `VARP`="总体样本方差"、`STD` 对 `STDP`。
   「估算样本方差」即分母 N−1。
2. **MACD 柱 ×2**：`czsc-tdx/src/CzscDynamics.cpp:76` 独立实现
   `Histogram = (Dif - Dea) * 2.0f`。
3. **递推不屏蔽预热**：同文件 `ComputeEma` 中 `Ema[0] = pPrice[0]`，
   `k = 2/(N+1)`，展开与本实现 `smooth(closes, n+1, 2)` 逐字一致。

**与预期不符的事实**：前一轮判定"`tdx-doc` 找不到 BOLL 定义"只搜了
`functions/` 目录。实际 `examples/专家系统.md` 就有完整 BOLL 公式与中文口径说明。
教训：该技能的公式散在 `examples/` 与 `tutorials/`，不只在 `functions/`。

**放弃了什么**：不再把这三项当作 M1 的阻塞项。B 层人工核对降级为
「建议做，用于排除数据读取/复权/历史起点差异」，不再是 M1 通过的前置条件。
