# 个人交易工作流

## 第一次配置

1. 在主页面“数据与连接”设置通达信根目录并扫描本地数据。源目录只读。日线用于浏览、RPS和研究，盘中预选另需连续的当日5分钟行情。
2. 打开 `/rps`，配置 Blocks 根目录。沿用 `申万行业`、`概念`、`中证指数` 子目录，A500名单为 `中证A500.txt`。先生成上一完成交易日的个股RPS，再检查行业与概念排名。
3. `/intraday` 默认关闭。选择数据来源、股票池、RPS周期与阈值，再启用；默认午盘11:20、尾盘14:40，可以调整为交易时段内的5分钟时点。
4. `/cls-review` 可手动预览导入Markdown。每日自动复盘需填报告目录并开启；它只读取已有任务产物，不运行或修改Windows新闻分析任务。

## 浏览行情与指数

行情页面的“指数行情”提供常用入口，也可搜索通达信名称表中的其他指数。名录不依赖日线文件；本地指数行情不可用时自动在线读取，也可点击“在线行情”主动获取。图表标明实际来源、行情日期和不复权口径，不拼接本地与在线 K 线。在线供应商不覆盖的品种会显示失败原因。

股票池保留所有本地品种。当前名称表缺失的历史股票用沪深交易所历史名录补齐，退市和代码变更分别标注，仍可选入历史研究。

## 盘前

保持应用运行，财联社自动复盘于08:00—09:30检查报告。只处理原文日期为当日、停止修改至少一分钟的报告；明确推荐且能唯一识别的沪深股优先，否则精确匹配板块并使用上一交易日RPS50排序。

同一天只固定一次主样本，保存原文版本、候选和实际选样时点。文件没有明确方向/日期、板块重名或数据缺失时查看原因，不以昨天报告补造今天预测。应用09:30后启动不会补选盘前样本。已有六月报告可导入核对事实，但不能倒填为当时已经固定的盘前样本。

## 午盘前与尾盘前

在 `/intraday` 看批次进度及候选。运行窗口为配置时点后的5分钟；电脑休眠、应用退出或数据过期可能错过，页面会显示状态。预选使用截至该时点的行情，收盘后另行确认或撤销，不覆盖原始预选。

现场核查的本地5分钟文件较旧，使用前需更新通达信盘中数据或选择在线来源。数据不足时没有候选不等于策略不成立；先看缺失原因。在线全池覆盖尚无真实盘中验收证据。

## 收盘后

- `/rps` 看个股、行业和概念六周期排名。A500成分显示全沪深RPS，行业和概念分别排名。点击板块进入成分浏览，再查看股票图表；优先高RPS是候选过滤，不是独立买入指令。
- `/intraday` 看预选收盘成立、撤销或数据不足，并可导出当时与收盘的行情证据。
- `/cls-review` 于15:05后核对已固定样本，查看当日与T+1/5/10方向、基准和超额收益。未到期、停牌、缺价单列。另对原文事实填写依据和支持/反证/待核对，价格上涨不等于新闻事实正确。

所有调度仅在应用运行时执行。自动任务是否完成，以页面最近检查和结果记录为准，不以Windows新闻任务退出码推定复盘成功。

## 周末或策略调整时

打开 `/research`，先选择股票池并加载品种清单，勾选本次研究的具体品种，再选择双突破或缠论、样本区间与保留验证期，设置入场等待、持有日数、仓位、成本与资金。任务保存所选清单，不自动扩展到全池。保留验证期与开发期分别计算，避免只挑选调参期成绩。

无需额外文件即可看事件价格观察；交易模拟需历史交易限制及无公司行动覆盖证据。完整分红送转结算尚未接入，受影响股票不参与模拟；不要为获得指标填造无事件记录。格式和口径见 `/research/data-guide`。

查看有效/排除/未平仓数量、净收益胜率、盈亏比、收益分布、每日净值与夏普。空分母显示“—”。原快照重跑用于复核；修改参数或更新行情应新建研究。当前名单回溯存在幸存者偏差，软件验证不等于真实盈利证明。

## 导出、清理与更新

研究、预选和财联社复盘均可导出证据后显式清理。财联社清理保留日期占位，防止同日重新选样。不要手工修改SQLite或源行情来消除错误。

本轮不自动交易、不发送测试消息、不提交或发布。最新源码与已准备的桌面资源不代表 `release/win-unpacked` 中旧exe已更新；重新打包需另行授权。开发预览使用独立 `QUANT_DATA_DIR`，不要连接生产库运行迁移。
