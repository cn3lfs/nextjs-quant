### 1.2 KDJ与RSI

§2.2映射SW07-zone-filter：K>80“不追多、等死叉”不能转成一到80立即卖；K<20“等金叉”也不等于立即买。20<K<80正常区按趋势，边界20/80另明示。§2.3震荡市使用及趋势钝化映射SW07-regime-filter，必须先定义可知环境，不能仅凭事后表现称为震荡市。父项SW07保留。

### 1.3 布林带

### 1.4 量价与量比

§5.1六种关系分别是SW11-volume-up-up、up-down、down-up、down-down、high-volume-divergence、low-volume-divergence（均SW11-volume前缀）。需复用量价家族，保留位置、分母与新高/新低比较点差异。直接新高缩量可关联VP-vp-high-low-volume-exit工程版本，不能宣称已完成所有顶底背离。

§5.2映射SW11-volume-breakout，VP-vp-breakout-1-5与VP-vp-breakout-2提供前20有效量记录的工程对照。原文只写20日均量，未明示含当根还是前20根；不能把均量含当根、排除当根和停牌跳过差异隐去。低于均量的无效突破仍需要独立过滤去向。

§5.3映射SW11-volume-ratio，保留>3、1.5至3、0.8至1.5、<0.8的状态与重大事件检查。表中1.5边界有重叠，量比若指盘中同时间均量，其输入不能被日量比静默代替；后续给出具名口径。

本源没有OBV、天量次日/二顶、孤量次根确认或“连续量增但涨幅递减”的具体规则，因此移除VP-vp-obv-top-exit、vp-huge-next-exit、vp-huge-second-exit、vp-isolated-filter、vp-stall-exit（均VP前缀）对此来源的归属。这五项的真实量价来源及实现保留。本轮只纠正方法清单；已有研究定义中宽泛的来源集合仍需在相应方法版本收口时细化，不能追改已保存快照。

§6.2三对双向交叉分别SW10-ma-golden-5-10、10-20、20-60（均SW10-ma-golden前缀）。原文1–3、3–10、10–30天是信号周期描述，不直接伪装为唯一强制持有日数；现最长持有期参数独立保存。§6.3四周期支撑压力为SW10-support-20、60、120、250，触及/回踩/失效仍待独立实现。父项SW10保留。

## 2. 仓位与纪律：六节与44个关联方法

### 2.1 参数与组合上限（§1、§2）

| 规则                         | 方法去向                          | 复用与缺口                                               |

### 2.2 加减仓与退出（§3、§4）

50/30/20盈利加仓对应已有RK-D7-pyramid，首仓冻结R、1R/2R加仓、净保本与首成本抬线、数量递减、总仓限制均复用现账本。SW11-no-average记录禁止亏损追加。SW02-half-entry的50/50来自trading-system，此仓位文件仅作冲突参照，不能写成50/50原始来源。

1R与2R各减初始仓位三分之一为SW06-r1-r2-exit，复用RK-D6-partial；两档后剩余仓位线放在第一目标为SW06-prior-target-tail，不能以当前2R/4R及ATR尾仓模板冒充。反向趋势线全退复用SW06-reverse-line-exit。重大利空/利好兑现为SW-P-news-exit，五交易日无进展为SW-P-time5并复用RK-D5-time。事件只能在当时可见后生效；时间时钟不因分批重启。

§4.1价格例50、止损48.5、目标51.5/53、尾仓线51.5作为上述1R/2R及前目标模板的固定验收例。费用、整手和实际减仓完成时点需另外验证；数值例不能替代真实可成交证明。§4.2有效止损检查归SW11-stop-required，结构位与公共止损家族复用。

### 2.3 准入、期望值与凯利（§5）

最低2R空间复用SW11-min-rr2；类似历史样本胜率至少45%为SW-P-win45；正期望为SW-P-expect-positive；五类信号至少3分为SW-P-quality3。样本必须在决策时已闭合且可用，不用当前全历史胜率指导过去。最小样本、费用、样本相似规则均待固定，缺失不是默认50%。

SW-P-expect-size保留原档位及0.2R重叠边界。三个带逻辑数值示例分别登记：

| 示例方法          | 算术             | 严格联合准入与仓位差异                                  |
| ----------------- | ---------------- | ------------------------------------------------------- |
| SW-P-example-50-2 | 0.5×2−0.5×1=0.5R | 通过45%/2R最低值；0.5R按分档为半仓，不是>0.5R标准仓     |
| SW-P-example-40-3 | 0.4×3−0.6×1=0.6R | 正期望，但40%违反45%最低值；严格版应拒绝                |
| SW-P-example-60-1 | 0.6×1−0.4×1=0.2R | 正期望，但1R违反2R最低值；严格版应拒绝，且0.2边界需明确 |

原文示例的“可出手/减仓”与最低准入并非完全一致，保留示例对照与严格组合，不能静默挑宽松版本。L=1R是计划损失假设；真实含费、跳空和无法止损的实际损失不保证等于1R。

半凯利由SW-P-kelly30与RK-C-kelly关联：风险2%、该模式总仓30%、b取第二目标空间/止损空间，输出风险仓位、半凯利及最终约束。这里30%与一般总仓60%按模式分开，不能把前者改成单股上限来消除差异。

### 2.4 交易纪律与记录（§6）

SW-P-preflight联合环境、双突破、2R空间、止损、2%风险、事件、情绪七项；SW11-event-window、stop-required、emotion-gate等复用，缺失必须显式留存。SW-P-review归K13研究记录，保存计划价位/实际交易/技术原因/人工情绪/计划实际偏差，并提供月度统计；它是支持策略验收的组件，不是恒不交易的伪策略。

| 暂停规则              | 方法                                 | 时点与未定义边界                                               |
| --------------------- | ------------------------------------ | -------------------------------------------------------------- |
| 连续2月胜率<35%       | SW-P-month-win                       | 完整月闭合交易，无交易月不可填0；目标45%另作报告               |
| 连续2月收益风险比<1.5 | SW-P-month-rr                        | 必须固定统计口径；无亏损/无样本不可制造分母                    |
| 连续3月负收益         | SW-P-month-negative3                 | 完整月，零不算负；月中不前视                                   |
| 连续3笔亏损休息       | SW11-three-loss-pause、RK-E-streak   | 按完整头寸闭合，普通暂停与五笔紧急暂停分开                     |
| 单日亏损>5%           | SW-P-day5-week、RK-E-daily           | 当时可知权益；至少一周冷静                                     |
| 连续5笔亏损           | SW-P-loss5-week                      | 不把分批退出记成五笔；与三笔普通规则组合时需保留各自状态与记录 |

## 3. 下一实施顺序与验收

1. 复用现有管理参数形成1R/2R各减三分之一、前目标尾仓、2%/30%/最多3只的具名组合；补齐独立总仓与5%距离禁入，按实际成交价/费用/整手验证。
2. 将四投票、五辅助和五类信号分开：补均线、明确方向/交叉，验证标准/半仓数量、未知/矛盾和量能否决。
3. 推进大盘环境与账户暂停状态机；先按因果顺序定义权益、完整月、整笔闭合交易、触发/冷静/恢复及受阻卖出。
4. 统计准入需要历史已知样本，新闻与人工纪律需要带时点输入；明确数据契约并继续独立家族，不拿缺证据当零信号。
