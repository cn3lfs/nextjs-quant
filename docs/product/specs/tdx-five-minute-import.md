# 通达信五分钟CSV导入

> 状态：代码与定向验证完成；桌面发布待另行授权。当前规则以[导入手册](../../wdz-import.md)为准。

## 目标与范围

用户在量化终端的“数据与连接”选择微盛CSV数据目录及通达信目录，直接更新沪深五分钟LC5。时间为北京时间，来源须为未复权行情。用户已明确授权该入口写入所选`vipdoc/sh/fzline`、`vipdoc/sz/fzline`；不修改全局默认目录、其他行情目录或研究数据库。

CSV使用`SH000001.csv`、`SZ000001.csv`等六位代码文件，列为Date、Open、Low、High、Close、Volume、Amount。SH/SZ只表示交易所。可选择包含SH/SZ的父目录或多个交易所目录。WDZ解包和直接导入由独立CLI提供，未新增WDZ界面。

## 当前验收契约

- 用户只选择数据源和通达信目录。股票、基金、指数及回购的量单位由导入规则核验，不要求逐类配置；无法确定的源异常不猜测修复。
- 新批次直接导入，不做整批预检、不创建备份、不二次确认。目录、进程、输入格式、时间和记录边界检查属于写入正确性约束，保留明确错误提示。
- 缺失时间按序追加或插入；完全重复输入去重，同时间不同内容报错。已有冲突保留，只有来源身份与旧规则量匹配，或源支持的零量恢复，可以修改成交量；其他字段不改。
- 成交量为uint32，超过4,294,967,295才置零并列出时间。指数与回购保留源量；股票/ETF核验×100、×1、÷100，规则与默认值见导入手册。
- 数千文件以有限并发处理，提供进度、逐文件结果和可见错误；取消等待当前写入完成。重复导入不产生重复时间点，不承诺整批原子提交。
- 原先生成的预检、备份批次保留查询和恢复兼容；不将旧规则批次静默升级为新口径。新报告有版本标识，禁止用旧规则报告跳过本轮新修复。

## 实现边界

Electron/Node负责目录、文件与任务调度；既有TypeScript解析CSV；C负责WDZ紧凑行情解码、排序、编码及LC5时间合并。新日期仅读尾条追加，历史缺口用同目录临时文件替换；完整覆盖区间通过映射与C仅修复量字段。WDZ原始金额元数据不写入LC5保留字段，也不暴露为批次JSON中的大Buffer。

来源合法性、复权、单位与报价真实性不能仅靠二进制结构证明。停牌不补造记录，原始源缺量不靠均价估算伪装成真实量。用户随后明确授权的近似看图量通过独立`tdx:estimate-zero-volume`脚本执行，提供股票/基金HLC3、B股/债券/旧回购局部校准，以及另行放宽精度的计划模式；只填已有零量，保留外部逐条标记，不加入普通导入默认逻辑；命令见[导入手册](../../wdz-import.md)。自动下载、付费数据、其他目录写入、交易和桌面打包不属于本功能的隐含授权。

## 验证与交付

固定fixture与非法输入覆盖解码、跨块、时间、排序去重、量单位、容量、幂等、冲突保留、原始金额身份、源支持修复及审计清理。操作手册、真实源对拍、正式补齐、历史修复与待补源目标见[当天交付记录](../../deliveries/2026-11-05-tdx-import.md)。普通导入阶段执行45项定向用例及类型检查、构建，后续离线估算执行7项定向用例及类型检查；不把较早全仓测试数字当作本轮验证。

旧版预检/备份设计已被用户后续明确要求取代；相关兼容代码保留用于旧批次，不能用旧规格阻止直接导入。

用户随后允许更低精度、尽量处理看图零量。独立`--visual-plan`模式可覆盖指数、债券、B股和历史业务字段的量额比估算及同刻/邻近插值；原32字节、正uint32、仅改原零量及外部逐条标记保持。它不加入普通导入默认逻辑，也不证明历史单位或真实成交量。最新结果见[放宽看图估算交付](../../deliveries/2026-11-05-tdx-visual-volume.md)。
