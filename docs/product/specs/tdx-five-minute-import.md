# 通达信五分钟 CSV 批量导入

> 规模：M · 状态：验证中 · 2026-11-05

## 目标与假设

在量化终端内将本机沪深 CSV 导入通达信五分钟行情，先预检再执行，保留可核验的备份。当前样本文件名为 `SH000001.csv` / `SZ000001.csv`，列为 Date、Open、Low、High、Close、Volume、Amount。用户明确授权此功能写入通达信的五分钟目录；其他通达信数据仍只读。

2026-11-05 用户要求预设成交量口径，仅需选择数据和通达信目录。微盛 WDZ CSV 的股票、基金和指数成交量均按手乘以 100。指数乘算后达到 2³¹ 的记录，按用户确认的微盛导出行为置零，并记录和展示时间；0 不代表真实成交量。CSV 时间按北京时间，价格使用未复权行情；来源复权状态仍需核实。

## 需求与验收

- R1（必须）用户选择微盛 CSV 目录和通达信目录，单位自动按预设处理；预检时看到文件数、可新增记录、重复、冲突、指数超限置零时间与错误；目录为空、数据非法或无权限时明确提示，不写目标。
- R2（必须）用户确认预检结果后执行导入，只添加缺失时间点，已有时间点保留并报告；输入或目标发生变化须重新预检。
- R3（必须）每个被修改的文件先备份并验证；中断或失败时保留逐文件结果及备份，不宣称整批原子成功；可安全恢复且不覆盖备份后已被其他程序修改的文件。
- R4（必须）对数千文件提供可观察的进度；一个错误不丢失其他文件的结果。重复导入不产生重复记录。
- R5（必须）异常时间、重复、数值及整数溢出不能写入；通达信正在运行或目标被修改时停止写入并提示。
- R6（必须）终端展示加载、错误、完成和部分成功状态；历史缺口、浮点精度、单位和备份位置清楚可见。

范围外：自动下载、行情复权换算、覆盖冲突、自动交易、直接修改其他通达信目录。完整历史的真实性和通达信客户端显示需人工核实。

## 设计

沿用数据与连接的现有组件和 tRPC 服务；采用逐文件处理与后台进度。预检绑定输入、配置和目标指纹；执行逐文件复核并先建立批次清单和备份。恢复逐文件比对导入后哈希，拒绝覆盖后续变更。清单和备份存放在应用数据目录，无数据库迁移；测试使用隔离数据目录。默认不改变任何源文件。

API 契约：启动预检传微盛来源、CSV 目录及目标通达信目录；服务端固定类别换算，目标目录绑定在批次内；查询预检进度与结果；确认执行传预检标识；查询执行及备份；恢复传批次标识，返回逐文件状态。长任务须支持中断结果可见和重启后的可恢复性。
