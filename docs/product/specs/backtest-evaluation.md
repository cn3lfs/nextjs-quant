# 回测绩效评价与年季月复盘

> Size: M · Status: verified · Updated: 2026-11-08

## 目标与范围

个人量化研究者需要判断收益是否值得承担风险、是否优于持有、表现是否集中在少数月份，以及回撤多久修复。成功标准：从既有回测报告进入评价，在同一实验内完成年度→季度→月度查看，并解释每项指标及缺失原因。

本轮交付统一评价内核、现有实验报告入口、年季月明细、月度收益热力图、回撤日期及修复状态。A1：沿用 Nocturne；A2：保留规则自检证据等级；A3：不凭自定权重生成“客观100分”或基金星级。真实收益、风险效率、相对基准和验证充分程度分别展示。

## 单一计算口径

- 仅使用扣除实验费用后的日收盘账户权益；期初本金参与首日收益及回撤。预热不计业绩，空仓交易日保留，不强制期末平仓。
- 年化因子252；无风险利率统一假设年化2%，日利率 `(1.02)^(1/252)-1`。这是可复现假设，不代表当时真实利率，也不向空仓资金虚记利息。
- 标准差统一样本标准差 `ddof=1`。收益率内部使用小数，展示时转换百分比。
- 区间收益：`end/start-1`；年化复合收益：`(end/start)^(252/n)-1`。不足252日不展示年化收益与Calmar，月/季展示实际区间收益。
- 夏普：`mean(r-rf)/sampleStd(r-rf)*sqrt(252)`；信息比率：`mean(r-b)/sampleStd(r-b)*sqrt(252)`。至少2日，短于252日标记“短样本，仅描述”。不使用CAGR替代夏普或IR分子。
- 索提诺：`mean(r-rf)*sqrt(252)/sqrt(sum(min(r-rf,0)^2)/n)`。下偏二阶矩分母为全部n日。
- 年化波动：`sampleStd(r)*sqrt(252)`；跟踪误差：`sampleStd(r-b)*sqrt(252)`。
- 最大回撤：相对期初及此前运行峰值的最大下降比例，展示为正的损失幅度。Calmar=`年化复合收益/同窗最大回撤`。
- 基准采用“同标的价格持有对照”：首个研究交易日开盘为起点，首日close/open，此后close/前close；明确不扣基准费用、不含分红。此对照只判断同标的择时，不代表市场超额或Alpha。实验本身尚不支持跨除权事件。新旧实验均使用其冻结五分钟OHLC派生同口径对照，保留原来源指纹，不读当前磁盘行情；导出同时附对照日收益。缺日、非有限值、重复日期拒绝评价，不取日期交集。
- 相对收益展示“策略区间收益−对照区间收益（百分点）”，不称Alpha；IR严格使用每日主动收益序列。
- 修复天数为最大回撤谷底→首次回到此前峰值的自然日；同时列峰值、谷底、修复日期。最长水下期为峰值→修复或截点的自然日。相同峰值取最近日期，同深度优先最早事件。
- 截点尚未修复：修复值null，展示“未修复，已观察X天”，不得记0或用后续日期修复过去的季/月报告。没有回撤时修复显示“不适用”。
- 零波动、零跟踪误差、无下行偏差、零回撤的对应比率null并解释，不展示无穷大。非正权益导致复合风险指标不可计算，明确失败原因。

## 需求与验收

### 2026-11-08追加：交易轮次指标结构化

- `quant-performance`0.2.0新增纯配对`pairPositionCycles`和评价`evaluateTrades`，不依赖回测/IO/应用。按同一股票从首次建仓到全清算一轮，加减仓合并；成交费用、分红、送转和配股现金纳入净损益，未平仓不参与闭合样本。
- 平均盈利=盈利轮次净损益均值；平均亏损=亏损轮次损失绝对值均值；盈亏比=二者之比；胜率=盈利轮次/全部闭合轮次（含持平）；利润因子=总盈利/总亏损绝对值；每轮平均净损益=全部闭合净损益均值。金额不是收益率，持平阈值1e-8本币。无对应样本或分母为零返回null和原因，不输出无穷大。
- 报告版本`performance-report-v2`新增全程`trades`，独立`trade-performance-v1`记录口径。未提供交易证据为null，空数组为真实零交易；日净值、年季月公式保持`daily-performance-v1`。不在季末强平，也不把全轮损益虚分到部分月份。
- 现有查询、完整导出及绩效页面接入同一计算；页面展示计数和六项指标，明确未平仓/部分止盈不单算胜笔，年季月选择不改变全程配对。CSI800研究的五个固定模式及经典矩阵也自动输出`tradeEvaluation`，含无止损基线；支持只读补评历史冻结结果，不改写历史成交/净值。
- 验证覆盖加减仓、公司行动、同日顺序、多股票、全赢/全输/持平/空样本、非法输入、API与导出一致及档案不变、桌面与320px显示；交付见[交易评价结构化](../../portfolio-ledger/2026-11-08-trade-performance.md)。

**R1 理解全程评价（Must）**

- R1.1 GIVEN 完成的双均线或因子实验 WHEN 打开“绩效评价” THEN 显示全程收益、年化、夏普、信息比率、最大回撤、Calmar及最大回撤修复，规则自检始终可见。
- R1.2 GIVEN 短样本/零成交/零分母 WHEN 阅读 THEN 显示真实值或逐项原因，零成交不评为低风险优秀策略。
- R1.3 GIVEN 指标名 WHEN 查看指标说明 THEN 可读公式、252日、2%假设、基准和短样本限制，不提供多口径切换。

**R2 年度、季度、月度复盘（Must）**

- R2.1 GIVEN 评价 WHEN 切换年/季/月与年份 THEN 按北京时间自然年季月、交易日收益复利分组，表格展示区间收益、对照收益、相差百分点、最大回撤、夏普、IR和样本天数。
- R2.2 GIVEN 月度热力图 WHEN 键盘或鼠标选择月份 THEN 切到月度并展示该月详情；无样本月份不可操作，有正负符号及文字，不只依赖颜色。
- R2.3 GIVEN 某季/月 WHEN 选择“查看” THEN 显示期初基准净值、真实起止、同窗回撤及修复状态；切换频率/年份清除旧选择，切换实验重置评价状态。
- R2.4 GIVEN 首尾月季年 WHEN 阅读 THEN 标为“窗口边界”并展示实际覆盖日期，不凭当前有限日历认证整月完整或将节假日误认为缺失；分期收益从上一期末权益开始，月季收益复利可还原全程，不能加总百分比。
- R2.5 GIVEN 跨季度回撤 WHEN 阅读 THEN 全程回撤持续跟踪；分期回撤按该期期初重新建峰，仅观察至该期末，不偷看未来，不能替代全程风险。

**R3 历史、失败与导出（Must）**

- R3.1 GIVEN 历史实验 WHEN 评价 THEN 使用冻结输入派生，不重跑策略、不改写历史结果、不访问生产行情。
- R3.2 GIVEN 读取中/失败/实验切换 WHEN 页面更新 THEN 不显示上一目标的评价，提供明确加载状态与重试。
- R3.3 GIVEN 导出完整实验 WHEN 下载 THEN 附同版本全程及年季月评价，原冻结输入保留。
- R3.4 GIVEN 320px/桌面/键盘 WHEN 操作 THEN 页面不横向溢出，表格内部滚动，选择和展开可访问。

**R4 独立模块与事务分离（Must，用户追加）**

- R4.1 GIVEN 不启动应用或数据库 WHEN 独立构建、测试并从应用目录外调用评价模块 THEN 可对普通权益和已单位化净值生成同口径报告。
- R4.2 GIVEN 回测已完成或评价输入失败 WHEN 查询/重试评价 THEN 评价不进入撮合/记账事务，不修改冻结实验、交易或账户。
- R4.3 GIVEN 维护者调整指标或接入其他来源 WHEN 定位实现 THEN 公式和分期集中在独立包，来源适配与界面分别归所属目录，公开包入口与禁止依赖检查可定位。

## 交互与接口

原报告增加“绩效评价”标签，保留概览、成交与订单、复现依据。全程指标与事实摘要在上，分期区在下：年/季/月分段→年份选择→该年12个月热力图→服务端已分组明细→选中期详情。年度默认该年，季度最多4行，月度最多12行；无客户端重排分页。回撤日期与修复状态在详情中展开。指标说明使用原生可访问details展开。

新查询 `maBaselineEvaluation({id, frequency: year|quarter|month, year?, period?})` 返回 `{overview, years, year, months, periods, selected}`；每次只返回所选年份的分期及12个月热力数据，不传冻结OHLC。报告查询失败保留任务身份并重试。无数据库迁移、无新依赖。

Stitch：[项目](https://stitch.withgoogle.com/projects/8346105525528703944)，画板 `f4325fb9435447de990ce2236ced1624`，主题 `assets/47474b08a6b14dd482cb13cf8643cfe9`。已查看截图，采用八卡→说明→分期控件→月度热力按钮→明细→选中期回撤详情。剔除稿中虚构版本、完整性认证、交易归因、季末平仓提示及交易日/自然日双展示；使用正值回撤幅度和真实缺失原因，保留原全站导航。

用户随后明确评价指标独立成模块、职责及事务分离。本轮独立工作区包`packages/quant-performance`拥有日收益指标、回撤、年季月分组及报告选择；零运行时第三方依赖，不依赖quant-backtest、应用、UI、IO或Node宿主。应用`src/server/performance/backtest-evaluation.ts`只把冻结回测结果映射成净值/对照输入；`src/components/performance`展示纯报告，回测容器负责查询与选择状态。旧账户绩效/wbt历史契约保留；本功能UI与导出只使用本次统一口径，不把旧wbt统计混入评价。旧实验数值不原地替换，评价带独立版本。

依赖方向：回测容器→评价展示/评价查询；评价查询→冻结实验适配→quant-performance。quant-backtest与quant-performance相互独立。回测撮合与账户记账事务只产出原结果；评价是只读派生，计算失败只影响评价查询，不回滚或修改实验事实。完整导出在读取时附评价，不改写持久化档案。以后普通盈亏公式调整只改quant-performance；新增数据来源只改适配器。本次不迁移旧真实账户模块或引入插件注册/事件总线。

模块边界通过独立构建/测试、应用目录之外ESM导入、反例可检出的禁止IO/应用/回测依赖检查验证；除包根公开入口外，消费者不深层导入实现。

## 搜索依据

- [CFA：Sharpe与IR](https://rpc.cfainstitute.org/-/media/documents/code/gips/sharpe-ratio-and-the-information-ratio.pdf)：分别衡量相对无风险资产和基准的风险调整收益；受区间、基准选择影响。
- [晨星：Sharpe](https://admainnew.morningstar.com/webhelp/glossary_definitions/mutual_fund/mfglossary_Sharpe_Ratio.html)：先算周期超额收益均值/标准差再年化。晨星该文使用月频，本工作台明确采用日频，不承诺与其数值完全相等。
- [晨星：回撤字段](https://morningstardirect.morningstar.com/clientcomm/customcalculations.pdf)：峰、谷、恢复日期与恢复长度。
- [QuantConnect：回测报告](https://www.quantconnect.com/docs/v2/cloud-platform/backtesting/report)：收益、风险和回撤事件组合阅读。
- [DSR原论文](https://davidhbailey.com/dhbpapers/deflated-sharpe.pdf)：多次试验带来选择偏差。此次绩效展示不声称已完成样本外验证；已有DSR/PBO不直接混用其旧夏普口径。

未查到支付宝公开完整评级算法；借鉴其易读的风险与修复展示，不宣称复刻其评级。长短样本展示门槛是本产品约定，不声称行业统一评级。
