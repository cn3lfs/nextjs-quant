# 回测工作台界面

> Size: M · Status: verified · Updated: 2026-11-07

## 问题、目标与范围

个人沪深量化研究者已有独立 TS 引擎和五分钟双均线，但当前页面把配置、
任务、成交和复现资料纵向混排，难以判断当前显示的结果属于哪一组输入。
本轮交付一个可配置、运行、阅读、追溯和恢复的回测工作台。

成功标准：用户可从空状态完成一次本地双均线回测，区分草稿与历史结果，
解释零成交和未成交请求，刷新后恢复实验，导出同一实验的冻结输入。
桌面和 320/400px 窄屏可操作，结果不出现无来源指标。

假设 A1：沿用现有深色工作台；A2：当前只开放主板、五分钟 SMA5/20；
A3：最近 20 个任务足以作为本阶段历史入口，完整任务管理继续由任务中心承担。

| 优先级 | 内容                                                            |
| ------ | --------------------------------------------------------------- |
| Must   | 配置/结果分区、输入错误提示、本地覆盖、运行/取消/恢复、真实概览 |
| Must   | 成交分页、订单状态与拒绝原因、数据/费用/规则依据、完整导出      |
| Must   | 空/失败/取消/零成交、历史恢复、确认删除、响应式和键盘访问       |
| Next   | 多实验对比、可编辑均线周期、更多统计（各自需定义口径）          |

不新增实盘、自动交易、付费数据、Python/C/Rust 宿主；不启用旧策略。
本轮不改引擎、行情或交易口径，不显示未经计算的年化/胜率/夏普。

## 需求与验收

**R1 配置实验（Must）**：研究者能先确认证券、窗口与成本，再开始计算。

- R1.1 GIVEN 首次进入 WHEN 无结果 THEN 显示配置说明及空报告，不出现模拟收益数字。
- R1.2 GIVEN 无效代码/日期/本金/费用 WHEN 编辑 THEN 显示可读原因且不能开始；有效输入恢复可运行。
- R1.3 GIVEN 已选证券 WHEN 读取覆盖 THEN 显示该证券真实首末日期、根数并填入末尾约一个月；明确覆盖不等于完整性已通过。
- R1.4 GIVEN 现有报告 WHEN 修改配置或复用历史配置 THEN 报告保留其原证券/窗口/费用；草稿不同有提示，复用仅填配置且不自动运行。

**R2 管理运行（Must）**：研究者知道任务是否仍在工作，并可中止或恢复。

- R2.1 GIVEN 输入有效 WHEN 开始 THEN 展示实际阶段/进度，禁止重复提交和历史切换，取消可用；结束后历史可刷新。
- R2.2 GIVEN 失败或取消 WHEN 任务终止 THEN 显示真实状态/错误并可修正配置重试，不保留另一任务的结果。
- R2.3 GIVEN 历史任务 WHEN 刷新后选中 THEN 恢复同一任务的状态和报告；失败查询可重试，隐藏页面不持续轮询。

**R3 阅读结果（Must）**：研究者能回答赚亏、账户状态、为何未成交。

- R3.1 GIVEN 完成 WHEN 进入概览 THEN 显示真实区间收益、逐根最大回撤、成交数和期末账户；日末曲线注明与逐根回撤不同。
- R3.2 GIVEN 零成交或期末待执行 WHEN 阅读 THEN 明确零成交不代表程序失败、可能原因与待执行原因，不伪造平仓或胜率。
- R3.3 GIVEN 超过 50 条成交/订单 WHEN 翻页或筛选订单状态 THEN 服务端返回该页和总数，不在客户端加载所有冻结行情。
- R3.4 GIVEN 有拒单/待执行 WHEN 查看订单 THEN 显示方向、确认时间、状态、尝试次数、真实原因；买卖和收益正负有文字或符号。

**R4 追溯与清理（Must）**：研究者能核对依据和有意识地删除实验。

- R4.1 GIVEN 报告 WHEN 查看复现依据 THEN 显示请求/实际窗口、本金/费用、数据周期/复权、预热、来源/引擎指纹、假设及读取/计算耗时；始终可见“规则自检”。
- R4.2 GIVEN 完成 WHEN 导出 THEN 下载所选任务完整归档；下载中防重复并显示错误；禁止导出未完成任务。
- R4.3 GIVEN 终态任务 WHEN 删除 THEN 先展示任务目标与影响；取消保留，确认成功后移除结果与历史项；失败保留并反馈。运行中不可删除。

**R5 交互（Must）**：研究者能在常用设备与键盘上完成同一流程。

- R5.1 GIVEN 桌面/320px/400px WHEN 使用 THEN 配置、报告和历史不导致页面横向滚动，表格仅内部滚动。
- R5.2 GIVEN 键盘 WHEN 访问标签页、按钮和删除弹窗 THEN 焦点可见，弹窗关闭返回触发点，状态变化可被辅助技术感知。

## UI 交接

遵循根 [DESIGN.md](../../../DESIGN.md)，记录已有 Nocturne，而非重新设计全站。
桌面：页头（回测实验室/规则自检）→ 左配置、右报告 → 最近实验。
配置分证券与窗口、本金与费用、固定策略说明；唯一主操作为开始回测。
报告顶部是被冻结的证券/实际窗口和状态，下面为概览、成交与订单、复现依据。
窄屏顺序为配置、运行反馈、报告、历史。旧策略入口由原页面底部继续折叠保留。

Stitch 已先绘制再开发：[量化项目](https://stitch.withgoogle.com/projects/8346105525528703944)，
画板 `bd2041d5c8a145c09e52a2d9df3d7170`，主题资产 `47474b08a6b14dd482cb13cf8643cfe9`。
采用配置侧栏、冻结报告身份、三标签报告与历史区；稿中自行增加的佣金、Tick 滑点、
基准线、逐根曲线、收益/均持仓、批量清空和虚构版本号不进入实现。
实际图为日末收益/回撤，五分钟最大回撤单独列示；费用取原契约。
复用现有量化项目，仅发送合成示意内容和公开的 UI token，
不发送真实账户、行情、路径或凭证。示意图数值不进入生产空态。
远程设计稿由用户 Stitch 项目持有，无本地自动生成缓存；仅在本文件保留固定链接。

## 数据与 API 契约

沿用现有任务/worker/数据适配，不迁移数据库；容器取数、展示组件仅接 props。

| 接口                                | 输入                                            | 输出/行为                                          |
| ----------------------------------- | ----------------------------------------------- | -------------------------------------------------- |
| maBaseline / jobSummary / cancel    | 原契约                                          | 原运行、进度及取消                                 |
| maBaselineCoverage                  | 主板代码                                        | 原真实覆盖，仅探测不认证完整                       |
| maBaselineHistory                   | 无                                              | 原最近 20 任务                                     |
| maBaselineResult                    | id/pageIndex                                    | 原概览、50 条成交、pending；不传全量输入           |
| maBaselineOrders（新增 query）      | id/pageIndex/status=all,filled,rejected,pending | 50 条订单、过滤后总数，未完成为 null，其他任务拒绝 |
| maBaselineExport / maBaselineRemove | id                                              | 原精确归档/终态删除                                |

前端明确 draft、selectedJob、coverage、tab、分页和确认删除目标；以所选 id 隔离请求，
旧数据不可作为新选择的报告显示。运行/覆盖读取/删除中约束会改变任务目标的操作。
无新的架构决策，组件只在回测领域拆成容器、配置、报告、历史及纯展示辅助。
