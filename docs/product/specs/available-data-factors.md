# 可用数据因子接入

2026-11-08，用户要求在已有财务因子基础上，把剩余可用数据接成因子，并参考网上常用定义。本阶段复用既有组合筛选、任务、分页、历史恢复和证据导出，不引入付费源、数据库迁移或新交易引擎。

## 入口与范围

“研究与档案 → 估值与财务质量 → 本地财务 → 财务组合筛选”，或行情图表的本地财务入口，新增“本地数据因子”。可以删除全部财务条件，独立运行技术、数据或RPS条件；所有条件总数不能为零。财务组仍按全部/任一组合，技术、数据与RPS各自为额外必要条件。历史配置复用不会重新运行，旧档案可读。

本地数据目录合计197项，其中181项是已有字典中明确命名的数值侧，不将它们宣传为197个独立alpha公式。目录是能力覆盖，不表示每只股票、每个日期都有数据。完整字段、单位、依赖与公式直接见共享层[目录实现](../../../packages/trading-strategy-core/src/factors/local-data.ts)；未引入第二份需手工同步的因子注册表。

## 来源和计算口径

- [BigQuant官方因子分类](https://bigquant.com/doc/data_features.html)作为收益、成交额、规模、估值和资金类别参考，独立实现明确公式，不承诺平台数值等价。
- [French动量说明](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/det_mom_factor.html)作为跳过最近月份的依据。默认250/20根是日线12−1月的近似，公式为`close[t−skip]/close[t−period]−1`，不是原始多空组合收益。周期和skip均冻结。
- [Amihud原论文](<https://doi.org/10.1016/S1386-4181(01)00024-6>)的绝对收益/成交额思路，采用输入人民币元，显示乘10^8；零成交额留空。此次浏览器未能读取出版社全文，不宣称逐句或平台实值核对。
- [既有Qlib冻结来源](../../data-sources/public-factors/qlib-v0.9.7/manifest.json)保持157/158覆盖；不改变其计算口径。[聚宽帮助页](https://www.joinquant.com/help/api/help?name=factor_values)仍返回地区不可用，未进行平台数值对照。
- [statsmodels OLS说明](https://www.statsmodels.org/stable/generated/statsmodels.regression.linear_model.OLS.html)和[残差均方定义](https://www.statsmodels.org/stable/generated/statsmodels.regression.linear_model.RegressionResults.mse_resid.html)用于核对含截距OLS与残差自由度口径；实现使用本地TypeScript，不新增Python依赖。
- GP/BK/SC元数据与双值侧单位复用`tstdx/financial-model`的`seriesValueDefinition`；文件解析、13字节记录、稳定读取仍由tstdx承担，应用不增加客户端格式解析器。

收益统计使用完整窗口，不年化。波动率是简单收益样本标准差，不是价格标准差；偏度与超额峰度使用总体中心矩，无小样本校正。下行偏差的分母是全体窗口观测。回撤只取窗口内收盘路径。量额基准排除当前根，均值窗口保留实际零量额。五分钟输入属于按根迁移变体，不能称日频原值。

本地筛选使用未复权日线，与既有技术筛选一致；拆分、除权等价格跳变会影响收益与风险统计。Beta使用61个逐日日期完全对应的收盘观测，得60组简单收益；缺日期、缺尾日、非法收盘、零基准方差留空。不对两条序列取交集或前填后伪装完整样本。特质波动为`sqrt(SSE/(60−2))×100`，非年化波动。

估值以同日GP16市值元与基准日前已可见的财报配对；TTM复用共享财务计算的上年年报+本期累计−上年同期，不用当前报表倒填历史。倍数的财务分母须正；负利润E/P与负现金流CF/P保留。严格模式继续按财报公告后的下一观测交易日起可见；当前下载版本及历史修订限制仍适用。

## 时点、缺失与证据

只使用已结束历史日期，GP/BK/SC必须有基准日恰好一条同组记录；无日期、旧日期、同日重复（即便值相同）、文件缺失、命名空间不符和未认证源零值均为unknown。源零值不冒充有效零；日线实际零成交额可以作为零观测，但不能作Amihud分母。

板块条件使用用户显式指定的同一个板块，不推断每只股票的历史行业；市场条件是环境因子，不冒充个股资金流。无公告时点的事件序列只标识其记录日期，不认证首次公开日期或首次披露版本。该限制会显示在冻结结果提示中，不据此认证可信历史业绩。

结果冻结输入、池、`local-data-factors-v1`、`priceBasis: local-unadjusted-day`、财报组成期和每项来源证据。序列证据含原值、元值、组/侧、日期、偏移、文件名和SHA256；风险因子保存61×2个收盘值及两份日线摘要。财报的原始字段与可见日期继续保存在原有证据中。完整导出继续校验内容哈希；损坏不导出。

无新增持久缓存或表；仅按所选因子依赖读取文件，市场/板块/基准每任务读一次，单股日线为技术与数据条件共用。结果仍由原任务及档案机制创建、导出和显式删除。

## 尚不具备的数据

GO映射、未知财务槽、SC未知组仍不启用。ETF专用GP47/51/52、日期/时间/枚举侧及官方标“暂无”的GP33不加入个股数值条件。普通日频自由流通市值/流通股本缺证据，故未用报表期末股数伪造当日换手率；成交额/总市值明确不是流通股换手率。

VWAP输入、横截面rank/scale、历史行业中性化、分析师一致预期及Alpha101其余依赖继续见[覆盖清单](../../data-sources/public-factors/alpha101-coverage.json)。没有以时序排名代替横截面。197项数据因子目前用于筛选，不塞入仅接OHLCV的五分钟回测；94项纯行情因子可直接复用该回测生命周期。
