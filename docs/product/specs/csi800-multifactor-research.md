# 中证800技术＋财务经典多因子研发规格

版本：`csi800-classics-spec-1`，2026-11-08。状态：研发与工程验收完成；主候选后段超额目标未通过，见[交付说明](../../deliveries/2026-11-08-csi800-multifactor.md)。用户最新要求优先于[上一轮简化规则](csi800-study.md)。经典来源及适配边界见[研究依据](../../research/csi800-classic-strategies.md)，执行阶段见[实施计划](../../csi800-multifactor-plan.md)。

## 1. 目标、继承约束与完成定义

以当前中证800成分为研究池，以中证800为业绩基准，充分利用项目已有技术和财务能力，比较经典策略与组合。沿用100万元本金、周调仓、只做多、现金账户、单股目标权重不超过净资产15%、30%最大回撤研究目标。用户已明确本轮先忽略幸存者偏差，固定当前成分回溯；被动上涨超15%允许，下次调仓纠正。

交付必须同时包含：经典来源映射、全目录因子采用/排除清单、真实财务时点与覆盖审计、可重放的技术和财务联合面板、固定策略及对照的扣费结果、分段与年度报告、因子诊断、风险与成本压力测试，以及能复现结果的单命令入口。不能只交一套新评分代码或一条最好看的净值。

“充分利用”以有效信息覆盖和对照实验为标准，不要求把所有字段机械等权相加。缺输入、未知语义、价格绝对水平、同义窗口和历史不可见数据，不因已有目录就取得组合资格。是否达到收益/回撤目标与工程完成分别判断；没有策略达标也应交付完整失败结论。

本批不做应用UI、自动交易、通知、付费数据购买、生产库迁移、提交、推送或打包。旧数据与旧实验不覆盖。因子代码与外部调仓入口已按本规格实现并通过交付中的验证；此前草稿状态不再作为当前进度。

## 2. 数据契约、时点与同口径样本

### 2.1 冻结与来源

- 价格与公司行动优先复用上一轮完整冻结输入；源文件、SHA256、股票池、取得时间、数据截止日期和代码版本均写入本轮manifest。新增财务输入另行冻结，不重复拷贝整个通达信目录。
- 证券池固定仓库2026-11-07的800只列表。退市缺失、缺行情及不满足条件的证券逐项记原因；不得把800改称“历史当时成分”。
- 财报包按期一次批读整个池，复用现有`readFinancialPoolHistory`、字段投影与财务计算；优先取最近68期满足报告日不晚于研究截止日的记录，为2016起点提供跨期预热。真实不足保留缺口。
- 读取正式累计与资产负债字段，不用源文件中的预测/快报或当前供应商TTM冒充历史已知实际。初始字段至少包含FN11、17、35、40、54、63、74、75、95、96、107、114、206、271；根据实际表达式追加字段须同步字典与版本。
- GP16同日总市值从已有GP文件解析器读取，按官方定义从万元转换为元。用有定义的`seriesValueDefinition`确定单位，不手写另一套二进制解析或猜测倍率。同日重复记录、零市值或非法数值记为不可用，不前填，不从当前总股本倒推历史市值。

### 2.2 财务可见性

一条报告只有在公告日期有效、晚于报告期、严格早于信号日，且已到本地交易日历中的公告后首个交易日时才可使用。公告当日不在盘后信号中使用，这是日期精度不足时的保守约定。

TTM、同比、三年CAGR的每个组成报告均须满足信号日可见性；不是只检查最新一期。报告期距信号日超过550自然日则整个财务快照过期。缺同期、负增长基数或非正分母沿用现有计算的`null`与原因，不补0、不用后一期回填。未经认证的源零值保持缺失。

金融企业只使用可解释的通用权益与盈利变量；毛利率、经营现金流质量、普通企业杠杆与商誉评分只在已核验为非金融企业时使用。行业身份未知不能默认当成普通企业。评分必须带最新报告期、公告日、可见日及源指纹。

当前下载财报可能含后续修订。即使上述日期检查通过，也只能称“公告时点筛选的现存版本研究”；没有首次披露版本证据前，不称严格PIT业绩。此限制独立于用户已经豁免的幸存者偏差。

### 2.3 行情、资格与共同窗口

使用截至当时已发生公司行动构造的连续经济收益价格计算技术指标；成交用原始价格。每个信号日要求：有当日有效行情、至少251条历史记录、近20条日均成交额至少5000万元；为组合风险估计，最近61个收盘日期还须与基准交易日历逐一一致。停牌不补成交或收益。历史上市时间、ST和准确涨跌停档案仍按上一轮简化边界披露。

先输出从2016年至本地最新完整交易日的全区间覆盖。主比较窗口仅由覆盖决定：在技术资格股不少于200只的周末中，连续4个周末至少60%的技术资格股同时具备质量组和价值组最低输入时，以第四个周末之后首个交易日作为共同起点。不得根据收益、市场阶段或某策略表现挑选起点。若始终不满足，联合策略暂不产出有效业绩；继续输出数据诊断及独立技术实验，不降低门槛冒充完成联合验证。

所有主要策略在该共同区间、相同价格源和费用下比较。额外报告2016起技术策略和财务覆盖前的空窗，但不与短窗口结果混排。每个调仓日列出技术资格数、财务可用数、各家族有效数与最终入选数。

## 3. 因子字典与组合规则

### 3.1 技术支路：13项，4个评分家族＋流动性诊断

以下全部调用已有`calculateFactor`，参数显式冻结。`t`为信号日已完成日线；250/20等表示交易根数近似，不当成自然月的精确复刻。

| 家族       | 因子与既有实现                                                                                     | 优先方向   | 角色                                                                                     |
| ---------- | -------------------------------------------------------------------------------------------------- | ---------- | ---------------------------------------------------------------------------------------- |
| 动量       | `skip-momentum(120,20)`、`skip-momentum(250,20)`、`high-distance(250)`                             | 高         | 前两项为跳月动量，高点距离为相关确认项；组内只占一个家族                                 |
| 趋势       | `bias(60)`、`bias(120)`、`up-frequency(60)`                                                        | 高         | 中期趋势与上涨持续性，不以绝对价格排序                                                   |
| 短期反转   | `short-reversal(5)`、`short-reversal(20)`                                                          | 高         | 原因子已取收益负值，不再反号                                                             |
| 低风险     | `return-volatility(20)`、`return-volatility(60)`、`downside-deviation(60)`、`window-drawdown(120)` | 低         | 排序方向统一反向；不能与组合目标波动率混称同一指标                                       |
| 流动性诊断 | `amihud-illiquidity(20)`                                                                           | 低更易成交 | 诊断、成本解释和同分最终择优；不以“低非流动性”冒充已证明的收益溢价，不占技术支路家族权重 |

技术评分为前四个家族等权。相对强弱/RPS属于同期横截面收益排名的已有能力，本批用标准化动量家族表达，不再额外叠加一份相同收益权重。

### 3.2 财务支路：16项，5个家族

`A`为最新可见总资产FN40，`E`为归母权益FN271，`M`为同日GP16总市值；`NP`为FN96归母利润，`NI`为FN95合并净利润，`CFO`为FN107经营现金流，`REV`为FN74收入。金额统一为元。TTM与同比优先复用已有`financialMetrics`；合并利润TTM遵循相同累计差分恒等式，需独立手算验证。

| 家族              | 因子                                                                                                | 优先方向与约束                                                                     |
| ----------------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 盈利质量（6）     | NP_TTM/E、NP_TTM/A、最近可见年报(REV−FN75营业成本)/A、CFO_TTM/A、(CFO_TTM−NI_TTM)/A、NI_TTM/REV_TTM | 高；后四项仅非金融企业；毛利/资产使用该年报自身资产，不混入最近季度分母            |
| 价值（4）         | NP_TTM/M、E/M、REV_TTM/M、CFO_TTM/M                                                                 | 高；现金流收益率仅非金融；非正市值无效；负利润保留为低值，权益非正时财务组合不入选 |
| 成长（3）         | 收入累计同比、归母利润累计同比、归母利润三年CAGR                                                    | 高；负或零基数按现有规则缺失，不把扭亏直接标成无限增长                             |
| 保守投资（1）     | A/上年同期A−1                                                                                       | 低；独立家族，后续用质量＋价值共同避免“越衰退越好”的误读                           |
| 资产负债质量（2） | FN63/A、FN35/A                                                                                      | 低；仅非金融；不把缺失商誉补成0，银行负债率不参与普通企业排序                      |

盈利质量至少2项有效；价值至少2项；成长至少2项；保守投资1项；资产负债质量至少1项。其他多指标家族至少有一半指标有效，向上取整。缺失项不贡献分数；家族未达到门槛时为未知，不是低分或中性0。

### 3.3 标准化、合成与持仓

- 每个周末对同一技术资格池计算横截面平均名次百分位，居中至[-0.5,0.5]。低值优先因子先反向；并列用平均名次。常数列无排序能力，分数为0，单独记录。排名削弱极端数影响，本批不另拟合截尾参数。
- 家族评分为有效子因子分数均值。家族计分必须先满足上一节输入门槛。两个及三个家族的经典组合要求全部家族有效；S7五家族组合至少4个有效且质量、价值、动量必须有效；S8技术支路至少3/4家族，S9财务支路至少4/5家族且质量、价值必须有效；联合组合同时满足两支路要求。任何使用财务的模型还要求最新可见归母权益为正，不能靠指标缺失绕开该资格。
- 联合组合先算技术支路等权均分与财务支路等权均分，再各占50%；不按13:16或原始字段数量赋权。各经典组合使用其指定家族等权，不训练权重或自动翻转因子方向。
- 按综合分选20只。已有目标持仓仍符合输入条件且排名前30时优先保留，按排名补足20只；这里的“已有”指上期目标名单，实际受阻持仓由执行账本独立记录。并列先用Amihud较低者，再按证券代码升序；不读未来收益决定入选。
- 持仓基础权重为60日收益波动率倒数，单股按账户净资产15%迭代封顶。候选不足20只时，基础股票预算乘以候选数/20，剩余现金；封顶无法分配也留现金。
- 未核验的历史行业分类不实施行业中性或行业30%上限，不把金融/非金融适用性标识冒充完整行业风控。本轮披露集中度与该限制，行业优化另立实验后才能加到本策略版本。

### 4.2 S11风险覆盖层

市场开关沿用上一轮：中证800收盘高于MA250、MA120高于20日前MA120，两项/一项/零项分别对应100%/50%/0%股票预算。不用本轮收益重新挑均线周期。

用已选股票及基础权重，在信号日前最近60个逐日完整、日期对齐的组合加权收益上计算样本标准差并乘sqrt(252)，得到持仓目标组合的历史估计波动率。股票预算再乘`min(1,0.15/估计年化波动率)`；不把个股波动率均值当作组合波动率。估计为0时风险缩放为1；输入不足或无效时本期预算为0并记录原因。最终总预算还受候选不足与15%单股上限限制。

目标波动率不等于最大回撤限制。30%回撤只作为结果验收线，不据此假定止损一定能在跌停时成交，不增设观察期内调参的净值熔断。

### 4.3 执行层

复用上一轮共享资金引擎。新增外部调仓目标输入，只接受合法交易日、池内证券、有限非负权重、单股≤15%、权重和≤100%；外部目标模式必须显式选择，不改变旧实验默认行为。

周末已完成日线生成目标，下一交易日开盘先卖后买，延迟压力测试为再晚一个交易日。买单当日有效，受阻卖单继续等待，下一批目标重算；只重试实际待卖数量，不能因为每日重新估值而触发计划外减仓。送配股同步调整持仓与待执行股数。现金不能为负，不卖当日新增股，不虚构资金或成交。

佣金双边万三且最低5元；卖出税费、过户费和普通板块限价情景继承上一轮已登记假设。单日金额上限为此前20条平均成交额的1%，价格落在原始OHLC与限价内才允许情景成交；不据此认证实际排队成交。现金分红/送配股处理、首次披露修订缺口、股息税与实际到账日均在报告中明确。

中证800价格指数和全收益指数均尝试从现有只读来源取得并核验代码与覆盖。全收益不足时，价格基准照常展示、股息口径差异单列；不能用价格基准的较低收益替代全收益超额验收。所有策略使用同一基准窗口，不允许按各自可见日期取交集后隐去缺口。

## 5. 研究设计、对照与选型

### 5.1 因子诊断

对29项初始指标输出逐周有效覆盖、方向、常数列、相关性与分家族统计。未来收益标签采用信号后下一交易日开盘至第21个交易日开盘的公司行动调整经济收益：以入场开盘买入后的股数及现金权益独立重放，入场当日除权权益不属于新买家，退出当日已生效权益计入；不使用依赖当日收盘归一化系数的“复权开盘价”直接相除。日期必须与基准逐一对齐，未来数据不够的行不生成标签。Spearman RankIC使用平均并列名次，同时输出5分组远期均值及高低组差；这些是诊断，不是已扣费组合业绩。

重叠20日标签的IC序列不按周数简单计算独立样本显著性；输出均值、标准差、正值比例、成熟标签数，并按入场日不早于前一标签退出日的规则构造非重叠子样本，不能简单假定4个自然周等于20个交易日。ICIR输出均值/样本标准差的未年化值；不足2项或标准差为0时留空。覆盖、IC与相关性分别按开发、验证、后段报告，相关性只用于解释冗余；本轮不依据全区间IC挑因子、翻方向或修改权重。

建立全量目录登记：技术因子、Qlib/Alpha101可用子集、197项本地数据因子和财务字段分别标记“主组合使用、同源相关项、诊断/过滤、缺历史输入、不适用该任务、缺语义证据”。至少每个现有因子ID有去向及原因，不能把未采用说成“没有”。原始GP融资/股东/机构、BK/SC市场等序列只有同日可解释且有完整时点证据才可进入后续独立实验，本批不为凑数量加进经典模型。

- 开发：共同起点至2022-12-31；验证：2023—2024；后段观察：2025至最新完整数据日。每段期初使用上一交易日真实净资产，不重置被套持仓或截去回撤。
- 若共同起点晚于2020-01-01，开发样本过短，禁止做正式“开发选型”；固定候选只作可用窗口观察，报告该限制，不改日期挑出更好看的验证区间。
- 这些历史行情已有研究接触，后段只称时间分段观察，不称独立未见样本。保留每次试验和源版本，后续新增交易日承担真正前瞻观察。
- 额外做3年/下一年滚动报告：固定参数，不在滚动区间寻优；不足三年不凑窗口。逐年、滚动结果均列最差区间，不能只给平均。

开发选型只在S6/S7/S10/S11中进行：先剔除开发段最大回撤>30%者，按扣费Calmar最高选择，若差小于0.02则优先家族更少者，再优先S6→S7→S10→S11。没有达标候选时明确“没有合格模型”，仍对S11执行既定压力测试用于诊断，不偷偷变成推荐。

选定后只评估验证与后段观察，不因后段失败切换到后段收益最高模型。其他模型全矩阵照常展示，但不能写成当时已经会选出的策略。

### 5.3 稳健性与贡献

对选定候选（无合格者则固定S11）增加：单边20/30bp滑点、延迟至第二个交易日开盘、持股15/30只。参数变化只作为稳健性，不能据此重选模型。加入去价值、去质量、去动量三个消融对照，删除后对剩余家族重新等权；支路组合按家族所属支路保持原有50/50结构，某支路为空才全部归另一支路。

对S11单独比较S10、只有市场开关、只有目标波动率和两者同时启用；用与S11相同逐期预算的B1等权对照区分选股与减仓贡献。披露现金、周转、拒单、实际暴露、收益集中度、最差年份和最大回撤持续时间。

实测补充（2026-11-08）：100万元分散到数百只B1股票时，整手约束使“同目标预算”不等于“同实际暴露”。保留原B1实验但不把收益差直接归因于选股；新增实际仓位匹配的中证800价格指数归因对照。隔夜使用上一收盘实际股票比例，开盘后使用模拟成交后实际股票市值/开盘净资产，分别作用于指数隔夜和日内收益，现金收益为0、指数端不扣交易成本。此为事后风险归因基准，不是假装可成交的股票组合，也不能消除股息和当前池偏差。独立验证两段复利手算、整手现金比例、无效权益拒绝和源hash，不能改动原策略/选型来配合该对照。

## 6. 输出、验收与边界

研究输出放唯一新建的`.data/csi800-factors-时间/`；至少包含manifest、冻结的财务输入、逐周因子面板、来源/覆盖与目录审计、全部运行结果、因子诊断、策略与成本比较、分年/分段/滚动报告、选型决定及中文研究结论。大面板可用gzip压缩，压缩前内容与压缩文件分别哈希。清单记录价格冻结文件路径和hash，重放必须核验，不能依赖源目录当前内容。

计算/评分/目标生成留在纯包；文件、包批读、序列读取、哈希、压缩、进度与报告归研究编排；评价复用`quant-performance`。禁止包反向依赖Next、React、数据库或通达信文件。

完成标准：来源与29项口径可追溯；真实财务参与最终入选且逐行可核对；所有固定模型与对照在共同窗口成功运行或有明确输入失败原因；所有已要求的诊断、压力和消融完成；关键行为测试、子任务全量测试、类型与构建按[实施计划](../../csi800-multifactor-plan.md)通过；文档状态与真实产物一致。

通过投资研究目标还要求：选定候选验证段和后段均不超过30%回撤，扣费相对同暴露等权有正超额，单边20bp与延迟一天后不出现方向性失效；取得完整全收益指数时还要对其单列比较。研究简化与历史版本缺口仍阻止“可信实盘业绩”认证。失败则给出失败来源，不无限优化到通过。
