# 中证800持仓风控：规则整理

2026-11-08。用户最新将ATR保护替换为EMA50均线保护：从买入起检查收盘价，严格低于当日EMA50即强制退出剩余仓位，不要求前一日曾站上均线。其余8%初始止损、单股整轮账户2%预算、5%保本及30%一次性减仓继续保留；按已确认的同日收盘竞价必成交假设和T+1执行。旧ATR实验仅作历史证据保留，当前代码不再实现ATR保护。

随后用户要求解决买入当天已经低于EMA50的问题。完整模式新增因果入场门槛：信号日收盘、买入前最后一个已完成收盘、实际买入开盘均不得低于各自已知EMA50，相等允许；任何均线缺失或观测不足50则不买入，也不加仓。开盘比较只用前一根已完成均线，并按截至开盘已发生的公司行动换算价格尺度，不读取买入当天的收盘/HIGH/LOW来决定资格。被过滤资金留现金，不自动补选或重分配。当天开盘合格后再急跌仍可能收盘失守，这是T+1隔夜风险，不能用未来收盘价格把该交易从历史抹掉。

## 1. 已确认的风险层级

用户明确2%指“单只股票的本轮交易最多亏入场时账户净资产的2%”，不是整个账户回撤2%清仓。以首次实际建仓时账户净资产E冻结该轮预算B=0.02E；止损触发后按可成交条件退出。跳空、跌停与T+1可能使实际损失超过计划预算，不把回测成交价强行截断为正好亏2%。

沿用100万元本金、单股目标不超过15%。满上限仓位15万元按8%价格止损，计划损失约1.2万元，低于2万元单笔预算；正常无跳空时2%条件通常不比8%止损更紧。这一关系单独披露，不误当作两重独立保护的收益。

## 3. 持仓和优先级约束

- 一轮交易从首次实际买入开始，到实际全部退出结束；不是以每周重新生成的选股信号重置成本与风险状态。
- 成本使用真实成交与费用记账。若既有调仓在止盈前继续买入，更新持仓加权成本；保本已激活时，上调至新的经济成本无需再次达到5%，但不得因降低成本下调已经生效的保护价。首次入场账户风险预算不随之后净值变化重置。
- 保本激活和一次性三分之一止盈标志必须持久到本轮清仓；涨跌反复不能重复卖三分之一。部分成交时记录应卖、已卖和剩余，不把下单当成交。
- 分批止盈后，普通周调仓不能自动补回卖掉的部分；剩余仓位进入只减不加管理，直到该轮结束。止损退出优先于普通调仓；不能同一轮旧目标刚卖完又买回，重新开仓需后续独立信号。
- 多个退出条件同时满足时，全退出优先于部分止盈；价格保护取已生效条件中更高的一条。8%/2%硬保护与保本保护只上不下（公司行动等价调整除外）。EMA50使用当日均线实际值，可以随行情下降，不替换为历史最高EMA50；即使未盈利也生效。一经触发的退出请求不因后来重新站上均线而取消。
- 分红、送转、配股需统一调整股数、单位成本、待执行数量与保护价，不能把除权当作价格暴跌止损。已实现收益和剩余仓位成本应分别留痕。
- 受T+1或缺失当日行情限制时，退出请求继续保留并显示风险超限；同收盘假设对有行情且可卖股份豁免跌停队列和成交容量约束。买入数量不能为满足整手要求而向上突破风险预算或15%调仓目标上限。

## 4. 已确认的触发与成交口径

1. 用户指定收盘确认、按当日收盘价模拟必成交。风险退出不施加滑点、成交容量或跌停拦截，费用税费照扣；普通调仓仍沿用次日开盘及原约束。保留A股T+1可卖库存：当天新增不可卖部分保留退出请求，随后可卖的收盘继续处理。不将必成交误解为允许卖出当日新买股份。
2. 最终收盘价确认和同次竞价报单存在真实时序差异，因此明确标为“同收盘假设”，不认证为真实可执行业绩。该模式允许风险信号日与执行日相同，不套用旧模式“所有交易次日执行”的断言。
3. EMA50从买入全程生效，复用共享`ema(bars,50)`：按本项目通达信口径以首个有效收盘价初始化，之后按`EMA(t)=2/51×Close(t)+49/51×EMA(t−1)`更新，含当日收盘。至少累计50个有效收盘观测后启用均线保护，避免用新上市短序列冒充完整预热。先按已发生公司行动连续化价格，再把EMA转换回当日原始价格尺度；预热不足或无有效值时不填造EMA，其他保护继续执行。
4. 单位经济成本含买入费用，现金股息降低该成本，送转摊薄、配股计入实缴成本；另记未扣股息的单位投入基准。5%与30%按“收盘价减经济成本 / 单位投入基准”计算，避免股息被误作跌价或净成本非正时除零。无公司行动时就是通常的含费持仓涨幅。保本价为经济成本，卖出费用仍可能造成小额净亏。
5. 8%保护价为经济成本减8%单位投入基准；2%预算冻结在首次建仓账户权益，按本轮已实现损益加剩余仓位假设扣费清算损益检查。8%/2%到线触发，EMA50按严格跌破触发，相等不触发EMA退出；达到或超过5%/30%即满足盈利阈值。
6. 收盘先更新保本与EMA50；全退出优先于部分止盈，不在同价拆两笔重复收最低佣金。没有全退出时，30%条件本轮只登记一次当前股数三分之一的目标；不足卖出整手不向上多卖。部分止盈后只减不加，全部退出后仅晚于退出日的新信号可重启。
7. 风险规则是触发与仓位预算，不保证实际损失恰好封顶8%或2%；收盘跳空穿透仍按真实收盘价和费用记账，单列预算穿透记录，绝不改成交价美化风险。

## 5. 对照与验证

已完成口径确认，集中编码与测试。以五家族＋波动率预算为同一选股底座，对比原规则、仅8%/2%初始保护、再加5%保本、再加30%分批、完整EMA50全程保护，逐层解释贡献，不根据全区间结果重新优化用户阈值。旧ATR结果从原冻结目录只读比较，不在当前实现中保留旧退出分支。

验证覆盖：8%与2%的交叉约束、真实入场费用、加减仓成本、5%上移后不回退、30%只减一次、整手和部分成交、周调仓不回补、止损后旧信号不重买、公司行动、EMA50预热/递推/当日值下降/相等边界、同日多阈值、跳空/跌停/T+1、未来数据追加不改写过去动作。每笔退出保存当时成本、风险预算、EMA50、保护价、触发时间、执行时间和原因。
