# L07 打板情绪：结构与成分

日期及来源常显，盘中快照与已完成历史日明确区分。炸板率、最高连板、晋级率为第一组重点，涨停/炸板/跌停/昨涨停数量与昨涨停今均涨为辅助摘要。不能把跌停数量用绿色“成功”徽标表达。

中部为连板梯队与行业分布，点击只过滤成分列表，保留所选维度提示及清除入口。来源未提供某维度时保留摘要，不拼造行业数或梯队。

下方四池标签分别保存排序和分页，表格按当前池显示适用字段，证券名称与代码、关键价格涨跌、连板信息和看图入口优先。全局统计基于当日池，不因下方筛选重新计算。

无数据要区分尚未取得、非可用日期、来源失败和真实零记录。来源更新时间不等于所有证券行情截至时间。看图带池及日期；返回原池、过滤和行位置。

本页是情绪观察，不新增打板订单、实时推送、成功率预测或推荐买点。空错说明贴近对应区域，不把每一种错误都升级为整页不可用。
