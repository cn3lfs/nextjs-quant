# L04 任务中心：找任务、看结果与失败恢复

## 主区和详情

采用单行紧凑状态摘要、筛选条、主表和选中详情。主表字段：任务类型/名称、状态、阶段进度、创建时间、最近更新和查看。进度优先使用后端实际阶段与已完成量，无可计算总量时不画虚假百分比。

全局计数为全部已记录任务，独立于下方筛选；标题明确范围和统计更新时间。五个指标为运行中、等待运行、今日完成、历史失败、历史已取消，不加平均耗时或成功率等无接口指标。

筛选沿现有历史查询字段：状态、类型、精确任务编号；没有日期筛选接口，不画日期过滤。时间按北京时间显示。查询草稿提交后生效，翻页不改变条件，刷新保留选中任务。详情展示输入范围、任务身份、阶段、错误、产物和来源页。混合状态示例列表必须对应全部状态与空ID过滤，不用自相矛盾的样例。

## 状态动作矩阵

| 状态             | 主要动作                    | 解释                                   |
| ---------------- | --------------------------- | -------------------------------------- |
| 等待运行         | 查看详情 / 请求取消         | 等待不假装已经执行                     |
| 运行中           | 查看阶段 / 请求取消         | 可离开页面，不承诺后台在应用退出后继续 |
| 取消请求中       | 等待反馈                    | 不把请求成功当已取消                   |
| 已完成有产物     | 查看真实结果                | 跳转携带来源任务身份                   |
| 已完成无可达产物 | 查看详情                    | 不提供无效报告链接                     |
| 失败             | 查看原因 / 去来源页重新配置 | 不新增一键重放                         |
| 已取消           | 查看保留证据 / 来源页       | 不撤销已发生外部请求                   |
| 不存在或已清理   | 刷新列表                    | 不显示旧选中内容冒充当前对象           |

统计读取失败不清空仍可用的列表；列表失败不把计数标零。详情加载失败保留列表且提供重读详情。

## 取舍

不采用任务瀑布图或日志终端作为首屏，个人工作台的关键是找到哪项结束、哪项失败和结果在哪。长日志收起但完整可读，错误摘要靠近恢复操作。审计不完整提示必须说明不能作为完整研究记录，并进入研究使用台账核对；不能假设快照已保存。来源跳转不自动回填参数或启动。

## 验收

给定历史失败任务，能从原因进入来源页配置；给定取消竞态，显示实际终态；给定列表筛选，仅列表随筛选变化，全局统计范围不暗改。跨页查看结果后返回恢复列表条件和行位置。
