# L17 盘中预选：已生效参数与当日批次

首屏显示已生效配置、午盘/尾盘批次及结果，配置默认折叠。草稿修改不改变当前批次解释；保存成功后更新已生效身份，保存过程中继续编辑的新草稿不可被旧响应覆盖。

配置保留启用、行情来源（本地/通达信在线）、午尾盘时刻、RPS周期及最低值、证券池、缠论配置。实际预选用上一交易日RPS及截至当时完整5分钟线；不能把今日盘后RPS带进盘中决策。

当前默认午11:20/尾14:40、RPS50≥90，只是可配置默认值，不是全站不可变规则。时刻必须是交易时段内5分钟时点，午盘在上午、尾盘在下午收盘前；执行窗口五分钟且右端不包含。池类别全沪深/指数/行业/概念与具体名单分别选；RPS周期来自已有1/3/5/10/20/50/120，最低0–100，缠论配置0/1100。非法值定位原字段，名单读取失败单独重读，不静默替换证券范围。

状态分未启用、窗口未到、窗口内、执行中、完成、部分失败、错过、休市、日历未知。时钟状态与实际批次进度分别展示。应用需保持运行，隐藏页面不代表暂停后台；错过窗口留记录，不新增补跑回放入口。

保留现有“检查并执行当前时段”，只检查当前窗口并返回started/running/pending/closed/unknown/missed/confirming等真实结果；未保存草稿、未启用或正在运行时禁用，不能把它改名为任意立即运行。午尾盘时刻仍按配置，不按设计稿臆造固定分钟。

窗口未到、休市或日历未知不额外禁用“检查并执行”，状态已读取/已启用/无草稿/无运行任务时仍可检查并返回对应原因；不能把“未启动任务”画成按钮不可检查。当前页面没有额外“检查日历服务”或独立取消任务接口，不补造。配置编号只显示0/1100，不擅自解释为基础笔/严苛中枢。

候选主表可筛选并查看命中依据、数据时点和原批次身份。收盘15:05后另行核对，确认、撤销、数据不足、尚未核对和待重试分别解释；缺数据不能算撤销。核对不覆盖原盘中记录。

观测查询字段仅日期起止、证券代码、午/尾盘、核对状态（未核对/待重试/已核对）、仅有预选信号；批次限定由进入批次带入且可清除，不新增任意批次文本搜索。默认不仅有信号，成功但无信号的观测仍可阅读。“重置为今日”“全部历史”保留，统计是当前筛选完整结果而非本页；有信号才计候选，候选总数不等于全部成功观测数。

历史批次完整可查，选批次后保留分页与候选位置，去任务或图表后返回。源读取失败局部重试，保留旧批次且标时点；无候选是合法完成结果，不显示为执行失败。日志/hash放证据明细，不压首屏。

批次查询保留独立日期起止、时段和执行中/完成/部分完成/失败/错过状态；可进入该批观测或展开原配置及失败原因。证据详情保留RPS日期、行情截止/捕获/完成时点、策略版本、逐项收盘结论、历次核对和原始完整依据。JSON导出覆盖当前完整观测；清理需确认，后台运行时禁用，只删除此观测及收盘核对、保留批次记录，不能设计成重跑或恢复。容量读取失败局部提示，不改变既有查询结果。

完整导出来自intradayExport，仅此观测和历次核对，不扩成整天RPS档案或ZIP。原始预览与表格RPS值必须一致，不手造另一个JSON字段契约；当前核对没有收益率/超额字段，收盘成立或撤销只据原信号在有效收盘证据中是否仍成立。运行中禁清理及确认清理，关闭确认仍可取消。原始证据容量为保留至手动清理、上限512MiB的来源状态；读取失败可局部重读，不虚报占用或自动清理。

当前ChartSymbolLink仅打开证券行情并沿用浏览列表，不自动加载原观测时点的冻结快照。设计入口标“查看当前行情”，原时点依据仍在观测详情/JSON，不能把当前图当原盘中证据。返回保留原行是导航设计目标，不新增历史回放能力。
