# 端到端流程与恢复契约

## F1 数据准备

设置来源 → 保存配置 → 只读诊断 → 查看实际覆盖 → 到RPS选择范围 → 提交计算 → 任务中心查看阶段 → 发布批次后进入排名。

诊断成功不等同数据完整；保存成功不等同后台任务完成。RPS运行时旧发布批次仍可读，明确日期。失败回来源配置并保留原草稿；不得默认重算正式历史。

验收：给定数据不足，从总览进入数据设置时知道缺哪类数据；处理后能回到原任务；来源和覆盖时点始终可见。

## F2 发现与比较

行情证券池 / 条件选股 / 情绪四池 → 提交过滤 → 选择候选 → 图表 → 前后证券连续比较 → 返回原候选。

图表承接代码、来源列表及位置；筛选时间与图表最新时间同时标明。切条件后原报告仍属于原冻结配置；新请求失败不可让旧图标题冒充新证券。

验收：给定第3页候选，查看图表并返回时仍位于第3页原行；未生成结果时显示运行入口，不画示意收益当结果。

## F3 实验与研究

策略中心识别规则/缺口 → 检查输入 → 配置实验 → 提交本机任务 → 查看结果 → 年季月/订单/交易轮次 → 复现证据 → 同口径比较。

策略实验保留当前基线及因子配置能力，统一策略目录归策略中心；历史弃用策略仅查证。样本研究是独立批量入口，其检验范围、准入与多重检验不能被单策略收益替代。

验收：给定历史报告，修改当前草稿不改变已选报告的参数说明；缺输入时看见具体缺项，不提供虚假的可运行状态。

## F4 证据与复盘

新闻查询提交 → 原文阅读 → 确认当前页/范围及实际条数 → 冻结分类 → 已分类日汇总 → 跨行业主题 → 价格核验 → 独立AI对照解读；行业研究从分类档案另行进入。各产物保持档案身份；证据分析从证券、问题和方法起步。

财联社复盘以原报告观点和实际盘前固定样本时点为依据，报告生成时间不能替代选样时刻；独立读取当日/T+窗口，待观察与缺失不计作命中或失败。报告结论、来源证据、数据时点与生成时间分别显示。

验收：给定一份历史观点，切观察窗口不改原文；从报告返回保留列表查询。导出对应完整选定产物，不把当前可见摘要当全文。

## F5 信号与账户追踪

监控范围与订阅保存 → 触发信号 → 交易状态核验 → 投递决策 → 信号台账观察；交易日志在本地单一账本追加成交事实，交割复盘另按账户别名和导入批次检查现金与纪律。

信号触发不代表成交，已订阅不代表已送达。账户现金对账不自动修正历史事实；未到期观察与已固定留空分别解释。

数字货币：行情浏览 → 模拟策略或平台账户独立标签；图表平台选择不改变策略账户，平台余额不替代策略账本。订单结果不明先对账，暂停不平仓。资源期货仅浏览。

验收：给定投递失败，从信号详情读到具体原因并进入对应设置；给定平台查询失败，旧余额明确显示旧快照时间，不能当最新余额。

## 共用详情规则

抽屉用于短详情/证据定位，完整报告为独立阅读页；关闭抽屉归还触发点焦点。切标签保存各标签筛选，切账户不得沿用上一账户数据。没有来源的直接访问返回所属列表。
