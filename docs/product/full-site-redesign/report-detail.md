# L14 研究报告详情：连续阅读与证据定位

## 报告身份

使用现有kind/id四类产物，不新增报告类型。标题旁显示证券、方法、生成时间与数据截至时间；ID与模型/提示词/技能版本放可展开身份区，长哈希不占阅读首屏。生成时间不能代替行情和财报可知时点。

实际路由仅report/chan-report/canslim-report/wyckoff-report；非通用报告ID须对应kind前缀加64位十六进制哈希，非法类型或ID沿用未找到处理。视觉缩略必须保留正确kind前缀，不能自创CSM/CZSC/WYCK后冒充原报告ID；目录、返回和导出始终绑定完整原始身份。

## 阅读结构

正文最大840px，左侧目录或右侧小锚点导航，主列依次为摘要/结论、支持与反向证据、分析章节、风险与缺项、后续验证。只在顶部给一份结论，避免每段重复卡片打断阅读。方法特有章节按原产物保留，不强行把四种报告内容削成相同字段。

证据引用点击可打开侧栏查看来源、时点和原始片段，正文位置保留；长原文与完整导出保持可达。导出针对当前产物，旧结构缺某字段显示未记录，不补当前模型版本或新证据。

导出格式依现有产物：通用报告为Markdown，CANSLIM/缠论/威科夫为JSON证据档案，不统一伪装PDF/ZIP。证据原文现有分段浏览保留，完整内容在导出中；相对强度原始来源下载只在确有对应来源和元信息时出现，不给所有引用加虚假原始数据入口。

## 错误与返回

报告不存在/已清理：回档案并保留原查询；格式无法读取：原因、重读，原档案不改写。刷新失败有旧报告时明确上次读取身份，不能当最新成功。一个方法区不可读不使整个导航崩溃。

来源回跳使用已有archiveReturnHref，关闭证据恢复引用焦点；直接访问无来源回档案列表。完整报告不拿分页摘要代替，超长表格内部滚动。

## 能力缺口

证据侧栏是新布局目标，依赖现有产物确有引用字段；没有引用定位元数据时以章节来源区为回退，不虚构逐句来源。报告不能新增重新生成、自动买卖、批注协作或任意版本恢复能力。
