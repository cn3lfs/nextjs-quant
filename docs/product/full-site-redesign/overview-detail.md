# L01 今日总览：状态到下一步

总览回答当前交易日/时段、数据是否足以继续、今天先处理什么。待办优先，市场摘要和自选为次级，不把全部模块压成密集卡片。每项状态指向已有来源页，不能让一个总览按钮暗中启动修复、计算、交易或通知。

日线、5分钟、RPS、调度和投递分别保留来源与读取/数据时点；一个模块健康不能代表全系统健康。未知日历不推断开市，无待办不等于数据全部完整，过去成功不当成当前新鲜状态。

首屏一项最突出下一步，次级事项表显示原因和查看入口。示例“RPS待更新”导航/rps，不在总览新建任务；盘中批次导航/intraday，不编造盘前撮合、因子修复或股指期货跟踪任务。

市场摘要红涨绿跌带符号，时点靠近数值；缺行情显示未取得，自选看图携带列表游标。午/尾盘/收盘阶段按已保存调度，不在设计图臆造具体分钟。隐藏/离开不宣称后台任务已停止。

无异常时给正常阅读与研究入口但不夸大全数据健康。局部失败在对应区域恢复，保留其他可读部分。跨页返回保留日期与自选上下文，不强制回到默认首屏。
