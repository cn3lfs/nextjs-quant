# 观澜全站浅色重设计 · 页面规格

日期：2026-11-12。依据当前工作区静态阅读；这是设计规格，不代表运行验证。所有示例数据均为设计示例。

## 01 今日总览 · `/`

- 源码依据：`src/components/overview/today-overview.tsx`。
- 用户任务：先知道今天能做什么，再进入对应工作区。
- 当前能力：现有交易时段、健康检查、待办、板块RPS及自选行情混排。
- 布局取舍：采用待办优先的工作日简报；放弃把所有模块压成仪表盘卡片，因为状态和行动会被行情淹没。
- 主流程与首屏：交易日与时点 → 优先处理事项 → 市场摘要 → 今日时间线；主操作按当前阻塞指向数据设置或盘中批次。
- 分支与恢复：数据过期显示截至时间；未知交易日不推断开市；无待办明确显示暂无待处理；单模块失败局部恢复。
- 上下文与边界：保留日期及自选上下文；进入任务或批次后可返回总览。
- 验收 01.1：给定上述入口，完成主操作时，能看到输入范围、当前状态和明确下一步。
- 验收 01.2：给定失败或缺数据，页面说明原因并给出恢复入口，不用虚构数据替代。
- 验收 01.3：从详情或跨页返回时，恢复上述已规定的列表/草稿上下文。
- 设计任务：主稿 → 关键状态标注 → 规格对照审阅 → 必要修订；设计状态见[覆盖索引](stitch-index.md)。
