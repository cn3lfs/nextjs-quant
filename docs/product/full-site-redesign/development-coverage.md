# 页面开发与运行覆盖

设计已按每路由最多3次调用封板；本轮不再调用Stitch生成或修改。下表沿用设计编号，并按优化方案更新现行页面；不把共享换色当单页交互改造。旧 `/research` 已退役，新增证券池独立路由；当前路由验收以真实导航目录加组件参考和报告详情为准。

共享层为浅色主题、216px分组导航、仅页面搜索、56px顶栏、14px正文/13px辅助、白底图表和统一控件。实际修改文件清单见[development-files.json](development-files.json)，交付与验证见[开发交付](../../deliveries/2026-11-13-full-site-light-redesign.md)。

初次浅色实施只做静态检查；后续工程、组件和隔离应用检查统一见[优化交付](../../deliveries/2026-11-13-optimization.md)。新增 `pnpm e2e:visual` 覆盖现行 24 个入口在 1440/1024px 下的初始状态，检查页面标题、运行错误、未分类请求与整页横向溢出，并输出截图。它使用合成行情、空业务记录与明确外部离线响应；新闻等待缺源错误稳定后截图，报告详情使用不存在的记录。此覆盖不代表完整业务数据、所有标签/弹窗、键盘或缩放验收。
