# L18 信号与通知：订阅、信号与投递

保留订阅/信号/投递三个历史标签，各自查询、分页和选中记录独立，顶部摘要标统计范围。主任务为维护监控和追溯实际触发，不把监控启用、信号产生、交易状态核验及消息送达合成一个绿点。

三个列表均每页20条、游标上一/下一。订阅筛选为名称或证券关键词、策略、证券代码、启用/暂停，没有日期；信号筛选为证券/策略名/信号ID关键词、策略、证券、创建日期起止、订阅ID；投递为标题/投递ID关键词、创建日期、状态、渠道、类型、关联信号ID，不加证券或策略筛选。消息类型“测试”仅历史过滤，不提供发送测试入口。

顶部五项原统计保持不同范围：当前启用订阅、今日新信号、今日平台接受投递、全部失败投递记录、暂停证券实例。今日按北京时间创建日期；暂停证券是订阅证券实例，不是唯一证券数；统计独立于当前标签筛选，人工重发成功也不抹掉原失败记录。

订阅编辑保留证券/自选范围、双均线/缠论/双突破策略、适用周期、来源、渠道、新信号附加AI及保存后启用。双均线日/5分钟与缠论/双突破日线15:05后规则按现有边界，不能自由放开周期。策略参数随选择显示，未知或缺数据单独解释。

明确代码列表最多20个，留空使用提交时的自选快照并显示数量与成员，不代表持续跟随以后自选变化；没有自选又不填代码时不能提交。

自选超过20时不能静默截取，要提示缩小显式范围。名称最多80字；双均线字段保留短/长均线、最低/最高涨幅及最低量比，监控配置与回测双均线基线是不同入口。共用StrategyFields目前带历史研究弃用说明，但监控仍实际支持保存此策略，设计不能据此删除监控入口或宣称监控整体已弃用；不修改本次应用实现。

新建缠论选择当前默认配置0，既有配置按原存储值显示，不能借别页的1100配置创造本页当前没有的调参控件；双突破参数固定为现有规则，向下突破为破位观察，不是自动做空。

保存订阅、保存并启用、暂停/启用使用既有行为；启用不发测试消息。无渠道或凭证失败指向具体设置，返回原草稿。并发配置变化时读取最新服务端值并保留本地草稿，由用户核对，不悄悄覆盖。

不选渠道允许保存与启用，只记录信号；已选渠道被删除才要求重新选择，未配置/未启用在列表如实标记，不把无渠道当表单必填错误。保存按钮随“保存后启用”变为保存订阅/保存并启用；既有订阅可暂停/恢复，当前无订阅删除接口，不造删除按钮。筛选结果预填新订阅也只是未保存草稿，必须选策略并明确保存才生效。

保存时继续编辑的新草稿保留，重新读取配置供对照而不覆盖当前输入；会话存储不可用时只保证当前页面草稿，并提醒未保存离开。来源选项沿用现有自动/通达信本地/tstdx/东方财富/腾讯自选股；历史已停用来源按原记录和现有提示读取，不改用户维护的MCP文案。

修改配置或恢复订阅会重新建立基线，不补发历史信号；本机退出或休眠时监控停止。该说明靠近启用动作，不藏在帮助页，也不加应用退出后仍全天运行的承诺。

信号详情给原规则、证券、时点与证据，投递详情给渠道、状态和决策原因；落库不代表已推送，已订阅不保证送达。停牌、交易状态未知、未订阅、失败与过期分别解释。

投递状态仅待发送/发送中/平台已接受/失败/已过期/已取消；平台接受不是收件人已读。消息正文、完整错误、平台回执标识和关联决策分别查看，缺原决策不能推断已发或被过滤。详情完整JSON导出绑定当前订阅/信号/投递，缺记录不能导出成功。

保留既有人工重发：只对失败/过期/取消且原渠道启用并配置的记录显示可用“核对并人工重发”；确认框点名历史标题、原时间/原因、渠道和脱敏目标，并说明会实际发送历史正文。确认创建独立新投递，原记录不改写，不把排队成功称已送达。渠道目标版本改变时拒绝并重新核对；结果不明保留原确认请求，同一请求重试按幂等返回，不悄悄换请求重复发送。这里只设计示例界面，任务执行不调用真实重发或测试通知。

跨入关联投递时带signalId并重置该标签游标，返回保留原信号；短详情用抽屉/侧栏，完整证据仍可读。后台刷新不重置正在编辑的草稿。页面不新增下单、真实测试通知或自动重放投递。

长订阅表单与列表分为同页两个状态：列表全宽浏览/查询/查看/编辑，新建进入全宽两三列表单并可返回列表；不新增路由。避免将完整表单挤进窄右栏导致底部保存被裁切，保存与全部字段在编辑状态完整可见。最终5张主稿与状态板分别为列表、完整表单、信号依据、投递确认、恢复状态；此处状态板数量不计新增页面。编辑稿HTML残留最大宽度1224px，公共收口去上限按主区自适应处理，业务流程已静态审阅。
