# L06 条件选股：草案、检查、执行和候选

## 现有入口与重组

保留通达信公式、本地双均线草案、本地可复现条件三类入口；公式内的一句话生成与双均线自然语言草案是不同能力，名称和解释分别呈现。公式区域现含单因子评估，设计为公式工作区的独立次级标签，不与条件筛选结果混成同一张表。

财务组合筛选当前归研究档案中的本地财务工作区。选股页可提供明确跨页入口，不暗示通达信公式支持财务函数，也不在此次设计新增财务执行接口。

## 公式流程

已保存公式 / 新公式 → 名称、源码、参数 → 可选一句话生成 → 阅读逐行解释和不支持条件 → 语法检查及未来函数门禁 → 保存或全市场执行 → 查看任务和候选结果。

修改源码或参数后已检查状态立即失效；未来函数命中拒绝执行，无“仍然运行”。公式执行针对本地全A股已完成日线、不复权；不支持的财务、即时行情、绘图与随机函数明确列出。

公式编辑器默认占工作区上半部，候选下半部全宽；长源码展开，编辑/结果可专注切换，不能为了并排而把证券表压成窄栏。运行按钮是最突出动作；未检查时禁用并显示下一步“先检查公式”。

## 双均线草案与可复现条件

自然语言 → 草案及不支持项 → 确认应用 → 核对可复现条件 → 提交。生成草案不启动筛选；不支持项存在时不能应用。草案、已提交配置和选中历史批次保持不同身份。

## 候选与失败

显示本次任务、冻结范围、覆盖和实际结果数量；分页、排序、证券名称及命中依据。选中证券进入行情，携带完整候选列表身份。空结果说明条件和时点，提供返回编辑；计算失败保留输入与旧结果身份；取消等待实际反馈。

## 单因子评估

独立配置公式、开始/结束日期、分位数 → 评估任务 → 持有期IC表 → 分位超额收益/累计IC。保留有效证券、无除权记录、不复权、跳过日与读取错误等原有结果口径。它是统计评估，不把IC当交易胜率或预测收益。

## 验收

给定已检查公式，修改一字符后不能直接执行；给定生成草案，不支持项不能被静默丢弃后自动执行；给定历史结果，当前编辑不改变其范围说明；给定空结果，恢复编辑仍保留源码与参数。
