# L24 公共组件参考：统一浅色与状态

这是设计交接参考，不是业务导航的一项任务。采用页内组件目录与示例画布，示例均标识，不能显示假任务或真实账户数据。

包含品牌与导航壳、字号/数字对齐、颜色语义、按钮、输入/下拉/日期、表单错误、查询草稿/已应用、页内标签、表格/分页/排序、空态/加载/局部失败、对话框/抽屉、图表坐标与证据引用。

每种控件并列默认/选中/焦点/禁用/错误，正文14px、辅助文字可读；上涨红/下跌绿带符号，任务成功/失败配文字，避免用同色暗示同义。示例日期YYYY-MM-DD，金额/百分比/基点单位明确，长ID与哈希只在证据详情。

统一观字方标和观澜品牌，清理各页生成的不同Logo、版本、假系统健康灯、重复图标、工程口号及无能力的操作。主按钮只有一个视觉重点，危险操作点名对象；不把“保存成功”画成“全数据通过”。

展示1440桌面、1024折叠导航与窄窗叠放的布局规则；宽表格在自身区域横滚，不以微小字号塞列。可见焦点、键盘路径、对话框焦点归还及状态文案作为交接约束，本轮不运行浏览器或无障碍深度测试。

参考现有Radix/shadcn及图表能力，后续实现映射src/styles/tokens.css，不新增第二套组件库。生成稿不包含原生功能/数据支持的证明；具体业务页的状态与流程仍按各页规格。

当前画廊现有Input/Textarea/Label、Checkbox/Switch、Select、Button、Badge/Alert/Card、Tabs、Dialog、DropdownMenu、Tooltip、Collapsible、ScrollArea、Separator、Skeleton和DataTable，应保留相应状态参考。表格本页示例为3条、每页2条，不能机械改成业务查询的20条；代码可排序、名称/状态不排序，翻页与排序重置按示例展示。加载/空/错误是明确可切换展示状态，不连接任何业务API或假装完成业务任务。

旧组件文案里的R1/18个组件及“图表暗色保持独立”不作为新交付目标；本次用户明确全站浅色，画廊与图表参考也按新规范。保留返回工作台入口，画廊不进入业务侧栏。组件比较区可以并列主按钮样式示例，但真实业务操作仍遵守单一视觉重点，不能借画廊引入第二套组件或无能力的业务操作。

现有对话框为复核展示内容/展示备注输入，只展示配色与键盘浮层，不保存业务；菜单“查看样例”只改变本地状态提示，“暂不可用”disabled。Tooltip通过焦点或悬停可读，Esc关闭浮层并把焦点还给触发；不能设计成真的导出/删除/通知。标签观察说明/使用边界，滚动区域8条本地观察和分隔线，Tab可达。表格失败重试仅把本地展示状态切回正常，不宣称读到业务数据。窄窗、浮层、表格状态各自可演示，不把全部错误态当真实应用同时故障。
