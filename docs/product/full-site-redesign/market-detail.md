# L05 行情图表：连续比较与清晰图表

## 主布局取舍

1440窗口扣除全局导航后，三条常驻侧栏会把图表压窄。采用240px候选列表和弹性图表；证券盘口/基本面默认为可收起区域，按需展开，不让图表主区低于可读宽度。宽窗口可并列摘要，小窗口候选列表改抽屉。

最上方对象身份行含代码、名称、行情时点和来源；其后为周期/复权/刷新工具条。来源与复权不藏在更多菜单里。指标、缠论参数、画线与对比属于第二层工具，不全部常驻展开。

## 按当前能力保留

证券池与自选、PageUp/PageDown连续翻股、分时/K线、指标和缠论设置、画线与编辑、叠加品种、联动第二周期、实时盘口及基本面。研究与策略实验承接当前已加载快照。

图表指标不是首屏卡片集。价格坐标、时间坐标、成交量和十字光标对比度优先，示例图标明“设计示例”。单位、时区、复权、数据范围与来源在图边即可找到。

用户已明确全站浅色，本次图表也默认白底，不保留首屏“加深背景”开关作为必需交互；旧UI Gallery曾写图表暗色独立，该说明由本次浅色目标取代。此轮仅规范设计，不修改历史数据或运行时设置。

## 状态与动作

| 操作         | 期望表现                                         |
| ------------ | ------------------------------------------------ |
| 从选股进入   | 保留候选列表顺序、来源批次、游标                 |
| 切证券       | 旧图保留时明确旧证券身份，加载完成才更新当前对象 |
| 切来源失败   | 不静默换源；提示失败并允许明确更换               |
| 切周期       | 保留证券及来源，周期数据缺失不回填其他周期       |
| 指数或板块   | 复权按现有适用条件禁用并解释                     |
| 展开第二周期 | 说明联动范围，保留关闭入口；不新增多窗口能力     |
| 编辑画线     | 明确选中对象和保存范围；删除点名选中线           |
| 点击研究     | 无快照时引导加载；有快照传递原身份               |

## 阅读与返回

返回候选列表恢复原位置。独立进入行情无来源列表时默认证券池；退出连续翻股有清晰入口。实时盘口的当前时段只是现有时钟/星期判断时，不以其代替官方节假日日历。

## 缺口

图表多周期、画线坐标和对比色均需后续沿现有ChartWorkspace规则实现。本次仅设计，不能按效果图假设指标或联动已经运行验证。
