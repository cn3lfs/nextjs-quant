# L19 信号台账：前向观察与原始证据

顶部是当前/最近每日任务、扫描进度、公司行动覆盖及时点，独立于下方历史筛选。全市场本地日线信号落库不等于投递，不把落库总量标成推送量或成交笔数。

列表按观察日期起止、证券代码、策略（缠论/双突破）、方向、原始质量精确值查询；更多筛选仅T+5/10/20与待观察/已固定有效/已固定留空。所选期限决定筛选和全范围计数，列表仍能读三个期限。首次到期结果固定，后来的价格不回写原结果。数据不足、停牌/无法观测与方向未命中不是同一状态，不用零收益替代缺值。

此台账的观察期限为T+5/10/20，不能套用财联社复盘的T+1/5/10。最近30交易日快捷范围依赖已知日历，不足时禁用并允许手动日期，不回退成30自然日。

主表突出证券、策略方向、原始信号时点、所选T+结果和证据入口。全样本分析独立标签，明确范围不同于当前筛选页。每日任务历史与投递决策历史均保留完整分页和原始依据，不能只剩最近几条。

详情显示原始快照、观察/端点日期、数据来源、失效条件、策略版本及适用的DLL摘要、后续结果及关联投递决策，不增添不存在的模型状态。长证据按需展开，可导出该条完整信号依据JSON；现有界面没有任意筛选范围批量导出，不补造。直接进入详情无来源时回列表，返回恢复筛选、页码、行和滚动，刷新任务不重置历史阅读。

台账由交易日15:05后应用运行且当日日线就绪时向前记录，不补录历史；当前界面只有活动任务取消，没有手动任意启动、清理或重跑动作。取消区分已请求/已请求仍等待/已结束/不存在，保留真实反馈，不改历史观察或自动纠正记录。界面不增加自动下单、处理收益或强制推送功能。

## 统计与独立历史

统计全样本分析与列表筛选独立：聚合按策略×引擎原始质量×期限，两方向合并；信息含量另按策略×方向×期限，全部历史服务端计算、每页展示一组策略方向的三个期限。收益是下一交易日开盘至T+5/10/20收盘的未复权价格变化，无费用/滑点，两种方向均不模拟做空。零收益进入胜率分母；正负任一侧无样本时盈亏比留空。停牌缺数不顺延；持有期含除权或除权状态未知留空，GBBQ最大事件日期必须覆盖持有区间。聚合blanks是样本数减有效收益数，含尚未固定；不能与历史列表“已固定留空”计数混同。留空原因可能重叠，不能相加当样本数。

V3信息含量去重证券×观察日×策略，保留字典序最小ID；去重优先、其余排除计数可重叠。截面至少5条，默认5组，每组期望不足10条降3组、仍不足留空；并列归低组，t值未修正重叠和截面相关，不作显著性判断或外推。统计口径可折叠但保留阅读入口，不能只剩赢家收益卡。

设计三条样例中，缠论向上有2026-09-01和2026-11-11两个观察日（各一个样本，其中后日未固定）。源码先建立日期截面再排除无效收益，故每期限有效/总截面为0/2，不能把全部无效的日期删去后误写0/1；原始2、参与1、排除1，IC无有效截面。分层请求5降到3后仍不足，每层结果留空。三条全样本聚合依旧每期限3条/有效1/无收益2，不与信息含量分组分母混同。

每日任务历史按日期起止/执行中、完成、部分完成、失败、已取消查询，完整游标分页；详情读原阶段、日历来源、GBBQ覆盖、扫描数、信号数、耗时和原因，每组20条错误可翻页。投递决策历史独立日期起止/证券/档位查询与分页，含未匹配台账的监控决策；详情保留原规则、原因、渠道/投递/信号编号与当时日上限/去重交易日/汇总时刻。档位不等于发送状态，实际结果去信号与通知核对，不在台账强制重发。
