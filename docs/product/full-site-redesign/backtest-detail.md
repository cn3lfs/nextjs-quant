# L09 策略实验：草稿与报告并存

## 当前能力与范围

MaBaselinePanel承载双均线SMA5/20基线及模块化因子组合，配置、覆盖读取、任务、报告、订单成交、评价与历史。当前是5分钟、主板单标的、100股整手、T+1，收盘确认、下一根开盘尝试；不能被策略中心的日线实验口径覆盖。当前代码只接受沪深主板代码。旧LegacyBacktestView保留历史证据入口，不恢复弃用执行。

页面与策略中心的职责不同：这里专注当前实验配置和已选报告，不重复一个新的全量策略目录；策略中心仍为统一方法浏览入口。

## 配置流程

策略模式选择 → 证券 → 读取本地覆盖 → 请求区间/资金/费用 → 提交实验。读取覆盖只证明可读取，任务仍需检查预热、日历及公司行动。费用单位用万分之/元，不能把1万分之写成1%。初始资金1千至10亿元按现有校验表达，不用设计稿私设上限。

因子组合可展开入场/退出条件、全部/任一组合、因子与比较阈值；复杂编辑另用附加画板，不能挤压报告。草稿无效时主按钮禁用并提供具体原因；运行中显示阶段与取消，等待实际终态。

当前defaultExecutionCosts默认佣金3bp、最低5元、卖出税费5bp、单边滑点5bp。展开示例若表达默认值须一致，用户自定义实验值应明确属于当前草稿，不能称历史实际费率。

## 报告结构

报告标题常显所选历史实验的证券、实际区间、输入身份、状态与证据等级。配置区用“当前草稿”，报告用“所选实验”，两者不相同时提示，不能按当前草稿给旧报告贴标签。

四标签：概览、绩效评价、成交与订单、复现依据。概览保留区间收益、对应频率最大回撤、成交笔数和期末持仓；评价区提供年季月、交易轮次与口径；交易表分信号确认和模拟成交时间；订单表保留拒绝/待执行及原因。

## 边界与恢复

没有真实完成实验时不展示虚构曲线；无成交是合法结果，说明信号/订单/资金限制。导出完整选定实验，失败可重试。删除点名实验，运行或导出时禁止删除，保留审计事实。历史恢复只改变所选报告，复制配置显式生成草稿，不悄悄重放。
