# L02 数据与连接：交互细化

## 页面骨架

全局导航之外另设页内设置目录：本地行情、新闻、研究模型、通知、数字货币账户、研究技能。默认打开上次使用项；来源跳转优先打开对应项。页内导航不用再复制一套全局菜单。

顶部只显示当前领域、保存状态和保存配置。已保存配置、输入草稿与最近诊断是三个对象，不能用一个“正常”徽标代替。

## 本地行情工作区

先显示当前来源及最近已知覆盖，再呈现路径与来源字段。折叠区域保留五分钟数据、市场序列和现有导入能力的入口，移除CSV界面的历史决定保持，不重新引入已删除入口。

诊断严格复用现有接口：显式选来源、证券、周期，最多核验64根返回样本；不称作全市场扫描。只使用已保存配置。输入已修改时显示“先保存配置，再检查”，不默默诊断旧值。

| 触发           | 页面反馈                            | 后续                       |
| -------------- | ----------------------------------- | -------------------------- |
| 修改字段       | 当前区显示未保存，不改变已知覆盖    | 保存或放弃                 |
| 保存中         | 保存动作忙碌，保留输入              | 成功后更新已保存身份       |
| 保存失败       | 错误靠近保存区域，草稿不丢失        | 更正或重试                 |
| 开始诊断       | 展示本次来源/证券/周期              | 完成后按连接/数据/时间显示 |
| 诊断后修改参数 | 旧结果标记与当前参数不同            | 再检查                     |
| 外部配置更新   | 按现有reconcileSettings语义提示差异 | 保留草稿并处理冲突         |
| 离开未保存     | 对话框明确保存、放弃、继续编辑      | 保存失败不能跳走           |

## 其他目录保留能力

- 新闻：路径、获取/分析配置及既有生效说明；不进入新闻业务操作。
- 研究模型：提供商、可用性和凭证是否已配置；不显示凭证内容，不在设置里生成研究。
- 通知：订阅策略与渠道配置；没有独立测试请求不发送测试消息。
- 数字货币：账户环境、认证状态与平台识别；图表来源与策略执行环境不混用。
- 研究技能：已有技能发现和状态；用户维护的MCP文案原样保留。

## 取舍与后续接口缺口

分领域展示并不意味着已有全局保存接口改成独立持久化接口。后续实现应沿用当前changedSettings/settingsToSave合并语义，只提交实际修改字段；若采用独立保存，需要另行接口设计。本次稿中“保存当前配置”只表达用户动作范围。

先验收“看见什么配置正在使用”，再验收“能否连通”，最后解释覆盖范围；这三者不相互替代。
