# L03 RPS：排名阅读与计算维护

## 信息层级

第一层是正在阅读的已发布批次及周期；第二层是排名和有效分母；第三层才是计算状态与历史日志。不能把“今日计算成功”显示在昨日排名上方而不说明批次归属。

初稿审阅后决定：1440宽采用全宽表格，计算管理由顶部按钮打开抽屉，避免九列被常驻侧栏挤压。合并为行业、排名/RPS、涨幅、成分/有效/端点不足、剔除说明、查看成分六列。更宽窗口才考虑并列维护栏，不作为主稿默认。

## 三类列表差异

个股复用行情证券池，保留最低RPS、证券搜索、周期、排序和分页；过滤不重新排名，分母仍为原市场范围。当前个股入口只有最新发布日，历史日期选择若没有对应查询能力，须标为后续接口缺口，不提供可点击假控件。

行业/概念保留日期、周期、名称和排序；显示总成分、本周期有效、端点不足、剔除原因及数量。成分不足或端点不足不能显示为零RPS；查看成分带上板块身份、日期及周期。概念还保留证券池审计入口。

首稿以行业为主状态，同时用状态说明标出个股差异；三类操作入口共享队列但不共享筛选草稿。

## 来源设置

行业和概念沿用外部Blocks/通达信研究一级行业两个成分来源。保留Blocks根目录、保存目录、核对当前文件变化；目录只读。来源设置只影响新批次，已有快照保持原来源。目录未保存时禁用核对与计算。当前文件变化的新增/缺失/变更与已存快照分别说明，hash收在证据明细。

## 计算行为

“回填最近250个交易日”的250是历史范围，排名周期仅1/3/5/10/20/50/120。计算今日保留15:05后的窗口规则。维护动作进入侧栏，不能为了清爽而隐藏当前执行任务或取消反馈。

| 状态       | 排名                           | 维护操作                       |
| ---------- | ------------------------------ | ------------------------------ |
| 无发布批次 | 说明未计算，提供配置与计算入口 | 按真实可运行条件启用           |
| 正在计算   | 保留旧批次并标日期             | 可请求取消，不能再启动共享任务 |
| 请求取消   | 保留现有结果                   | 显示正在请求，等待真实终态     |
| 失败       | 保留原发布批次                 | 查看具体原因和来源，不自动重放 |
| 完成发布   | 切换可用新批次并标身份         | 刷新排名，保留过滤与可用选中行 |

## 返回契约

行业进入成分再进入行情后，返回先回成分列表，再回原行业行。个股直接进入行情带原排名列表，支持前后证券比较。当前所读历史批次与行情最新日期有差异时分别说明，不把最新图表当历史信号依据。

## 必须避免的误解

高RPS不等于买入；排名不是收益预测。有效分母不同的周期不能凭表面分数当成相同样本比较。历史日志是证据，设计不提供修改历史结果或删除源文件操作。
