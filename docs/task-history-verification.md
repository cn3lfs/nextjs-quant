# 任务摘要与历史分页验收

2026-09-09，原方案模块 C 的响应大小和任务可追溯交互增量；不代表整个 C 或 A–H 已验收。

`jobs` 继续返回最近 80 条任务，保留身份、类型、状态、进度和创建/更新时间。数据库只投影这些字段及短阶段/错误摘要，不把任意附加对象带入响应。中文和转义字符按 JSON UTF-8 字节裁剪文本，使用省略号；完整文本仍在原档案，可在“全部任务与失败详情”中按需查看。

`taskHistory` 每页 20 条，按创建时间和 ID 倒序游标分页，支持状态筛选；创建时间不随进度变化，所以更新进度或插入新任务不会挤动既有下一页游标。列表没有定时轮询，手动刷新回到第一页。状态筛选的成员可能随任务完成/取消而变化，刷新用于获取新状态；这不是冻结数据库快照。`taskState` 只返回状态元数据与完整阶段/错误，不加载计算结果到浏览器。选中运行中任务才每两秒更新状态详情，终态停止轮询。

任务中心仍显示最近 8 条概览，新增全部历史、状态筛选、全文、总历时和取消所选任务。总历时包含排队及执行，不冒称纯计算耗时。原有选股分页、AI 报告和回测详情入口不变，取消使用既有任务状态机。

- `output/job-summaries-size-before.json`：生产数据库只读抽样，目前只有 10 条任务，原摘要 1673 字节。不能由此推出长错误场景也满足目标。
- `tests/job-summaries.test.ts`：80 条长中文/特殊字符错误及大附加对象，旧投影反例超过 20 KB；新完整 tRPC 风格 JSON 响应低于 20000 字节，身份/状态/进度/时间保持，数据库记录未改写。
- `tests/task-history.test.ts`：85 条同创建时点任务全部遍历无漏项/重复；每页小于 20000 字节，全文保留，非任务 ID 不泄漏，更新与插入不挤动既有游标，状态筛选与非法输入校验通过。
- `output/task-history-http-verification.json`：独立测试库 45 条带大结果/长错误的样本，经真实生产 HTTP 接口验证全部可读。摘要 8069 字节，历史页 6089/6089/1535 字节，失败筛选页 6958 字节，单项完整状态 5332 字节。原始计算结果不在这些响应中。

- `output/playwright/task-history-cancel-after.txt`：无后台模型进程的排队样本从详情取消，排队筛选降至 0 条，详情变为已取消。不是取消真实用户任务。
