# 中证800：经典策略依据与采用决定

研究日期：2026-11-08。用户要求以中证800为基准，充分利用已有技术与财务因子，自主研发；随后明确优先借鉴已经过公开研究的经典策略，并要求先完成策略与配套文档，再集中编码测试。

本文件回答“为什么研究这些策略”；可执行规则见[研发规格](../product/specs/csi800-multifactor-research.md)，实施顺序见[实施与验收计划](../csi800-multifactor-plan.md)。上一轮[简化动量实验](../deliveries/2026-11-08-csi800-study.md)独立保留，其结果不是本轮多因子组合结果。

## 1. 对“已被证明”的判断

优先采用有原始论文、公开构造方法、跨时期研究或实际指数方法论的思路。区分以下证据：公开研究支持某种因子现象；现有代码正确实现了一条规则；该规则在本地中证800样本中扣费有效；该策略取得可投资的前瞻业绩。这四件事不能互相代替。

本轮不是把某个机构的历史年化收益搬到A股，也不把长短组合的溢价直接当作只做多账户收益。所有中证800适配都单独标明，原始文献及本地实验分别记录。

## 3. 如何组合，而不是堆指标

先按经济含义分成技术与财务两条支路，再在家族内部合成。两个动量窗口、多个风险指标不能因为“数量多”就压倒盈利质量。主要比较以下问题：

1. 单独的经典动量、价值、质量，在同一池和费用下是否有效？
2. 价值＋动量、质量＋价值、质量＋价值＋动量，是否改善收益与回撤的平衡？
3. 加入保守投资和低风险后，收益是否仍保留？
4. 财务支路能否改善上一轮技术策略的高回撤；技术支路能否降低财务组合的价值陷阱和长时间落后？
5. 风险改善来自选股，还是仅来自减仓？用同暴露对照、现金比例和暴露归一收益解释，不能只比较总收益。

市场仓位开关属于A股适配层，不以它代替选股证据。比较无开关与有开关的同一组合，再加目标波动率版本。所有固定候选均完整披露，不只展示最好的一条净值。

## 5. 已核实的项目条件

- 已有技术因子目录、公开因子子集、财务指标、TTM/同比、财务可见性判断及日频本地数据因子，无需另起一套指标实现。
- 本地 `vipdoc/cw` 当前有148个`gpcw*.dat`文件名；部分为20字节占位，因此148不能当成148期有效财报。实际覆盖由下一阶段读取时逐包统计。
- 财报模型已有公告日和下一交易日可见性判断，也明确当前下载版本可能包含后续修订；“公告时间正确”不等于“当时首次披露版本已被保存”。
- GP16提供总市值序列，现有估值因子使用同日数据，不前填。实际中证800覆盖起点尚未批量核验，不能先宣称2016年起估值全部可用。
- 上一轮已经有多证券共享资金、T+1、费用、成交阻塞和15%目标限仓的离线引擎。复用成交账本，不另写一套“收益率相加”的伪组合回测。

## 6. 当前决定

采用“经典单家族 → 经典两三家族 → 技术/财务支路 → 两支路合成 → 风险控制对照”的研发顺序。先完成本轮文档与规则冻结，再集中编码和测试。模型效果由中证800同口径实验决定，既不要求一定优于文献，也不为了通过30%回撤目标反复修改观察期。
