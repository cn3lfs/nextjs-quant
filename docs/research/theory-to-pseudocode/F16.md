# F16 衍生品、carry 与微观结构

> v0 模型知识初稿，未外部核验，不构成收益验证

本稿依据模型记忆区分风险溢价、相对价值、对冲和执行工具，不依赖外部来源。Carry 是在特定价格或状态假设下的持有收益分解，不等于最终总收益；不同定义可能重复计量。本文仅为跨市场理论目录，不扩展应用市场范围，不提供真实下单、保证金或现行合约规则。

## F16.01 利差与外汇 carry

- **名称别名、类型：** Interest-rate Carry、FX Carry、套息；融资与持有利差策略。
- **理论及收益机制：** 以较低成本融资并持有较高收益资产，期待利差超过价格或汇率损失；回报可能补偿融资风险、崩盘风险及流动性风险。用远期表达外汇 carry 时，远期点已包含利率关系，不能再次把同一利差计作额外利润。
- **选取与退出：** 明确融资币种、资产币种、期限及是否对冲汇率，比较可执行利率和融资成本；可按利差排序分散持有，并在利差变化、风险预算触发或融资条件失效时退出。完全对冲后的收益需要重算，不能沿用未对冲收益假设。
- **适用与失败：** 适合融资可持续、市场流动性较好的条件；风险厌恶骤升、汇率跳变、融资召回和高收益资产违约可一次吞噬多年利差。
- **记忆不确定点：** 覆盖与非覆盖利率平价的具体推导、报价方向及不同工具损益口径需核验，本文不声称利差本身构成无风险套利。

## F16.02 展期收益与期限结构 carry

- **名称别名、类型：** Roll Yield、Roll-down、期限结构 carry；期货或债券持有收益分解与策略信号。
- **理论及收益机制：** 在给定期限结构保持方式的假设下，合约趋近到期或债券剩余期限缩短可能产生价格变化；商品期货展期与债券沿收益率曲线滚降是不同机制，不能共用同一价格公式。
- **选取与退出：** 明确期限结构快照、持有合约、换月日期及实际成交价，按预定方向选取有利结构，结构逆转或风险条件触发时退出。换月当刻买卖不同合约的价格差不是凭空实现现金利润，应与随后价格变化及持仓数量一致核算。
- **适用与失败：** 适合期限结构和交易成本可观察的市场；库存冲击、曲线形状变化、现货趋势逆行和近月流动性消失会抵消预期 carry。
- **记忆不确定点：** 不同研究对展期收益和现货收益的分解约定存在差异，正反向市场的术语需连同报价方向核验，不能把某种曲线形状解释成必赚。

## F16.03 基差 carry

- **名称别名、类型：** Basis Carry、基差持有、套保与基差暴露；持有收益信号及相对价值风险策略。
- **理论及收益机制：** 现货与衍生品价差随到期、资金供需或风险补偿变化，持有基差头寸可能获得收敛收益；这与具备完整交割路径、成本可锁定的期现套利有交叉，但并非所有基差仓位都能锁定终值。
- **选取与退出：** 先声明基差是期货减现货还是相反，统一价格、乘数、到期距离和年化方式，分别估算现货对冲与融资成本；按净差额及资金约束建立头寸，在到期、收敛或基差与资金风险越界时退出。
- **适用与失败：** 适合标的匹配、对冲可达且期限关系清晰的产品；交割错配、价格指数失真、保证金追加、抵押品折扣及提前平仓可让预计收益无法实现。
- **记忆不确定点：** 同名基差在股指、商品和数字资产中对应不同结构；基差 carry 与展期、融资利差可能重叠，正式规格需核对分解后避免重复计数。

## F16.04 永续合约资金费率 carry

- **名称别名、类型：** Funding-rate Carry、永续与现货对冲；合约资金交换收益策略。
- **理论及收益机制：** 永续合约通过定期费用交换约束与参考价格的偏离，持有收款侧并对冲方向风险，可能赚取费用减融资和交易成本；费率可翻转，预期收款不能当作固定票息。
- **选取与退出：** 根据具体合约确认正负费率的付款方向、结算时点与计算规则，再组合现货或其他衍生品对冲。按保守可得费率估计净收益，设定费用逆转、基差扩大、保证金压力和平台风险的退出条件，不把历史平均费率锁定成未来收益。
- **适用与失败：** 适合两腿流动性和资金安排可靠的研究；平台违约、提款限制、指数异常、清算、抵押品贬值和费率反转可能同时发生，方向中性不消除这些风险。
- **记忆不确定点：** 结算周期、费率上限和标记价格规则由平台与合约决定，现行规则未核验；这里只描述理论，不认可任何平台或真实交易方案。

## F16.05 隐含波动率与实现波动率比较

- **名称别名、类型：** Implied-versus-Realized Volatility、波动预测交易；含权价格比较与波动方向策略。
- **理论及收益机制：** 期权价格隐含的波动与对未来实际波动的预测存在差异时，可以研究买入或卖出波动暴露；隐含波动率取决于定价约定，过去实现波动率不等于未来实现波动率。
- **选取与退出：** 匹配标的、期限、行权价与波动测量方式，区分总体波动、偏斜和期限结构，扣除交易及对冲成本后比较。按价差收敛、到期、预测证伪或风险限额退出，方向是否对冲需单独说明；不以单一历史波动低于隐含波动直接推断期权必然高估。
- **适用与失败：** 适合期权价格与实际波动样本可靠的市场；跳跃、波动聚集、离散对冲、偏斜变化和流动性价差会令预测正确仍然亏损。
- **记忆不确定点：** 波动与方差暴露的转换及常用近似条件需核验，不同交易工具不能仅以同一波动差直接比较损益。

## F16.06 波动率风险溢价

- **名称别名、类型：** Volatility Risk Premium、Variance Risk Premium、卖保险收益；风险溢价假说与系统卖出波动策略。
- **理论及收益机制：** 投资者可能为尾部保护支付费用，使风险中性与现实分布的预期方差不同；卖方承担市场崩跌、波动跳升和流动性风险，获得的权利金不是免费收益，也不要求每段时期都有正溢价。
- **选取与退出：** 先明确卖出的对象是期权组合、方差暴露还是其他结构，预设期限、方向对冲、保证金和尾部损失上限；按固定到期轮换、风险阈值或结构失效退出。必须将极端亏损与追加资金计入结果，不能只展示多数小盈利交易。
- **适用与失败：** 适合能承受明确尾部预算的研究；市场跳空、连续波动冲击、保证金抬升和拥挤平仓会使历史胜率失去意义，止损也不保证按预设价格成交。
- **记忆不确定点：** 风险溢价符号约定、方差互换与期权复制的理论条件待核验；常见“卖波动长期赚钱”的无条件表述不被本稿接受。

## F16.07 期权组合与非线性收益结构

- **名称别名、类型：** Option Spreads、跨式、宽跨式、价差、备兑与保护组合；收益结构设计工具，单独不构成预测优势。
- **理论及收益机制：** 通过不同方向、行权价和到期日的期权组合，改变方向、波动、时间和尾部暴露。多头跨式与宽跨式购买较大波动，空头版本收取权利金并承担尾部；垂直价差限制一部分盈亏，日历价差混合期限波动与时间风险；蝶式、铁鹰偏向特定价格区域，不是所有横盘都获利。
- **选取与退出：** 备兑由现货加卖看涨形成上行受限的风险，保护性看跌购买下行保护，领口再以卖看涨部分融资。各结构均需明确腿、合约数、到期与提前退出条件，按组合总损益和风险决策，不能只看某一腿获利。
- **适用与失败：** 适合已明确目标情景与可承受收益形状的研究；偏斜、提前行权、除息、流动性及跨期限跳空可能令简单到期图失真，有限到期损失也不自动消除过程保证金压力。
- **记忆不确定点：** 中文组合名、欧式美式条件和理论最大盈亏须逐结构核验；本文不将组合名称当作完整可交易策略。

## F16.08 Delta 对冲

- **名称别名、类型：** Delta Hedging、动态方向对冲；局部风险控制与波动策略组成部分。
- **理论及收益机制：** 通过现货或相关工具抵消期权价值对标的小幅变化的一阶敏感度，减少当时的方向暴露；对冲本身不创造预期超额收益，最终损益仍受 Gamma、时间衰减、波动变化及成本影响。
- **选取与退出：** 预先确定 Delta 模型、对冲工具与比例，并选择定时或偏离阈值再对冲；期权退出、到期或风险目标变化时平衡相关头寸。跳空后的 Delta 与跳空前不同，不能假设连续、无成本对冲，也不能把最终看起来中性倒推为全程无风险。
- **适用与失败：** 适合对冲工具流动性充分且风险敏感度可估的场景；跳跃、价格限制、模型误差、对冲基差和高频成本会留下风险，短 Gamma 在趋势急变时可能不断追涨杀跌。
- **记忆不确定点：** 不同报价模型、分红与行权条件下 Delta 定义需核验；所谓 Gamma scalping 收益必须与权利金和时间成本合并理解。

## F16.09 订单流

- **名称别名、类型：** Order Flow、主动买卖量、成交方向不平衡；微观结构特征与短期预测假说。
- **理论及收益机制：** 主动订单的方向、持续性和规模可能反映信息、库存转移或未完成大单，引起短期价格压力；成交量只能显示发生过的交换，不能直接证明机构身份或未来意图。
- **选取与退出：** 事先定义主动方向判别、聚合窗口和相对成交强度，以当时可得逐笔信息形成信号；研究延续还是耗尽反转必须明确选择。按短持有窗口、流量逆转或冲击阈值退出，不能把交易完成后的分类信息提前使用。
- **适用与失败：** 适合逐笔数据质量高、成本和响应时延可衡量的场景；买卖方向误判、拆单、隐藏流动性、虚假大单叙事及竞争延迟会抹去优势。
- **记忆不确定点：** 常见成交方向分类算法与各市场逐笔字段含义需要核验，订单流与订单簿事件不完全相同，本稿不声称仅靠“大单净流入”即可预测。

## F16.10 订单簿失衡与队列

- **名称别名、类型：** Order-book Imbalance、盘口失衡、队列压力；短期微观结构信号。
- **理论及收益机制：** 买卖侧可见深度、撤单与补单速度可能影响下一次价格变化或成交概率；挂单可以撤回，可见深度不是对未来成交的承诺，盘口优势也可能由诱导行为造成。
- **选取与退出：** 明确使用档位、深度加权、事件时间和快照年龄，区分静态深度比与动态订单流失衡；只有在信号当时可见且可按现实队列参与时研究交易。设短期时间退出、失衡逆转和点差变宽退出，不能忽略排队成交概率。
- **适用与失败：** 适合盘口连续、撮合规则清楚的研究；隐藏订单、撤单激增、跨场所价格领先、数据丢包与延迟会让表面失衡失真，预测微小价格变化也可能不足以覆盖点差。
- **记忆不确定点：** 不同论文使用的失衡公式、事件定义和队列模型不同，特定市场订单类型与优先规则需后续核验，不能照搬跨市场结论。

## F16.11 做市与库存控制

- **名称别名、类型：** Market Making、双边报价、库存偏移；流动性提供策略与库存风险管理。
- **理论及收益机制：** 在双边提供可成交报价，期望赚取有效点差或合规费用返还，同时承担逆向选择、库存价格变化及撤单不及时的风险。报价点差不等于实现收益，成交往往更容易发生在价格即将不利变化时。
- **选取与退出：** 预定公平价格估计、报价宽度、订单大小和库存限额，库存过多时改变报价以鼓励回到目标；按市场状态撤单、降低规模或对冲库存。触及库存、损失、数据可靠性或波动限制时停止新增并处理存量，不能假定总能按中间价清仓。
- **适用与失败：** 适合允许相应交易、延迟与手续费条件可支持的场景；单边行情、跳空、毒性订单流和流动性抽离可使库存损失远超点差收入。
- **记忆不确定点：** 经典库存模型假设、最优报价公式和实际做市义务需分别核验，理论最优报价不能直接代表现实可成交策略。

## F16.12 VWAP 执行

- **名称别名、类型：** Volume-Weighted Average Price Execution、成交量加权执行；订单执行算法，与作为价格锚点的 VWAP 指标分开。
- **理论及收益机制：** 将一个已决定的母单按预估市场成交量节奏分配，目标可能是接近指定窗口的市场 VWAP 并控制冲击；它优化执行而不决定证券是否值得买入。
- **选取与退出或边界：** 先明确方向、总量、窗口、价格限制及完成要求，依据历史量曲线或在线调整分配子单；窗口结束按预设余单政策结束。事后全窗口实际量不能当作事前已知曲线，是否追赶未完成量需提前确定。
- **适用与失败：** 适合数量相对流动性合理、成交节奏可估的订单；异常放量、停牌、趋势行情和量曲线变化会造成偏离，紧追基准可能增加冲击或不利选择。
- **记忆不确定点：** 实务 VWAP 算法的动态调整与成交量预测并无唯一版本，评价基准包含自身成交与否也需明确，不以跑赢一次 VWAP 证明交易信号优势。

## F16.13 TWAP 执行

- **名称别名、类型：** Time-Weighted Average Price Execution、时间均分执行；订单执行算法。
- **理论及收益机制：** 将既定总量分布在若干时间片，减少单次冲击并分散择时误差；时间均分并不会创造价格预测能力，执行价格仍受市场路径影响。
- **选取与退出或边界：** 预先确定开始结束时间、分片数量、价格限制及未成交补偿规则，可在既定约束下轻度随机化节奏；完成总量或到达终止条件后结束。按时间均分数量与以时间平均价格作为基准是两个相关概念，实际成交不保证等于该基准。
- **适用与失败：** 适合流动性较稳定且无可靠量曲线预测的执行任务；成交量低谷、持续趋势、公开可预测节奏和过多小单费用可能使结果变差，强制完成可能引发冲击。
- **记忆不确定点：** 各执行系统对未成交切片、休市和撤单的规则不同，无单一原版 TWAP；本稿只给出经济边界，不延伸到下单工程。

## F16.14 POV 参与率执行

- **名称别名、类型：** Percentage of Volume、Participation of Volume、成交量参与率；随市场成交变化的执行算法。
- **理论及收益机制：** 让订单成交量随观察到的市场量变化，试图保持约定参与程度并控制冲击；它只表达执行节奏，不能保证低成本或完成期限。
- **选取与退出或边界：** 预先定义目标参与率、观测窗口、最大总量、价格及期限限制，明确分母是否剔除自身成交；量增时加快、量减时放缓，在完成或终止条件到达时结束。若必须在截止前完成，追赶逻辑属于额外规则，需要明确其风险。
- **适用与失败：** 适合有连续成交且希望跟随可用流动性的任务；成交骤降会导致未完成，事件放量或自成交反馈可能诱发过度追单，高参与率仍会显著影响价格。
- **记忆不确定点：** 不同市场的可见成交统计及分母口径不同，目标参与率与真实成交占比之间还受排队和价格限制影响，不能把目标率当已实现结果。

### F16.07 期权组合与非线性收益结构

**v1 / C1：** [F16-S06](sources-F13-F18.md#f16-s06)目录中的腿描述与[F16-S07](sources-F13-F18.md#f16-s07)铁鹰正文辅助核验；正文图示替代文字存在与腿方向不一致处，采用明确合约腿和代数复算，不复制错误图注。以下是收益结构，不自行产生择时信号。
**A、输入：** 每股C_K=max(ST−K,0)、P_K=max(K−ST,0)，d为整个组合每股全部初始净支付（收款为负；涉及现货时已包含S0，不能再次减S0），乘数M、数量q、费用c、到期/行权类型。下表是本研究按合约现金流推导的到期净额，须再减d和c；同到期且K1<K2<K3<K4。

| 结构               | 终值或腿组合（每股）         | 区别                                                    |
| ------------------ | ---------------------------- | ------------------------------------------------------- |
| 多/空跨式          | ±(C_K+P_K)                   | 同执行价，空头损失可很大                                |
| 多/空宽跨式        | ±(P_K1+C_K2)                 | 不同执行价，中间无内在价值                              |
| 牛市看涨垂直       | C_K1−C_K2                    | 收益被价差宽度限制；熊市看跌为P_K2−P_K1                 |
| 多头蝶式           | C_K1−2C_K2+C_K3，等距        | 中心附近终值最高                                        |
| 信用铁鹰           | P_K1−P_K2−C_K3+C_K4          | 两侧有限宽度尾部，收益来自净收款                        |
| 备兑/保护看跌/领口 | ST−C_K；ST+P_K；ST+P_K1−C_K2 | 现货购买成本S0已经计入d，分别封顶、保底、同时限两端     |
| 日历               | 卖近月C(K,T1)，买远月C(K,T2) | T1时远月仍有时间价值，不能用同一到期max公式当已定净收益 |

```text
if 已持有且到预定退出日/损失限/指派事件: ALL_LEGS_EXIT_OR_SETTLE_INTENT
if 合约腿/报价/乘数/类型/资金缺失: UNKNOWN
按表指定每腿符号数量; d=全部期权与现货买腿ask金额之和-全部卖腿bid金额之和（统一每股口径）
以分段线性终值逐执行价及两端检查盈亏; 日历需T1的远月估值输入
if 没有独立方向/波动信号或人工情景批准: return PAYOFF_ONLY
仅在最大可接受损失与过程资金满足时输出COMBINATION_INTENT
一腿未成或被提前指派: PARTIAL_EXPOSURE; 重新计风险并按预案处理
```

**E：** 90/95/105/110铁鹰收2，ST100赚2、ST120亏3未扣费；保护看跌保底依赖合约有效且含保费；日历缺远月估值仅画情景。**状态/适配：** 同期结构代数可形式化；择时人工/外部信号、日历估值与提前行权未完全形式化。

### F16.08 Delta 对冲

**A、输入：** 带符号合约数n_j、每张乘数M_j、当时δ_j、股票数qS，D=qS+ΣnMδ；容许带b、最大调整Qcap、费用、定期重算间隔为A。delta来自指定估值模型或可追溯提供者，不能以未知当0。

```

### F16.12 VWAP 执行

**A、输入：** 已授权母单方向、总量Q、时段1…N、历史样本估计并冻结的量占比v_j（≥0且和1）、价格限L、已成F、未成挂单O。累计目标T_j=QΣ至j v。事后基准VWAP=Σ实际市场成交价×量/Σ量；不可将当天最终量曲线提前输入。

```

### F16.13 TWAP 执行

**v1 / C1：** [F16-S11](sources-F13-F18.md#f16-s11)正文说明时间加权目标及可能部分成交。等时间等累计目标是本研究A，不代表该券商全部规则。
**A、输入：** 母单Q、N个等长有效交易时段、限价L、已成F、未成O和截止时点。每段累计目标Q*j/N；收盘/午间休市是否计入时钟预先规定，不能临时加速掩盖偏差。

```text
if 母单撤销或截止到: CANCEL_REMAINDER; return
if 时钟/交易时段/母单缺失: return PAUSE_NEW_CHILD
到第j段: target=Q*j/N
child=max(0,target-F-O); 按限价形成子意向
实际成交更新F; 不许F+O>Q
到期未完报告UNFILLED，不默认无条件追价
```

**E：** 1000分4段累计250/500/750/1000；价格超限则目标到也可零成交；时区未知暂停。**状态/适配：** 执行组件可形式化，不保证最佳价格。

### F16.14 POV 参与率执行

**v1 / C1：** [F16-S11](sources-F13-F18.md#f16-s11)正文支持目标参与率与动态量信息，官方实现还含预测；本卡是仅用已观测量的A反应式代理。它与固定历史量曲线VWAP不同。
**A、输入：** 目标占总成交比例0<p<1、起点后其他市场参与者成交量Vother、母单Q、已成F、挂单O、限价L、截止时点。若Vother不含自己，目标己方量=p/(1−p)*Vother；若提供总量含自己则不得再次套此分母。

```text
if 母单取消或截止到: CANCEL_REMAINDER; return
if Vother/自成交识别/母单未知: return PAUSE_NEW_CHILD
target=min(Q,p/(1-p)*Vother)
child=max(0,target-F-O); 服从限价与单次上限
成交确认才更新F并从其他成交量中剔除自身
市场无新增量则不新增量目标; 不保证到期完成
```

**E：** p10%、其他成交900，己方目标100才占总量10%；错用0.1×900为90只占9.09%；无法剔除己方量不循环放大。**状态/适配：** 执行组件可形式化，实时量可靠性和反应滞后待验证。
