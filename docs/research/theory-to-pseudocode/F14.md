# F14 事件、日历与宏观

> v0 模型知识初稿，未外部核验，不构成收益验证

本稿只整理模型记忆，不引用已核验来源。事件信息必须按首次公开且研究者可获得的时点处理，公布后形成的解释不能视为提前信号。公告时间、新闻抵达时间与实际可成交时间分别记录；宏观初值、修订值及市场预期也不能混用。本家族不提供现实交易建议或固定获利窗口。

## F14.01 财报后漂移 PEAD

- **名称别名、类型：** Post-Earnings-Announcement Drift、盈余公告后漂移；财报事件效应与方向策略假说。
- **理论及收益机制：** 投资者可能未立即消化盈利惊喜，价格在公告后继续沿惊喜方向调整；风险变化、微观结构和成本也可能解释观察到的收益，不能仅凭公告后上涨确认反应不足。
- **选取与退出：** 事先定义实际盈利相对历史模型或公告前一致预期的惊喜，明确是否标准化；在事件公开后的首个可执行窗口观察或建立方向组合，按固定持有窗口、预期消化或失效条件退出。不能使用后来更新的分析师预期计算先前惊喜。
- **适用与失败：** 适合公告时点和预期记录可靠的证券；公告已充分预期、流动性不足、费用覆盖漂移、同期指引反向及市场跳空均可能使方向失效。
- **记忆不确定点：** 原始研究的惊喜指标、跳过窗口和持有区间存在不同版本，需要核验；本稿不主张某个期限普遍有效。

## F14.02 业绩预告、快报与盈利惊喜

- **名称别名、类型：** 业绩预告事件、Earnings Surprise、盈利预警；事件识别与方向筛选，和财报后的持续漂移分开。
- **理论及收益机制：** 预告、快报或正式报告改变市场对盈利水平及分布的判断，价格可能重新定价。同比大增不必然构成正惊喜，关键是公开信息相对事前合理预期的差异。
- **选取与退出：** 记录首次预告、修正和正式报告的先后关系，比较同口径预期，拆除非经常损益与基数效应；区间预告需预设使用中值还是保守端点。事件前押注和公开后反应是不同策略，应分别定义持有期限及预告被撤回、盈利质量下降时的退出。
- **适用与失败：** 适合信息发布时间明确、比较口径一致的场景；重复披露、提前泄露、季节差异、不可持续收益和“利好兑现”会破坏简单方向规则。
- **记忆不确定点：** 各类披露的监管阈值、最晚日期及修正义务随市场变化，本稿不依记忆给出法定规则。

## F14.03 分析师预期修正

- **名称别名、类型：** 盈利预测上调下调、Estimate Revision；预期变化因子与事件策略。
- **理论及收益机制：** 盈利预测和目标判断可能逐步吸收基本面新信息，连续修正或修正扩散或许伴随价格趋势；分析师跟随价格也会产生反向因果，修正不能自动视为领先信息。
- **选取与退出：** 保留每个时点实际发布的预测，比较相同财年及同一盈利口径，定义幅度、广度、新鲜度和覆盖人数；预测滚动到下一财年应单独处理。按修正排名或连续上修条件选择，出现反向修正、期限届满或拥挤风险时退出。
- **适用与失败：** 适合历史预测快照完整的证券池；少数机构异常值、覆盖偏差、更新频率差异及预测数据库回填会制造虚假信号，成本可能抵消小幅修正收益。
- **记忆不确定点：** 预期修正相关研究采用的聚合方式和滞后处理不统一；一致预期是供应商口径，不代表交易者当时共同掌握的唯一预期。

## F14.04 公告驱动与回购事件

- **名称别名、类型：** 公告催化、Share Repurchase、回购计划及实施；事件研究框架与资本配置事件策略。
- **理论及收益机制：** 公告可能改变现金流、股数或管理层信号判断；回购可能改善每股指标，也可能只是抵消股权稀释。计划、授权、实际成交及注销具有不同经济含义，不能统一视作买盘到来。
- **选取与退出：** 一般公告先分清事件内容、经济影响与新颖性；回购另记录资金规模、资金来源、价格限制、用途及执行进度。公开后才形成信号，按实施兑现、期限届满、撤回或估值变化退出；不得用最终回购量替代公告时已知量。
- **适用与失败：** 适合有可核查进展及明确资本用途的事件；象征性授权、高价回购、借债回购、内部人减持及执行不足均会使利好叙事失效。
- **记忆不确定点：** 不同回购形式和法律程序存在市场差异，统一的回购收益规律尚未核验；一般公告不能只凭关键词判多空。

## F14.05 分红公告与除息事件

- **名称别名、类型：** Dividend Event、分红惊喜、除息交易；资本分配事件策略，与长期红利因子不同。
- **理论及收益机制：** 分红变化可能传达现金生成和资本配置信息；除息日前后的价格变化还受机械除息、税费与投资者结构影响。领取股息本身不是无风险套利，因为证券价值相应调整。
- **选取与退出：** 区分董事会提案、批准、权益登记、除息和到账时点；以事前预期衡量增减派息，另列特别股息。公告反应策略与除息窗口策略分别设定入场、持有和成本口径，分红取消、现金来源恶化或窗口结束时退出。
- **适用与失败：** 适合事件日期和税务成本可明确的研究；预期已反映、交易拥挤、税负差异、流动性损失和价格超额下跌会超过股息所得。
- **记忆不确定点：** 现行税率、持有期限规则和除权参考价公式需按市场核验，不能依记忆给出可执行的税务或套利结论。

## F14.06 限售解禁与潜在供给

- **名称别名、类型：** Lock-up Expiry、限售股解禁、股东减持供给事件；制度事件与流动性压力假说。
- **理论及收益机制：** 可流通股份增加可能改变供给预期，但获得出售资格并不等于实际卖出；股东成本、意愿、约束和市场承接共同决定影响。
- **选取与退出：** 基于当时已公开解禁安排识别规模、相对流通盘比例、持有人结构及已披露减持计划；分别研究提前预期与实际实施窗口。预设事件前后持有期、实际供给验证条件和计划变化退出，不能按后来的实际减持识别先前“必跌”样本。
- **适用与失败：** 适合制度和持有人信息透明的证券；长期持有承诺、价格过低不愿出售、事件早已消化及强势需求会令供给冲击不发生，单一解禁日期不构成完整策略。
- **记忆不确定点：** 解禁与减持限制、预披露要求及可售额度受现行规则影响，后续必须核验具体市场制度，不能用统一比例推算实际卖压。

## F14.07 并购、重组与事件套利

- **名称别名、类型：** Merger Arbitrage、Risk Arbitrage、重组催化；条件事件相对价值策略及事件方向策略。
- **理论及收益机制：** 交易对价与目标价格的差额补偿等待、融资和交易失败风险；现金收购与换股收购的暴露不同，重组故事则未必有可锁定对价，不能统称无风险套利。
- **选取与退出：** 以已公布条款识别现金、换股比例、交割条件、监管和股东批准风险；现金交易研究目标股折价，换股交易另研究收购方对冲。按交割、条款变化、价差收敛、失败或期限上限退出，并事前估计失败后的损失与双腿可交易性。
- **适用与失败：** 适合公开条款清楚、对价可估且允许必要对冲的场景；反垄断否决、融资中断、竞价变化、停牌与借券召回可能造成大幅损失。
- **记忆不确定点：** 复杂对价、或有支付和各地要约规则不在本稿确定范围；并购完成概率不能由当前价差直接无条件反推。

## F14.08 政策催化

- **名称别名、类型：** 政策事件、监管与财政产业催化；事件解释框架及条件策略。
- **理论及收益机制：** 政策改变需求、成本、竞争资格或资金条件，可能导致盈利预期及折现率重估；政策方向与上市公司利润之间存在多环节传导，不能将支持行业直接等同于股东受益。
- **选取与退出：** 区分征求意见、正式发布、执行细则和实际落地，对照事前预期提炼新增内容，再映射收入成本与竞争格局。可设事件窗口或跟踪兑现里程碑，在执行低于假设、受益逻辑证伪、窗口结束时退出；不得事后挑上涨行业补写受益链条。
- **适用与失败：** 适合政策有明确实施对象和可观测经营传导的场景；口号无增量、政策反复、盈利让利、市场提前交易及受益范围过宽会削弱信号。
- **记忆不确定点：** 不存在跨时期通用政策利好表；具体政策真实性、生效时间与法规含义均需后续查证，本稿不作现行政策判断。

## F14.09 新闻情绪与信息新颖性

- **名称别名、类型：** News Sentiment、新闻情感、舆情因子；文本信号与事件筛选方法。
- **理论及收益机制：** 新信息与投资者关注可能推动价格反应或过度反应；文本情绪只是语言特征，正面措辞不必然增加现金流，媒体跟随股价也会形成假预测关系。
- **选取与退出：** 先明确新闻首次出现时间、来源可靠性、重复转载和实体归属，再区分事实变化、评论及传闻；基于预先选定的方向持续或反转假说构造信号。按信息衰减窗口、事实撤回或相反证据退出，不能观察收益后才选择顺势还是反向。
- **适用与失败：** 适合时间戳与全文历史可追溯的来源；转载伪新颖、讽刺与否定误判、媒体偏好、付费信息延迟和情绪拥挤会令效果不稳。
- **记忆不确定点：** 情绪词典和模型的适用语言、训练时期及校准标准需核验；本文不声称任何模型已能可靠识别可交易新闻。

## F14.10 指数纳入、剔除与调仓

- **名称别名、类型：** Index Rebalance、指数事件效应；规则驱动资金流与事件策略。
- **理论及收益机制：** 跟踪资金可能在生效附近调整持仓，提前交易者试图捕捉预期需求及随后反转；可预测性吸引竞争，也会提前消耗收益。新增成分与权重微调的冲击不可等同。
- **选取与退出：** 以正式公告或当时可复现的规则预测识别事件，严格区分预测名单和实际名单；估计相对成交容量的潜在需求，预设公告、生效及生效后窗口。名单改变、资金流不兑现、窗口结束或冲击超过预算时退出。
- **适用与失败：** 适合指数规则、公告日期及可交易性明确的标的；预测错误、停牌、涨跌停、收盘竞价拥挤和被动资金提前执行可使推断失效。
- **记忆不确定点：** 各指数委员会裁量、缓冲机制、自由流通权重与生效安排不同，不能用一套记忆规则代替官方方法和当期公告。

## F14.11 季节性、月末与日历效应

- **名称别名、类型：** Calendar Anomaly、月末月初、星期及节日前后效应；时间条件统计假说。
- **理论及收益机制：** 现金流、机构考核、结算和行为习惯可能造成某些时段收益分布差异；日历相关性本身不是因果，重复检验很容易发现偶然模式。
- **选取与退出：** 预先冻结市场日历、交易日定义、时区及窗口，分别研究月末、月初、节前后等具体假说，明确盘中、隔夜或全日收益。策略只在指定窗口暴露并按日历退出，若样本外效果衰减或成本超过预期则暂停，不能事后扩缩窗口。
- **适用与失败：** 适合跨时期重复事件足够多且制度稳定的市场；假期变更、月份样本少、税制与结算改变、竞争套利和异常年份会使规律消失。
- **记忆不确定点：** 各效应的最初定义、市场覆盖与当前有效性尚未核验，本文不把流传口诀或特定月份涨跌当可靠事实。

## F14.12 经济周期与信用周期

- **名称别名、类型：** Business Cycle、Credit Cycle、复苏繁荣衰退框架；宏观状态识别与资产配置依据。
- **理论及收益机制：** 增长、通胀、融资供给与资产负债表约束会影响盈利、折现率及违约风险，资产对不同状态的敏感度可能不同；经济周期与信用周期不必同步。
- **选取与退出：** 预设可在当时获得的增长、通胀、信贷及金融条件指标，用变化方向或明确阈值识别状态；依据已登记资产暴露规则调整权重，状态证据改变时退出或转配。应保留不确定状态，不把事后公布的衰退起止当实时可知标签。
- **适用与失败：** 适合跨资产、中长期的情景研究；数据滞后与修订、政策反应、供应冲击和市场提前折现会导致状态正确但交易方向错误。
- **记忆不确定点：** 常见四象限、信用脉冲与各周期学派定义不同，阈值及资产对应关系需要分别核验，没有唯一通用周期时钟。

## F14.13 宏观趋势与全球宏观

- **名称别名、类型：** Macro Trend、Global Macro；跨资产主题研究与方向策略框架。
- **理论及收益机制：** 利率、通胀、汇率、财政和国际资本流动的持续变化可能引发资产重估；宏观趋势可由基本面判断，也可由跨资产价格趋势识别，两者的信息与风险来源不同。
- **选取与退出：** 将宏观假说明确为驱动变量、受影响资产及可证伪路径，比较预期差而非仅判断数据好坏；选定工具、持有期限与风险限额，按催化兑现、价格保护或宏观前提失效退出。价格趋势版本应另按既定趋势规则处理，不借宏观叙事事后解释。
- **适用与失败：** 适合有流动性、风险可量化的跨资产研究；政策逆转、关联关系改变、过早交易、杠杆及多头寸共享同一美元或利率风险会放大损失。
- **记忆不确定点：** 全球宏观不是单一作者或固定公式，具体因果链与历史案例尚未核验，本稿仅保留方法边界。

## F14.14 战略与战术资产配置

- **名称别名、类型：** SAA、TAA、战略配置与战术偏离；组合决策层，通常不提供单证券买卖优势。
- **理论及收益机制：** 战略配置通过长期风险承担和分散获取资产回报；战术配置试图利用估值、宏观或趋势变化调整短中期暴露。两者的期限、基准和评价标准不同，不能把战术收益归于战略分散。
- **选取与退出：** 战略层先确定目标、期限、负债与容忍风险，设资产范围及长期权重；战术层预先规定信号、可偏离区间和恢复基准条件。定期或阈值再平衡，目标变化才修订战略权重，战术假设失效则撤回偏离。
- **适用与失败：** 适合能持续执行并清楚负债需求的组合；长期参数不稳定、过度调仓、资产名义不同但风险相同、成本和税费会削弱结果。
- **记忆不确定点：** 各机构的期限分界和配置模型不同，无统一最佳资产比例；战略、战术和风险平价之间仅有交叉而非等义。

## F14.15 全天候配置

- **名称别名、类型：** All Weather、增长与通胀情景平衡；跨资产风险配置理念及其不同实务变体。
- **理论及收益机制：** 不同资产对增长、通胀及其预期变化的暴露不同，通过分散经济环境敏感度，试图降低依赖单一情景的程度。目标是风险平衡，并不意味着任何天气都上涨或没有回撤。
- **选取与退出：** 先定义经济情景和资产风险作用，再配置股票、利率、通胀敏感等暴露；是否使用杠杆、风险平价和何种再平衡规则需单独声明。环境识别不必直接触发择时，资产角色变化、约束触发或定期再平衡才引起调整。
- **适用与失败：** 适合跨资产分散研究；股债同步下跌、通胀冲击、融资成本上升及历史相关性失效会压缩保护效果，高债券风险预算可能隐藏久期集中。
- **记忆不确定点：** 机构原始全天候方法与大众固定比例简化版本不能等同，具体权重、杠杆和调仓规则未核验，不在本稿擅自给出“官方配方”。

**E：** 明确资产受益假说且历史价格同向可研究；经济好但超预期不足或价格反向时不选；宏观“好坏”无资产映射时UNRESOLVED。**状态/适配：** 人工因果判断+A；待检验是否仅重复时序动量。

### F14.14 战略与战术资产配置

**v1 / C1：** [F14-S11](sources-F13-F18.md#f14-s11)正文区分不依赖预测的All Weather与主动Pure Alpha；只支持层级区分，不给出本卡权重。保留v0，战略权重不能用战术失误临时重命名。

**A1、输入：** 经目标约束确定的基准w0、各资产允许偏离b、明确已定义信号s∈[−1,1]、风险与资金上限；战术α为A。现金承接剩余，负权重禁用版本固定为多头。

```text
if w0/风险目标未明确: UNRESOLVED
if 战术信号缺失: deviation=0; 不重写w0
else: deviation_i=clip(alpha*s_i,−b_i,b_i)
desired_i=w0_i+deviation_i
target=最小化sum((w_i-desired_i)^2)，约束w_i>=0、sum(w)<=1、abs(w_i-w0_i)<=b_i及预定风险限
if 约束不可行: 基准w0合法则return TARGET(w0)，否则return UNRESOLVED
复核全部边界后将余量给现金；到调仓日先减后加，战术失效恢复合法w0
```

**E：** w0股票0.5、b0.1，最大升到0.6；不能因牛市强就把上限改成1；长期目标未知时不优化。**状态/适配：** A下可形式化，基准需人工目标；资金冲突由统一约束处理，比较基准后的净贡献待验。

### F14.15 全天候配置

**v1 / C1：** [F14-S11](sources-F13-F18.md#f14-s11)原机构正文支持对增长和通胀预期意外进行风险平衡，并强调无需预测下一环境。补充v0：固定大众比例不是机构原配方；本卡不推断其实际专有权重。

**A1、输入：** 人工明确的四环境资产子篮子、子篮子历史收益与sigma_j>0、总杠杆上限1、再平衡阈值b。A采用四篮子逆波动权重近似，未考虑相关性时不称精确等风险贡献。

```text
if 任何环境篮子角色未论证或sigma缺失: UNRESOLVED
raw_j=1/sigma_j; weight_j=raw_j/sum(raw)
将重复底层资产的权重相加; 检查集中与现金约束
if 约束不可满足: NO_NEW_ENTRY; 不暗增杠杆
if 实际权重偏离目标>b: REBALANCE_INTENT先减后加
输出环境暴露说明; 不根据事后赢家切换篮子
```

**E：** 四篮子同波动则各25%只是A近似；四篮子都持同一种长债不算环境分散；缺通胀敏感资产证据则UNRESOLVED。**状态/适配：** 代理可形式化，原机构策略未复现；股债同跌、融资及角色失效是必要反证。
