## 怎样理解“结合权威书籍”

能取得原作者相关正文或合法书籍节选的内容，按实际章节作校订。仅有出版社目录时，只据此定位书籍，不据此认证规则。作者公开规则、原始论文、原作者博客或官方技术定义可以支持各自的具体命题，但它们与全书审读分别记账。

原作者材料优先用于回答“这个方法到底怎样定义”，不自动回答“今天应用在沪深是否仍有费用后优势”。书中的历史案例、作者的获利陈述、比赛成绩、网站宣传以及研究者设计的数字例子，都没有被转成当前系统的实证业绩。

遇到多种版本时，保留版本差异，不从中事后选择最有利的规则。没有明确原始出处的龙头/情绪术语、争议流派和部分平台指标，也保留在目录内；其证据不足与可研究的代理定义分别标记。

## 阅读一张卡时的核对顺序

1. 先看 V0，了解模型原有认识和不确定点。
2. 再看来源支持的命题与校订，点击来源 ID 查阅读深度。
3. 区分来源支持的 R 与本研究为了明确规则而加入的 A。
4. 按伪代码检查成立、失效、缺数据和无法成交的分支。
5. 最后看形式化边界和反证条件；人工证据节点不能被省略为自动信号。

来源尚未取得的细节标为 `UNVERIFIED_SOURCE`；需要人工裁定或输入无法确定时标为 `UNRESOLVED/UNKNOWN`。这些标记不是遗漏后的免责语，而是研究结论的一部分：本轮明确交付已确定的部分和仍不能确定的部分，不虚构闭合规则。
