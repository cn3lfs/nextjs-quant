# F02 道氏与经典趋势结构

状态：v0 模型知识初稿，未外部核验，不构成收益验证。

本文件仅用模型知识形成初稿；原著、作者版本和通行解释尚未核验。趋势结构的历史发生位置与实时确认时间不同，后续形式化必须保留这一区别。以下不预设拐点窗口、幅度或成交量阈值。

## F02.01 道氏理论（Dow Theory）

- **类型**：市场趋势解释与确认框架。
- **核心原理与潜在收益机制**：市场价格反映已知影响，趋势具有延续性；主要趋势由连续的高低点推进及相关市场确认来判断，成交量作为辅助证据。常见表述还区分趋势层级和主要趋势发展阶段，不能把全部内容缩减为一次均线交叉。潜在收益来自参与持续的主要趋势并容忍中途回撤。
- **交易逻辑或边界**：在主要趋势获得确认后顺势，在结构反转获确认时退出；原理论不是具有唯一窗口和订单规则的完整机械系统。确认通常晚于最低点或最高点，这是可观察证据的代价。
- **适用与失败环境**：趋势延续且市场有代表性时较适合；宽幅震荡、确认指数结构变化或急速反转可能导致反复迟到。
- **模型不确定点**：不同作者整理的原则、收盘价与盘中极值取舍、反转确认细节均需原著核验；不能把后来的简化规则直接归于原作者。

## F02.02 趋势层级（Primary / Secondary / Minor Trends）

- **类型**：多时间尺度的结构描述方法。
- **核心原理与潜在收益机制**：同一价格路径可同时存在较长趋势、反向调整和更短波动，短期下跌未必否定较长上升。该层级有助于避免把持仓周期与信号周期混用，潜在价值来自让风险承担与目标趋势相匹配，本身不创造方向优势。
- **交易逻辑或边界**：先固定主要决策尺度，再区分该尺度的调整与反转；可以研究大趋势同向的小级别入场，但需独立确认小级别信号。退出不能在亏损后擅自扩大到更长尺度。
- **适用与失败环境**：嵌套趋势较清晰时有助于控制噪声；尺度间频繁冲突、急速结构跃迁和过密观察容易导致选择性解释。
- **模型不确定点**：原始层级是否有严格时间范围、不同尺度如何客观对应待核验；周线与日线不是天然等价于某个理论层级。

## F02.03 指数相互确认（Intermarket / Average Confirmation）

- **类型**：道氏框架中的交叉验证规则。
- **核心原理与潜在收益机制**：经济活动相关的市场平均指数若共同创出对应结构突破，趋势判断比单一指数孤立变化更一致；未确认代表证据不足，而非自动产生反向交易。潜在作用是过滤局部推动形成的假趋势，代价是延迟和漏失。
- **交易逻辑或边界**：需事先选定具有经济关联的指数、各自比较的转折点以及允许的确认时间关系；一方先突破时等待或保持待定，不能用未来另一方突破回填早期信号。
- **适用与失败环境**：两个指数对经济活动具有互补代表性时较有意义；产业结构迁移、指数成分集中或两者高度重复会削弱确认价值。
- **模型不确定点**：经典工业与运输平均指数的原始确认方式需核验；迁移到沪深指数或行业指数属于另建假设，不能宣称已被经典理论直接验证。

## F02.04 支撑与阻力（Support / Resistance）

- **类型**：价格位置与供求反应的描述工具。
- **核心原理与潜在收益机制**：历史交易密集区、显著高低点或反复转折区域可能影响持仓盈亏、挂单和预期，从而使价格再次接近时出现反应。支撑阻力更适合看作区域；反复测试既可能确认关注度，也可能消耗承接，不能先验认为测试越多越强。
- **交易逻辑或边界**：可分别研究区域内拒绝后的反转、突破后的延续和突破回测，三者应保持独立触发条件；退出依据区域被有效穿越或原假设失效，角色互换需要新证据。
- **适用与失败环境**：关注点稳定且流动性正常时较易观察；跳空、基本面重估或拥挤止损可能一次穿透区域。
- **模型不确定点**：区域宽度、触碰次数、有效突破与失效定义待确定；不能事后挪动水平线来吸收不符合判断的价格。

## F02.05 趋势线（Trendline）

- **类型**：趋势斜率与结构约束工具。
- **核心原理与潜在收益机制**：连接同类、已确认的拐点描述价格推进方向，后续接近线附近的反应被用于观察趋势是否维持。趋势线只概括所选点与坐标尺度，不是价格必守的物理约束；潜在收益来自延续或破坏某个既有趋势假设。
- **交易逻辑或边界**：可研究顺势回踩、破线反转或破线后的回测；必须先确定连接点与有效时间。穿线本身不必然意味着主要趋势逆转，退出应与交易原始尺度一致。
- **适用与失败环境**：斜率较稳定的趋势中更易形成一致判断；抛物线加速、跳空与震荡会频繁破线。
- **模型不确定点**：采用影线还是收盘价、线性还是对数坐标、允许多少穿越及连接点选择均未确定；动态重画必须保留旧版本，避免事后完美拟合。

## F02.06 价格通道（Price Channel）

- **类型**：趋势范围与边界描述工具。
- **核心原理与潜在收益机制**：围绕趋势方向形成上下边界，描述价格相对推进路径的偏离。平行趋势通道、回归通道及滚动最高最低价通道构造不同；本节以由结构点构成的几何通道为主，Donchian 主归属 F04。潜在收益来自趋势内回摆或边界突破后的再定价。
- **交易逻辑或边界**：顺势边界回踩、逆势边界减仓和出通道后延续是不同假设；事前确定边界、进入时点和破坏条件，不能同一突破同时被解释为追涨和做空依据。
- **适用与失败环境**：斜率与波幅稳定时较有描述力；趋势加速、波幅扩张及水平震荡会改变通道性质。
- **模型不确定点**：上、下边界对应点的选择、是否强制平行及重建条件需核验或形式化；通道宽度不能由完整未来区间反推。

## F02.07 Livermore 关键点与领涨股（Pivotal Points / Leaders）

- **类型**：结合大势、关键价位与股票选择的实务体系。
- **核心原理与潜在收益机制**：等待市场或重要股票在关键位置给出方向证据，再跟随真正有力量的领涨股；关注价格对事件的实际反应，而不是仅凭观点提前下注。收益假设是重要趋势由相对强势品种率先体现，关键点后的跟随行为使走势延续。
- **交易逻辑或边界**：区分延续关键点与反转关键点，在突破得到市场行为支持时介入，判断错误时退出；盈利后加码和试探仓属于管理规则，不能与不断摊低亏损成本混淆。
- **适用与失败环境**：主要趋势清晰、领涨结构稳定时较匹配；假突破、领涨快速切换和过度集中会恶化结果。
- **模型不确定点**：不同著作、传记及后世归纳中“关键点”“正常回撤”和领涨股定义可能不同；精确规则、作者归属及加仓限制须逐条核验。

## F02.08 Weinstein 四阶段（Stage Analysis）

- **类型**：中期趋势阶段与选股框架。
- **核心原理与潜在收益机制**：将走势区分为筑底、上升、顶部和下降四种阶段，常结合较慢均线方向、价格位置、成交量和相对强弱观察。潜在收益来自在底部转向上升阶段时参与，在顶部转弱或进入下降时降低风险；阶段名称本身不保证转移按完整顺序发生。
- **交易逻辑或边界**：关注底部整理向上突破及上升阶段内的续行机会，退出依据阶段恶化和保护规则；对做空下降阶段需另行考虑市场可行性。图上事后清晰的底部不能视为当时已确认。
- **适用与失败环境**：中期趋势持续且成交量有解释力时较合适；震荡反复切换、快速 V 形转折和缺乏流动性时可能滞后。
- **模型不确定点**：原始均线口径、阶段子分类、相对强弱和量能要求待核验；不把常见周线周期当作已确认的强制阈值。

## F02.09 高低点序列与市场结构（Swing Structure）

- **类型**：通用趋势结构描述，不专属于某一学派。
- **核心原理与潜在收益机制**：依次抬高的高点与低点描述上升结构，依次降低描述下降结构；高低点冲突可能形成区间或转变。潜在收益来自结构延续，但其有效性取决于拐点如何当时确认，不能把任意视觉波峰自动视为信息充分的交易点。
- **交易逻辑或边界**：可研究突破前高、回踩守住前低或相反方向结构破坏；必须区分候选拐点、确认拐点与确认延迟。一个低点被跌破是否足以反转，应由事前规则决定。
- **适用与失败环境**：波段分离清晰时较直观；噪声、极端跳空、内包行情与结构嵌套会产生多种合法解释。
- **模型不确定点**：拐点确认方式、同价高低点处理、嵌套结构选择与“趋势破坏”和“新趋势成立”的关系尚未固定；不借用未来 K 线抹平历史路径。

### F02.01 道氏理论

- **C1 来源与 v1 校订**：[F02-S01](sources-F01-F06.md#f02-s01)、[F02-S02](sources-F01-F06.md#f02-s02)。Hamilton 原书支持三层运动和平均指数相互印证；Rhea 获许可转载承认理论并非必胜。纠正 v0 的泛化：量能不可当作所有道氏版本共同的硬门槛。
- **输入与参数来源**：两个事前选定指数的完成收盘、SW(k)结构；k、确认间隔w及市场迁移均为A。
- **R1 / A1 规则**：R1 趋势判断需多证据；A1 用两指数同时存在抬高高低点代表多头过滤，不冒称完整Rhea系统。

```text
P1 对每个指数计算最近两个已确认高点H1,H2与低点L1,L2
P2 up[i] = H2>H1 且 L2>L1；down[i] = H2<H1 且 L2<L1
P3 任一指数缺点或确认尚未完成：return UNKNOWN
P4 两指数均up：return FILTER(多头结构)
P5 两指数均down：return FILTER(空头结构/多头风险)
P6 其余return WAIT；不由单指数突破反推另一指数已确认
```

- **E 正例 / 反例 / 缺失例**：正：两个指数同向抬高高低点→多头过滤；反：一升一降→WAIT；缺：第二指数历史不足→UNKNOWN；歧义：两套k得出不同结构须分别登记。
- **形式化状态、市场适用与待验证点**：A下可形式化组件；原典研究对象为当时美国平均指数，迁移沪深并非原法认证。

### F02.02 趋势层级

- **C1 来源与 v1 校订**：[F02-S01](sources-F01-F06.md#f02-s01)、[F02-S02](sources-F01-F06.md#f02-s02)。保留三层并存；Rhea转载给出次级反应通常时长与幅度，Schannep注释强调不应机械硬化，二者分开归属。
- **输入与参数来源**：完成的长/中/短三个频率OHLC、各自SW(k)，频率和k为A。
- **R1 / A1 规则**：R1 较短反向波动不必否定较长趋势；A1 同一结构定义分别用于三个预先固定频率，输出状态向量。

```text
P1 按预登记三个频率聚合，仅使用各自已收盘行情
P2 每个频率读取H1,H2,L1,L2，缺失则该层UNKNOWN
P3 H2>H1且L2>L1记UP；同时降低记DOWN；否则RANGE
P4 长层UP、中层DOWN记候选回调，不能称回调已经结束
P5 长层DOWN时不得以短层UP改写长层结果
P6 return FILTER(长,中,短)，不自动产生入场
```

- **E 正例 / 反例 / 缺失例**：正：周线上升而日线回落→回调候选；反：长层自身高低点降低→原上升假设不再满足；缺：本周未完成→沿用此前完成周而非预知周收盘。
- **形式化状态、市场适用与待验证点**：A多尺度过滤；保留确认延迟。次级反应的原典通常范围不是不可违背的自然常数。

### F02.03 指数相互确认

- **C1 来源与 v1 校订**：[F02-S01](sources-F01-F06.md#f02-s01)、[F02-S02](sources-F01-F06.md#f02-s02)。支持一方运动需另一方证据；保留 v0。当前只复现确认思想，不把Schannep现代扩展当作Hamilton原话。
- **输入与参数来源**：两指数各自已冻结阻力U[i]、本根与前根完成收盘、候选开始时刻、有效期w（A）。
- **R1 / A1 规则**：R1 不确认不同于做空；A1 两指数在w内越过各自边界且首个未失效才输出确认，超时重新准备。

```text
P1 任一边界不是事前冻结或数据缺失：return UNKNOWN
P2 若任一已登记候选年龄>w：清除两候选并使本组U失效，return WAIT；仅新确认边界可重新准备
P3 若已登记指数C[i]<=U[i]，取消该指数的候选确认
P4 无候选的指数首次满足Cprev[i]<=U[i]<C[i]时登记SETUP及确认时刻
P5 若两指数候选均有效、各自年龄<=w且时刻差<=w：return FILTER(CONFIRMED)
P6 仅单方成立：return WAIT，不逆向开仓
```

- **E 正例 / 反例 / 缺失例**：正：A先破、B随后破且A保持→确认；反：B突破前A跌回→未确认；缺：B停牌缺收盘→UNKNOWN；歧义：不同经济含义指数不能只因相关性高随意替换。
- **形式化状态、市场适用与待验证点**：A确认流程闭合；w与边界定义需前推验证，晚确认可能损失趋势初段。

### F02.04 支撑阻力

- **C1 来源与 v1 校订**：[F02-S03](sources-F01-F06.md#f02-s03)。Murphy作者文章支持前期反应高低点及突破后的角色变化；保留v0，区域宽度与有效性并未由本文唯一规定。
- **输入与参数来源**：已确认支撑p、完成OHLC、容差δ>0、有效期w，均为A形式化。
- **R1 / A1 规则**：R1 历史位置可作观察；A1 仅给支撑拒绝信号，不混用突破策略，区域[p-δ,p+δ]事前冻结。

```text
P1 若p尚未确认或已过有效期w：return WAIT
P2 若必要OHLC缺失：return UNKNOWN
P3 若C[t]<p-δ：return FILTER(支撑失效)
P4 若L[t]<=p+δ 且 L[t]>=p-δ 且 C[t]>p+δ：return SIGNAL(拒绝确认)
P5 曾深穿p-δ后收回属于另一个假突破模型，本卡不触发
P6 其余return WAIT；宿主另定入场、保护与退出
```

- **E 正例 / 反例 / 缺失例**：正：探入支撑区后收在上沿之外→信号；反：收盘低于下沿→失效；缺：支撑仅为人工回看画线无确认时刻→UNKNOWN。
- **形式化状态、市场适用与待验证点**：A组件；支撑不等于订单簿真实需求，需与无区域基准比较。

### F02.05 趋势线

- **C1 来源与 v1 校订**：[F02-S03](sources-F01-F06.md#f02-s03)。作者文章区分两点画线和至少第三次触及的验证；补充v0：本代理把第三触点单列，而非两点即可宣称充分验证。
- **输入与参数来源**：两个已确认低点(i1,p1),(i2,p2)、线性坐标、δ、k（A）。
- **R1 / A1 规则**：R1 趋势线是连接结构点的观察；A1 p2>p1才研究上升支撑线，线冻结后等待第三次接近且收回，不动态追着价格改线。

```text
P1 若i2<=i1或p2<=p1或端点未确认：return WAIT
P2 a=(p2-p1)/(i2-i1)；line(t)=p2+a*(t-i2)
P3 若数据不足：return UNKNOWN
P4 若C[t]<line(t)-δ：return FILTER(破线)
P5 若t晚于第二点确认且abs(L[t]-line(t))<=δ且C[t]>line(t)：return SIGNAL(第三触点)
P6 其余return WAIT；新画线形成新候选，不改旧判断
```

- **E 正例 / 反例 / 缺失例**：正：第三次回踩冻结线后收回→信号；反：收盘跌穿线及容差→破坏；缺：第二低点右侧尚未确认→WAIT；歧义：对数坐标结果不同需另登记。
- **形式化状态、市场适用与待验证点**：A几何组件；原著对不同坐标和可成交保护没有统一机械定义。

### F02.06 价格通道

- **C1 来源与 v1 校订**：[F02-S03](sources-F01-F06.md#f02-s03)。Murphy正文支持趋势线思想，但本次未核到其通道完整章节；保留v0，以下平行通道为A，通道原法细节标UNVERIFIED_SOURCE。
- **输入与参数来源**：按F02.05冻结下边线a*t+b；形成期已知高点集合；δ与有效期w为A。
- **R1 / A1 规则**：A1 上边线取同斜率且覆盖形成期高点的最小截距；输出通道位置，避免把回归与突破假说混为一条指令。

```text
P1 若下边线未固定或形成期不完整：return UNKNOWN
P2 bUpper=max(形成期每根H[i]-a*i)；形成后冻结
P3 lower=a*t+b；upper=a*t+bUpper
P4 若upper<=lower：return UNKNOWN
P5 C[t]>upper+δ记ABOVE；C[t]<lower-δ记BELOW；否则INSIDE
P6 return FILTER(位置,A,UNVERIFIED_SOURCE)，不自动逆势交易
```

- **E 正例 / 反例 / 缺失例**：正：收盘在已冻结通道内→INSIDE；反：越上轨→ABOVE而非同时卖出与追买；缺：上轨由未来最高点确定→UNKNOWN。
- **形式化状态、市场适用与待验证点**：A位置组件；通道是否带来额外信息、频繁重建与过拟合仍需研究。

### F02.07 Livermore关键点与领涨股

- **输入与参数来源**：已确认并冻结的阻力U与低点S、二者组成候选的首次可知时刻τ、股票与市场过去n期回报、候选有效期w（A）；本代理将完成收盘跌破S定义为准备结构失效。
- **R1 / A1 规则**：R1 等待关键点；A1 以相对收益为领涨代理、收盘越U触发，跌破S退出；不称精确复现，未核细节UNVERIFIED_SOURCE。

```text
P1 若缺数据或U/S未确认：return UNKNOWN且保留已有保护

```

- **E 正例 / 反例 / 缺失例**：正：相对强于市场且突破已确认U→入场意图；反：突破无延续并破S→退出；缺：无市场对照→UNKNOWN；歧义：这不是原著全部关键点记账法。
- **形式化状态、市场适用与待验证点**：A简化策略；领涨代理、止损与市场迁移需验证，原作者获利陈述不作业绩证明。

### F02.08 Weinstein四阶段

- **C1 来源与 v1 校订**：[F02-S05](sources-F01-F06.md#f02-s05)。只读到1988原书书目与目录，不能据此核验阶段细则；v0保留未核验身份，以下明确A代理与UNVERIFIED_SOURCE。
- **输入与参数来源**：完成周线C、n周SMA、斜率比较间隔d、平坦容差ε、此前确定UP/DOWN状态；n等全部A。
- **R1 / A1 规则**：A1 用价格/均线/斜率区分趋势；近乎平坦时须依据此前趋势区分筑底与顶部，起始不明则UNKNOWN。输出过滤，不完整复制原法。

```text
P1 若完成周或n+d期样本不足：return UNKNOWN
P2 M=SMA(C,n)；s=(M[t]-M[t-d])/M[t-d]
P3 若C[t]>M且s>ε：stage=2
P4 否则若C[t]<M且s<-ε：stage=4
P5 否则若abs(s)<=ε且此前确定趋势为DOWN：stage=1
P6 否则若abs(s)<=ε且此前确定趋势为UP：stage=3
P7 否则stage=UNKNOWN；return FILTER(stage,A,UNVERIFIED_SOURCE)
```

- **E 正例 / 反例 / 缺失例**：正：已知下降后均线走平→筑底代理；反：价格仍在下降均线下方→阶段4；缺：起始平坦却无此前趋势→UNKNOWN；歧义：阶段1与3不能仅靠当下横盘区分。
- **形式化状态、市场适用与待验证点**：A过滤器；30周等通行值未在本轮原著正文核定，故不硬编码。需补原书量能、相对强弱及子阶段。

### F02.09 高低点序列与结构

- **C1 来源与 v1 校订**：[F02-S02](sources-F01-F06.md#f02-s02)。Rhea转载支持高点和低点的相继推进；保留v0。具体拐点确认算法属于A，不归于Rhea。
- **输入与参数来源**：完成OHLC、左右k根（k>=1，A）、价格口径；输出拐点发生与确认时刻。
- **R1 / A1 规则**：A1 在i+k时刻才能确认i；严格极值不接纳并列；同型后续更极端点建立新候选，不改已冻结交易锚点。

```text
P1 在t仅检验i=t-k；若i左侧不足k根：return UNKNOWN
P2 hi = H[i]严格大于[i-k,i+k]其余高点
P3 lo = L[i]严格小于[i-k,i+k]其余低点
P4 hi与lo同真：记AMBIGUOUS不决定先后；否则记录对应点(i,t)
P5 读取最近交替结构的H1,H2,L1,L2；不足则UNKNOWN
P6 H2>H1且L2>L1记UP；都降低记DOWN；否则RANGE
P7 return FILTER(结构及确认时间)，原决策不被新候选改写
```

- **E 正例 / 反例 / 缺失例**：正：i低点经右侧k根后确认，再计结构；反：确认前出现更低价，原候选不成立；缺：窗口缺根→UNKNOWN；歧义：一根同时高低极端无法从OHLC知先后。
- **形式化状态、市场适用与待验证点**：A结构组件；确认延迟与k敏感，图上历史低点不能回填为当时信号。
