# 研究与伪代码约定

本约定只统一阅读与交易逻辑，不设计软件架构、数据库或运行时接口。每章可引用这里的共同约束，不重复长篇工程说明。

## 四层关系

1. **理论**解释市场为何可能呈现某种规律。有效市场、行为金融、反身性等通常不能单独给出买卖点。
2. **信号/筛选组件**识别条件，如均线、RSI、财务比率；它们必须搭配退出与资金约束，才能成为完整交易方案。
3. **策略**明确在何种市场、哪些标的、何时入场、如何管理和退出。
4. **资金与执行**决定持有多少和怎样成交；良好的仓位或低成本执行不能自动创造价格预测优势。

每个方法标注类型。组件伪代码可以输出 `FILTER/SIGNAL/EXIT_LEVEL/TARGET_WEIGHT`，解释理论可以输出可检验假说及 `NO_DIRECT_TRADE`，不强行给每个概念编造买卖策略。

## 知识身份与证据

- `V0`：模型知识初稿，未做本轮外部核验；可包含明确标记的不确定记忆。
- `S`：本轮实际读取的原著、作者文章、原始论文或专业机构材料。书目/目录只证明书目与定位，不能证明细节。
- `C`：某张卡的具体命题或校订主张，须连到支持它的 S；`C1/R1/A1` 等编号均以方法 ID 为作用域。
- `R`：从来源支持的命题得到的规则；原文模糊时保留歧义。
- `A`：为了让规则可计算而作的研究假设、代理定义或市场适配；不能冒称原作者原法。
- `P`：伪代码步骤；能追溯到 `R` 或 `A`。
- `E`：说明规则的正例、反例与缺失例；是假设案例，不是历史收益或实证结果。

来源访问层级：正文全文、相关正文/节选、摘要、目录、书目、不可得。定义来源可靠与盈利证据充分是不同问题。出版社宣传、作者自述和交易冠军故事不作为费用后稳健盈利证据。

## 伪代码的共同语义

`t` 表示决策时刻，只读此刻已经可用的信息。`C[t]` 若表示当期收盘价，则该根必须已完成；以它确认的信号只能在之后符合交易规则的机会尝试成交。高周期信号只读已经完成的高周期，不拿未收线周线作为确定值。

`prior_high(n)`、`prior_low(n)` 默认只取当前根之前的 n 根；形态端点、浪、笔等另记录首次确认时间。历史上一个点的价格位置与当时是否知道它是关键点是两件事。

`ENTER/ADD/REDUCE/EXIT` 表示交易意图，不表示必然成交；`HOLD` 不增加敞口，`WAIT` 不新开仓，`UNKNOWN` 表示证据不足。跳空、停牌、价格限制、数量限制、借券不足或双腿失败可能阻止成交。具体制度由后续市场适配核验，本轮不编码固定制度阈值。

缺少关键输入时停止新的风险暴露，保留已有保护与退出意图；不能用零值填缺失。退出优先于加仓/入场；买卖同刻冲突时，先按该卡明确的优先级处理，未定义则 `WAIT`。同一已处理信号不重复创建新的风险暴露。

若策略需要状态，至少说明空仓/准备、待进入、持有、待退出、冷却。若仅是指标或筛选组件，其宿主策略负责这些状态，组件卡必须写清输入和输出，不能声称自身已构成完整策略。

默认单策略研究的资金约束使用符号参数：可用资金 `B`、权益 `E`、单笔风险预算 `r`、最大敞口 `w`。有有效保护价时，数量受 `r*E/单位风险`、`w*E/价格` 和 `B/价格` 三者的共同上限约束；还需符合品种单位。保护价是计划风险锚点，跳空或无法卖出会使实际损失超出该预算。参数不是本轮推荐值，不把止损和成交保障混为一谈。

上述简式限现金证券，或“价格/单位风险”已经换算成同一账户币种下的完整单位金额。期货、期权和跨币种方法使用各卡明确的合约乘数、保证金、现金流及汇率约束，不能把报价点数直接当每张合约成本，也不能以保证金低替代总敞口约束。

## 每张方法卡的最小闭环

保留 V0，然后写来源支持的核心命题、修订差异、数据/假设、规则与伪代码、正常/失败/缺失例，以及适用性和待验证点。对于价格行为、波浪、缠论、Wyckoff、龙头等主观环节，必须写出代理定义或人工证据节点；不得以 `is_leader()`、`is_wave3()`、`is_absorption()` 等未解释函数掩盖问题。

来源不足的项依然保留理论讨论与明确标为 A 的可检验版本，同时返回 `UNVERIFIED_SOURCE`。它可以是研究假说，但不能计为原著精确复现。没有可确定规则的理论输出 `NO_DIRECT_TRADE`，并给出可验证的命题或观测方法，不制造形式化完成假象。

## 示例与反例

每项至少说明三个情景：条件满足时怎样判断，条件失效/环境切换时怎样退出或否定，信息不足时缺什么。复合或主观方法再说明一个歧义/不可成交案例。可用极小数字例或明确的条件例；不得把人为例子称为实测胜率或收益。

数值阈值必须有出处或 A 标签。`n/k/阈值` 等符号可以保留，说明含义和方向即可，不在本轮枚举参数或挑最赚钱的值。

## 后续检验命题

各方法要回答：预期优势是什么，在哪些状态出现，成本/换手/尾部如何侵蚀它，什么结果会推翻它，与简单基准相比新增了什么。复杂方法需要同时问“是否只是趋势、Beta、流动性或卖保险的重复暴露”。

后续历史、样本外和自然前推应分别验证。预先登记参数族及试验次数、保留负面结果与来源缺口。已经看过的历史不因更名或换一张卡就重新成为未见数据。本轮只描述这些检验，不实施。
