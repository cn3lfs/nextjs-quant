# F18 统计学习与策略组合

> v0 模型知识初稿，未外部核验，不构成收益验证

本稿仅据模型知识描述学习方法，不读取或声称复现外部论文。模型类别不是收益来源；可交易优势仍须来自可在决策时获得的信息与可验证假说。训练只使用当时已完成并可知的样本，预测目标不得混入特征，完整期间标准化、历史成分回填和未来修订都会造成泄漏。本阶段没有训练、参数优化、回测或工程实现。

## F18.01 线性模型与正则化

- **名称别名、类型：** 线性回归、Logistic 回归、Ridge、Lasso、Elastic Net；监督学习与统计估计工具。
- **理论及收益机制：** 用特征的加权关系估计未来收益、方向概率或风险，若关系在未来仍有效且强于成本，预测才可能有交易价值。正则化通过收缩参数控制复杂度，不会创造不存在的信息。
- **选取与退出或边界：** 先冻结目标期限、可用特征与样本权重，按时间分离拟合、参数选择和评价；标准化仅依据训练信息。Ridge 连续收缩，Lasso 可压零部分系数，Elastic Net 混合两者；预测变为排名、阈值或仓位需要独立登记，退出由目标期限、信号反转或风险约束定义。
- **适用与失败：** 适合关系近似可解释、样本量有限的基线研究；非线性、共线性、分布漂移、重叠目标和反复调参会令估计不稳，拟合显著不等于经济可交易。
- **记忆不确定点：** 各损失、惩罚尺度和概率校准条件需核验，不能用训练期系数符号直接宣称金融因果关系。

## F18.02 树模型

- **名称别名、类型：** Decision Tree、回归树、分类树；非线性监督学习工具。
- **理论及收益机制：** 通过特征条件把样本划分为不同区域，捕捉阈值和交互作用；可能发现线性模型遗漏的条件关系，但树结构本身没有金融收益保证，分裂规则也可能仅拟合噪声。
- **选取与退出或边界：** 先定义标签和特征可知时点，限制深度、叶节点支持样本与分裂复杂度，并按时间外样本选择模型；回归树估计数值，分类树估计类别或概率。将叶节点输出转成交易阈值前独立说明成本和持有规则，预测不满足条件、期限结束或风险失效时退出。
- **适用与失败：** 适合存在门槛和交互的假说研究；少量极端样本、相近阈值不稳定、时间漂移和高维筛选可能导致过拟合，易解释的树图也未必稳定或因果。
- **记忆不确定点：** 不同树算法的分裂指标、缺失值与剪枝处理不同，经典算法定义待核验；随机森林和提升树归入下一卡的集成，不把单树结果冒充集成性能。

## F18.03 集成学习

- **名称别名、类型：** Bagging、随机森林、Boosting、Stacking；多个学习器的组合方法。
- **理论及收益机制：** 集成试图降低单模型误差或修正系统性偏差；若模型错误高度相关，增加数量可能只重复相同风险。预测精度改善也未必改善换手后交易收益。
- **选取与退出或边界：** Bagging 对重采样学习器聚合，随机森林额外随机化候选特征；Boosting 顺序纠正损失，Stacking 用上层模型组合下层输出。时间序列重采样不得破坏信息边界，Stacking 上层只能使用严格时间外生成的下层预测；交易转换、退出期限和风险约束需单独预设。
- **适用与失败：** 适合单模型误差存在可分散部分的场景；共同泄漏、非平稳性、样本太少、调参次数过多和集成后高换手会破坏优势。训练样本内输出训练上层模型尤其容易制造虚假收益。
- **记忆不确定点：** 各集成算法的原始定义及金融时间数据适配不是同一问题，具体随机性、损失和学习率不在本稿指定，后续应分别核验。

## F18.04 状态切换与 HMM

- **名称别名、类型：** Regime Switching、Hidden Markov Model、隐马尔可夫；潜在市场状态模型。
- **理论及收益机制：** 收益、波动或相关结构可能随不可直接观测的状态变化，估计当前状态概率有助于条件风险或策略选择；统计状态不自动等于经济意义上的牛熊或吸筹派发。
- **选取与退出或边界：** 预先定义观测量、候选状态数和更新时点，仅用历史训练参数及当时观测计算过滤概率；使用未来观测的平滑概率只能事后分析，不能充当实时信号。按明确概率阈值或软权重调整策略，设切换缓冲、最短停留和失效退出规则。
- **适用与失败：** 适合状态持续性有依据的研究；状态标签交换、估计不稳定、状态数过多和突发新环境会使模型失真，切换确认滞后也可能错过转折并增加交易。
- **记忆不确定点：** HMM 与 Markov-switching 回归的观测和转移假设不完全相同，经典估计方法及实时推断条件待核验，不宣称模型能准确预告市场状态。

## F18.05 元标签与二级交易过滤

- **名称别名、类型：** Meta-labeling、元标注、信号过滤；在已有方向信号上学习是否参与或分配规模的框架。
- **理论及收益机制：** 一级方法给出候选方向，二级模型学习哪些候选更可能满足预定结果，试图减少低质量交易；若二级只学习一级已使用的噪声，过滤不会产生真实优势。
- **选取与退出或边界：** 固定一级信号的首次产生时点、候选集合、评价期限及成败定义，可使用预设止盈止损和时间界限，但这些属于标签规则选择。训练特征只能在候选出现时获得，重叠事件需隔离；二级拒绝则不入场，接受后按一级退出或明确另定的规则管理。
- **适用与失败：** 适合已有可解释候选信号且事件数量足够的研究；同段数据设计一级又筛二级、标签重叠、类别失衡和低频样本会形成严重过拟合，过滤还可能移除少数关键大盈利。
- **记忆不确定点：** 元标签与普通二分类的边界、常见三重屏障和仓位映射原始表述需核验；过滤概率不等于胜率已校准或可以直接做 Kelly。

## F18.06 机器学习排序

- **名称别名、类型：** Learning to Rank、横截面学习排序、Pointwise/Pairwise/Listwise；证券相对选择工具。
- **理论及收益机制：** 直接学习同一决策时点证券间的相对顺序，目标更接近选取前列或多空两端；正确排序若只发生在不可交易或高成本证券中，仍不能产生可实现收益。
- **选取与退出或边界：** 以当时真实可选池构造每期横截面，明确未来收益、风险调整收益或其他排序标签；逐点预测、成对比较与整列损失分别优化不同对象。按时间分组训练和评价，使用预定名额、缓冲和权重建组合，排名下降、持有期届满或风险约束触发退出。
- **适用与失败：** 适合证券池较大且历史成员可追溯的研究；幸存者偏差、跨日随机拆分、行业主导、缺失值提示未来和高换手可能制造虚假有效性，排序分数也不天然是收益概率。
- **记忆不确定点：** 各排序损失、评价指标与交易目标之间未必一致，原始算法及金融应用结论需核验，不能只凭排序指标上升声称策略改进。

## F18.07 深度学习

- **名称别名、类型：** 神经网络、MLP、CNN、RNN/LSTM、Transformer；非线性表示学习工具族。
- **理论及收益机制：** 从多个特征、序列或文本中学习复杂表示，可能压缩现有手工特征未捕捉的信息；网络容量大只提高表达能力，不证明价格具有可利用的深层规律。
- **选取与退出或边界：** MLP 处理固定特征，CNN 捕捉局部结构，循环网络表达序列状态，Transformer 用注意力关联输入；所有输入都必须在决策时可见，序列遮罩不能接触未来。训练、选择和评价按时间隔离，预测转成阈值、排序或风险仓位另作规则，退出与目标期限一致。
- **适用与失败：** 适合样本数量、输入结构与假说相匹配的研究；小样本高容量、价格图像伪形态、随机种子敏感、非平稳和反复挑模型会导致过拟合，文本预训练信息还可能含历史之后知识。
- **记忆不确定点：** 架构的原始定义和各金融应用证据需逐项核验；注意力权重不自动等于因果解释，本文不假定深度模型优于简单基线。

## F18.08 强化学习

- **名称别名、类型：** Reinforcement Learning、策略学习、序列决策；在环境与奖励定义下学习动作的方法。
- **理论及收益机制：** 联合考虑当前动作、后续状态和累计奖励，理论上可表达仓位调整与执行等序列问题；收益来自环境中真实可利用结构，学习器也可能只利用模拟器漏洞或不现实交易假设。
- **选取与退出或边界：** 事先定义可观测状态、允许动作、资金约束、奖励和终止条件，奖励需体现费用及风险偏好；训练使用历史之前可得环境，冻结策略后再评价。清仓和停止属于显式动作或约束，不允许借未来最优动作标签假称在线决策，也不进行真实市场探索。
- **适用与失败：** 适合可描述序列影响且环境可信的研究；市场非平稳、部分可观测、离线分布外动作、稀疏样本和奖励投机会导致不可迁移，忽略自身冲击尤其危险。
- **记忆不确定点：** 价值学习、策略梯度、离线强化学习的假设与保证各不相同，经典算法和金融适用证据需核验，不能把累计模拟奖励当已验证投资能力。

## F18.09 混合策略与环境切换

- **名称别名、类型：** Strategy Ensemble、Mixture of Experts、Regime-based Allocation；策略层组合与条件资金分配。
- **理论及收益机制：** 将机制、期限或风险不同的策略结合，希望分散收益来源；环境选择可能让更适配的方法承担更多风险。仅名字不同而实质相同的策略不会提供多少独立分散。
- **选取与退出或边界：** 固定候选策略、暴露预算及组合规则：固定权重、按风险调整、软概率混合与硬状态切换是不同变体；选择器仅用当时信息，不能事后指定每段赢家。设资金冲突、相关风险、切换成本和恢复规则，单策略失效或组合风险超限时减配退出。
- **适用与失败：** 适合已有独立策略逻辑且相关性可研究的集合；共同市场暴露、危机相关性骤升、环境识别滞后和追逐近期赢家会使组合一起亏损，频繁切换也可能累积成本。
- **记忆不确定点：** 策略组合、模型集成和多因子选股处于不同层级，不能直接混算数量；“不同环境用不同方法”的直觉须转成事前可测规则后再核验。

## v1 原著校订与 v2 规则伪代码

本章先区分「算法有可核验定义」与「它在金融市场有样本外收益」。下列来源支持前者；本文没有训练模型，也没有验证后者。除来源明确给出的数学定义，特征、标签、阈值、训练窗口与组合约束均为研究假设 A。预测、过滤和目标权重都是组件输出，须接入已定义的持有、现金和风险规则，不能把九种模型计作九套完整策略。

**共用训练约定 A：** 决策时点 t 的输入默认由当时真实可选池、截至 t 的价格/成交及已披露资料组成。示例数值特征 X=(过去20期收益、过去20期收益标准差、当期成交额/过去20期平均成交额)，窗口不足返回 UNKNOWN；公司行动与历史成分按当时口径。预测期限 H 固定，标签 y 是下一可交易时点入场到 H 期后指定退出时点的收益，减预先冻结的双边成本模型；没有可实现入场或退出价的样本不补造。训练截止 T 只收录退出及标签均已可知的样本，标准化、缺失处理、参数选择均只用各训练段。验证以时间推进；删除训练中与验证标签区间交叠的事件，并采用预先给定隔离间隔 E；若反向使用验证后的训练段，还须隔离该段相邻信息，不能把普通随机拆分称为防泄漏。选择后的版本须在下一未用于选择的区间评价。下文 TRAIN/拟合表示具名算法在该限定样本上求解，不代表已经执行。

**共用交易包装 A（仅在声明启用时）：** 输入证券、持有上限 H、单资产目标上限 c、入场阈值 θ_in、退出阈值 θ_out<θ_in、已有仓位及硬风险退出。先检查硬退出/期满；再以评分决定进入候选、维持或退出，缺评分不新开仓但保留独立退出。组件默认只报告评分或过滤结果，资金分配由 F17 等组合组件提供。分类概率超过阈值只表示模型分类，未同时估计盈亏幅度时不声称正期望，不接 Kelly。

### F18.01 线性模型与正则化

**v1 / C1：** [F18-S01](sources-F13-F18.md#f18-s01) 正文公式1–3和11–13支持线性预测、Ridge/Lasso/Elastic Net惩罚及Logistic概率；补充 v0：回归系数是条件拟合关系，不能解释为金融因果。令 P_a(β)=(1−a)||β||²/2+a||β||₁，回归最小化均方误差/2+λP_a，Logistic最小化二元交叉熵+λP_a；截距不惩罚。a=0为Ridge，a=1为Lasso，0<a<1为混合；λ=0才是未正则化基线。

**A、输入：** 共用 X、已完成 y，模型模式、λ≥0、a∈[0,1]、最少样本 n_min、训练时间窗及阈值均事前冻结或仅由过去验证选择。二分类标签为 1[y>0]，不等同收益大小。

```text
if 训练样本不足/参数无效/当前X未知: return UNKNOWN
D = 仅保留在训练截止T已完成且可知的(X,y)
尺度 = 仅由D训练段计算；变换D及X_t
if 回归模式: β = 最小化均方误差/2 + λP_a(β)
else: β = 最小化二分类交叉熵 + λP_a(β)
score = β0 + X_t·β；分类模式改为1/(1+exp(-score))
return SCORE(score, 目标类型, H)；交易包装另行执行
```

**E：** 正例：回归预测净收益2%且阈值1%，进入候选；反例：分类概率0.6却损失幅度远大于盈利，不能推出值得买；缺失例：未来财报字段尚未披露则该特征 UNKNOWN，不用后来数值回填。**状态/适配：** FORMALIZED_COMPONENT；跨市场须验证目标、成本、特征稳定性，未训练、未验证收益。

### F18.02 树模型

**v1 / C1：** [F18-S02](sources-F13-F18.md#f18-s02) 的回归森林正文描述树分裂、随机候选变量与平均预测；[F18-S03](sources-F13-F18.md#f18-s03) §2明确回归树的叶权重函数。它们支持树表示，本卡为可手算的 A 单树规则，未声称复现 Breiman 等人的整本 CART 原著。分类叶频率是训练样本比例，不天然为校准概率；缺失值路由随算法不同，本卡不自行猜测。

**A、输入：** 使用共用 X、y；回归模式以训练平方误差下降最大选择二元切分，分类模式以Gini不纯度下降最大选择。最大深度 D、最少叶样本 m、最小改进 ε、固定特征排序/切点排序打破平局；候选切点仅在训练值之间。回归叶输出均值，分类叶输出正类比例，退出沿共用包装。

```text
if 训练样本不足/当前特征未知/配置无效: return UNKNOWN
root = 截止T已完成的训练样本
对节点枚举满足每叶至少m样本的训练切点
若深度<D且最佳改进>ε: 按固定平局规则切分并继续
否则形成叶：保存训练y均值或正类比例
score = 当前X按已冻结树路径到达叶的输出
return SCORE(score, H)；不以叶名称自动下单
```

**E：** 正例：两叶训练收益均值1%和−1%，当前样本落入第一叶便输出1%；反例：只含一个极端盈利样本的叶被 m=20 禁止；缺失例：当前分裂特征缺失且没有事先训练的处理规则，返回 UNKNOWN。**状态/适配：** FORMALIZED_COMPONENT；分裂启发式属于 A，单树金融优势未核验。

### F18.03 集成学习

**v1 / C1：** [F18-S02](sources-F13-F18.md#f18-s02) 支持随机森林随机化树和回归平均；[F18-S03](sources-F13-F18.md#f18-s03) 支持按可微损失逐步加入树、复杂度惩罚及收缩。Bagging重采样后平均，随机森林额外限制每次分裂的候选特征；Boosting顺序减少损失，并非给近期赢钱策略加权。Stacking的上层输入是模型预测，本文采用严格过去训练生成的预测，不能拿同一训练集的拟合值冒充样本外。后者为 A 时间适配，未核验 Stacking 原始论文。

**A、输入：** 四模式选一；基学习器、数量 B、随机特征数 m_f、学习率 η、树深度和惩罚由过去验证冻结。Bagging/RF只在合法训练段内部重采样，不重排到验证未来；Stacking将历史划为顺序段，每段预测只由更早段拟合的底层模型产生，上层用已完成标签拟合 F18.01。

```text
if 共用样本/当前X/所选模式配置不足: return UNKNOWN
if Bagging或RF: 拟合B个重采样树；RF每个分裂仅取m_f候选特征
if Bagging或RF: score = B棵树当前预测的算术平均
if Boosting: 按冻结损失/η/惩罚顺序拟合B棵树；score=加性预测
if Stacking: 生成仅过去训练的历史预测；用其已完成标签拟合上层
if Stacking: score=上层(各冻结底层模型对X_t的预测)
return SCORE(score,H)；沿共用交易包装处理进入和退出
```

**E：** 正例：三棵回归树输出1%、2%、3%，均值2%；反例：100棵共享未来信息的树仍是泄漏；缺失例：Stacking没有足够历史外推预测时 UNKNOWN，不退回训练拟合值。**状态/适配：** FORMALIZED_COMPONENT；Stacking与时间重采样方案为 A，成本和模型误差相关性待验证。

### F18.04 状态切换与 HMM

**v1 / C1：** [F18-S04](sources-F13-F18.md#f18-s04) 原始教程的前向概率定义支持「截至当前观测」推断；本次正文来自带OCR瑕疵的原文镜像，以下递推用数学重新书写。隐状态HMM与状态切换回归不是同一个观测模型；本卡具体化高斯HMM，未冒称完成所有变体。向后平滑及整段最优路径可改变旧状态，不可作为当时已知信号。

**A、输入：** 观测 o_t=(已实现收益,过去20期波动)，状态数 K、训练窗、Baum–Welch估计的初态π、转移 A_ij、各态高斯发射密度 b_j、概率阈值θ、最短停留h。训练仅用≤T观测；状态命名只按训练发射均值/波动排序。α_t(j)∝b_j(o_t)Σ_i α_(t−1)(i)A_ij，归一化和必须为正；已确认状态初始化为UNKNOWN，首次满足概率阈值即可确认，其后才要求停留h；不将状态编号直接命名为「赚钱环境」。

```text
if 参数/观测缺失或发射密度无法定义: return UNKNOWN
if 首次观测: u_j=π_j*b_j(o_t)
else: u_j = b_j(o_t) * sum_i(α_prev(i)*A_ij)
if sum_j(u_j)<=0: return UNKNOWN
α_t = u / sum(u)
candidate = 按固定顺序打破平局的最大概率状态
if 尚未确认状态且α_t(candidate)>=θ: 首次确认并记录切换时点
else if candidate不同于已确认状态且α_t(candidate)>=θ且距上次切换>=h: 切换并记录时点
同态仅更新α，不刷新切换时点
return STATE_PROBABILITY(α_t,已确认状态)；本卡不独立发出买卖
```

**E：** 正例：概率(0.8,0.2)、θ=0.7且冷却已满，确认第一态；反例：使用明天大跌后的平滑概率改写今天状态构成泄漏；缺失例：所有发射密度为零时 UNKNOWN。**状态/适配：** FORMALIZED_COMPONENT；经济意义和策略状态映射仍须事前说明，观测性输出不算完整策略。

### F18.05 元标签与二级交易过滤

**v1 / C1：** [F18-S05](sources-F13-F18.md#f18-s05) 作者公开正文定义三重屏障、元标签、purging与embargo；访问层级支持概念，未等于逐章核验《Advances in Financial Machine Learning》。补充 v0：二级只能决定接受或拒绝一级的方向，本卡不让它反向改写一级；不把过滤概率直接映射Kelly。标签、费用和执行先后均属 A。

**A、输入：** 一级在 t 首次产生的方向 s∈{−1,+1}、X_t、当时波动σ_t>0、盈利屏障uσ、亏损屏障dσ、期限H、首次可执行入场价及成本。事件终点为三屏障先到者，标签为实际可执行退出的方向净收益>0；跳空用可执行价，非理想屏障价。无法判定同一根K线双触及先后则标签 UNKNOWN；一级提前退出也结束标签。模型用已结束事件训练Logistic，阈值p_min为A。

```text
先执行已有仓位的一级/风险/期限退出；二级无权阻止退出
从历史一级候选构造已结束且先后可判定的屏障事件标签
训练仅使用截止T可知的(X,一级方向,标签)，隔离重叠事件
if 无新一级候选: return NO_CANDIDATE
if 当前X/σ/一级方向/训练样本未知: return UNKNOWN
p = 冻结Logistic预测(二级事件成功标签)
if p>=p_min: return ALLOW(一级方向) else return REJECT_ENTRY
```

**E：** 正例：一级做多、二级p=0.7≥0.6则允许该方向；反例：二级低分只能拒绝，不能改做空；缺失例：日线同时触及两屏障而无更细先后证据，该训练标签不纳入。**状态/适配：** FORMALIZED_COMPONENT；一级规则需独立闭合，过滤改进和概率校准待验证。

### F18.06 机器学习排序

**v1 / C1：** [F18-S06](sources-F13-F18.md#f18-s06) RankNet原文支持基于分数差的成对概率与交叉熵；原研究是信息检索，不提供金融有效性证据。Pointwise逐个回归后排序；Pairwise比较同组两对象；Listwise优化整组次序，三者损失不同。本卡具体选择Pairwise，不将一个RankNet实例冒充全部排序算法。

**A、输入：** 同一交易时点的可选证券组成一组，标签为共用净收益y；P_ij=1/(1+exp(−(f(X_i)−f(X_j))))，目标标记在y_i>y_j时为1、相等为0.5、否则0；损失为组内交叉熵总和。训练/验证按整组时间划分，网络结构和正则化过去冻结。组合选前K，单股上限c，总股票预算G≤1，实际等权为 min(G/K,c)，剩余现金；只在固定再平衡日更新，排序退出后移出候选。

```text
if 训练组/当前组特征/模型配置不足: return UNKNOWN
在已完成标签的历史同日组内训练RankNet成对损失
score_i = 冻结模型f(X_i,t)；按分数降序/代码升序排序
if 非预定再平衡日: return KEEP_PREVIOUS_TARGET
selected = 有效可交易组前K名；不足K时不补造名额
w_i = min(G/K,c) 若i入选，否则0；其余为现金
return TARGET_WEIGHTS(w)；风险退出优先，实际成交另行约束
```

**E：** 正例：K=2、G=0.6、c=0.2时两只各20%，余60%现金；反例：排序分数10不表示收益10%或胜率10%；缺失例：当前组只有一只有效股票，最多保留一个名额，不把其权重翻倍。**状态/适配：** FORMALIZED_COMPONENT_WITH_ALLOCATION_A；排名、样本选择及交易成本待验证。

### F18.07 深度学习

**v1 / C1：** [F18-S07](sources-F13-F18.md#f18-s07) 作者正文核实Transformer注意力架构与阻止读取后续位置的遮罩。MLP固定特征、CNN局部结构、RNN/LSTM递归状态等 v0 分类保留为背景；这些变体的各自原始论文尚未逐一核验，标 **UNVERIFIED_SOURCE（仅这些变体的原始定义）**。本卡用具体Transformer回归代理，未声称金融深度学习已验证，也未把注意力当因果解释。

**A、输入：** 长度L的X_(t−L+1:t)序列、已完成y；模型定义固定为带位置编码、因果自注意力层和最终时点线性输出的Transformer，层数、宽度、优化器、学习率、迭代次数和随机种子均只经过去验证冻结。损失为净收益标签均方误差；外部预训练权重如无法确认其知识截止，不参与历史因果检验。CNN只用历史卷积、LSTM只读到t可作为另行登记A，不能混合择优回报。

```text
if 序列不足L/特征未知/训练配置或权重截止不明: return UNKNOWN
D = 仅标签在T前完成的历史序列；尺度只拟合训练段
用冻结Transformer定义与因果遮罩最小化D上的均方误差
固定训练所得权重；不根据评价区间表现选种子或迭代次数
score = 模型对截至t序列的最后时点输出
return SCORE(score,H)；净收益标签已扣成本，不再重复扣同一项
```

**E：** 正例：输入20期历史而预测第21期之后持有收益，时间界限可检验；反例：序列包含目标期收盘，即使有遮罩也不能保证目标头没读到未来；缺失例：文本模型训练截止未知，历史文本预测不作已无泄漏样本。**状态/适配：** FORMALIZED_COMPONENT；部分架构原始出处未核验，非平稳、样本量和可交易性待验证。

### F18.08 强化学习

**v1 / C1：** [F18-S08](sources-F13-F18.md#f18-s08) Watkins–Dayan原文支持有限动作、状态、奖励、折扣和Q学习；其收敛条件不等于现实金融保证。价值方法学习Q，策略梯度直接优化策略分布，离线RL受历史动作覆盖约束；本卡仅闭合表格Q学习A，不声称涵盖后二者的全部算法或复现Sutton–Barto教材。

**A、输入：** 状态是过去动量分箱、过去波动分箱、当前仓位档位、可用资金档位和当前DD档位；分箱边界只用训练历史；DD档位纳入奖励相关信息，但有限分箱仍只是A近似，不保证充分Markov性。动作{0,0.5,1}为目标多头权重，需满足现金/交易约束。训练转移只来自≤T的已完成历史，简单价格接受者环境明确不含自身冲击反馈。奖励为实际持有权重×下一期收益−真实转换权重的成本−λ·max(0,DD_next−DD_current)，λ≥0；资产与回撤按同一单位净值更新。Q更新为Q(s,a)←Q(s,a)+α[r+γmax_合法b Q(s',b)−Q(s,a)]；终止状态后项取0；训练若无合法后继动作，本A结束该回合、不假定已经强行平仓，并报告这种截断的局限。α、γ、探索计划、回合数、环境版本事前冻结，评价和部署不探索。

```text
训练仅遍历截止T已完成的历史转移；按合法动作更新Q
按实际现金/仓位及收益推进含DD的状态；后继max只取合法动作，终止或无合法后继时续期价值为0
if 当前硬风险退出触发: return TARGET_WEIGHT(0)
if 状态/约束未知或当前状态无训练支持: return UNKNOWN
legal = {0,0.5,1}中当前现金及交易规则允许的动作
if legal为空: return WAIT_NO_NEW_RISK（保留保护退出）
a = legal中Q最大的动作；平局选较小风险权重
return TARGET_WEIGHT(a)；下一期收益不可参与当前动作选择
```

**E：** 正例：同一状态Q(0)=0、Q(0.5)=0.02、Q(1)=−0.01，选择50%；反例：用当期未来收盘计算奖励再选当前动作是泄漏；缺失例：新状态无支持时不做真实市场探索。**状态/适配：** FORMALIZED_COMPONENT_WITH_POLICY_A；需要可信环境及动作覆盖，离线样本和实盘可迁移性未验证。

### F18.09 混合策略与环境切换

**v1 / C1：** [F18-S09](sources-F13-F18.md#f18-s09) 作者摘要支持多个专家分担任务的模型组合概念，但不是交易策略配置证据，完整门控训练原文未读；[F18-S04](sources-F13-F18.md#f18-s04)的实时过滤可提供状态概率。修正 v0：模型输出的集成与可执行策略持仓的组合分属不同层级，本卡仅组合已独立闭合的策略目标。固定权重、风险预算、软状态混合、硬切换须择一登记，不事后选每段赢家。

**A、输入：** J个策略当前净资产权重向量w_j及有效状态、其风险/退出指令、预先冻结的状态到策略权重矩阵B（每行非负和为1）、实时α、单股上限c、总多头上限G≤1。具体采用软门控 a_j=Σ_k α_k B_kj，合成u=Σ_j a_jw_j；本卡仅支持非负多头策略，做空/杠杆须另定义净额与保证金规则。失效策略的份额保留现金不重分配；任一策略自主退出优先按上次已知分配比例扣减其仍持有的组合贡献，再将其w_j更新，不能被选择器拦截；子策略贡献记录与实际成交必须可对应。退出/减仓不受调仓日限制，当前门控数据缺失也保留这些独立意向。组合硬退出优先。硬门控变体以已确认状态的B行替代α混合，并固定h/θ切换缓冲；风险权重可改用F17.12，但不混称为同一公式。

```text
组合硬退出则return全现金；先消费子策略退出，按上次分配扣减其贡献并输出独立EXIT/REDUCE意向
更新子策略目标w_j；若当前门控数据未知，仅保留上述退出、禁止新增，return UNKNOWN
if 状态概率/冻结B/有效子策略目标未知: return UNKNOWN（保留已收到退出）
a_j = sum_k(α_k*B_kj)；明确失效策略对应贡献置0，保留现金
u_i = sum_j(a_j*w_ji)
v_i = min(u_i,c)；若sum(v)>G则整体乘G/sum(v)
若未到预定调整日且无强制退出: return KEEP_PREVIOUS_TARGET
return TARGET_WEIGHTS(v,现金=1-sum(v))；计入切换成本后另行评价
```

**E：** 正例：两策略同股各80%、门控各50%，合成80%再由c=30%限制至30%，不因名字不同绕过集中度；反例：一策略失效后把它的预算自动全给另一策略不符合本A；缺失例：α缺失不能事后用收益最好的状态补值，保留独立退出。**状态/适配：** FORMALIZED_COMPONENT，B需要研究者事前解释并冻结；组合分散、切换成本和危机共同暴露待验证。
