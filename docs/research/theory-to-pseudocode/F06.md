# F06 波浪、周期与比例及争议扩展

状态：v0 模型知识初稿，未外部核验，不构成收益验证。

本稿仅来自模型知识。数浪、锚点与周期识别存在较大解释自由度，后续必须保留当时所有合法候选及其失效条件，不能在看到结果后只展示吻合的路径。附录用于容纳广泛传播的方法，不把传播、原始材料存在与独立实证混为一谈；本轮不提供引用或收益结论。

## F06.01 Elliott 推动浪（Impulse / Motive Waves）

- **类型**：递归波浪结构的描述与路径假设。
- **核心原理与潜在收益机制**：标准推动结构通常以五段同向展开、其中穿插两次逆向调整来描述群体行为，理论假设是结构具有一定重复性。常见硬规则包括第二浪不越过第一浪起点、第三浪不是相应推进浪中最短者、标准推动浪第四浪不进入第一浪价格区域；楔形类推动结构需单独处理。
- **交易逻辑或边界**：可在调整完成候选处参与后续推动，或在结构失效处退出，但“调整完成”不能由事后浪号替代。不同合法数浪应同时记录，不能提前获知最终第五浪终点。
- **适用与失败环境**：波段层次清楚时便于提出路径；噪声、复杂调整、扩延与快速反转会造成大量替代解释。
- **模型不确定点**：硬规则、指引、例外以及推动浪与驱动浪的翻译边界待核验；结构合法不等于路径概率已知。

## F06.02 Elliott 调整浪（Corrective Waves）

- **类型**：与较大级别推进方向相反的波浪结构家族。
- **核心原理与潜在收益机制**：常见分类包括锯齿形、平台形、三角形及组合调整；模型记忆中锯齿常用五—三—五子结构描述，平台常用三—三—五，三角由多段调整波构成。不同类型对应深浅、横向延展和时间消耗的差异，不能把所有调整都强制为简单 A-B-C。
- **交易逻辑或边界**：在候选调整接近完成时观察恢复原趋势的证据，形态或价格规则被破坏则取消该路径；组合调整允许延长，因此不能仅凭已经出现三段就断言结束。
- **适用与失败环境**：已有较大趋势且调整层级可辨时较易使用；类型在形成中不断切换、B 浪越过起点或长时间复杂整理会降低确定性。
- **模型不确定点**：扩张、顺势平台、双重/三重组合及三角的子浪限制需原著核验；不得把新增组合标签当作无限免于证伪的补丁。

## F06.03 浪级、交替与替代计数（Degree / Alternation / Alternative Counts）

- **类型**：波浪框架的尺度组织与候选管理原则。
- **核心原理与潜在收益机制**：较大浪可以包含较小结构，不同浪级共同描述市场；交替通常提示同一推动结构中的调整在深度、形态或时间上可能有所不同。交替更像经验指引，不能与硬性排除规则等量齐观。其价值是组织假设和限制冲突，不直接创造交易优势。
- **交易逻辑或边界**：先选研究尺度，同时保存主要和替代路径；仅在新增信息排除候选时调整判断。仓位与退出应围绕共同失效位置或明确的情景选择，不以“换了浪级”取消原止损。
- **适用与失败环境**：波段嵌套清楚时可减少孤立解读；数据长度不足、尺度任意切换和过多候选会使理论难以被否定。
- **模型不确定点**：浪级命名与客观时长无一一对应，交替原义和候选优先级待核验；不能事后宣布唯一正确浪数。

## F06.04 Fibonacci 回撤（Retracement）

- **类型**：以已选波段为锚点的比例位置工具。
- **核心原理与潜在收益机制**：在一个已发生波段的高低点之间标示黄金比例及其衍生位置，用于观察回调深浅与潜在反应区。常见一半回撤也常被纳入工具，但不应因此说它严格来自相邻斐波那契数之比。价格关注度或自我强化可作为假说，数学比例本身不证明市场会反转。
- **交易逻辑或边界**：先固定已确认锚点，在回撤区结合独立价格证据研究入场，越过结构失效位置退出；不因到达某比例就无条件逆势买入。多个比例和多个波段叠加会显著增加事后挑选空间。
- **适用与失败环境**：趋势中有可辨识回调时可作位置参考；强趋势浅调、趋势破坏深调和任意锚点会降低作用。
- **模型不确定点**：锚点确认、比例集合、线性或对数坐标及容差待明确；所谓“共振”是否有新增信息需独立检验。

## F06.05 Fibonacci 扩展与投射（Extension / Projection）

- **类型**：波段长度比例的潜在目标工具。
- **核心原理与潜在收益机制**：以已知波段长度向外延伸，或从后续回调点投射原波段的比例长度，形成潜在目标区。二点扩展与三点投射的锚点不同，即使使用同一比例也可能得到不同价格；工具表达情景目标，而不是市场必须到达的吸引力。
- **交易逻辑或边界**：可用于分批退出、观察趋势延续或比较预期收益风险，但首次入场仍需独立理由。目标未到而原假设失效时必须允许退出，不能等待任意远的比例补偿亏损。
- **适用与失败环境**：重复波段和较稳定推进结构中可作观察参考；趋势突然加速、基本面重估或目标层层外推会使工具失去约束。
- **模型不确定点**：软件术语、锚点选择、比例来源与目标区宽度需核验；达到某扩展位后反转的回看案例不能证明事前预测能力。

## F06.06 Hurst 周期分析

- **类型**：以多个周期叠加解释价格波动的分析体系。
- **核心原理与潜在收益机制**：模型记忆中的该体系关注不同长度周期的叠加、名义周期关系、相位及波谷同步，并允许周期长度和幅度变化。潜在收益来自识别较大周期背景下较小周期的有利阶段；这里的 Hurst 周期体系与统计长记忆的 Hurst 指数不是同一方法。
- **交易逻辑或边界**：先提出可能周期与相位，再用价格结构验证候选转折窗口；时间窗口只给出“何时关注”，不能直接决定价格方向与成交。退出应承认周期偏移和路径失效。
- **适用与失败环境**：具有相对稳定振荡成分时较易描述；外部冲击、周期漂移、趋势占优或多周期相互抵消会降低可靠性。
- **模型不确定点**：原始周期原则、名义谱、包络线及位移工具定义待核验；居中滤波可能使用未来样本，端点估计不应被事后平滑值替代。

## F06.07 附录：江恩（Gann）

- **类型**：包含价格时间比例、角度与周期解释的多流派集合。
- **核心原理与潜在收益机制**：通行说法尝试用价格和时间的几何对应寻找支撑阻力或转折；角度线、方形排列和周期法并非一套可直接互换的规则。所谓一比一角度依赖价格单位与时间刻度，图形呈现不能证明存在市场自然定律；潜在机制需另行提出并检验。
- **交易逻辑或边界**：只有固定锚点、刻度、比例与失效条件后才能形成待检验规则；不能随缩放变化重选“正确角度”，也不能以任意周期解释所有转折。
- **适用与失败环境**：可作为几何位置假说研究；单位任意、锚点繁多、事后挑选及缺乏证伪条件会使结论失效。
- **模型不确定点**：原始文本、后世神秘化扩展与作者业绩传说需要严格分离。
- **证据状态**：广泛传播：模型知识印象为是，未核验；原始出版物：模型印象存在，版本与规则归属未核验；独立实证：本轮未检索，未知。

## F06.08 附录：谐波形态（Harmonic Patterns）

- **类型**：以多段转折及特定比例约束构造反转候选的形态家族。
- **核心原理与潜在收益机制**：常见 X-A-B-C-D 路径以不同回撤与扩展关系定义潜在反转区域；Gartley、蝴蝶、蝙蝠和螃蟹等在转折比例与终点相对起点的位置上不同，不能只换名称。收益假设是比例结构对应某种可重复供求反应，目前仅作为待验证命题。
- **交易逻辑或边界**：完成候选终点区域后还需定义价格确认、保护和退出；候选未完成时不能预知 D 点，识别过程也不能用未来确认的极值倒填入场。
- **适用与失败环境**：波段清楚时便于提案；强趋势、比例容差任意和大量相似候选会制造事后吻合。
- **模型不确定点**：早期形态与后期精确比例体系的作者归属、每型必要比例和容差待核验。
- **证据状态**：广泛传播：模型知识印象为是，未核验；原始出版物：模型印象存在且分属不同作者，未核验；独立实证：本轮未检索，未知。

## F06.09 附录：SMC（Smart Money Concepts）

- **类型**：以结构、流动性位置和交易区块解释价格的非统一流派集合。
- **核心原理与潜在收益机制**：常用结构突破、性质变化、流动性扫荡和订单块等标签描述走势。其交易假说可能是极值附近止损触发后反转，或强位移后回调再延续；二者需按情景分开。仅凭 K 线不能确认机构真实持仓、意图或未成交订单，“聪明钱”属于解释而非可直接观测事实。
- **交易逻辑或边界**：先固定结构点、区域及首次可识别时间，再研究区域回测或扫荡后的方向确认；订单块失效、结构反转与时间失效需明确，不能不断更换区域。
- **适用与失败环境**：清晰边界可能便于提出价格行为假说；术语不统一、区域重绘和用意图叙事解释亏损会削弱可检验性。
- **模型不确定点**：BOS、CHOCH、订单块等各版本定义及与传统结构法的新增差别待核验。
- **证据状态**：广泛传播：模型知识印象为是，未核验；原始出版物：未确认存在统一原典；独立实证：本轮未检索，未知。

## F06.10 附录：ICT（Inner Circle Trader）

- **类型**：具有特定传播体系的价格行为、时间窗口与流动性叙事集合。
- **核心原理与潜在收益机制**：常把流动性位置、较强价格位移、FVG、交易区间上下半区和特定时段组合解释市场。FVG 常指特定多根 K 线的不重叠区域，并不能据此证明那里没有真实成交或存在必须填补的缺口。潜在收益假说是特定背景下回补或续行概率不同。
- **交易逻辑或边界**：需逐一选定模型，明确先有何种结构、何时出现区域、等待哪种回测与失效；不能把多个课程版本的条件混为唯一系统。时间窗口必须对应明确时区、夏令时与市场会话。
- **适用与失败环境**：特定市场的会话规律可形成研究问题；换市场失效、频繁重标和主观选择“流动性目标”可能导致过拟合。
- **模型不确定点**：原始课程版本、FVG 与 OTE 等定义及传播变体需要核验。
- **证据状态**：广泛传播：模型知识印象为是，未核验；原始出版物：需区分署名课程与正式出版物，尚未核验；独立实证：本轮未检索，未知。

### F06.01 Elliott 推动浪与驱动结构

- **C1 来源与 v1 校订**：[F06-S01](sources-F01-F06.md#f06-s01)。EWI 官方书籍节选和规则文章支持标准推动浪三项硬约束，且第三子浪本身为推动浪；[F06-S02](sources-F01-F06.md#f06-s02)明确对角线属驱动结构却不是标准推动浪。v0的方向正确，补充不能遇到重叠就临时改叫对角线；领先对角线子结构在已读正文中仍有未定论。
- **输入与参数来源**：时间递增的候选端点p0…p5、每段高低极值、子浪分段与首次确认时刻；人工给出的浪级/子浪证据必须可追溯。A最底层可用F02.09 SW(k)替代，但SW数量不自动等于波浪数量。
- **R1 / A1 明确规则**：本卡是必要条件校验器，非自动数浪器。上涨标准版：p2不低于p0，p3>p1，第四段全部价格>p1，第三长度不得小于第一和第五二者；方向相反取负后用同一差值规则。边界相等保留BOUNDARY供人工核对，不冒充各版本统一硬规则。末浪截短可保留候选，不能强制p5>p3。

```text
P1 缺端点确认时间、段内极值或子结构证据：return UNKNOWN,NO_DIRECT_TRADE
P2 确认五段方向依次上/下/上/下/上、时间递增，且当前时刻已知道全部所用点
P3 若p2<p0或p3<=p1或第四段最低<p1：拒绝标准推动浪候选
P4 len1=p1-p0；len3=p3-p2；len5=p5-p4；若len3<min(len1,len5)：拒绝
P5 若p2=p0或第四段最低=p1：标BOUNDARY，不作为已核定标准推动浪
P6 检查第三段子结构含五段且满足同类约束；第一/第五允许人工注明对角线；无法下钻则标PARTIAL_VALIDATION
P7 有重叠时仅对事前另列的ENDING_DIAGONAL候选核五段三子浪、位置在较大浪5或C、收敛边界及第三不最短；缺证据UNKNOWN
P8 LEADING_DIAGONAL或扩张对角线版本未定，本卡保留人工复核，不借例外挽救已拒绝候选
P9 输出仍合法候选集合及各自失效点；NO_DIRECT_TRADE
```

- **正例 / 反例 / 缺失例**：p2越p0立即否定标准上涨计数；三浪较一、五都短也否定；只有六个价格点而没有子结构仍为部分校验；重叠但没有较大级别位置证据不能直接升格对角线。
- **形式化状态 / 适用与待验证**：R必要条件+A校验流程；依赖人工分段和浪级，未完全自动形式化。波浪合法只说明没有违反已检规则，未给下一段概率。

### F06.02 Elliott 调整浪

- **C1 来源与 v1 校订**：[F06-S03](sources-F01-F06.md#f06-s03)。官方书籍节选核到锯齿5-3-5、平台3-3-5、三角3-3-3-3-3及组合；补充常规/扩张/顺势平台的端点区别。保留v0并限制组合不能无限延长以免无法证伪。
- **输入与参数来源**：候选类型、端点与子段计数证据、较大浪位置；A相近端点容差e、候选最长q。人工分段先登记，比例不能用于事后挑选浪级。
- **R1 / A1 明确规则**：向下调整：锯齿B不越A起点；普通平台B近起点且C略低A终点，扩张平台B越起点且C低A终点，顺势平台B越起点而C未达A终点。三角E不必精确触边。复杂组合只输出部分校验。

```text
P1 缺子浪证据/较大浪位置：UNKNOWN,NO_DIRECT_TRADE
P2 若类型ZIGZAG，检查三段子数5/3/5且B终点<A起点；否则拒绝该候选
P3 若类型FLAT，检查3/3/5；按端点关系分regular/expanded/running；相近用e*abs(A起点)，零尺度UNKNOWN
P4 若类型TRIANGLE，检查五段各有三子段、交替方向；以A-C和B-D连线区分收敛/一边平/扩张；不要求E恰到线
P5 三角所处较大浪位置由人工注明4、B、连接X或组合末段；无证据仅PARTIAL_VALIDATION
P6 组合W-X-Y或W-X-Y-X-Z逐个提供简单调整标签和X证据；不支持任意续添更多段；超过q标过期
P7 保留多个合规解释；新数据导致旧解释失效时记录失败，不回写成从未判断过
P8 输出合法/拒绝/部分校验及NO_DIRECT_TRADE；向上调整用有向差值镜像
```

- **正例 / 反例 / 缺失例**：ABC三段但子数3/3/5不是锯齿，可作平台候选；B越起点不自动否定所有调整；只给A/B/C大端点不能检子数；running标签不得凭C没创新低就认定。
- **形式化状态 / 适用与待验证**：R分类+A必要条件检查，仍依赖人工子结构；不是完整Elliott语法验证器。需研究标注一致性、候选数量与前推失效率。

### F06.03 浪级、交替与替代计数

- **形式化状态 / 适用与待验证**：A可复核管理流程；原法浪级仍人工，原理本身无直接交易。待检验其价值是否超出普通多尺度趋势。

### F06.04 Fibonacci 回撤

- **C1 来源与 v1 校订**：[F06-S05](sources-F01-F06.md#f06-s05)。EWI 书籍节选讨论.382/.618等比例及常用50%回撤；补充50%不是相邻Fibonacci数比的极限值。保留v0，数列性质不证明市场必在相应价位反转。
- **输入与参数来源**：已确认且事前冻结的上涨段L→H，H>L；比例集合Q、容差e、观察期限q。Q可登记{.382,.5,.618}，.5为市场惯例项；锚点选择SW(k)为A。
- **R1 / A1 明确规则**：水平Zr=H-r*(H-L)；触及只产生位置标签。A确认需先触区再收盘重新上越区上沿，失效为收盘跌破L；下跌段镜像使用有向段长，保持正尺度。

```text
P1 锚点未确认、H<=L或比例不在(0,1)：UNKNOWN
P2 在H首次确认时冻结L/H/Q，不把后来高点倒替换旧锚点
P3 每r计算Zr及区间[Zr-e*(H-L),Zr+e*(H-L)]；记录触区时刻
P4 先检查C<L或期限已过，取消全部旧区间
P5 已触区且后续收盘上穿该区上沿，输出SIGNAL(r,A)并消费该区；一根跨多个区保留全部标签但不叠加风险
P6 输出触及/确认/失效统计；单纯触及NO_DIRECT_TRADE
```

- **正例 / 反例 / 缺失例**：100→200段的.618位为138.2；价格从未进入区间不发确认；高点仍在延伸时不能提前冻结最终H；多锚点可得不同水平，须预登记一个版本。
- **形式化状态 / 适用与待验证**：R比例思想+A位置/确认组件；非完整策略。比较等距非Fibonacci网格，避免任意密集水平天然容易命中。

### F06.05 Fibonacci 扩展与投射

- **C1 来源与 v1 校订**：[F06-S05](sources-F01-F06.md#f06-s05)。来源支持同级推进段间的比例关系；保留v0并固定两种工具的不同起算点，不能混用目标公式。具体平台名称未统一，公式才是研究身份。
- **输入与参数来源**：预登记模式EXTENSION仅需确认两点上涨A→B；PROJECTION另需后续确认回撤C；正段长D=B-A；扩展比例集合Q>1，投射集合Q>0（可含1）；A目标确认/到期规则。锚点均只能在确认之后使用。
- **R1 / A1 明确规则**：两点扩展T=A+rD；三点投射T=C+rD，r可预登记1、1.618等（投射可用1）。价格到达只是退出参考，不是预先做空理由；不给新入场。

```text
P1 事前选择EXTENSION或PROJECTION及合法Q；模式不明则return UNKNOWN
P2 两模式均需确认A/B且D>0；仅PROJECTION还需确认C，缺所需锚点则return UNKNOWN；冻结本模式所需锚点
P3 EXTENSION逐r输出A+rD；PROJECTION逐r输出C+rD
P4 PROJECTION若价格跌破冻结C：return INVALIDATED参考；EXTENSION没有C条件；两模式均先服从宿主已有保护退出
P5 持有多头且未有保护退出时，若完成根Cprice>=某目标，输出TARGET_REACHED与REDUCE参考；数量由事前宿主计划决定
P6 保留所有目标及未到达结果；不得事后只展示最近一次触中的比例
```

- **正例 / 反例 / 缺失例**：A=100,B=120,C=110时1.618扩展132.36、投射142.36，不是同一目标；尚无C只能两点版；到目标并不证明反转。
- **形式化状态 / 适用与待验证**：A公式闭合的目标组件；R只支持比例思想，目标兑现率和相对等距网格增量待验证。

### F06.06 Hurst 周期分析

- **C1 来源与 v1 校订**：[F06-S06](sources-F01-F06.md#f06-s06)。David Hickson 的本人软件/教学词典支持叠加、谐和、波谷同步和周期变化；它是后继作者解释，非Hurst1970原书/1973课程。本轮原典细节UNVERIFIED_SOURCE。保留v0，并明确Hurst指数不属于本方法。
- **输入与参数来源**：只到t的价格、事前固定周期族P、训练窗w、紧随训练的验证段v、验证完成后新预测窗h、误差改善阈值η∈[0,1)（均A）；A线性趋势+正余弦回归，周期族可约束2/3整数关系但不声称复现名义谱。原法人工相位分析另记录证据。
- **R1 / A1 明确规则**：A纯因果有限周期代理：y(s)=a+bs+Σ[uj*cos(2πs/Pj)+vj*sin(2πs/Pj)]，训练最小平方估计；不居中滤波，不对验证段重选周期。FLD/VTL原课细节未核验，不能以本拟合冒称原工具。

```text
P1 缺连续等间隔价格或训练长度w<2*max(P)（A最低覆盖）：return UNKNOWN
P2 固定P/w/v/h/η后，用训练段最小化Σ(price-y)^2估计系数；秩不足return UNKNOWN；同窗拟合只含a+bs的基准
P3 冻结两模型系数预测紧随训练的v根；验证尚未结束仅留预测记录，不产生通过评分的FILTER
P4 在验证终点tV比较两模型MSE；若未满足MSE_cycle<(1-η)*MSE_base，return UNSUPPORTED；不重调或回填验证段信号
P5 仅对tV之后尚未观察的h根，用原冻结系数外推；预测周期和一阶差负转正标TROUGH_WINDOW、正转负标PEAK_WINDOW
P6 在tV登记上述未来窗口FILTER，绝不用于同一验证段；实际价格确认由宿主在未来到时执行；NO_DIRECT_TRADE
```

- **正例 / 反例 / 缺失例**：事前周期组合在后续段相位和误差稳定才保留；只在训练段正弦拟合漂亮不算；缺时间戳UNKNOWN；两周期抵消时转折不明不能强行选谷。
- **形式化状态 / 适用与待验证**：A代理可运行，原法人工相位/名义模型未完整形式化；持续趋势、冲击和漂移可能失败。应与等参数普通自回归/趋势基准比较。

### F06.09 附录：SMC

```text
P6 空头按反向颜色/边界定义镜像；冲突保留多个标签，输出FILTER/SIGNAL而不自动入场
```

- **正例 / 反例 / 缺失例**：上涨结构上破旧高标BOS，首次下破旧低标CHoCH；收盘没破只探影不是BOS；没有确认结构点UNKNOWN；OB与sweep同时出现仍不能证明机构吸筹。
