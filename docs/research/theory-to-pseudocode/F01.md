# F01 市场理论与研究基准

状态：v0 模型知识初稿，未外部核验，不构成收益验证。

本文件仅记录模型知识形成的独立初稿；未读取书籍、技能或已核验来源。以下理论解释、历史归属及实证倾向均待后续核验。理论不能直接替代交易规则，基准也不代表投资建议。编号在后续核验和形式化阶段保持稳定，不将参数变化计作新方法。

## F01.01 有效市场假说（EMH）

- **类型**：信息与资产定价理论，也是研究零假设的来源。
- **核心原理与潜在收益机制**：价格吸收相应信息集合，不能仅凭该集合稳定获得扣除成本并调整风险后的异常收益。弱式关注历史价格量能，半强式关注公开信息，强式进一步涵盖非公开信息；三者不是同一强度的命题。合理收益仍可来自承担风险、提供流动性或信息生产成本补偿。
- **交易逻辑或边界**：没有独立买卖信号；用于要求策略说明新增信息、限制条件和异常收益口径。检验结果同时依赖基准定价模型，不能把一次超额收益直接当作市场无效。
- **适用与失败环境**：适合作为竞争充分市场的研究约束；信息迟滞、套利受限、制度摩擦可能使某些版本不成立，但不保证可兑现机会。
- **模型不确定点**：弱式、半强式与强式的原始表述、有效性的条件期望定义及联合假说边界待核验；有效不等于价格永远准确。

## F01.02 随机游走与鞅基准（Random Walk / Martingale）

- **类型**：价格或收益的随机过程假设，不是交易策略。
- **核心原理与潜在收益机制**：随机游走通常将价格变化描述为不可从既有路径预测的增量；带漂移版本允许长期正期望。鞅条件只约束条件期望，不必要求增量独立同分布；波动聚集也不自动否定收益均值不可预测。其研究价值在于区分运气、风险暴露和额外预测能力。
- **交易逻辑或边界**：不能从“随机”推出必买或必卖；可作为无择时能力对照。若预测的是波动率或尾部风险，不能仅因收益方向接近随机就否定该研究。
- **适用与失败环境**：适合构造零假设和检查路径依赖偏误；结构断点、时变风险溢价、微观结构噪声会使某种具体随机模型失配。
- **模型不确定点**：价格、对数价格、收益和折现价格分别适用什么假设需要明确；随机游走、独立性、鞅及有效市场不能互换。

## F01.03 行为金融（Behavioral Finance）

- **类型**：行为与定价解释框架，包含多种可相互竞争的机制。
- **核心原理与潜在收益机制**：有限注意、锚定、损失厌恶、处置效应、过度自信与从众可能造成反应不足或过度反应；套利成本和职业约束可使偏离持续。反应不足可支持动量或公告漂移，过度反应可支持反转，但二者不能在没有区分条件时同时解释所有结果。
- **交易逻辑或边界**：先指定行为主体、可观测代理变量、发生时点和修正催化剂，再构造交易假设；“大家恐慌”不是充分入场条件，退出需说明偏差何时收敛或被证伪。
- **适用与失败环境**：注意力失衡、噪声交易集中和套利受限时更值得研究；拥挤交易、基本面持续恶化或偏差代理失真可令逆向策略长期亏损。
- **模型不确定点**：各偏差与具体资产收益间的因果关系、原始实验到市场的外推及风险解释竞争均待核验。

## F01.04 适应性市场假说（Adaptive Markets Hypothesis）

- **类型**：随竞争和生态变化演进的市场解释框架。
- **核心原理与潜在收益机制**：参与者采用有限理性决策，盈利方法被复制、资本进入后机会衰减，环境变化又可能产生新机会。因此效率及策略优势可能随时间变化，收益可来自暂时的适应速度、稀缺能力或未被充分竞争的约束。
- **交易逻辑或边界**：框架本身不提供可计算买卖点。若转成策略，需要预先说明环境指标、优势衰减证据、停用与恢复规则，不能在亏损后任意声称市场已变。
- **适用与失败环境**：适合研究制度变化、参与者更替和策略拥挤；状态识别滞后、样本稀少及反复追逐近期赢家会让适应过程本身成为过拟合。
- **模型不确定点**：原始命题与后续实务“自适应策略”的界限、可被否定的预测及环境变量选择尚未核验；动态解释力不等于稳定择时能力。

## F01.05 分形市场假说（Fractal Market Hypothesis）

- **类型**：多尺度参与者与市场稳定性的解释框架。
- **核心原理与潜在收益机制**：不同持有期限的参与者提供不同尺度的需求与流动性；期限结构失衡、参与者集中到同一时间尺度时，市场可能变得脆弱。自相似、长记忆、厚尾等统计描述与此相关，但不是同一个命题，也不保证存在方向可预测性。
- **交易逻辑或边界**：不能仅凭分形维数或 Hurst 指数直接买卖。若研究趋势延续或风险状态，需要指定估计窗口、估计误差和对应经济机制；退出不能依赖未来才能确认的尺度切换。
- **适用与失败环境**：有助于描述多时间尺度和流动性危机；有限样本、非平稳性和结构突变可能制造虚假的长记忆。
- **模型不确定点**：分形市场假说与数学分形、赫斯特统计量的确切联系待核验；此处 Hurst 统计量不得与 F06 的周期分析体系混为一谈。

## F01.06 风险溢价（Risk Premium）

- **类型**：收益来源与定价框架，不是单一择时体系。
- **核心原理与潜在收益机制**：投资者承担在不利经济状态下尤其难以承受的风险，可能要求正的预期补偿。股票市场风险、期限、信用、流动性及波动风险等是不同暴露；“风险更高”并不必然有溢价，分散可消除的风险未必被补偿，预期溢价也可能时变或为负。
- **交易逻辑或边界**：配置应先确认实际暴露、预算、持有期限和退出约束。没有统一价格入场点；可以持有风险暴露，也可研究定价偏离，但不能把所有盈利事后命名为风险补偿。
- **适用与失败环境**：适合分解基准收益与策略超额；尾部冲击、融资约束和持有期不足会使理论上的长期补偿难以承受。
- **模型不确定点**：每种溢价的方向、可交易代理和独立实证需要逐项核验；因子收益不自动证明风险因果机制。

## F01.07 反身性（Reflexivity）

- **类型**：认知、价格与基本面反馈的解释框架。
- **核心原理与潜在收益机制**：参与者对现实的理解影响决策，决策推动价格，而价格又影响融资、抵押品、公司行为和未来现金流。正反馈可延长趋势，约束触发后的负反馈可导致急剧反转。潜在机会来自识别反馈链及其尚未充分计价的持续性，而不是假设价格必定回归固定真值。
- **交易逻辑或边界**：需要明确反馈变量、传导顺序、融资约束与失效事件；不能仅因上涨就断言泡沫，也不能仅凭“泡沫终将破裂”选择做空时点。
- **适用与失败环境**：融资依赖高、杠杆和抵押品反馈明显的环境更适合研究；反馈方向不稳定、外生政策冲击或持仓容量不足会使交易难以兑现。
- **模型不确定点**：可操作的转折先行证据、原始理论与后续叙事化使用边界待核验，需防止事后解释所有涨跌。

## F01.08 拍卖市场理论（Auction Market Theory）

- **类型**：价格发现、接受与拒绝的观察框架。
- **核心原理与潜在收益机制**：市场通过报价和成交寻找愿意成交的价格区域；平衡阶段围绕被接受的价值区域双向交易，失衡阶段向新区域探索。潜在机制分别是平衡中的回归与失衡后的延续，前提是能在当时区分价格探测、接受和拒绝。
- **交易逻辑或边界**：可研究被拒绝的区间外探索回归，或被接受的新区域顺势延续；退出依据原假设被破坏。停留时间、成交分布与成交量只是不同证据，不能从它们直接断言某类机构意图。
- **适用与失败环境**：连续双向拍卖、成交数据较完整时较便于观察；开盘跳空、单边涨跌停及低流动性会削弱常用判断。
- **模型不确定点**：接受与拒绝的可复现定义、会话划分及与 Market Profile 的原始关系待核验；相关量价工具主归属 F08。

## F01.09 现金基准（Cash Benchmark）

- **类型**：研究与资金占用对照，不是预测策略。
- **核心原理与潜在收益机制**：不承担目标市场方向风险，将资金保留为现金或事先指定的可实现现金替代品。收益可能来自存款、货币工具利息，现金本身并非必然取得某个“无风险利率”；名义稳定还需与通胀和机会成本区分。
- **交易逻辑或边界**：基准不按市场信号择时。研究必须明确是否计息、计息工具、费用、日历及再投资口径；策略空仓收益应与同口径现金对比，不能单方面忽略闲置资金收益。
- **适用与失败环境**：用于衡量承担风险是否值得、资金空置与回撤控制的代价；工具信用风险、流动性限制或现金替代品价格波动可能使所谓现金不再稳定。
- **模型不确定点**：本项目最终可用工具与历史利率尚未选择；在核验前不假定现金收益恒零，也不赋予无法获得的融资利率。

## F01.10 买入持有基准（Buy and Hold）

- **类型**：被动持有对照与风险暴露方案。
- **核心原理与潜在收益机制**：在预先确定时点买入指定资产或可交易指数代理并持续持有，收益主要来自资产现金流、价值变化及风险溢价，减少主动换手。单只股票买入持有、固定股票篮子和随指数规则更新的产品不是同一基准。
- **交易逻辑或边界**：起点、资金投入和终点由研究问题确定，不能挑选事后低点；分红、退市、停牌、公司行动与指数成分更替必须口径一致。不存在从理论导出的择时退出信号。
- **适用与失败环境**：适合检验主动规则是否优于承担同类市场风险；单一企业永久损失、长期估值压缩和无法承受的回撤会限制实用性。
- **模型不确定点**：应采用价格收益还是可实现总回报、分红何时再投及指数代理成本待后续约定；长期上升不能作为无条件前提。

## F01.11 等权基准（Equal Weight）

- **类型**：组合构造与比较基准，包含不同再平衡版本。
- **核心原理与潜在收益机制**：向事先定义的成员分配相同权重，降低按市值加权时对大公司的集中。相对市值基准的差异可能来自规模、行业暴露和再平衡；持续等权需要买入相对落后者并卖出相对领先者，收益差异不是免费的分散红利。
- **交易逻辑或边界**：初始等权后不再调仓与定期恢复等权必须分开；成员纳入、剔除、停牌和不可成交处理需预先规定。入退不是个股技术信号，而是组合规则触发。
- **适用与失败环境**：适合检查选股增益与集中风险；强者持续领先、小盘流动性差、频繁换手和下跌资产不断加仓可能使其落后。
- **模型不确定点**：历史成分可得性、再平衡频率、成本及缺失成员处理尚未决定；不得用今天仍存续的股票回填历史等权池。

### F01.01 有效市场假说

- **C1 来源与 v1 校订**：[F01-S01](sources-F01-F06.md#f01-s01)。支持信息集合与联合假说边界；保留 v0，补充：拒绝检验不单独定位为市场无效。
- **输入与参数来源**：历史可知信息集 I、同期费前可实现收益与另计成本、预登记风险模型 M、检验区间与显著性标准 α（A）。
- **R1 / A1 规则**：R1 检验对象是信息效率与 M 的联合命题；A1 冻结仅使用 I 的预测规则，分离训练与后来已实现结果。不是交易指令。

```text
P1 冻结 I、M、样本切分、规则与 α，不根据结果重选
P2 对已结束的评价期收集当时预测、实际收益、基准和费用
P3 超额 = 费前实际策略收益 - M解释的收益 - 尚未包含的费用
P4 若存在足够独立观测，报告超额估计、区间和试验次数
P5 超额不能稳定区别于0：未拒绝联合假说；否则：联合假说受挑战
P6 return NO_DIRECT_TRADE，附模型与信息集边界
```

- **E 正例 / 反例 / 缺失例**：正：仅历史价格规则在留出期仍有费用后异常收益，挑战弱式联合假说；反：优势被风险暴露或成本解释；缺：历史信息时间或风险基准缺失→UNKNOWN。
- **形式化状态、市场适用与待验证点**：可形式化为研究检验；不等于直接可交易。适用各市场，检验结果依赖成本、数据与风险模型。

### F01.02 随机游走与鞅

- **C1 来源与 v1 校订**：[F01-S01](sources-F01-F06.md#f01-s01)。支持随机游走与有效市场并不等同、方差比例检验能研究增量相关；保留 v0，明确拒绝随机游走不证明可套利。
- **输入与参数来源**：等间隔对数收益 r、聚合尺度 q>1、训练期均值 μ、预登记推断法；独立同分布是 A 的被检验零假设。
- **R1 / A1 规则**：R1 鞅只约束条件期望，随机游走可更强；A1 用方差比描述固定 q 下的增量关联，推断须容许所声明的异方差。

```text
P1 若价格不正、间隔不齐或样本不足：return UNKNOWN
P2 r[t] = log(P[t]/P[t-1])；只用已完成区间
P3 VR = Var(sum最近q个r)/(q*Var(r))
P4 若分母为0：return UNKNOWN；不把常数序列当作盈利机会
P5 按预登记推断法报告 VR 与1的差异及区间
P6 return NO_DIRECT_TRADE；不得从拒绝零假设直接生成订单
```

- **E 正例 / 反例 / 缺失例**：正：VR 稳定偏离 1，提示该随机游走版本不符；反：差异在费用、非同步交易或抽样修正后消失；缺：除权造成价格断点但无公司行动数据→UNKNOWN。
- **形式化状态、市场适用与待验证点**：A 下可检验；此处不实现统计检验。方向均值、波动可预测性和鞅性质必须分别报告。

### F01.03 行为金融

- **C1 来源与 v1 校订**：[F01-S02](sources-F01-F06.md#f01-s02)。支持套利依赖资本、错价扩大可引发资金撤出；保留偏差框架，但本次来源没有逐项证明锚定、从众等全部偏差。
- **输入与参数来源**：事前定义的事件、关注度或预期差代理、公开时间、已实现后续收益、风险/行业对照；分组边界及持有期是 A。
- **R1 / A1 规则**：R1 纠偏交易可能受资本约束；A1 仅选一个可被否定的机制，例如低关注公开事件反应不足，禁止涨跌后在过度与不足反应间切换解释。

```text
P1 固定机制：低关注事件的信息反映比高关注事件慢
P2 按事件首次公开前的关注指标分组；记录方向明确的预期差
P3 等待事前持有期结束，计算两组费用后风险调整收益
P4 比较低关注组是否存在预登记方向的后续漂移
P5 若差异不存在或被已知风险解释：否定该代理命题
P6 return NO_DIRECT_TRADE；不将组间相关性等同于行为因果
```

- **E 正例 / 反例 / 缺失例**：正：符合机制预期且对照后仍有漂移，只支持候选命题；反：低关注组没有差异或逆向；缺：分析师预期只有后来修订值→UNKNOWN。
- **形式化状态、市场适用与待验证点**：A 研究设计；可迁移市场但代理需重验。各偏差原始实验、因果识别和可实现收益仍未覆盖。

### F01.04 适应性市场

- **C1 来源与 v1 校订**：[F01-S03](sources-F01-F06.md#f01-s03)。支持竞争、适应与机会随环境变化，以及风险收益关系可能时变；保留 v0，不把作者定性命题说成已给出切换阈值。
- **输入与参数来源**：固定策略、策略可见结果、参与者/拥挤或制度变量、前后分段；环境分段与停用阈值 θ 为 A。
- **R1 / A1 规则**：R1 优势会随生态变化；A1 预登记环境变量，检验其是否解释后续优势变化。策略亏损本身不能事后定义全部环境。

```text
P1 在训练段冻结策略与环境分段边界
P2 于每个决策时点仅按已知环境变量分组
P3 后来结果可用时，计算各组净超额及不确定区间
P4 比较环境变量能否解释下一段优势，而非同段结果
P5 若分组不能改善样本外解释：拒绝该自适应代理
P6 return NO_DIRECT_TRADE；研究停用/恢复规则另行登记
```

- **E 正例 / 反例 / 缺失例**：正：事前拥挤指标升高后同一优势下降；反：只有看到亏损后重命名环境才成立；缺：参与者代理历史不存在→UNKNOWN。
- **形式化状态、市场适用与待验证点**：解释理论已获正文支持，环境代理为 A；尚未获得稳定状态切换策略或收益证明。

### F01.05 分形市场

- **C1 来源与 v1 校订**：[F01-S04](sources-F01-F06.md#f01-s04)。作者公开正文支持期限异质性、趋同和流动性脆弱链条；补充：官网说明其第七条为后续新增，不能全部追溯为1994原版。
- **输入与参数来源**：参与者持有期限分布 p[h]、价差/深度等流动性量、波动；分组、观察窗口为 A。
- **R1 / A1 规则**：R1 期限趋同是作者的脆弱性假说；A1 用 H=-Σp log p 描述期限多样性，下降是否领先流动性恶化才是具体检验，H 不等于 Hurst 指数。

```text
P1 若无期限分布或无法说明代理对应关系：return UNKNOWN
P2 按固定期限组计算比例 p[h]，总和校验为1
P3 diversity = -sum(p[h]*log(p[h]))，0项贡献为0
P4 记录 diversity 的变化和随后价差、深度、波动变化
P5 在独立时段检验多样性下降是否领先预期的脆弱化
P6 return NO_DIRECT_TRADE；价格尺度代理不得冒充真实投资期限
```

- **E 正例 / 反例 / 缺失例**：正：期限分布集中后深度下降，只支持该方向证据；反：期限趋同而流动性不恶化；缺：只有单条价格序列且无合格期限代理→UNKNOWN。
- **形式化状态、市场适用与待验证点**：R 定义已支持；A 观测模型需验证。作者援引实证不等于本轮完成独立复现。

### F01.06 风险溢价

- **C1 来源与 v1 校订**：[F01-S05](sources-F01-F06.md#f01-s05)。Sharpe 本人访谈支持系统风险补偿、坏状态暴露及预期与实现收益区别；保留 v0，限定本次来源主要为 CAPM，不能外推证明所有溢价。
- **输入与参数来源**：资产/市场总收益、现金收益、估计窗口及市场代理；窗口与风险代理为 A。
- **R1 / A1 规则**：R1 不是所有风险都应获补偿；A1 用单因子残差分析检验某收益是否主要来自市场暴露，β估计只用此前样本。

```text
P1 若资产、市场、现金收益缺失或市场方差为0：return UNKNOWN
P2 β = Cov(资产超额,市场超额)/Var(市场超额)，仅用训练期
P3 将 β 固定到下一评价期
P4 残差[t] = 资产超额[t] - β*市场超额[t]
P5 报告平均残差、坏状态损失、费用及估计不确定性
P6 return NO_DIRECT_TRADE；残差非零也不直接证明alpha
```

- **E 正例 / 反例 / 缺失例**：正：高收益伴随更高市场 β，风险补偿解释更有力；反：净残差持续存在，单因子解释不足；缺：现金利率或退市收益缺失→UNKNOWN。
- **形式化状态、市场适用与待验证点**：CAPM 代理可形式化；估计 β 不是事前真实 β。市场、期限、信用及波动溢价应分别研究。

### F01.07 反身性

- **C1 来源与 v1 校订**：[F01-S06](sources-F01-F06.md#f01-s06)。Soros 原讲稿明确价格可改变基本面，区分正反馈与负反馈；保留 v0，补充正反馈可能中途被负反馈打断。
- **输入与参数来源**：当时可知价格、融资成本/抵押品/信贷数量、后续经营或现金流指标；因果链与滞后是 A。
- **R1 / A1 规则**：R1 双向反馈是核心而非单纯错价；A1 为一个经济链条写两条可证伪预测，不能仅以价格上涨认定泡沫。

```text
P1 冻结链条：价格上升→融资条件改善→可观测经营扩张
P2 记录价格变化先于融资变化的时点证据
P3 记录融资变化先于经营变化的时点证据
P4 检查政策、需求等共同原因是否可解释两者
P5 任一必要环节不出现：标记该链条未获支持
P6 return NO_DIRECT_TRADE；方向与转折交易仍需独立规则
```

- **E 正例 / 反例 / 缺失例**：正：价格上升后融资改善并支持经营扩张，是候选证据；反：融资未变或融资先于价格变化；缺：只有价格无融资信息→UNKNOWN。
- **形式化状态、市场适用与待验证点**：A 因果研究，不提供泡沫做空时点；作者主张与独立因果证据分开。

### F01.08 拍卖市场理论

- **C1 来源与 v1 校订**：[F01-S07](sources-F01-F06.md#f01-s07)。CME 定义支持用价格与时间观察接受和拒绝；只核到官方工具定义，未取得 Steidlmayer 原典，故具体拍卖交易法仍 UNVERIFIED_SOURCE。
- **输入与参数来源**：逐时段价格访问、预先固定价值区 [L,U]、观察窗 m 与接受比例 θ（全部 A）；相关量价工具见 F08。
- **R1 / A1 规则**：R1 接受/拒绝是观察分类；A1 用完成时段在区间外的占比作为接受代理，回到区间且占比不足作拒绝代理，输出状态而非交易。

```text
P1 若价值区未在观察前冻结或时段缺失：return UNKNOWN
P2 outside = 完成的m时段中收盘在U上方的数量/m
P3 若 outside >= θ 且 C[t]>U：return FILTER(上方接受代理)
P4 若曾越过U且 C[t]<=U 且 outside<θ：return FILTER(上方拒绝代理)
P5 其余 return WAIT；下方情景按L镜像判断
P6 输出附 A 与 UNVERIFIED_SOURCE，不断言机构意图
```

- **E 正例 / 反例 / 缺失例**：正：预定窗口持续收于 U 上方→接受代理；反：冲出后迅速回区间→拒绝代理；缺：价值区由全日最终数据反推→UNKNOWN。
- **形式化状态、市场适用与待验证点**：A 下可形式化的过滤器，非完整拍卖原法。θ和m需前推检验；连续拍卖缺失时不适用。

### F01.09 现金基准

- **C1 来源与 v1 校订**：[F01-S08](sources-F01-F06.md#f01-s08)。SEC 正文支持现金与现金替代工具不同、存在通胀及部分工具损失风险；保留 v0，收益口径由具体可获得工具决定。
- **输入与参数来源**：期初现金、实际可获得的逐期费前计息利率 i[t]、日计息规则与费用；不计息版本 i=0 是 A 并明确命名。
- **R1 / A1 规则**：R1 现金替代品并非同质；A1 固定一个工具及复利规则，不因事后利率更高切换基准。

```text
P1 若计息工具或利率口径未声明：return UNKNOWN
P2 V[0] = 初始现金；禁止目标风险资产敞口
P3 每个已完成计息期：V[t] = V[t-1]*(1+i[t]) - fee[t]
P4 若利率缺失：暂停报告该期收益，不补0
P5 若工具有价格风险，按真实净值计量并重命名基准
P6 return TARGET_WEIGHT(现金工具=1)，无市场择时
```

- **E 正例 / 反例 / 缺失例**：正：明确零息现金或有真实利率的存款序列均可对照；反：把货币基金亏损抹平为零；缺：只知道当前利率却无历史值→UNKNOWN。
- **形式化状态、市场适用与待验证点**：A 基准规格闭合；不同货币、工具、税费需各自口径，非投资建议。

### F01.10 买入持有基准

- **C1 来源与 v1 校订**：[F01-S09](sources-F01-F06.md#f01-s09)。FINRA 解释被动持有与基金内部成分更替可以并存；保留 v0，明确持有一只基金不等于固定持有其最初全部股票。
- **输入与参数来源**：事前固定资产、开始/终止日期、未复权可交易价格、费用、实际现金分红与拆并股等公司行动；禁止用含分红再投的总收益价再叠加现金分红；分红留现金或再投为 A。
- **R1 / A1 规则**：R1 低干预持有与主动择时不同；A1 本卡固定资产持有至预登记终点，分红留现金，禁止按表现换标的。

```text
P1 在预登记起点提交一次买入意图，按确认成交建立持仓
P2 已持有：仅处理真实分红、拆并股、退市和现金费用
P3 分红进入现金；不再买入，不按价格涨跌退出
P4 到预登记终点：发 EXIT 意图，未成交仍为持有
P5 缺公司行动或终值：return UNKNOWN，并保留资产状态
P6 报告持仓市值+现金；不将订单意图当作成交
```

- **E 正例 / 反例 / 缺失例**：正：买入基金后其内部调仓仍可属于持有该基金；反：跌时换资产却继续称固定买持；缺：退市无回收价值资料→UNKNOWN。
- **形式化状态、市场适用与待验证点**：A 下闭合基准；停止交易、清算与资产替换会产生版本差异，应保留且说明。

### F01.11 等权基准

- **C1 来源与 v1 校订**：[F01-S10](sources-F01-F06.md#f01-s10)。S&P 官方定义支持同成分在季度再平衡时等权；保留 v0，固定初始等权与周期重置等权分为两版本，季度仅为该指数规则。
- **输入与参数来源**：历史时点证券池 U[t]、再平衡日历、总收益、交易费用、不可成交成员；本研究日历和池为 A。
- **R1 / A1 规则**：R1 等权是重置时点的目标，不是每日自动相等；A1 输出目标权重并单列无法实现的残差，禁止删除停牌成员后悄悄重算。

```text
P1 非再平衡日：return HOLD，允许权重自然漂移
P2 若历史成员或成员价格缺失：return UNKNOWN
P3 N = size(U[t])；若N=0：return WAIT
P4 对每个成员 i：target[i] = 1/N
P5 对已确认可成交差额发调仓意图，扣费用后记录实际权重
P6 不可成交差额保留并披露；不得声称已达到等权
```

- **E 正例 / 反例 / 缺失例**：正：两资产各半，涨跌后在指定日恢复各半；反：每日恢复却标称季度基准；缺：某期成分只剩幸存公司→UNKNOWN。
- **形式化状态、市场适用与待验证点**：R 目标定义明确、A 市场适配；需比较规模暴露、换手、成本和停牌处理。
