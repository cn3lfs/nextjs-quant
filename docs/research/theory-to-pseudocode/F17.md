# F17 仓位、组合与交易管理

> v0 模型知识初稿，未外部核验，不构成收益验证

本稿只依据模型知识整理。仓位规则改变收益路径、风险与资金需求，不自动把负期望信号变成正期望；止损价不是保证成交价，名义分散也不是独立风险。除有明确说明，所有增加资金需求都必须受可用资金约束，不假设无限融资或事后补款。心理与纪律组件约束研究和决策，不作为价格预测信号。

## F17.01 固定金额仓位

- **名称别名、类型：** Fixed Notional、定额投入；单笔资金分配方法。
- **理论及收益机制：** 每次信号使用相同名义金额，使交易间投入较易比较；它不随账户增长自动复利，也不保证各笔风险相同，因为价格波动和退出距离可能差别很大。
- **选取与退出或边界：** 先由独立策略决定是否交易，再把固定金额换算成可成交数量，并预设现金不足、最小交易单位和多信号冲突时的处理。金额随投入计划定期重设可以作为明确变体，不能事后逐笔修改；交易退出依基础策略而非金额规则本身。
- **适用与失败：** 适合比较信号或控制单笔绝对投入的场景；连续亏损后同一金额占权益比例越来越大，多个相关头寸可能叠加风险，跳空及高波动标的也可能造成不均衡亏损。
- **记忆不确定点：** 固定金额、固定股数和固定手数在传播中常混称，正式规格必须写清被固定的对象；此卡不主张某个金额适合任何账户。

## F17.02 固定权益比例仓位

- **名称别名、类型：** Fixed Fractional Allocation、按权益定比；资金分配方法，与按止损距离定风险不同。
- **理论及收益机制：** 每笔或每项资产投入当前权益的固定比例，使盈利后规模增加、亏损后规模减少，影响复利和回撤路径；比例仓位不能凭空形成交易优势。
- **选取与退出或边界：** 预先说明权益按已实现现金还是含浮盈净值计算，比例对应名义仓位还是风险金额；本卡按名义金额定义。处理同时信号时规定总分配上限与优先级，退出由基础策略触发，是否随权益变化持续再平衡另行声明。
- **适用与失败：** 适合投入规模希望随账户变化的策略；高相关持仓、杠杆、估值滞后和跳空会令实际风险远高于名义比例，频繁重平衡还会增加成本。
- **记忆不确定点：** 固定比例中文名也可能指按利润台阶增仓的 Fixed Ratio 方法，二者不应混用；后者具体台阶关系需另核验，不能从此卡推定。

## F17.03 固定单笔风险

- **名称别名、类型：** Fixed-risk Position Sizing、R 风险单位、止损距离定仓；仓位管理组件。
- **理论及收益机制：** 以账户可承受的计划损失除以入场到风险退出位置的单位损失，试图让不同波动和不同价格资产的计划风险可比；这是风险分配，不是止损必然有效的承诺。
- **选取与退出或边界：** 先由策略或结构定义有效退出位置，再计入乘数、费用和保守滑点确定规模，另设名义仓位、流动性和组合总风险上限。风险距离为零或不可解释时不反向制造巨量仓位；退出依已登记规则，不能为了扩大仓位任意缩短止损。
- **适用与失败：** 适合有明确价格失效条件的交易；跳空、涨跌停、停牌和多个相关标的同时止损可造成实际损失超过计划，期权等非线性产品更不能只按价差近似。
- **记忆不确定点：** R 值的统计口径、是否含费用以及对浮动止损的处理不统一，正式研究应固定定义，不假定一个风险百分比有普适合理性。

## F17.04 波动率目标

- **名称别名、类型：** Volatility Targeting、波动缩放、目标风险仓位；动态暴露控制。
- **理论及收益机制：** 按过去可得风险估计调节仓位，波动高时减少、波动低时增加，使预计组合波动接近目标；可能改善某些风险路径，但收益变化依赖波动与回报关系，不能视为无条件增益。
- **选取与退出或边界：** 先选定波动估计窗口、更新频率和目标，再明确单资产或组合协方差口径、最大杠杆、换仓缓冲及现金去向。风险估计过低不能无限增仓，触及风险或资金约束时减仓；基础信号退出优先于缩放规则。
- **适用与失败：** 适合风险可观测且交易成本可控的组合；平静后跳跃、估计滞后、相关性同步上升和危机中被迫去杠杆可能导致追跌，重新加仓过慢也会错过反弹。
- **记忆不确定点：** 波动控制、风险平价和逆波动权重相互关联但并不相同，各文献目标实现与收益改善结论需核验，本文不指定最佳窗口。

## F17.05 Kelly 与分数 Kelly

- **名称别名、类型：** 凯利准则、Log-optimal Growth、Fractional Kelly；在给定概率模型下的长期增长仓位原则。
- **理论及收益机制：** 在特定假设下选择使预期对数财富增长最大的下注比例，关注复利增长而非短期胜率；若优势或分布估计错误，最优解也会错误，高估优势尤其危险。
- **选取与退出或边界：** 只有在收益分布、相关性和损失边界可合理描述时估计比例；简单二元赌局公式不能直接套到多资产、非固定盈亏的交易。分数 Kelly 对估计比例做折扣，并另设杠杆与回撤上限；比例可为零，资金分配不代替基础信号的退出。
- **适用与失败：** 适合研究概率与资金增长关系；非平稳市场、尾部漏估、相关下注及借贷限制会使理论增长率不可靠，即使模型正确，完整 Kelly 仍可能出现难以承受的回撤。
- **记忆不确定点：** 原始定理条件、连续分布与多资产推广需核验，胜率和盈亏比的有限样本估计不能被当成已知真实参数。

## F17.06 金字塔、反金字塔与分层加仓

- **名称别名、类型：** Pyramiding、分层建仓、反金字塔；头寸路径设计，名称在不同资料中有歧义。
- **理论及收益机制：** 分次建立仓位可把部分资金留待趋势确认，但也会提高后续成交价并改变风险；顺势加仓不是盈利保证。为避免名称混乱，本稿分别明确“后续批次递减”和“后续批次递增”，不依据名称推定方向。
- **选取与退出或边界：** 预定首次仓位、加仓触发、每批大小、最多批数与全仓风险，区分价格朝有利方向加仓和下跌摊低成本。每次增加后重算最差损失及相关风险，达到失效条件时按统一或分批规则退出；浮盈不能被视为没有成本的免费筹码。
- **适用与失败：** 适合信号逐步确认或需控制初始试错的策略；震荡假突破、后段大额加仓、跳空和集中撤退可把已有盈利转为大亏。
- **记忆不确定点：** 金字塔、倒金字塔和反金字塔在作者及中文实践中的对应关系须逐源核验，正式规格必须直接写批次序列和触发方向。

## F17.07 马丁与反马丁

- **名称别名、类型：** Martingale、Anti-martingale、亏损后加码与盈利后加码；仓位递推规则。
- **理论及收益机制：** 马丁在亏损后增加下一次投入，试图用一次获利覆盖先前亏损；反马丁在获利后增加、亏损后减少。两者只改变资金路径，有限资金和负期望游戏不会因递推而获得保证盈利。
- **选取与退出或边界：** 预设初始投入、放大倍数、最大层数、总损失与资金上限，明确连续交易之间是否独立及何时重置。马丁必须评估最坏连续亏损的累计需求，反马丁须限制胜后大额下注的回吐；基础信号和停止条件仍需独立存在。
- **适用与失败：** 可用于比较仓位路径的研究；厚尾、长连败、流动性枯竭和杠杆限制会使马丁资金需求失控，反马丁也会在连胜结束时承受较大回撤，不能只看高胜率统计。
- **记忆不确定点：** 马丁投注法与概率论“鞅”概念有关联但不等义，交易文献的具体变体差异大；任何恢复亏损保证都必须被资金与成交约束否定或核验。

## F17.08 分批投入与定期定额 DCA

- **名称别名、类型：** Staged Entry、Dollar-cost Averaging、定投；现金流与建仓安排，信号分批和定期定额是不同变体。
- **理论及收益机制：** 将一次性投入分散到多个日期或确认节点，减少对单一入场时点的依赖；DCA 在价格较低时同额购买更多份额，但不保证优于立即投入，长期上涨中保留现金也有机会成本。
- **选取与退出或边界：** 明确资金是已在手还是未来工资现金流，固定投入周期、金额、资产与最长计划；基于信号的分批另登记触发条件，不能事后改成择时。退出依据投资目标、资产假设或既定期限，不由平均成本低于现价自动定义成功。
- **适用与失败：** 适合稳定新增现金流或降低单次时点风险的安排；资产永久衰退、过度集中、现金中断和无限延长计划可造成持续损失，定投不能拯救失去价值的标的。
- **记忆不确定点：** DCA 与一次性投入研究是否假设资金提前可得非常关键，历史比较结论需按现金流和机会成本口径核验。

## F17.09 价值平均

- **名称别名、类型：** Value Averaging、目标市值路径投入；动态现金流分配方法，与基本面价值投资不同。
- **理论及收益机制：** 预设组合市值的目标增长路径，低于路径时补入较多资金，高于路径时减少投入或卖出，形成机械逆向再分配；收益表现包含外部现金流影响，不能仅用账户终值比较优劣。
- **选取与退出或边界：** 固定初值、目标增速、检查频率、最大新增现金及超额资金处置规则；资金不足时必须有降级或停止条件，不许在回测中无限补款。达到投资目标、计划期末或基础资产假设失效时退出，现金储备与组合一起计量。
- **适用与失败：** 适合现金调配能力明确且可承受逆势增投的安排；长期下跌会不断要求追加资金，长期上涨可能过早减仓，路径过于激进会造成不可持续现金需求。
- **记忆不确定点：** 原始价值平均方法的目标路径、现金账户及收益率评价建议需核验，资金加权收益率与时间加权收益率不可混为一谈。

## F17.10 再平衡与恒定权重

- **名称别名、类型：** Rebalancing、Constant Mix、日历或阈值再平衡；组合维护方法。
- **理论及收益机制：** 将漂移的资产权重恢复到预设配置，以维持风险意图；某些波动和相关结构下可能形成再平衡收益，但它不是不依赖资产回报和成本的免费利润。
- **选取与退出或边界：** 先确定资产与目标权重，再选择固定日期、偏离区间或新增现金优先纠偏；阈值和目标变更规则事先冻结，考虑税费与最小交易量。战略假设改变时修订目标，不以价格下跌自动认定必须无限补仓，组合退出另由目标或风险规则决定。
- **适用与失败：** 适合目标配置稳定且资产可交易的组合；单边趋势、资产永久损坏、交易成本高和相关性骤升会使机械卖强买弱不利，名义权重稳定也可能掩盖风险权重变化。
- **记忆不确定点：** 再平衡溢价、分散收益与波动收割的数学条件和术语常被混用，需要后续核验，不保证任意两个资产反复换仓均能获利。

## F17.11 均值方差配置

- **名称别名、类型：** Mean-Variance、有效前沿、最小方差；组合优化理论与配置方法。
- **理论及收益机制：** 在给定预期收益和协方差下，选择收益风险权衡符合目标的权重，利用不完全相关降低组合方差；有效前沿是输入假设下的结果，不是未来真实最优保证。
- **选取与退出或边界：** 明确资产池、估计时点、预期收益模型、协方差和权重约束，可选择目标风险、目标收益或最小方差变体；按固定频率重估并限制权重变动。无信号优势时不凭优化器制造收益预测，退出或换仓依约束和目标更新，而非单证券形态。
- **适用与失败：** 适合目标和资产集合明确的研究；预期收益误差、协方差不稳定、极端权重和非正态尾部可使样本内优秀组合在未来恶化，方差也未必对应投资者全部风险。
- **记忆不确定点：** 经典假设、不同有效前沿定义与后续稳健改进需核验；收缩、Black-Litterman 等扩展不应自动冒充原始均值方差理论。

## F17.12 风险平价

- **名称别名、类型：** Risk Parity、Equal Risk Contribution、逆波动近似；组合风险分配方法。
- **理论及收益机制：** 让不同资产或风险来源贡献更平衡，减少名义均分却被高波动资产主导的问题；风险平衡不自动提高预期收益，也不能保证危机期间风险仍均等。
- **选取与退出或边界：** 先定义总风险指标与各资产的边际贡献，明确相关性估计、约束和是否使用杠杆，再按目标调整权重。只用波动倒数的简单权重不总等于考虑相关性的等风险贡献；定期再估或偏离阈值触发换仓，融资和杠杆限制必须优先。
- **适用与失败：** 适合多资产且风险估计相对可靠的组合；低波资产可能获得很大名义仓位，久期集中、股债同跌、相关性上升与杠杆成本会使风险平价遭遇回撤。
- **记忆不确定点：** 风险贡献定义、求解条件以及与全天候和最小方差的关系需核验，不把一种固定资产比例称为唯一风险平价公式。

## F17.13 CPPI 组合保险

- **名称别名、类型：** Constant Proportion Portfolio Insurance、恒定比例组合保险；动态风险资产配置规则。
- **理论及收益机制：** 根据组合价值超过保护底线的安全垫，按预设倍数配置风险资产，余下配置保护资产；上涨时可能增加风险暴露，下跌时减少，属于路径相关风险管理而非真正无条件保险。
- **选取与退出或边界：** 明确保护底线如何随时间变化、倍数、再平衡频率、风险资产和保护资产，以及是否允许杠杆；安全垫耗尽时停止风险暴露，是否恢复必须事前规定。底线的利率折现、费用和保护资产风险也需计入，不能把目标底线当法律承诺。
- **适用与失败：** 适合用于研究下行预算与上涨参与之间的权衡；价格跳空、交易间隔、涨跌停和保护资产失效会穿透底线，急跌后退出还可能造成无法参与反弹的现金锁定。
- **记忆不确定点：** CPPI 与固定比例投资、恒定权重及有担保结构并非同义，原始模型连续交易条件与实际离散误差需要核验。

## F17.14 回撤控制与风险预算停机

- **名称别名、类型：** Drawdown Control、权益曲线保护、风险熔断；组合风险管理组件。
- **理论及收益机制：** 从账户高点或预设基线测量损失，达到阈值时降低或停止风险暴露，以限制继续恶化；这改变路径依赖，不能保证最大回撤被阈值精确封顶，也不证明基础策略失效。
- **选取与退出或边界：** 固定权益口径、峰值是否含浮盈、软硬阈值与减仓比例，区分单笔、策略和账户级预算；设置恢复条件、观察期及峰值重置规则。停机后需以事先定义的观察信号判断恢复，不能根据错过反弹的后悔随意重启。
- **适用与失败：** 适合明确不能承受无限损失的组合；跳空使阈值失守，震荡使反复减仓加仓损耗，错误恢复条件可能永久停机或追涨杀跌，连续亏损也可能是正常随机路径。
- **记忆不确定点：** 回撤控制研究的触发、恢复及评价口径差异大，所谓收益曲线均线等代理并无普适有效性，后续须逐法核验。

## F17.15 交易心理、纪律与决策日志

- **名称别名、类型：** Behavioral Discipline、预先承诺、交易日志、连续亏损应对；研究与执行约束组件，不是价格预测或收益信号。
- **理论及收益机制：** 事先约束决策可减少后见之明、确认偏差、处置效应、损失厌恶和过度交易造成的规则漂移；它可能改善既定方法的执行一致性，不能弥补没有优势的策略。
- **选取与退出或边界：** 入场前记录可知证据、反证条件、计划风险与退出理由，结束后分开评价过程合规和随机结果；对连亏预设减风险、冷静期或复核条件，不能为回本临时加码。区分统计上可容忍连亏与数据、规则或市场关系失效，恢复须遵守预先承诺。
- **适用与失败：** 适合所有需要持续决策的研究与交易流程；日志若只写事后故事、纪律被用来拒绝反证、无限延长亏损容忍，反而可能固化错误。情绪状态可提示休息或复核，不据此推断下一根价格。
- **记忆不确定点：** 各认知偏差的实验定义及交易干预效果需独立核验，不能把成功交易者访谈当因果证据，也不声称某种心理训练保证盈利。

### F17.01 固定金额仓位

**v1 / C1：** 保留v0，A定义为每次独立新交易使用固定预算B；[F17-S01](sources-F13-F18.md#f17-s01)、[F17-S03](sources-F13-F18.md#f17-s03)支持区分固定投入与随财富变化的比例，未把该简式归为某作者独创。


**E：** B1000、P10得100股；权益由10000跌到5000仍投1000，占比翻倍；C缺失不计算。**状态/适配：** 可形式化仓位组件，需外部交易生命周期；有限资本可耗尽。

### F17.02 固定权益比例仓位

### F17.04 波动率目标

**v1 / C1：** [F16-S05](sources-F13-F18.md#f16-s05)正文指出低波环境可能积累杠杆；本卡缩放公式为A，低估波动可导致过量敞口，目标波动不是实现保证。

### F17.05 Kelly、分数 Kelly 与经验最优 f

**v1 / C1：** [F17-S01](sources-F13-F18.md#f17-s01)正文是期望对数财富最大化；[F17-S02](sources-F13-F18.md#f17-s02)正文讨论估计误差和fractional Kelly。[F17-S08](sources-F13-F18.md#f17-s08)节选支持几何增长与实际目标区别，但不认证完整optimal-f算法。
**A、输入：** 二元每单位投注赢净b、输1，赢率p，均已含费用；g(f)=p ln(1+bf)+(1−p)ln(1−f)，f*=p−(1−p)/b。使用f=max(0,min(fcap,c*f*))，0<c≤1。p/b来自仅已完成样本或明确人工概率，不把胜率均值视为已知真值。经验连续收益变体是A：过去每单位风险回报r_i，最大化Σln(1+f r_i)，要求全部正且压力亏损约束满足；不是未经读取的Vince精确原法。

```text
if 外部退出或资金硬限: EXIT_OR_REDUCE_INTENT; return
if 样本截止/费用/权益/模式/分数c或预算上限未知: return UNKNOWN
if 二元模式且(p/b未知 or p不在[0,1] or b<=0 or fcap>=1): return UNKNOWN
if 连续模式且(r_i/压力情景/有界可行域未知): return UNKNOWN
二元模式: fStar=p-(1-p)/b
连续模式: 在预设有界区间求Σln(1+f*r_i)最大且压力约束成立的fStar
f=max(0,min(fcap,c*fStar)); f=0则NO_NEW_RISK
仅有外部入场信号时输出风险投注预算=f*E
有限资本低于最小交易量即STOP，不宣称长期优势可支付当下亏损
```

**E：** p0.55、b1得f*=10%，半Kelly5%；E1000一亏后950，下笔47.5；p实际0.48时原估计仍可能持续亏。缺p只给公式不下数。**状态/适配：** 二元/经验A规则可形式化；概率可人工、Vince完整optimal-f归属UNVERIFIED_SOURCE，相关交易不能逐项独立Kelly后直接相加。

### F17.07 马丁与反马丁

**v1 / C1：** [F17-S01](sources-F13-F18.md#f17-s01)已区分财富期望和复利存续；以下翻倍风险用自主有限等比和推导，不借“资金管理”给负期望加盈利保证。反马丁是胜后加注，仍可回吐。
**A、输入：** 基础投注b、倍数m>1、连续输/赢层数k、轮次上限K、总预算B、累计损失限L≤B及单笔上限。马丁第k笔b*m^k，前n笔全输累计b(m^n−1)/(m−1)；m=2可承受完整次数floor(log2(B/b+1))。每笔全输假设仅用于此例；证券持仓亏损不固定时必须改用实际现金损失。K定义允许的最大层级数，合法k为0至K−1；初始化k=0。每个结算事件只消费一次；已投注后未结算时不产生下一注。单笔上限截断后已经不具原等比翻倍序列及回本代数性质，不能仍用原回本承诺。

```text
if 轮次已STOP或上一注尚未结算: return WAIT
if 现金/累计已实现损失/事件状态未知: return UNKNOWN
若有未消费的新结算事件: 马丁输则k+1、赢则k=0；反马丁赢则k+1、输则k=0
标记该结算事件已消费；stake=min(预设单笔上限,b*m^k)
if k>=K or 累计损失+stake>损失限 or 当前现金<stake: STOP_CYCLE; return
仅在独立有效外部信号时输出SIZE(stake)，否则WAIT；投注后等待结算
STOP后不自动另开一轮，重新预算须独立审核
```

**E：** B1000、b100、m2：100+200+400=700，余300不能下800；第四笔无法“保证回本”。反马丁100赢后200再输，会回吐并亏100（净赔率1）。结果未结算不可提前升级。**状态/适配：** 教学资金序列可形式化，非收益策略；马丁可导致停止或破产。

### F17.12 风险平价

**v1 / C1：** [F17-S07](sources-F13-F18.md#f17-s07)作者正文定义风险贡献匹配预算；真正ERC使用协方差，不一般等于逆波动。原Maillard论文入口不可达，用共同作者后续原始论文核验。
**A、输入：** 历史Σ、预算b_i>0且Σb=1；σp=sqrt(wᵀΣw)，RC_i=w_i(Σw)_i/σp；目标RC_i=b_iσp。选择长仓Σw=1；可用约束最小化Σ(RC_i/σp−b_i)²，并要求残差≤ε；ε和H为A。任意额外权重上限可能破坏精确平价，须报告残差而非改称已满足。

```text
if 资产失效或硬限触发: REDUCE_INTENT; return
if Σ/预算b/可行域缺失 or Σ非对称半正定 or b_i<=0或预算和非1: return UNKNOWN
if 非调仓日: HOLD_TARGET; return
在长仓、权重和1且wᵀΣw>0的域内求风险贡献误差最小的w
if 无可行解或求解后σp<=0: return NO_NEW_RISK
if 最大贡献误差>ε: return NO_NEW_RISK并报告不可满足
否则TARGET_WEIGHT=w; 杠杆另由F17.04独立限制
```

**E：** 两独立资产σ10%/20%，ERC权重2/3与1/3；多资产相关性不等时逆σ未必平价；协方差缺失不能声称风险平均。**状态/适配：** 配置组件可形式化，相关性突变和共同尾部待验。

### F17.13 CPPI 组合保险

**v1 / C1：** [F17-S03](sources-F13-F18.md#f17-s03)正文给出风险资产金额=m(E−floor)，m>1，并明确来不及再平衡的急跌可击穿底线。保留v0并补充非担保边界。
**A、输入：** 期初底线F0、已实现安全利率滚动F_t、E、倍数m、最大风险比例L≤1和周期H；cushion=max(E−F,0)，A_risk=min(L*E,m*cushion)。底线不能每跌一次下调；安全资产信用/利率风险另核验。

```text
更新F为预定安全利率累积后的底线，不随亏损降低
if E/F/利率或持仓未知: UNKNOWN; 保留已有风险退出; return
if E<=F: TARGET_RISK=0; 标记FLOOR_BREACH或CASH_LOCK; return

```

### F17.14 回撤控制与风险预算停机

**v1 / C1：** v0保留为A风险治理；[F17-S02](sources-F13-F18.md#f17-s02)支持过度投注与有限资金危险，但本文回撤阈值不是Thorp原法。净权益路径需剔除外部入金造成的假恢复。
**A、输入：** 以单位净值NAV而非含新入金资产额计算peak=max(历史已知peak,NAV_t)，DD=1−NAV/peak；软线d1、硬线d2>d1、缩放a<1、冷却N和恢复人工复核J为A。只能用当时历史峰值，不能用全样本最终最高点。本A恢复条件固定为DD<d1、冷却完成且J通过；恢复预算先保持a，下一预定复核仍DD<d1才升回1。全现金后若净值不能恢复，可能长期停机；不自动重设峰值或以入金解锁。

```text
if NAV/历史peak缺失: NO_NEW_RISK; return
peak=max(peak,NAV); DD=1-NAV/peak
if 非HALTED且DD>=d2: HALTED; 仅本次记录冷却起点; CANCEL_NEW; EXIT_OR_REDUCE_INTENT
if HALTED且(DD>=d1或冷却未满或J未通过): 仅减仓与退出; return
if HALTED且恢复条件全满足: 清除HALTED; RISK_SCALE=a; return
if DD>=d1: RISK_SCALE=a
else if 到预定复核且非刚恢复: RISK_SCALE=1
日志保留原峰值、软硬线状态与复核结果，不因重复DD重启冷却
```

**E：** peak100、NAV85，DD15%；入金50不应使单位净值跳到135并“恢复”；硬线触发仍可能因跳空亏更多；缺NAV停止新增。**状态/适配：** 状态机可形式化，恢复审核人工；停机机会成本待验。

### F17.15 交易心理、纪律与决策日志

**v1 / C1：** [F17-S09](sources-F13-F18.md#f17-s09)作者正文支持过度交易、费用和过度自信解释；并不证明某种日志必然增收益。v0列出的确认偏差、损失厌恶作为待检视行为分类，本轮未分别核验全部心理学原始实验。
**A、输入：** 每笔事前记录方法ID、可观察证据、失效条件、预算、退出、允许例外；事后记录真实执行和违规，不按输赢倒改理由。连续亏损数N、冷却时长H、复盘负责人J事前定；情绪自评是人工输入，不作价格预测。监控亏损计数只消费新增已结算事件；进入冷却后不因旧亏损条件仍成立反复延后结束时点。复核通过时消费该触发批次并将下一批监控计数归零，历史完整连续亏损记录仍保留。

```text
if 已有退出条件成立: 继续EXIT_INTENT，不被纪律暂停拦截
if 事前方法/证据/预算/退出任一空缺: BLOCK_NEW_RISK; return
只对新增未消费结算/违规事件更新监控计数与事件记录
if 非COOLDOWN且(新触发监控连亏>=N或新违规): COOLDOWN(H)，冻结本批触发起点
if COOLDOWN且(冷却未满或J未通过): 禁止新增/扩大风险；return DISCIPLINE_PAUSED
if COOLDOWN且冷却完成且J通过: 消费触发批次、监控计数归零、结束COOLDOWN
复盘区分盈利违规与合规亏损，保存原历史；输出纪律状态而非价格预测
```

**E：** 连亏3触发N3即暂停新增、仍执行止损；一笔违规盈利不免除记录；缺事前日志阻止新风险。**状态/适配：** 纪律组件可形式化、复核人工；完整认知偏差分类及因果收益效应未验证。
