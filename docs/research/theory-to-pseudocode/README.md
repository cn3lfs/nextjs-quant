## 本轮范围

理论覆盖跨市场，适用性首先考虑沪深股票和项目已有 BTC/ETH 现货。跨市场理论收录不扩大系统授权。没有策略实现、参数寻优、回测、数据库操作、行情下载、订单或部署。

理论完成度、来源可核验程度、形式化程度和收益证据是四个独立维度。某项可写成伪代码，既不说明理论必然正确，也不说明费用后收益为正。
