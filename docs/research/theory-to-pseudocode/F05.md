# F05 价格行为与图形

状态：v0 模型知识初稿，未外部核验，不构成收益验证。

本稿仅来自模型知识，尚未核对任何形态教材、原著或项目定义。图形是对可见价格路径的压缩描述；名称不能证明交易者意图或后续方向。每个形态都应区分形成中、已确认和失败，不能从未来结果反向选择最漂亮的图形。

## F05.01 蜡烛图（Candlestick Analysis）

- **类型**：以开高低收描述单根及多根价格关系的观察语言。
- **核心原理与潜在收益机制**：实体描述开收变化，上下影描述期间极值与收盘位置，多根组合观察先前方向是否被承接或否定。十字线强调开收接近，吞没强调相邻实体关系，星形组合强调多根转换；这些是不同证据，不能只凭颜色或名字赋予固定胜率。潜在优势必须来自特定位置与环境下的条件分布变化。
- **交易逻辑或边界**：先有趋势、支撑阻力或波动背景，再将完成的蜡烛关系作为候选；是否需要下一根确认和如何退出需另定。形态收盘前可能消失。
- **适用与失败环境**：关键区域的价格拒绝或延续可提供观察信息；随机中段、极低流动性和隔夜跳空可能产生大量无意义形态。
- **模型不确定点**：各日式形态原名、实体与影线比例、缺口要求及后世改写需核验；蜡烛不能直接显示根内成交先后。

## F05.02 Pin Bar（针形 K 线）

- **类型**：长影线表达价格拒绝的单根形态框架。
- **核心原理与潜在收益机制**：价格明显探索某方向后收回，长影线与较小实体被视为该方向推进失败的候选。下影较长常被用于观察下方拒绝，上影较长用于上方拒绝；与锤子线、射击之星有视觉交叉，但命名背景和上下文要求不必相同。
- **交易逻辑或边界**：在事先指定的位置等待形态完成，再研究突破形态另一侧、回撤进入或下一根确认；三者的成交与失败路径不同。失效常与再次越过被拒绝极值有关，但跳空会超越理想保护价。
- **适用与失败环境**：明确边界或趋势回调中较容易提出假设；趋势加速中的逆势长影、低流动性单笔成交和无背景孤立形态可能误导。
- **模型不确定点**：影线、实体与收盘位置要求及“Pin Bar”与传统蜡烛形态的关系待核验，不预先指定比例。

## F05.03 Inside Bar（内包线）

- **类型**：当前价格范围位于前根范围内的压缩形态。
- **核心原理与潜在收益机制**：内包表示短时波动收缩、暂时未突破前根边界，后续突破可能意味着平衡结束。它不等于只比较实体的孕线，也不等于范围最窄的 NR4/NR7；内包可以发生在本来就很大的母线内。
- **交易逻辑或边界**：先确定母线与内包完成，再观察母线边界或内包自身边界突破，两种参照风险不同；单内包、连续内包和假突破后收回需要不同规则。不能从压缩本身预先选择方向。
- **适用与失败环境**：趋势短暂整理或重要边界附近有研究意义；宽大母线、震荡内反复双向突破和低流动性会降低可交易性。
- **模型不确定点**：高低点相等是否允许、多层内包以哪根为母线、触发有效期及日线跳空处理需明确；同根双边触发不能假定有利次序。

## F05.04 头肩顶与头肩底（Head and Shoulders）

- **类型**：多波段趋势反转候选形态。
- **核心原理与潜在收益机制**：头部超越两个肩部，连接中间反向转折形成颈线；顶形观察创新高后无法继续推进，底形作相应镜像。理论假设是旧趋势力量衰退并在颈线破坏后转入新方向；仅出现三个凸起或凹陷不足以成立。
- **交易逻辑或边界**：区分右肩形成中的提前假设、颈线突破确认和突破回测；更早入场与更迟确认的风险不同。重返形态或越过关键结构可作为失败证据，按形态高度推算目标仅是经验假设。
- **适用与失败环境**：前置趋势明显、波段可分辨时较适合；持续区间、倾斜颈线及趋势中继的近似外形会造成误认。
- **模型不确定点**：肩部对称程度、头肩高度、颈线取点、量能及确认标准需核验；未完成右肩不能事后被当作当时完整形态。

## F05.05 双顶与双底（Double Top / Double Bottom）

- **类型**：重复试探极值后的反转候选形态。
- **核心原理与潜在收益机制**：价格两次接近相似极值而未顺利延续，中间反向波段形成确认参考。双顶强调向上试探失败，双底强调向下试探失败；两次位置相近只是候选，突破中间颈线才常被视为进一步确认，不能把任意 M/W 外形都当作反转。
- **交易逻辑或边界**：可研究第二次试探后的提前入场、颈线突破或回测，分别承担不同确认风险。突破极值继续原趋势是失败路径，形态高度目标不能被当作确定收益。
- **适用与失败环境**：已有趋势动能减弱且重复拒绝清晰时较有意义；强趋势中的短暂双试探、宽幅区间和极值差异过大时易误判。
- **模型不确定点**：两顶底允许误差、间隔、第二次是否可刺穿及量能角色待核验；底部与顶部的时间、流动性和做空约束并不完全对称。

## F05.06 三角形（Symmetrical / Ascending / Descending Triangle）

- **类型**：边界收敛的整理与突破形态家族。
- **核心原理与潜在收益机制**：对称三角上下边界均收敛，上升三角常见水平上沿与抬高下沿，下降三角作相应镜像。它们描述交易区间压缩；某一边倾斜可形成方向倾向假设，但不能把上升三角定义为一定向上突破。收益假设来自压缩后的持续方向扩张。
- **交易逻辑或边界**：先根据已确认拐点建立边界，再等待突破或回测；随着新点出现可更新候选，但需保存原判断。目标测量、假突破退出及接近尖端是否停用需另定。
- **适用与失败环境**：边界清晰、波幅逐步收缩时较适合；稀疏成交、接近尖端自然穿线和反复假突破可能产生无效信号。
- **模型不确定点**：最低触点、收敛程度、允许穿越和量能要求待核验；方向性命名不能代替实际触发。

## F05.07 旗形与三角旗（Flag / Pennant）

- **类型**：强方向运动后的短暂整理候选形态。
- **核心原理与潜在收益机制**：旗形通常在较显著的旗杆运动后形成较小、平行或近似平行的整理，三角旗则形成较小收敛区。两者共同假设短暂休整后原方向继续，但旗杆、整理持续性和幅度必须当时可辨，不能把任何回调都归为旗形。
- **交易逻辑或边界**：可在整理边界沿原趋势方向突破时进入，或等待回测；反向破坏、过深回调或迟迟不续行可否定假设。旗杆投射目标属于经验测量，不是承诺。
- **适用与失败环境**：趋势动量强且调整相对有序时较匹配；消息冲击后立即反转、末端过热和过长整理可能转为派发或普通区间。
- **模型不确定点**：旗杆识别、整理与旗杆相对大小、方向倾斜和期限界限待核验；三角旗与一般三角的差别主要依赖前置运动和尺度。

## F05.08 楔形（Rising / Falling Wedge）

- **类型**：同向倾斜且收敛的波段形态。
- **核心原理与潜在收益机制**：上升楔形的上下边界均向上但逐渐收敛，下降楔形作镜像，表示方向推进与区间压缩并存。常见解释将其视为动量衰减，也可在特定背景中作为趋势回调；外形本身不能决定是中继还是反转。
- **交易逻辑或边界**：在已识别楔形边界破坏后研究反向或顺大势延续，或等待回测；必须先固定前置趋势和具体交易假设。边界被反复重画时，所谓突破可能只是绘线结果。
- **适用与失败环境**：有足够波段形成收敛且方向推进减弱时较有意义；强趋势持续挤压、极窄区间或拐点太少会使模式不稳定。
- **模型不确定点**：触点、斜率关系、与通道和三角的边界及确认方式需核验；不同价格行为流派对“楔形”可能使用并不相同的结构定义。

## F05.09 杯柄形态（Cup with Handle）

- **类型**：调整、恢复与较小整理组合的突破形态。
- **核心原理与潜在收益机制**：价格经历相对圆滑的调整与恢复，接近前期高位后形成较小柄部整理，再向上突破。潜在机制是先前持仓压力被逐步消化，较浅回调后需求重新占优；这只是待验证解释，不能从圆弧外观确认机构吸筹。
- **交易逻辑或边界**：以完成的柄部或相关枢纽突破为候选，失败可表现为突破回落、柄部结构破坏或整个底部失效。没有柄部的圆弧底不是同一触发，杯底位置也不是形态完成时间。
- **适用与失败环境**：前期有趋势、恢复过程有序时较符合常见使用背景；过深破坏、尖锐 V 形、柄部位置过低或市场整体转弱可能失败。
- **模型不确定点**：深度、持续时间、柄部位置和量能要求待核验；本节仅讨论图形，与 F09 的基本面、相对强弱及市场方向条件分开。

## F05.10 平台与平底整理（Base / Flat Base）

- **类型**：较紧密横向整理后的续行候选形态。
- **核心原理与潜在收益机制**：价格在先前趋势后维持较有限回撤并形成可辨识的水平边界，可能意味着持有者抛压受控、供求重新平衡。一般平台与成长股体系中的特定平底形态不完全等价；仅波动很小也可能只是缺乏交易需求。
- **交易逻辑或边界**：先明确平台开始、上下边界和是否已形成，再研究向趋势方向突破或回测；跌穿平台、突破后无跟随或价格结构恶化可构成失败。不能用整个未来整理区间来提前确定边界。
- **适用与失败环境**：强趋势中的有序休整较匹配；顶部派发、持续停滞和低流动性可能形成相似外观，突破仍可能失败。
- **模型不确定点**：宽度、持续时间、前置涨幅、平台之间是否重叠及成交量条件待核验；与箱体共用观察不代表两套完整体系相同。

## F05.11 缺口（Price Gaps）

- **类型**：相邻交易区间不连续的价格现象及情境分类。
- **核心原理与潜在收益机制**：普通、突破、持续和衰竭缺口是常见解释类别，分别偏向区间噪声、离开整理、趋势推进和末端失速。类别往往需要随后走势才能确认，不能用事后“衰竭”标签在缺口发生时直接做空。缺口可能反映信息重估，也可能来自公司行动或交易日历。
- **交易逻辑或边界**：追随缺口后保持、回补缺口或反向拒绝是相互竞争的策略假设；需先确定分类依据、可成交时点与失效位置。“缺口必补”不是有效的无期限退出规则。
- **适用与失败环境**：真实信息冲击和流动性充足时更便于研究；涨跌停、盘前不可成交、除权除息及复权口径差异可能扭曲信号。
- **模型不确定点**：区间缺口与开盘跳空的定义、部分回补和完全回补、分类时点及确认标准待核验。

## F05.12 Al Brooks 价格行为

- **类型**：强调趋势、交易区间和逐根背景的裁量框架。
- **核心原理与潜在收益机制**：同一根 K 线在不同背景中有不同意义，先判断市场更接近趋势还是交易区间，再观察突破、回调、失败突破和二次尝试。潜在优势来自识别情境下更合理的跟随或反向机会，而非孤立形态；“始终偏向多或空”的方向判断也不是必须始终持仓。
- **交易逻辑或边界**：可研究趋势中的回调续行、区间边界反向及失败突破后的转换，但必须逐类明确触发。H1/H2、L1/L2 等计数和信号根、入场根区分不能只凭名称猜测；退出要匹配波段或短线目标。
- **适用与失败环境**：连续流动市场中可形成细致情境判断；过细图表、费用、主观重标和经验依赖会限制可复现性。
- **模型不确定点**：原著术语、尝试计数、Always In、楔形和具体概率陈述待逐项核验；本稿不把作者经验描述视为独立统计证明。

## F05.13 点数图（Point and Figure / P&F）

- **类型**：按价格移动而非固定时间生成的图表与突破框架。
- **核心原理与潜在收益机制**：价格达到箱格尺度才增加标记，反向达到指定格数才更换列，忽略不足尺度的摆动。固定价格格、百分比格及波幅自适应格保留的结构不同；潜在价值来自过滤微小波动和识别供求边界，不是消除所有噪声。
- **交易逻辑或边界**：可研究同向列突破前列极值、支撑阻力和横向或纵向计数目标；箱格与反转规则先固定，未完成列不能按未来最高位置提前标记。目标计数是特定体系的估计，不保证到达。
- **适用与失败环境**：价格趋势明显且箱格符合研究尺度时较有意义；震荡、跳空和对格宽高度敏感时可能失效。
- **模型不确定点**：高低价法与收盘价法、同根双向移动顺序、动态格宽是否重绘历史及各计数法原始规则待核验。

### F05.01 蜡烛图

- **C1 来源与 v1 校订**：[F05-S01](sources-F01-F06.md#f05-s01)。Nison 作者网站明确实体/影线、十字线、实体吞没及晨星/暮星的三根关系；保留 v0，补充孕线仅看实体，不等于全范围内包。比例、趋势窗与确认期限在本卡均为 A，不把网站教学中的方向性措辞当胜率。
- **输入与参数来源**：OHLC；A：趋势窗n、十字比例d、小实体比例s、长实体比例b、确认期q。B=|C-O|，R=H-L，u=H-max(O,C)，l=min(O,C)-L；R=0单独标无范围。
- **R1 / A1 明确规则**：输出形态与上下文组件。此前趋势A为C[t-1]相对C[t-1-n]；晨星采用严格实体缺口版本，取消缺口的连续市场变体必须另登记。

```text
P1 校验OHLC及足够历史；缺失返回UNKNOWN
P2 Doji=(R>0且B/R<=d)；只输出中性标签，不由十字单独买卖
P3 BullEngulf=此前下行且C[t-1]<O[t-1]且C[t]>O[t]且O[t]<=C[t-1]且C[t]>=O[t-1]
P4 若R1<=0或R2<=0，Morning/Evening=UNKNOWN_NO_RANGE；否则Morning=第一根此前下行、阴线且B1/R1>=b，第二根B2/R2<=s且max(O2,C2)<C1，第三根阳线且C3>(O1+C1)/2
P5 BearEngulf与Evening将价格取负、OHLC高低互换后应用相同关系和范围守卫；保留原时间顺序，其他形态独立判定
P6 形态完成输出SIGNAL(type,t,极值)；确认A为随后q根收盘突破形态最高/最低，期间越过反向极值则取消
P7 同根多空标签并存输出AMBIGUOUS；宿主决定仓位、保护和退出
```

- **正例 / 反例 / 缺失例**：实体吞没前根而影线未吞没，仍可满足吞没；无此前下行则不标看涨反转；缺前根开盘价UNKNOWN；同根十字兼其他形态不凭名称排序。
- **形式化状态 / 适用与待验证**：R定义+A识别组件；无完整策略。适用于一致OHLC口径；待检验位置过滤是否增加费用后信息。

### F05.06 三角形

- **C1 来源与 v1 校订**：[F05-S02](sources-F01-F06.md#f05-s02)。Murphy 公开正文区分上升、下降、对称三角；对称没有固有方向，确认靠边界突破。保留v0；形态倾向不代替实际破位。

- **正例 / 反例 / 缺失例**：上平下升且上破为上升三角确认；上下同时外张不是三角；只有一个低点UNKNOWN；不同锚点产生相反突破标歧义。

- **C1 来源与 v1 校订**：[F05-S09](sources-F01-F06.md#f05-s09)。读到原著合法节选强调趋势与区间的环境区别、每根的双向解读与不确定性；不是读完全套。保留v0，作者概率示例不当本研究实证。High1/2等精确计数正文未取得：UNVERIFIED_SOURCE。
- **输入与参数来源**：OHLC；A趋势窗n、效率阈值e、收盘位置c、回调计数；作者式语境判断保留人工节点。
- **R1 / A1 明确规则**：A窄代理为趋势中的两次向下回调后向上尝试，明确不称原法High2精确复现。效率=|C-Cn|/sum|ΔC|；趋势UP需C>Cn且效率>=e。

```text
P1 缺n期数据或价格路径分母为0，UNKNOWN/区间标签
P2 计算UP代理；人工可另给趋势/区间标签及当时证据，冲突时WAIT
P3 UP且首次H[t]<=H[t-1]开始PULLBACK，冻结失效低点为该回调起点低；k=0
P4 PULLBACK中每次由H<=Hprev切换为H>Hprev，k加1；切换后须再出现H<=Hprev才允许下次计数
P5 k=2且H>L、阳线、(C-L)/(H-L)>=c，输出多头SIGNAL并结束该回调；失去UP或跌破冻结低点则取消
P6 区间环境只输出NO_DIRECT_TRADE，避免把此代理用于追突破；空头镜像
```

- **正例 / 反例 / 缺失例**：趋势效率高，两次分离向上尝试才给代理信号；连续三根高点抬升只计一次；缺前根UNKNOWN；人工判断强区间而A判趋势时WAIT。
- **形式化状态 / 适用与待验证**：A有限组件可显式运行；原法仍依赖逐根语境解释，未形式化区间反向、微结构、全部High/Low家族。

### F05.13 点数图

- **C1 来源与 v1 校订**：[F05-S10](sources-F01-F06.md#f05-s10)。官方文档确认X/O列、格值与反转格数，并警告动态ATR格值会改变历史图。保留v0，补充按收盘与高低法不是同一图；本卡选择固定格值收盘法A，杜绝重画历史。
- **输入与参数来源**：完成收盘C；A固定格b>0、反转整数r>=1；格坐标z=floor(C/b)，初始化第一z0；历史各列极值。
- **R1 / A1 明确规则**：只计算列和突破组件。双顶突破是本X列超过前一个X列格顶，不是时间K线双顶反转；两者名称不可混淆。

```text
P1 缺C/b或非法参数UNKNOWN；首值设z0，方向NONE
P2 NONE时z>z0建X列[z0+1..z]，z<z0建O列[z..z0-1]；相同WAIT
P3 X列时若z>列顶则延长至z；否则z<=列顶-r才建O列[列顶-1..z]
P4 O列时若z<列底则延长至z；否则z>=列底+r才建X列[列底+1..z]
P5 新X超过前X列顶输出BUY_SIGNAL；新O低于前O列底输出SELL_SIGNAL；同一列同一边界仅一次
P6 不足两个同类列只输出FILTER；格值/反转值改变开启新研究版本，不覆盖旧图
```

- **正例 / 反例 / 缺失例**：b=1,r=3，X顶10，收盘7触发O，收盘8不触发；动态重算b改变旧图不允许；只有首列没有突破对照。
- **形式化状态 / 适用与待验证**：R图示原则+A因果构图组件；不实现原著所有计数目标，退出和资金由宿主定义。
