# 对账单作为资金流水权威来源的核验（2026-09-13）

用户补充 `duizhang20-26.xls`（2970 行，2021-01-25 → 2026-06-18）。
本文记录只读核验的事实，供 W5 立项使用。

## 一、决定性发现：期初资金是 0，之前的 126,200 是错的推断

对账单按时间倒序，末尾三行是账户最早的记录：

```
2021-01-25 15:45:01  银行转存  +10000  资金余额 10000
2021-01-27 09:55:53  银行转取  −10000  资金余额 0
2021-01-29 13:14:23  银行转存   +4000  资金余额 4000
```

**首条的发生金额等于资金余额，因此期初资金 = 0。**
账户确实从 2021-01-25 零起步，[W2](w2-real-account-review-2026-09-13.md) 里
按"现金不得为负"反推的下界 126,200 **不是真实值，而且方向性地错了**。

之前之所以算出现金最低 −126,150，是因为成交明细**不包含全部资金变动**。
对账单 2970 行 vs 成交明细 2871 行，多出的正是这些。

## 二、对账单独有的资金流水

现有解析器把对账单判为"成交明细形态"，210 行无法解析：

| 未解析原因 | 条数 | 实际内容 |
| --- | ---: | --- |
| 未知业务类型「其他」 | 102 | 银行转存 60、银行转取 27、**利息结算 8**、银行返回码（失败）7 |
| 成交价格或数量缺失/非法 | 108 | 股息红利扣税、股息入账、新股配号/中签扣款、**利息结转 17** |

**利息结算与利息结转是其他任何来源都没有的**（`lishi` 与 `yinzheng` 都不含），
它们很可能就是 `jiaoge` 口径下那 56 条柜台余额残差的一部分来源。

## 三、成交记录两来源基本一致，差异集中在逆回购记法

按「日期 + 代码 + 方向 + 数量（取绝对值）+ 价格」比对：

- `lishi` 2775 笔，对账单 2777 笔，**净差 2 笔**
- 各自"独有" 172 / 174 笔，几乎全部是逆回购（131810 / 204001）的记法差异

同一笔逆回购在两个来源里的记法完全不同：

| 来源 | 方向 | 价格 |
| --- | --- | --- |
| `lishi` | 卖出 | **6.3550**（年化利率） |
| 对账单 | 买入 | **100.0000**（面值） |

**对账单的成交数量带方向符号**（卖出为负：−300、−800），
`lishi` 则一律为正、方向由「操作」列决定。这是解析对账单时必须处理的格式差异。

逆回购本就被排除在个股分析之外，对回合统计影响有限，
但对**资金流向**有影响，不能按同一套规则硬套。

## 四、现有解析结果

`duizhang20-26.xls` 经现有解析器：2759 笔成交、**0 条现金流**、215 笔逆回购、
210 条未解析、**2759 笔全部带资金余额锚点**。

对比 `lishi20-26.xls`：2775 笔成交、96 条现金流、232 笔逆回购、零未解析、无余额锚点。

## 五、结论

对账单应当成为**资金流水的权威来源**，成交仍以 `lishi` 为准（零未解析、逆回购记法与
既有实现一致）。两者结合可解决三个悬而未决的问题：

1. 期初资金从"反推下界 126,200"变成**确证的 0**
2. 补齐利息结算/结转，有望消解 56 条柜台余额残差
3. 2759 个资金余额锚点可用于逐日对账

代价是需要支持对账单格式：摘要列的业务类型识别、带符号的数量、
以及"操作列写买卖但实为资金变动"的行。见 [W5 任务书](../tasks/w5-statement-import.md)。
