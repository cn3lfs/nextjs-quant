# P1 口径与人工核对表

本地账本是事实来源；同花顺模拟盘只是默认关闭的可选层。以下人工项未由执行者填写。

| 待确认口径 | 本次实现 | 人工核对 |
|---|---|---|
| 费用 | 复用 cost-experiment-1：成交金额×佣金3bp、最低5元；卖出税5bp；滑点5bp另计，成交价格原值保留。标注「实验参数，非历史实际费用」 | □ |
| 移动加权成本 | 买入金额加实验费用纳入总成本；卖出按当时平均成本移除，不用卖出盈亏重算剩余成本 | □ |
| 日期与 T+1 | 本地交易日历；同日按录入顺序。今日买入不计可卖，历史买入须有日历依据；日历不覆盖时不猜工作日 | □ |
| 数量 | 买卖均为100股整数倍，零股暂不支持。A股技能没有该条款，补用 mock-trading API 的明确条款；两份技能出处与文件 hash 都随交易保存 | □ |
| 涨跌停 | 输入当日终端上下限及出处，服务端包含边界校验；不自行计算除权参考价、价格取整或无涨跌幅限制日 | □ |
| 日线估值 | 仅本地已完成不复权日线收盘，显示报价日期；行情缺失，或报价早于持仓除权事件，浮盈留空 | □ |
| 普通除息/送转 | 除权日先于当日交易处理；净成本减每股派息，股数增加送转比例，重新计算单位成本。留存原成本、事件与来源版本 | □ |
| 送转可卖 | GBBQ没有到账可卖日期，新增股先不计可卖；可在除权明细按账户显示补录可卖日期与依据，只追加一次 | □ |
| 配股/缩股及碎股 | GBBQ不足以证明实际认购、资金支付与到账，成本与浮盈留空，不捏造交易；事件和原成本仍可查 | □ |
| GBBQ未知 | 缺失/不可读或文件级最大事件日期未覆盖估值日，显示「成本未按除权调整」；参考成本单列，核对后成本和浮盈留空 | □ |
| 止损距离 | 人工录入/更新止损位；(收盘价−止损位)/收盘价。无价格或无止损位留空，不自动卖出 | □ |
| 做过与没做 | 是否关联任一交易决定分组，多笔不重复计信号。两组均比较既有N1同口径向前收益，不把成交盈亏与假设收益混比，不作因果或P3因子分析 | □ |

## B 层（仅用户）

- □ 决定是否开启模拟盘。开启开关不开户、不请求；首次开户另有明确按钮。
- □ 若开启，用户在界面亲自开户、预览并确认一笔模拟委托；执行者不代劳。
- □ 核对本地与远程数量、可卖数量、成本差异。远程委托受理不等于成交，不自动写入本地交易。
- □ 开户/委托结果未知时人工核对，不自动重复。模拟盘契约未定义北交所市场代码，因此北交所仅支持本地账本。
