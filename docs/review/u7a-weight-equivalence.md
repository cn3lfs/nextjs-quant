# U7a 权重表等价性验证

结论：**不建议替换**。本次针对任务书给定的“收盘实际持仓投影 + 滞后一日收盘收益 + 权重差换手成本”表达式；不否定权重表用于结果展示，也不据此评价策略业绩。U7 不进入实现，仍由用户决定是否立项。

受控投影往返锚点通过（绝对日收益容差 `1e-12`），但**一般无 unfilled/excluded 模拟的往返不通过**。七项约束尚未出现之前，开盘成交与收盘估值就已构成确定性反例。不能将受控锚点通过写成普遍等价，也不能将下面的会计分解当作七种约束的因果影响估计。

## 固定口径与往返锚点

权重输入是每个交易日的完整收盘快照：省略的证券为零仓位，整日空表为空仓，不 forward-fill；未知持仓权重显式为 null。初始仓位为现金。收益为相邻交易日 `close[t]/close[t-1]-1`，缺价不跨日连接；非零前日持仓缺收益令当日整体不可得。没有前日持仓时无需首日价格收益。历史投影额外读取原样本日线；trades 的 lastPrice 仅是最终标记，绝不回填到历史日期。

严格保留任务书公式：`gross[t]=Σw[t-1]r[t]`，`turnover[t]=Σ|w[t]-w[t-1]|`，`net[t]=gross[t]-turnover[t]×commissionBps/10000`。全额换仓换手为 **2.0**。这个公式也会对纯价格漂移导致的权重变化收费，不能称为实际成交换手。

E3 costs 没有一个能概括全部费用的“单边费率”。此处只将 commissionBps 映射到该费率，保持单位 bp/10000；最低佣金、卖出税与滑点明确留给费用差异，不平均税费、不拟合参数，也不声称已无损转换全部 costs。

未来函数门禁通过：两证券三日手算与当日权重突变测试证明当日价格收益不变、次日才改变。零费率时净收益也不变；非零费率时当日权重可改变当日费用及净收益，**任务书的净收益完全不变要求与其当日收费公式无法同时普遍成立**。测试同时保留这两类断言，没有将当日仓位用于当日价格收益。

锚点是预先定义的数学控制，不是调参拟合：单只股票、5 日、10000 本金、初始买入 500 股、5000 现金、持有 3 日、零费用；入场和退出日开收盘相同，持有期间价格从 10 到 11 到 12。

| 项目 | 逐日值 |
| --- | --- |
| E3 NAV | 10000，10000，10500，11000，11000 |
| 收盘权重 | 0，0.5，5500/10500，6000/11000，0 |
| 两侧日收益 | 0，0，0.05，500/10500，0 |

无 unfilled/excluded，含实际入场、持仓收益、现金稀释和退出，全部日收益误差小于 `1e-12`。这是**投影实现的受限正确性锚点**。

负对照仅将入场日 close 从 10 改为 11，其他条件不变，仍无 unfilled/excluded：E3 当日赚 `500×(11−10)/10000=0.05`，权重回测因前日空仓得到 0，最大偏差 **500 bp**。因此一般往返锚点未通过；不能宣称任务书的无条件等价验收全部完成。该反例保护的是失败事实，测试通过不代表反例已经等价。

## 七类来源的量化与可识别性

方向统一为 `权重净收益 − E3 日收益`；下表单位均为 **bp**（收益率乘 10000），绝对值均值的分母为全部 12 个可得日，含 4 个空仓验证日。贡献先逐日带符号相减，再取绝对值统计；不能把各行绝对值均值相加当总差。

**表中 0 是对实际成交投影的直接差异贡献，不是“解除该约束的收益为零”。** 未成交、等待及上限约束的反事实影响在本样本中不可估计；不以 0 冒充其因果估计。任务书把“目标权重”与“成交后权重”混在了一起：后者已经携带约束作用后的持仓结果，单凭它无法恢复被拒绝的目标。

| 七类来源 | 本次投影贡献绝对均值 bp | 最大绝对贡献 bp | 能据此认定什么 |
| --- | ---: | ---: | --- |
| T+1 | 0.000000000 | 0.000000000 | 投影保留实际入退场日期；holdingDays 最小为 1，既有日频策略没有同日退出意图。解除 T+1 的影响不可识别 |
| 涨跌停 / 停牌未成交 | 0.000000000 | 0.000000000 | 主样本 attempts/unfilled/excluded 全为 0，未触发；不能估计受阻目标的损失 |
| entryMaxWait | 0.000000000 | 0.000000000 | 本次无入场重试或过期；不能分离等待与未成交的交互贡献 |
| maxPositions | 0.000000000 | 0.000000000 | 一只股票、上限五只，未触发；不能推断并发信号拥挤时的影响 |
| 整手约束 | 0.000000000 | 0.000000000 | 投影沿用真实整数股数，未改为连续股数；因此不会直接造成投影差异。解除整手会改变现金，不能重复归因 |
| 现金拖累 | 0.000000000 | 0.000000000 | 权重和不要求等于 1，没有强制满仓；实际现金自然保留。现金的机会成本需要事先指定替代部署策略，当前未指定 |
| 费用口径 | 0.216054378 | 1.731467211 | 按实际固定成交数量计算佣金、税、滑点成本 / 前日 NAV，再减权重公式当日成本；包含无交易权重漂移收费 |

这六个 0 是同一持仓路径的会计恒等关系，未执行“逐个解除约束”的消融实验，不做 Shapley 或任意分摊。没有可识别反事实就不能交付七个看似精确的因果数值。

最后一行以原始收益率计：均值 `1.1539597473218297e-17`、最大 `8.998878031629687e-17`，在浮点容差内。七类残差不是零；加入独立的时点机制后才闭合。闭合只是同路径会计解释，并不表明只需给权重加几个参数即可执行同样策略。

可复核的独立分解：设前日股数为 q，开盘净买入数量为 Δq（卖出为负），开盘 O、收盘 C，E3 当日实际费用 F 含滑点。相同交易与日线下：

`E3[t] = Σq[t-1]×(C[t]−C[t-1])/NAV[t-1] + ΣΔq[t]×(C[t]−O[t])/NAV[t-1] − F[t]/NAV[t-1]`

第一项正是前日实际权重吃当日收盘收益。于是 `权重−E3 = (F/NAV前日−权重收费) − ΣΔq×(C−O)/NAV前日`。归因直接从逐笔数量、开收盘及费用计算，**不把总差倒灌成原因**。当前 E3 不做同日新仓退出、没有部分成交，本式适用于本批无公司行动的样本；不外推到更复杂结算。

## 决策与后续所需证据

**不建议替换当前 E3。** 普通无受阻成交已能反证给定表达式的一般等价。恢复它需要至少携带开盘前后持仓或逐笔成交时点、成交价、股数、真实费用与现金路径；若还要从目标生成可成交结果，又必须保留交易规则、逐日 attempts、等待窗口、持仓上限及排序、同股去重和期末未成交状态。这实际上仍需要现有执行模拟器，权重表可以是其输出投影，无法成为本任务声称的单表替代。

样本规模**不足以支持七种成交约束的影响大小、发生概率、任何策略业绩或更广义 U7 架构优劣判断**。本次“不建议”针对当前替换方案的已证伪语义与证据不足，不是用一笔交易推断整个市场。

若后续要评估扩展范式，需另行授权包含以下证据的固定样本：多证券同日竞争超过 maxPositions；买入涨停/停牌后恢复、跨 entryMaxWait 过期；卖出跌停连续延迟及期末未平仓；缺行情产生 stale 及次日不可得；最小申报数量与现金不足；最低佣金和比例佣金两侧；有明确同日反向意图的更细粒度事件以识别 T+1；独立目标权重与信号时点。每种机制要有正反控制及联合触发样本，预先固定反事实次序或交互分摊方法，防止等待/受阻、整手/现金重复计算。代表性发生频率还需带历史规则证据的更长、多证券样本；本批不采集、不新建这些实验。

## 与任务书不符之处及验收

1. `trades/nav` 没有历史每标的收盘价，不能独立完成市值投影，故额外只读相同 fixture 日线；不改 E3。
2. 一个对称费率不能完整承载 E3 costs；commissionBps 单独用于原公式，其余显式归因。不得把平均税费伪称同一口径。
3. 当日换手扣费与“当日权重不得影响当日净收益”冲突，价格收益门禁和费用响应分开验证。
4. 受控往返锚点通过，一般无排除往返不通过；主样本自身就不等价。保留失败事实，无调参对齐。
5. 七类不能穷尽差异，额外发现开盘/收盘时点项；六项约束反事实缺少识别条件，表中零仅是已成交投影贡献。一般约束归因验收未具备，不能宣称完全满足原任务书。
6. 未新增迁移、依赖、路由；未修改 E3 或 mcp.ts；未提交、推送、打包。实现是独立诊断工具，不是功能交付。
