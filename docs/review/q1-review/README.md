# Q1 图表体验核对

本目录是执行者 A 层证据，**不是达到 TradingView 体验的判定**。B 层由用户目视确认。

| 交付 | 实现与 A 层证据 | B 层核对 |
|---|---|---|
| 日/周/月/5 分钟 | 周线复用 weekly-bars；月线同口径；q1-chart.test.ts 覆盖周/月边界、完成时点、缺日/日历冲突 | 周/月 OHLCV 与同口径终端对照 |
| 四类画线 | 点击定锚、端点表单编辑、删除；chart_views 按标的×周期持久化；单元与浏览器重载验证 | 画线位置、编辑方式是否顺手 |
| 参数可调 | MA 四条、MACD/KDJ/RSI 三参、BOLL 二参；只调用 indicators.ts；默认策略结果保持兼容 | 参数布局、各数值与终端对照 |
| 对数坐标 | 仅主图价格轴对数；副图显式线性；实际组件选项回归 | 正负 MACD 不应被对数压缩 |
| 持仓成本线 | 调用 P1 tradeDashboard，读取 adjustedCost；无持仓或成本待核对不画线 | 成本与账本一致，红/绿方向是否清晰 |
| 暗色主题 | 图表画布、网格、文字切换；随视图保存 | 对比度、配色 |
| 手感 | 图表聚焦后左右平移、上下缩放；原生价格轴拖拽；Esc 取消画线 | 缩放速度、键盘与鼠标是否顺手 |

## 明确边界与待用户确认

- 周/月图不请求、不绘制日线缠论与双突破证据，明确显示不可用；5 分钟保留既有缠论，双突破仅日线。
- 参数仅改变图表；策略仍用原有固定参数。指标公式、递推和默认参数不改口径。
- 现有参考日历只覆盖最近 400 个已有交易日，未提供休市日；历史周/月和含节假日的周期可能因日历未知被排除。实测茅台月线只保留 9 个周期，长指标预热不足显示空值。页面显示排除数量与原因，不能拿它当完整历史月线。
- 画线按时间/价格定锚；趋势线为两端点线段，水平线横跨主图；矩形与斐波那契两次点击。斐波那契为价格线性回撤（即使主图用对数坐标），比例 0/23.6/38.2/50/61.8/78.6/100%。
- 编辑、删除及设置通过「保存视图」统一保存；切换前应保存，页面有未保存提示。每视图最多 200 图形；周期 1–500，BOLL 周期至少 2、倍数 0–20。
- 键盘每次平移可见宽度 10%；向上缩小到 80%、向下扩大到 125%；只在图表聚焦时生效，输入框保留原生按键。
- 数据库新增 v6 迁移，仅建 chart_views 表。共享生产库未运行迁移；旧桌面包需管理者重新打包。
