# 资金对账：12.6 万缺口的最终定位（2026-09-14）

前两次判断都错了（先以为资金缺失、再以为是利息）。本次用对账单的余额列逐日核对，
定位到确切原因。

## 一、对账单的排列规则：天间倒序、天内正序

三种排序假设里只有这一种自洽：

| 假设 | 结果 |
| --- | --- |
| 整体倒序（reverse 全文件） | 2905 / 2968 对不符 |
| 按「交收时间」升序 | 1456 笔不符（时间是批处理时间，非成交顺序） |
| **天间倒序、天内正序** | **710 个交易日中 670 天完全相符** |

余下 40 天不符，但**差异成对出现并完全抵消**（如 `−13,779.67` 紧跟 `+13,779.67`），
累计仅 **−0.82 元**。成对差异来自货币基金 T+1 确认的跨日归属，不是丢钱。

**结论：对账单本身完全自洽。**

## 二、两种口径的总额只差 296.80 元

银证流水的「变动资金」列是**绝对值**，方向由「转帐类别名称」决定，不能直接求和。
按方向重算：

| 口径 | 净额（元） |
| --- | ---: |
| 对账单发生金额合计 | **+0.90** |
| 历史成交净额 | −228,521.35 |
| 银证转账（转存 − 转取） | +228,225.45 |
| 成交 + 银证 | −295.90 |
| **差额** | **296.80** |

期初为 0、末期余额 +0.90，两条路径的总额几乎一致。
**所以从来没有"丢失 12.6 万"这回事。**

## 三、−126,150 是过程性的：缺货币基金往来

成交明细里**没有 007864 的记录**（货币基金申购/赎回，摘要形如 `[007864]申购`）。
对账单有 48 条，**净额仅 +114.13 元**（就是收益），但过程中资金先流出、后流回。

缺了这些记录，中间时点的现金曲线就会塌到负数——最低 −126,150.68（2024-01-12）。
**总额对得上，过程对不上。**

顺带一提：007864 的记录同样是**操作列标「卖出」而金额为负**，
与 [W8](../tasks/w8-repo-direction.md) 修的逆回购是同一类问题——
券商导出里，现金管理类品种的操作列一律不可信。

## 四、修法

把对账单里的货币基金申购/赎回纳入现金流。W5b 目前把这类记录
（23 条 −387,800 的申购扣款）留在了 `unresolved`，需要正式归类。

注意**不能简单按金额符号归入 transferIn/transferOut**：它们不是银证转账，
而是账户内部的现金管理，应当独立成类，否则会污染"净入金"的口径。

## 五、这次诊断的方法教训

前两次判断失败，都是因为**从摘要关键词猜语义**（先猜"资金缺失"，再猜"利息"）。
这次成功，靠的是**用余额列做恒等式校验**——数据自带的一致性约束，
比任何关键词匹配都可靠。

凡是带余额/累计列的数据源，应当优先用恒等式定位问题，而不是读摘要猜。

## 补充：负现金是记录顺序造成的假象（W9 交付后）

W9 把货币基金独立成 `cashManagement` 类后，最低现金从 −126,150.68 变成
**−126,036.55**——只改善了 114.13 元，正好是货币基金的净额。
执行者如实指出「48 条均发生于 2021 年，未证实其解释主要现金缺口」。

继续查对账单自己的余额列，答案出来了。以 2024-01-12 为例：

```
19:54:09  131810 买入  −126,001.26   余额 −125,887.88   ← 融出（新一笔）
19:54:11  131810 卖出  +126,022.32   余额      134.44   ← 购回（昨天那笔到期）
```

**当日末余额 134.44 元，是正的**，前后几天也都是正的几百元
（01-11 收 113.38、01-15 收 140.81）。负数只出现在日内中间时点，
因为记录顺序是「先记融出、再记购回」，而业务上是先收回昨天的钱才能再借出。

全区间统计：

| | 天数 | 最低值 |
| --- | ---: | ---: |
| **日末**余额为负 | **3 / 710** | −64,892.91（2021-08-24） |
| **日内**出现负余额 | 164 / 710 | −165,805.96（2022-11-10） |

**绝大部分负余额是日内现象。** 账户实际一直有正余额，
所谓的"12.6 万现金缺口"从头到尾不存在——它是**同日内记录排序**的产物。

### 修法

同日内，现金流入（逆回购购回、证券卖出）应排在流出（融出、买入）之前。
这符合 A 股 T+1 交收的实际：当日卖出资金可用于当日买入。

剩余 3 天日末为负需要单独解释，但量级（−6.5 万）与占比（3/710）都小得多，
不影响主结论。

### 三次判断，三次修正

1. 以为是**资金缺失** → 错，两个来源总额只差 296.80 元
2. 以为是**利息** → 错了五个数量级（真实利息 0.82 元）
3. 以为是**货币基金缺失** → 只解释了 114.13 元

三次都是从现象猜原因。真正管用的还是**恒等式校验**：
先用余额列验证对账单自洽，再逐日比对定位，最后看日内明细才看清是排序问题。
