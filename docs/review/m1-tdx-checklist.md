## 三项存疑的独立佐证（2026-09-09，管理者补充）

在无通达信软件的情况下，已用两个独立来源交叉验证。**用户人工核对仍建议做，

### 存疑项 1：STD 分母 N−1 —— 已佐证

`tdx-doc references/examples/专家系统.md:17-25`：

```
* UPPER赋值:MID+2*收盘价的N日估算标准差
MID :=MA(CLOSE,N);
UPPER:=MID+2*STD(CLOSE,N);
```

`tdx-doc references/functions/统计函数.md:37-75` 明确区分：

| 函数 | 说明 |
|---|---|
| `STD` | 估算标准差 |
| `STDP` | 总体标准差 |
| `VAR` | 估算**样本**方差 |
| `VARP` | 总体样本方差 |

BOLL 用的是 `STD`，对应「估算样本方差」，即分母 **N−1**。本实现一致。

### 存疑项 2：MACD 柱 ×2 —— 已佐证

```cpp
M.Histogram[i] = (M.Dif[i] - M.Dea[i]) * 2.0f;
```

本实现一致。

### 存疑项 3：递推早期值不屏蔽预热 —— 已佐证

同文件 `ComputeEma`：

```cpp
float fK = 2.0f / (float)(nPeriod + 1);
Ema[0] = pPrice[0];                                  // 首值取 X0，无预热屏蔽
Ema[i] = pPrice[i] * fK + Ema[i-1] * (1.0f - fK);    // = (2X + (N-1)Y')/(N+1)
```

与本实现的 `smooth(closes, n+1, 2)` 展开式逐字一致；DIF/DEA 亦同（`EMA12−EMA26`、`EMA(DIF,9)`）。

**仍需人工确认的**：上表各指标的具体数值（尤其 sh600519 的 MA/EMA/KDJ/RSI），
用于排除数据读取、复权设置、历史起点差异导致的偏差。
