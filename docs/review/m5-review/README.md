## 逐项复算

- **有效案例**：两高点相隔7根，观察日距第二点9根。`27.66 + (27.66-28)/7×9 = 27.222857142857`。两点分别在02-18、02-27确认，突破前已可知。成交量 `4,890,100 / (49,403,888/20) = 1.979641764`。MACD DIF>DEA、K>D、RSI6>50、C>BOLL中轨，四项同向；最小形态库无匹配。结构止损23.80（03-05已确认），目标一为整数关口30，目标二不存在，风险回报比未知。后续五个收盘31.29、29.60、30.77、29.40、30.46均在27.66上方，支持将其作为有效突破复核样本。
- **假突破案例**：两高点相隔8根，观察日距第二点5根。`1598.25 + (1598.25-1657.99)/8×5 = 1560.9125`。阳线实体收于线及1562.38上方，但 `3,548,050 / (63,665,106/20) = 1.114598003 < 1.5`。MACD否、KDJ是、RSI否、BOLL否，仅一个同向；看涨吞没成立。止损1562.38、目标一1572.8495（前日MA20）、目标二1598.25，`X=(1598.25-1568.88)/(1568.88-1562.38)=4.518461538`，记1:4.52。高风险回报和吞没都不能抵消量能门槛失败。下一根收盘1500跌回关键位以下，仅作为案例选取依据。
- **不足案例**：59根历史，即使量比 `3,619,322 / 2,127,630.15 = 1.701104865`，仍无法形成“突破日前60根”结构窗口。没有趋势线、关键位或目标，不能用已能递推出的部分指标拼成信号。
