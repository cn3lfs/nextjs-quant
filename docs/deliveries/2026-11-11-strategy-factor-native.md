# 成长、年度财务与原生结构的策略边界

日期：2026-11-11。接续[上一批](2026-11-11-strategy-module-boundaries.md)，按相同多 Agent 实施、独立验收流程继续执行。历史输入、结果及原档案哈希不因模块重构而改写。

## 本批结构

成长因子 215 项方法的数值计算、组合递归与排名进入 `research/growth/growth-factor-engine`。请求及九组成长输入 schema 为中性契约，实际消费者直接导入；应用仍负责时点证据、单位、新闻原文不可变性与摘要验证、数据档案及最终哈希。纯引擎使用显式的已验证事实读取接口，不调用供应商或 Node。

年度质量、杜邦、现金质量、F-Score 已知项及增长/CAGR 计算归 `research/value/financial-quality` 与 `financial-growth`。年度输入显式携带归一数值、币种、引用和缺失原因；原始值只作为不解析的证据载荷。应用保留原证据解析、来源摘要、时点及档案重建验证，不能把重算一个哈希当作有效原始证据。

另将高低点结构保本、TMT 拥挤度、均线筛选、组合分派和固定公式规则迁入包，整文件台账累计 128 条（127 TS、1 JSON）；成长、年度财务和原生/周线编排属部分拆分，不计整文件搬迁。方法表补充其真实包内实现路径，保留应用适配与历史证据关联。

盘中成长的入场、固定止损、跳空管理、时间退出、R 倍数保本/减仓、ATR 尾仓、尾盘减仓、加仓及 OP08 补仓时间/次数资格均由纯策略维护；实际触发调度、成交、T+1、权益和持仓账本留应用。OP08 保留“成交日之后”的原判断，没有暗改成必须紧邻下一日。

Wyckoff 的 52 周高低点同升、20 日双 RS、评分/阶段/盈亏比准入、TR 下沿止损及目标计算归包；应用保留周线聚合、可知时点、历史行业归属和重叠行情防修订。CH18 小转大/三买组合、中阴 ended 选择规则同样归包，原生循环和去重仍归应用。旧 CZSC 质量分档与双突破止损/回调加仓意图不再散落在事件生成器。

组合、固定技术及公式规则五个旧文件完整删除，无旧路径转发。包仅依赖中性 `FormulaRuntime`，应用唯一实现执行既有 DSL 求值与原式编译探测；包中不导入应用解释器，不执行 LLM 生成代码。恐惧贪婪背景数值计算也已归纯因子，证据封装仍由应用维护，不计为新增交易策略。

## 原生三买实际执行

既有 `research-chan` 代表 ID 接入独立原生观察输入，统一目录仍为 91 项：56 项纯行情日线、1 项需要原生结构的日线、25 项组合预设、3 项研究、6 项数据缺口。原有纯行情策略数组不加入需要 DLL 的策略，纯行情调用不能用外部原生观察覆盖规则。

原生任务固定开始日前 140 根为输入起点，最多 366 个自然日。每个收盘都以该固定起点以来的完整前缀，复用原有单进程串行 `projectCzsc → analyzeCzsc`；不按日滑窗、不从最终结构反向筛历史，也不另开 FFI。这个有限起点不等同全部源历史。

结构输入复用执行包唯一的现金分红前向价格调整，只在事件已经发生后调整后续价格，不把未来事件倒调到更早观察。原始行情与公司行动仍冻结，可重建每个同口径前缀。

固定配置为笔级 0、日线锚 1。基线已有三买只登记；随后首次合格信号以实际观察收盘作为可知日期，下一合法开盘撮合，默认经过五个持仓交易记录后确认退出。端点日期、信号确认日和观察日分别保存；同端点三买按稳定身份去重，中枢归属修订、消失和再现只追加审计，不重复入场或重写原事件。

门禁区分中枢成立与最终定型。上游 v22 的 `established` 表示第三成员段分型使中枢成立，ZG/ZD 此时已固定；中枢 `confirmedAt` 表示延伸终点及 GG/DD 从此不再改变。基础 CH03 要求信号已确认、中心已成立且引用属于当前前缀，允许中心尚未最终定型为 `-1`。不能额外等待最终定型而暗中延后入场；信号未确认则仅登记 pending，缺失或未来时点拒绝。

每行观察冻结实际 DLL SHA256、API 22、构建标识、配置、前向价格前缀摘要和入场事实；版本/配置中途变化失败。仅存首次观察、修订、撤销等摘要，不逐日重复保存整张原生大表。任务可取消，取消检查覆盖每次原生调用前后和发布前。

比较原生任务时额外要求 DLL、配置、固定起点、基线和价格口径一致；同价格来源的普通均线基线仍可比较。输出来自同一撮合、费用、现金及绩效链，不创建另一套账本。
