# 数字货币模拟自动交易交付

## 实现

按用户指定调用 keel 架构设计，三个 Agent 各自读取 coding-protocol 分工平台、执行、界面，主 Agent 集成与集中验收。完整架构与扩展路径见[规格](../product/specs/crypto-auto-trading.md)。

- BTCUSDT/ETHUSDT；币安Demo/Spot Testnet、OKX模拟盘、Bybit Demo；现货市价做多。
- SMA5/20、1小时默认，可改15分钟和均线周期；每币启动可用USDT的40%目标预算，买入保留1%费用余量。买单按USDT预算提交、向下保留两位，基础币数量仅作预估，实际成交以交易所记录为准。
- 纯策略、领域服务、平台适配、tRPC/UI职责分离。旧手动API/客户端退休，无兼容转发，历史记录和旧DPAPI文件保持原样，不自动复用旧Key。
- 持久化意图及策略证据，固定客户端编号；按平台订单/成交对账，部分成交去重，不明结果不重发。主机及账户写入互斥，暂停竞态受准入边界约束。
- 手续费按币种投影，外部余额变化暂停，卖出不接管账户原有BTC/ETH，零碎持仓留存并支持下一轮。
- 应用运行时10秒调度，页面隐藏不停止；应用退出停止，重启/休眠恢复不补发旧信号。

## 已知边界

- 真实三平台模拟账户联调未执行；未读取默认生产凭证、未运行真实模拟订单，不把fixture验证当交易所实测。
- 固定支持模拟环境，未开放实盘、合约、借贷、转账、通知或自动运行生成代码。
- 首次启动后暂不支持账户凭证替换/轮换；未来需账户UID核验。Bybit仅无借贷、无衍生品保证金占用的现货模拟账户。
- REST轮询；分页安全上限会明确失败，不截断冒充完整。平台历史保留期过后未知订单可能无法自动收敛，保持暂停。
- 页面显示最近200笔订单，本地恢复读取全部订单；现阶段没有完整历史分页页。账户诊断是请求时快照。
- 未提交、推送或打包。原有工作区改动保留，MCP保护文件未改动。
