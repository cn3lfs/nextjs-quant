# 证券上市资料核验

2026-09-09，原方案模块 A 的日期资料链路。

行情页展开“证券主档与名称来源”，可主动核验上市/退市资料。后端通过同花顺问财 `hithink-basicinfo-query` 查询，要求唯一且完整的一条响应、带交易所的精确股票代码和匹配的上市地点。日期必须有唯一 DATE 列及有效八位日期；重复列、非法日期不采纳，退市早于上市也不采纳退市日期。

本地保存 `security-lifecycle-{symbol}`，记录来源、查询时间、相关原始字段及 SHA256 指纹，主档查询按证券关联。TNF 名称刷新不会覆盖独立日期资料。只保存核验所用字段，不保留网关 token。重复请求合并，结果缓存 24 小时；远端请求失败保留原记录。页面读取不请求问财，主动核验才查询。

- 展开原始核验字段：`output/playwright/security-lifecycle-evidence.txt`。
- `output/security-lifecycle-http-verification.json`：主档关联正确，交易状态 unknown，缓存重复调用未修改记录/更新时间，报告和投递共 0。
- 144 文件 681 测试、类型检查、生产构建（包含 runtime）、桌面准备及冒烟通过。桌面冒烟 `quant-desktop-l7RouR`，本地行情源不变。
- 新增 6 项测试涵盖缺失退市、不匹配身份、多行/未完整返回、非法日期/重复元数据、日期顺序、请求合并、缓存、主档关联及失败保留；非法输入为负向样本。

## 范围

查询时间不是历史时点可知时间。日期信息不推断当前可交易、停牌、退市状态；缺失退市日期也不证明未退市。此轮真实样本只验证上海证券有上市日期、缺少退市日期的路径；有效退市日期和日期冲突通过固定样本测试，尚未完成多交易所/退市证券真实契约验收。

旧研究和行情证据不改写，无真实模型调用、消息发送或 EXE 打包。完整历史证券池、证券状态与 A–H 其余要求继续推进。
