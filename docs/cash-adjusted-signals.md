# 纯现金复权信号研究口径

新建现金实验使用 `cash-dividends-2` / `backtest-5`。旧 `cash-dividends-1` 档案仍由 `backtest-4` 原始价格信号重放，不补写新字段。

信号 OHLC 使用纯现金后复权：除息时累计因子乘以前收价 /（前收价 − 税前每股现金）。因子只改变除息日及以后观测，新增未来事件不改写此前价格。税率不参与价格因子；成交、持仓估值、成交量和成交额保持原值。分红应收与到账仍由各账户独立账簿核算。

worker 按真实评估起点向前取 slow + 2 根信号预热范围，再校验对账覆盖并重建事件计划。预热中的现金事件参与信号调整，但模拟账户从零持仓开始，不获得开仓前登记的分红。预热现金缺项拒绝运行；其他股本事件作为未处理影响提示，持仓模拟区间内存在其他事件则拒绝纯现金实验。

这不是交易所官方复权：参考价未按价格最小单位取整；缺行情日事件在下个观测应用，不能证明完整交易日历。非现金送转配股、持有期补税、退市、实际历史交易状态与组合仍待完成。已知未来事件仅不能改写此前信号价格，不等于来源具备历史时点可得性证明。
