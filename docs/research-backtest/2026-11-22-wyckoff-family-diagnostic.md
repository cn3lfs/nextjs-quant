## 关键发现：三个策略零入场

`signals` 是逐日“入场或出场布尔为真”的计数；威科夫规则的出场标志在空仓时也会为真，所以 signals 很高不代表有可执行入场。三个零成交策略的真实情况是**入场信号为 0**，不是被引擎拒绝。

用 `createExtendedStudyRule` 直接对五标的原始日线逐 bar 求值（预热 140 后）：

| 策略                           | sh600519 | sz000001 | sh601318 | sz000333 | sz300750 |
| ------------------------------ | -------: | -------: | -------: | -------: | -------: |
| `wy-spring-daily` 入场         |        1 |        7 |        1 |        0 |        1 |
| `wy-sos-daily` 入场            |        1 |        1 |        3 |        1 |        0 |
| `wy-sos-jac-daily` 入场        |        0 |        3 |        1 |        3 |        1 |
| `wy-lps-daily` 入场            |        0 |        0 |        0 |        0 |        0 |
| `wy-reaccumulation-daily` 入场 |        0 |        0 |        0 |        0 |        0 |
| `wy-trend-pullback-daily` 入场 |        0 |        0 |        0 |        0 |        0 |

- 单元测试已证明这三条规则在构造的 LPS/再吸筹/趋势回踩结构上可以入场（`strategy-capability.test.ts` 的触发序列池），所以不是 `study-rule` 接线或预热错误。
- 逐条件计数与判定见[威科夫零入场排查](2026-11-22-wyckoff-zero-entry.md)：属于当前参数下的稀有结构，量能/价格带/次日确认在 23,760 根有效日线上均未同时满足。
- 真实数据上零入场说明条件过严或结构识别口径与日线数据不匹配。LPS 要求“已确认推进后 10 根内、缩量到均量 50% 以下、回踩不破结构位 1% 且收盘低于前一根”；再吸筹和趋势回踩共享同一父结构。这个组合在 5 只标的全历史上一次都没有满足。
- 按计划，诊断验收要求“每个 ID 至少一个标的产生成交”；**这 3 个 ID 未达到**。本批不修改策略规则，只登记为下一阶段的研究前置问题：要么调整结构识别，要么确认这些 profile 只适用于更高频或不同市场状态的数据。

## 其他观察

1. **Spring / SOS / JAC 可执行**：分别 18 / 12 / 28 笔成交（strict）。三个策略都在多个标的产生入场，组合层也有成交。
2. **滑点档对威科夫影响很小**：strict 96 → clamp 88 次拒绝，fills 68 → 70。成交少，滑点越界机会也少。
3. **容量档只裁剪 9 笔**：成交笔数少、单笔规模相对日成交额小，0.5% 参与率基本不绑定。
4. **`hold` 拒绝仍来自开盘涨停/一字**；与量价家族一致。
5. **没有发现同日多信号竞争导致的重复订单**：`orderFillConservation`、`orderFillCardinality`、账本重放全部通过。

## 结论

- 威科夫家族的工程链路可用：数据、信号、成交、费用、账本在 5 标的全历史上闭合。
- 3 个 profile 的真实零入场是策略层问题，不是引擎或数据层阻断；在解决之前，不应把它们的“0 成交”当作执行拒绝或数据缺口。
- 研究结论同样必须并列 strict / clamp；本批不做收益比较、样本外或参数寻优。
