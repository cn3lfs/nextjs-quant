# 成长/CANSLIM 财务 PIT 数据审计（2026-11-22）

> 数据能力审计，不是策略回测，也不评价任何成长策略的收益。

## 口径

- 入口：`readLocalFinancialHistory(root, symbol, { asOf: "2026-11-20", strict: true, limit: 200 })`
- 数据源：`E:/new_tdx64`，只读
- 隔离：`QUANT_DATA_DIR` 指向 `.test-data/growth-audit-*`
- strict 模式要求 `announcementDate > reportDate` 且 `availableFrom <= asOf`；非 strict 只要求 `reportDate <= asOf`

## 结果

| 标的       | strict 报告数 | 报告期范围              | 有公告日 | 有 availableFrom | issues |
| ---------- | ------------: | ----------------------- | -------: | ---------------: | -----: |
| `sh600519` |            95 | 2001-12-31 ~ 2026-09-30 |       95 |               95 |     27 |
| `sz000001` |           114 | 1994-06-30 ~ 2026-09-30 |      114 |              114 |     27 |
| `sh601318` |            84 | 2003-12-31 ~ 2026-09-30 |       84 |               84 |     27 |
| `sz000333` |            54 | 2013-06-30 ~ 2026-09-30 |       54 |               54 |     27 |
| `sz300750` |            36 | 2015-12-31 ~ 2026-09-30 |       36 |               36 |     29 |

- 五个标的所有严格可用报告都带公告日，`availableFrom` 在 strict 模式下全部可计算。
- 非 strict 模式的 `availableFrom` 为 0：该字段只在 strict 计算路径生成，不能拿非 strict 结果做 PIT 判断。
- strict 比非 strict 少 4 份 `sz000001` 报告、1 份 `sz000333` 报告：公告晚于 `asOf` 或缺少可用日期，属于预期过滤，不是数据缺失。
- 27 条 issue 全部是 `未下载或未来报告期空占位包` 的 2000 年以前季度包（如 `gpcw19990331.dat`），是整份财务包的占位文件，不是这五只标的的字段缺失；`sz300750` 多 2 条同类占位。

## 小样本 PIT 对照

`sh600519` 2020 年报：报告期 `2020-12-31`，公告日 `2021-03-31`，`availableFrom` 为 `2021-04-01`（公告后首个交易日）。

| `asOf`                      | 该年报严格可见 |
| --------------------------- | -------------- |
| 2021-03-30                  | 否             |
| 2021-03-31（公告日）        | 否             |
| 2021-04-01（availableFrom） | 是             |
| 2021-04-02                  | 是             |

结论：strict 的可见时点是公告后的首个交易日，而不是公告日当天；成长研究必须统一用 strict + 同一 `asOf` 口径，不能用公告日当天收盘当作可见。

## 结论

- 五个标的具备做 PIT 成长研究的基础：报告期覆盖上市以来，公告日齐全，strict 可计算 `availableFrom`。
- 已验证公告日前后的可见性切换；尚未验证财务重述/更正记录的版本处理、亏损/负值字段语义、报告期与交易日历的完整对齐。
- 建议下一步实现 CANSLIM 适配器并用小样本对照；在此之前 `research-growth` 仍只是价格代理。

## 边界

- 只审计 5 只当前存续标的，不代表全市场覆盖。
- 公告日来自本地财务包，未与交易所公告原文交叉核对。
- 不做收益、估值或策略优劣判断。
