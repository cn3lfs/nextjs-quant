- 当前唯一应用策略 `ma-cross-baseline-v1` 为五分钟 SMA5/20 交叉。旧策略、组合预设与代表方法都标记弃用；旧回测、策略研究、旧规则选股/公式选股和旧方法执行被 RPC 拒绝，自动台账、盘中预选和订阅策略调度停止。历史配置、报告、查询/取消/导出保留。行情/RPS/财务等数据能力和图表结构计算不等于旧交易策略，不批量删除。
- 包的撮合/数量约束与费用沿用已有纯规则实现并成为唯一源，应用旧导入路径仅再导出；旧引擎留作兼容证据。旧规则特征测试在明确隔离的夹具中继续覆盖原行为，生产禁用另有真实策略政策测试，不删除测试、不放宽原规则断言。
- 回测页默认只显示新基线：读取本地覆盖、选择窗口、费用与本金、启动/进度/取消、最近任务恢复、日末曲线、服务端逐笔分页、完整冻结输入/订单导出和终态任务删除。旧控件与结果折叠展示。
- 应用只读现有 LC5 解析器、基准交易日历与 GBBQ；输入保留实际窗口和前一交易日最后 20 根预热。缺日/时段、预热不全、源数据修复/丢弃、缺公司行动来源和已知除权/股本事件明确拒绝。
- 引擎按“执行已有请求 → 完成信号 → 登记下一根请求 → 估值”推进；订单与成交分开，只有成交修改账户。下一根开盘、100 股整手、不加仓、T+1、最低佣金、卖出费用与滑点均显式。受阻退出保留，买入失败不追单，末尾持仓不强制平仓。
- 结果与冻结输入归同一 job 管理；删除终态基线任务一并释放它的输入和结果，审计事实继续保留。运行/排队任务拒绝删除，取消和异常使用既有 worker 生命周期处理，不建立第二套任务调度器或数据库迁移。

## 仍然存在的边界

- 固定为 `rule-check-only`。当前没有完整历史 ST/IPO、停牌、涨跌停价格与队列、市场冲击、历史费率、派息到账/税负/送股可卖日等证据；不宣称可信业绩。已知公司行动拒绝不能证明未列事件不存在。
- 本地 LC5 有看图估算量，不能凭非零量认证成交。五分钟 OHLCV 的一字/无量/滑点范围过滤是事后保守限制，不能证明在开盘时已知或排队可成交。
- 核心只建模单证券现金权益 T+1，当前应用限定主板。没有全市场共享资金组合、做空、期货、多市场框架或参数优化平台。后续扩展须逐项定义口径再实现。
- 图表日末值与逐根最大回撤不同；收益和回撤均包含初始本金，不能隐藏首日费用。构建会注入包源码/共享原语/lockfile 摘要，直接源码运行标记 `source-development`。
- 未做 Python 或原生语言接入。开始按原方案创建的 `.venv-hikyuu` 因 pip 缓存权限错误未完成安装；自动审批又拦截了该新建目录的递归删除，故停用并在 `.gitignore` 隔离，没有继续尝试删除或更改全局 Python。
- 未提交、推送或打包，不替换 `release`，不迁移生产库，不触碰用户维护的 MCP 文件，不发送测试通知或交易。
