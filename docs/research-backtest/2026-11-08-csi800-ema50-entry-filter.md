# 中证800：EMA50入场过滤

2026-11-08。用户要求解决买入当天已低于EMA50的问题。已为完整风控的所有买入和加仓增加因果过滤，阻止已经知道在均线下的开仓；没有使用当天最终收盘价倒筛历史交易。

## 现行规则

1. 信号日收盘不得低于当日已完成EMA50。
2. 买入前最后一个已完成收盘也不得低于对应EMA50，避免延迟执行时仍使用已经失效的旧信号。
3. 实际买入开盘不得低于前一根已完成EMA50。此前已生效的分红、送转和配股按同一原始价格尺度换算后比较；不读取买入当天最终收盘价或当天EMA决定入场资格。
4. 相等允许，均线缺失或不足50个观测则跳过。拒绝后资金留现金，不补选其他股票、不重分配剩余权重，也不逐日追单。过滤同时作用于新开仓和加仓，不影响已有持仓退出。

开盘合格之后，日内价格仍可能急跌，使当天收盘低于EMA50；这属于T+1隔夜风险，不能事先知道或假设当天可卖。该类交易保留原收盘退出请求，等可卖时继续执行。其他8%/账户单笔2%、5%保本、30%一次性减仓、公司行动与费用保持，退出仍采用用户指定的同收盘必成交假设及T+1，普通买入保持次日开盘。

包版本0.9.0，风控输出`csi800-study-position-risk-3`，研究清单版本3记录入场语义。`entryChecks`保存每次买入资格判断的信号日期/收盘/均线、最后完成收盘/均线、实际开盘/除权换算后的已知均线、资格与原因。该检查是资格记录，不等于最终成交；容量、资金和交易单位约束仍在后续执行。

### 补充：按已闭合交易轮次的统计

用户询问时核对发现，统一`quant-performance`当时只输出日净值评价。以下是当次从冻结轮次补算的统计；随后用户授权结构化，现已接入统一评价代码、API、导出和界面，见[结构化交付](2026-11-08-14-trade-performance.md)。日/周/月上涨比例仍不能当作交易胜率。

口径：同一股票从首次实际建仓到全部清仓算一轮，加仓及部分止盈合并；采用引擎已记费用与公司行动经济成本后的`realizedPnl`。当前1345轮已闭合，盈利425轮、亏损920轮、持平0轮；期末14轮未平仓整体排除，不把其中已部分卖出的盈利拆成独立胜笔。此口径为整仓交易轮次，并非逐买单FIFO配对。持平阈值为净损益绝对值不超过1e-8元。

| 指标                   | 当前EMA50＋入场过滤 | 旧EMA50仅退出 | 历史ATR |
| ---------------------- | ------------------: | ------------: | ------: |
| 已闭合轮次             |                1345 |          3920 |    3038 |
| 平均盈利额（元）       |             5646.39 |       2515.25 | 4205.66 |
| 平均亏损额绝对值（元） |             1718.67 |       1336.38 | 1954.51 |
| 盈亏比                 |               3.285 |         1.882 |   2.152 |
| 交易胜率               |              31.60% |        43.27% |  41.38% |
| 利润因子               |               1.518 |         1.435 |   1.519 |
| 每轮平均净损益（元）   |             +608.58 |       +330.04 | +594.32 |

平均盈利额只对盈利轮次取均值，平均亏损额只对亏损轮次损失绝对值取均值；盈亏比=平均盈利额/平均亏损额，胜率=盈利轮次/全部已闭合轮次（含持平）；利润因子=盈利总额/亏损总额绝对值，不能与盈亏比混用。金额指标不是单笔收益率，跨版本资金规模、仓位和交易轮次不同，不能把金额均值差异直接当作收益能力提升。

结果保存在当前冻结目录的`closed-trade-statistics.json`，附三份输入结果压缩文件的SHA256。独立核对闭合轮次净损益加未闭合轮次损益等于账户净收益，当前误差小于1e-8元；本次仅读取既有交易结果，未重跑或修改成交与净值。纯报告补充执行内容、格式及差异检查，不机械重跑应用测试。
