## 7. V 系列：研究可信度（2026-09-13 立项）

依据 [个人量化软件调研](personal-quant-survey.md) 的差距对照立项。调研把本仓库的缺口排成四类：
多重检验修正、信号有效性评价、证券池时点、留出集治理。**本系列只补这四类，
不碰组合仓位、实盘执行与多品种**——按调研结论，那三项应当在策略被证明之后才做，
现在做等于给一个尚未证伪的东西加装配件。

### 立项依据（已核实，不是推测）

- `walkForward` 每个 fold 在训练段评估 `walkForwardCandidates()` 的 N 个候选、取训练净收益
  第一名，再报告其测试段收益。`summary` 只有 folds / positiveFolds / average / median /
  worst / worstDrawdown。**从 N 个里挑最优这个动作抬高了被选中者的表现，现有输出没有任何
  一项对此做修正**，只在 `assumptions` 末尾写了一句"人工反复修改参数仍可能对整个历史过拟合"。
  一句文字提示不是量化。
- 信号台账 `LedgerSignal` 已有连续 `score` 与 T+5/10/20 `outcomes.returnPct`，
  `aggregateLedger` 只做了分组中位数/胜率/盈亏比。**评分与后续收益之间有没有单调关系，
  现在答不出来**——而这正是"这个信号到底有没有信息"的核心问题。
- A500 用当前名单，`roadmap` 已要求提示生存者偏差，但**提示是文案，没有可核对的数字**：
  区间起点尚未上市、区间内退市、区间内代码变更各有多少只，现在无处可查。
- 没有任何机制记录"同一段数据被研究过多少次"。留出集无从谈起。
