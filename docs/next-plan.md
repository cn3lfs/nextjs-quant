## 已确认的边界

- 恢复公式选股、双突破；旧功能直接用现行流程替代，不维护兼容入口。
- 信号监控、信号台账、盘中预选调度先暂停；不补跑、不补发消息。
- 清理不用的历史衍生结果、证据与日志，保留原始数据源及现行功能/测试输入；业务数据库、凭证和正式包不属于文件清理目标。
- 原通达信和 D:\wsWDZ\Blocks 只读。SQLite 文件格式与应用 schema 版本分开处理，保留版本保护。
- 当前数字货币模拟交易/账户功能保持已有授权范围，本轮不扩展实盘、合约或自动交易权限。src/server/mcp.ts 和用户维护文案不动。
- 优化阶段可继续自主推进；提交、推送、正式打包和用户库操作分别按其授权范围处理，不挪用其他任务的授权。
