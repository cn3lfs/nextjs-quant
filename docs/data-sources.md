# 免费行情数据源

行情页「行情数据源」可切换 **本地源、tstdx、腾讯自选股、东方财富**，也可选择「自动」。切换证券、图表周期保留选择。设置页可保存默认来源；监控任务单独选择来源。手动失败有错误提示和重试，不静默改用其他源。

| 来源 | 适合用途 | 限制与本次真实探测 |
| --- | --- | --- |
| 本地源 | 完整历史、RPS、可复现选股与研究 | 读取通达信文件，不负责下载；显示真实数据日期，文件缺失或过期不补造 |
| 东方财富 | 在线不复权日线和分钟图表 | 2026-09-14 对 sh600000 实取成功，末日为 2026-09-14；公共接口可能限流，无可用性保证 |
| tstdx | 通达信 7709 行情、盘口与分钟数据 | 复用本地 TypeScript 协议实现，不安装 Python；本次多服务器 K 线返回不完整响应或超时，手动选择会如实报错；连接故障转移有 15 秒预算 |
| 腾讯自选股 | 已知证券的延迟 K 线及已有资料查询 | 复用 westock-data skill；修正 bfq 请求兼容后，日线、5 分钟及周线实取成功；最多 2000 根，单位未独立核验 |

自动图表顺序：**本地 → 东方财富 → 腾讯 → tstdx**。优先级来自本次接口探测，后续接口恢复后仍可手动选用。自动回退显示实际来源与失败原因；不把空响应、无效字段、CLI 退出码 0 当成可用行情。图表显示末根日期及形成中状态；数据源成功不代表行情实时或完整。

盘中批量报价仍复用已有 **7709 → 腾讯报价** 路径（腾讯报价接口与 skill K 线是不同能力）；失败保留缺口。基本面、公告等已有腾讯资料模块继续可用，行情下拉框不把这些资料转换成另一种数据。免费源的已知标的数据查询不能替代原 MCP 自然语言全市场筛选，因此旧在线筛选入口暂时撤下。

RPS、策略样本历史研究和本地选股继续使用本地行情及原有数据时点约束。手动图表选源不会改写生产数据、通达信文件或已有研究快照。

原 tdx-finance MCP 代码与认证存储保留，应用入口已断开，不再读认证或请求服务。恢复需明确重新接入调用和页面，并重新核验额度与接口；不能仅靠修改环境变量恢复。

腾讯故障原因：用户默认命令使用前复权 qfq；应用要求不复权，显式 bfq 被当前代理接口拒绝。项目仅在该 skill 子进程中将 K 线请求的 bfq 映射为空 fqtype，不修改本地 skill。2026-01-05/06 宁德时代不复权 OHLC 与东方财富 fqt=0 逐项一致；2026-09-14 最新收盘为 337.11。不能以删除 bfq、接受默认前复权代替修复。

TCP 协议复核：对照 [xmtdx 0.2.1](https://pypi.org/project/xmtdx/) 和 [rustdx-complete 1.11.0](https://crates.io/crates/rustdx-complete) 发布源码，K 线 38 字节请求、0x052d 命令及 xmtdx 三段握手与项目一致。xmtdx 在同机三个服务器也因两字节响应解析失败；Rust 股票解析器明确保护此类截断。当前证据尚不能区分服务器与网络中间层原因，保留严格报错和免费来源回退，不把空数据作为查询成功。`src/server/tdx.ts` 的本地文件读取保持复用。

本地 skill 同步：注册并接入独立 guo-yongqing-valuation，郭永清估值方法改读该目录的 SKILL.md 及四份 references；更新引用校验、方法版本和报告提示版本。其他方法继续从本地 skill 读取并计算文件哈希。

本次隔离 API 验证：宁德时代东方财富/腾讯日线最新为 2026-09-14、收盘 337.11；本地日线截至 2026-09-11，未冒充今日数据。三者切换周线保持来源。保存腾讯默认来源后省略来源加载 5 分钟线，最新为 2026-09-14 15:00。浏览器控制服务不可用（nodeRepl.fetch request failed），尚未完成真实点击验收。

命名约定：本地文件（vipdoc）只读取磁盘行情；tstdx 是项目自定义 TypeScript 行情协议源，二者独立。旧配置键 pytdx 保留兼容，界面统一显示 tstdx；实际行情来源标识 tdx-7709 不变。
