### 2.5 工程遗留

- **Playwright 在 codex 沙箱内不可用**：`EPERM` 写 `%LOCALAPPDATA%\ms-playwright`（工作区之外）。浏览器验收须由管理者在沙箱外执行。本轮由管理者补跑并通过（见 §3）。
- **`czsc-tdx` 行尾混用**：源码存 LF，`.editorconfig` 与 `LICENSE` 存 CRLF。跨仓库写文件必须按各文件约定，否则 `git add -A` 会把无关文件整体重写（本轮曾误把 67 个无关文件重写，已修正为只含 14 个真实改动文件）。
- **codex 后台调用必须带 `< /dev/null` 与 `--disable code_mode`**：否则会卡在 `Reading additional input from stdin`（曾空耗 2h15m），或工具宿主握手失败。
- 机器上的 node 进程多为 MCP 服务器与用户自己的 vite 开发服务器，**不可清理**；只清 codex 进程。
- E0-2 的测试并行化**未测得提速**（318.14s 对串行 317.30s），分类器按能力闭包保守判定使 294/396 文件仍串行。双项目划分保留但已停止投入，效率改以 L3 次数衡量。
