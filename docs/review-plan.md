# T 阶段：已有功能审视与优化

生效日期：2026-09-10。用户指令：**不新增功能**，对已有功能做 UI 与功能优化；
**此前冻结的模块也纳入优化范围**。工作流不变：管理者出 plan、执行者实施并自证、
管理者验收后提交打包。

## 0. 冻结清单的调整

`roadmap.md` §2 的冻结清单在本阶段**部分解冻**：

| 允许 | 不允许 |
|---|---|
| UI 一致性、信息架构、可用性改造 | 新增功能、加深策略、接新数据源 |

解冻只在 T 阶段有效。T 结束后按当时结论重新划定。

## 1. 实测发现（管理者 2026-09-10 实际运行点击所得）

在真实数据副本上跑 `pnpm start` 并用浏览器逐页点击，截图见
`docs/review/t-baseline/`。以下是**实证问题**，不是推测。

### 1.1 信息架构

- **面包屑重复且中英混排**：页面顶部是「我的工作台 › 行情图表」，
  正文上方又出现「RESEARCH / MARKET」。两套面包屑、两种语言，
  且「行情图表」被归到 RESEARCH 之下，与侧栏「研究」区含义冲突。
- **「研究」一词在同一页面出现 51 次且含义不同**：侧栏是二级入口区名，
  候选表每行的操作按钮也叫「研究」。选择器实测撞到 51 个同名元素，
  用户同样会混淆。
- **两套导航模型**：侧栏四项是客户端标签切换（保留上下文），
  信号台账 / 持仓与交易日志 / RPS 数据管理是 `<a href>` 整页跳转
  （丢失工作台状态），子页面再用「返回工作台」跳回。

### 1.2 页面密度

- **行情图表页控件散成四行**：对数坐标/暗色主题/保存视图 一行、
  指标参数 折叠一行、画线工具 纯文本一行、
  双突破/BOLL/副图/缠论结构 又一行。四行控件压在图表之上。
- **条件选股页四个入口全部常驻堆叠**：通达信公式选股、在线自然语言筛选、
  本地条件草案（双约线）、本地可复现条件。用户要滚过三个才到第四个，
  且没有任何说明指出何时该用哪一个。

### 1.3 状态与文案

- **任务中心显示两天前的陈旧任务**，且错误文案被截断
  （「AI 研究 · 模型连续两次返…」），截断处没有展开入口。
- 行情页加载时长时间显示「双突破计算中…」「缠论计算中…」，
  首屏可用性受影响。

### 1.4 工具链

- **`pnpm desktop:prepare` 没有「应用运行中」守卫**：DLL 被占用时
  直接抛原始 Node 堆栈（`EPERM: unlink ... CZSC64.dll`）。
  对比 `desktop:pack` 有干净提示「Please exit GuanlanQuant before packaging」。
- **`pnpm build` 后未重跑 `desktop:prepare` 时，`pnpm start` 返回 HTTP 200
  但页面静默白屏**（30 个 `_next/static/chunks/*.js` 404）。
  失败没有任何提示，只有打开控制台才看得到。

## 2. 分批

### T1 — 信息架构与导航

1. 统一面包屑：去掉重复的一套，中文，层级与侧栏一致。
2. 消解「研究」歧义：候选表的行内操作改名（如「个股研究」或「分析」），
   或侧栏区改名，二选一，理由记入 decisions。
3. 统一导航模型：信号台账 / 持仓账本 / RPS 收进同一套导航，
   消除整页跳转与「返回工作台」补丁。**若技术代价过高，
   至少保证跳转后能回到原上下文**，并说明取舍。

### T2 — 页面密度

1. 行情图表页控件归并，图表上方控件行数**减到两行以内**。
2. 条件选股四个入口改为一次只展示一个（分段/标签），
   并给每个入口一句话说明适用场景。**四个入口都要保留，不删功能。**

### T3 — 状态与文案

1. 任务中心：陈旧任务的呈现方式（时间分组或默认折叠），
   错误文案截断处提供展开。
2. 首屏「计算中」状态的呈现优化，不阻塞图表本身可用。

### T4 — 工具链守卫

1. `desktop:prepare` 增加与 `desktop:pack` 同样的运行中守卫与清晰提示。
2. `pnpm start` 启动时校验 `.next/standalone` 的静态资源与当前 build 是否匹配，
   不匹配则**明确报错并提示先跑 `desktop:prepare`**，而不是静默白屏。

### T5 — 清账

1. `docs/review/` 十份核对材料**逐份处理**：
   能自动验证的转成测试、几十秒能做完的保留给用户、其余关闭并说明。
   **不允许继续无限累积「待用户确认」。**
2. `tests/m4-monitor.test.ts` 与 `tests/p2-notification-policy.test.ts`
   硬编码旧路径导致 `docs/` 下存在两份必须手工同步的重复样本，一并解决。
3. `/ui-gallery` 是否随包分发，给出结论。
