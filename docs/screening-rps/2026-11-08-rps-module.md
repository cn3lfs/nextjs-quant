# RPS 多周期与独立模块

## 交付范围

计算周期统一为当日（RPS1）、RPS3、RPS5、RPS10、RPS20、RPS50、RPS120，均按交易日间隔计算。按用户追加要求，不为兼容保留 RPS250 或旧路径再导出；现有图表默认采用 20/50/120。公式输入、个股池、行业/概念排名、盘中预选、财务组合筛选与图表配置共用包内周期定义。

`packages/quant-rps` 独立承载证券资格、后复权端点收益、并列平均排名、逐周期缺失分母及板块等权聚合，无运行时依赖，不读取应用配置、文件或数据库。所有消费者直接从包根引用计算与类型。应用 `rps-adapter.ts` 负责后复权准备与证据哈希，行业适配负责快照校验与元数据，任务与存储仍在应用内。旧 `rps-engine.ts` 已移除。

计算仍使用 `(1-rank/N)*100`，板块先平均成分股收益、再排名；不平均成分股 RPS，不补缺失价格。最长计算窗口变为 120 个交易日，上市年龄等证券资格规则不改变。

## 历史与运行边界

已有历史事实按各自保存的 `periods` 读取，不删除、改写或自动补造新周期。旧批次缺 RPS1/3 时显示未计算，状态摘要也使用该批次的真实周期。新七周期向量为 112 字节，旧六周期为 96 字节；共存不需要数据库迁移。新增周期在新计算批次生效，已有日期仍遵循发布不可变规则。

本轮未写入默认正式库、外部通达信/Blocks 目录，未发送通知或交易，未提交、推送或打包。现有 release 未替换。测试与页面验证使用隔离合成数据，不能作为真实市场排名的人工验收。
