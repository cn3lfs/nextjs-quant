# 任务书 R11：逆回购本金要按面值算，不能用成交金额

R10 把指标失真彻底修好了（收益 >1000% 的分段 4 → **0**，
最大回撤 99.97% → **20.26%**，日收益 +151466% → **+9.84%**，残差稳定 295.90）。
但净值可得率从 **1265/1265 回落到 587/1265**，678 天不可得，
原因全部是同一条：

```
2023-06-30 131810 未到期逆回购本金为负（-65.81），回款多于融出或记录不全
```

## 1. 根因

R10 任务书让本金取「成交金额」。但**回款笔的成交金额含利息**：

```
2023-06-29 sell 量1260  成交金额 126000.00   净额 -126001.26   ← 纯本金
2023-06-30 buy  量1260  成交金额 126065.81   净额 +126065.81   ← 本金 + 利息 65.81
```

于是回款时多扣 65.81，未到期本金变成 `-65.81`，触发「本金为负」判定，
后续净值全部作废。真实账户里 `131810` 64 笔、`131801` 2 笔、
`204001` 166 笔中有 54 笔存在这个差额。

## 2. 正确算法：本金 = 数量 × 面值

国债逆回购的面值是固定的市场规则：

| 代码 | 市场 | 每张面值 |
| --- | --- | --- |
| `204xxx` | 上交所 | **1000 元** |
| `131xxx` | 深交所 | **100 元** |

管理者已用真实数据核对，融出笔的成交金额与「数量 × 面值」**分毫不差**：

```
204001 量 99   → 99 × 1000   = 99000   ＝ 融出成交金额 99000
131810 量 1260 → 1260 × 100  = 126000  ＝ 融出成交金额 126000
```

## 3. 要求

- 未到期本金按 **数量 × 面值** 增减，**不要用成交金额**：
  - 融出（`sell`）：本金 `+= 数量 × 面值`，现金 `-= |净额|`；
  - 回款（`buy`）：本金 `-= 数量 × 面值`，现金 `+= 净额`；
  - 利息 = `回款净额 - 数量 × 面值`（例中 `126065.81 - 126000 = 65.81`），
    在回款日确认为收益。
- 面值按代码前缀判定（`204`→1000，`131`→100）。
  **前缀不在这两类的逆回购**（如果将来出现）→ 报告为无法确定面值并留空，
  不要默认一个数字。
- 「本金为负」的检查**保留**——它是有效的护栏，只是之前被错误的本金口径触发。
  修好口径后，真实账户不应再触发；若仍触发，说明确有记录缺失，照旧报告。
- `basis` 里写明本金按面值计价、利息在回款日确认。

## 4. 验收目标（管理者用真实账户复验）

- 净值可得率回到 **1265/1265**；
- R10 已达成的指标**不得退化**：收益 >1000% 的分段保持 0、
  最大回撤最高保持 20% 量级、日收益最极端保持 10% 量级；
- 残差保持 **295.90**；
- 月度收益可得数显著提升（当前 7/64，R8 时曾是 18/64）。

## 5. 测试

- **面值口径**：构造沪市（量 99、面值 1000）与深市（量 1260、面值 100）各一组
  融出+回款（回款净额含利息），断言未到期本金在回款后**精确归零**，
  利息被确认为收益，净值在融出日不变。
- **回款金额含利息不影响本金**：断言本金只随数量变化，与成交金额无关。
- 未知前缀：断言报告无法确定面值并留空。
- 既有用例全部继续通过。
