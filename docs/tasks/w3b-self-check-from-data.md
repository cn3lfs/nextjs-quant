# 任务书 W3b：自校验目标值必须来自数据，不能硬编码

补 [W3](w3-counterfactual-discipline.md) 的一处设计缺陷。由管理者在验收时审代码发现，
不是执行者的实现问题——**是我的任务书把目标值写成了具体数字**。

## 1. 问题

`discipline-source.ts:111` 的 `calculateDiscipline` 里：

```ts
const result = runDisciplineGrid(evidence.input, {
  a: { count: 784, netProfit: -230837.38 },
  b: { count: 774, netProfit: -197422.44 },
});
```

这两组数字来自**某一个特定账户在某一次导入后的结果**。后果：

- 用户导入**任何其他账户**（或同一账户补充更早的对账单、改变期初资金反推值），
  自校验必然失败，整个功能报"基线不符"并停止
- 这个功能因此只对一份特定数据可用，不是一个能用的功能

任务书 §3.3 写的是"必须与 W2 实测的 −230,837 在 1 元内一致"，
执行者照做了。**错在我把一次性核对的验收标准，写成了运行时的永久契约。**

## 2. 自校验该验什么

自校验的真实目的是**证明反事实重放器与既有复盘算的是同一个东西**。
这件事不需要知道具体数字，只需要两条路径在同一份输入上得出同一个结果：

| 校验 | 左边 | 右边 | 含义 |
| --- | --- | --- | --- |
| **A** | `runDisciplineGrid` 的 unchanged 点（不施加规则、不排除） | 同一份输入跑 `reviewTrades` 得到的**有效已平仓回合净利润合计与回合数** | 重放器口径正确 |
| **B** | 网格基线点（不限加仓 + 不启用止损，跨除权退出统计） | 同一份输入按 `crossesExRights === false` 过滤后的合计与回合数 | 可比基线自洽 |

两边都从**同一份运行时输入**算出来，不出现任何字面量金额。

## 3. 交付

- `runDisciplineGrid` 的 `expectations` 入参改为**由内部从输入推导**，
  或保留入参但由 `calculateDiscipline` 从 `evidence.input` 计算后传入。
  **无论哪种，`discipline-source.ts` 里不许再出现具体金额或回合数字面量**
- 容差：金额 1 元、回合数精确相等。不匹配时**照旧抛错并停止**，
  错误信息里带上两边的实际值（便于诊断），但不带任何"期望值"常量
- W3 已有的其他行为一行不改

  ——这条是本批的核心，它证明功能不再绑定单一账户

## 6. 管理者裁定（2026-09-13）

执行者按"不成立就停"拒绝实现，指出 §5 的 grep 验收标准**过宽**：
`multiple-testing.ts:75,83` 的 Acklam 逆正态 CDF 系数 `0.007784…` 也命中 `784`。
照原标准它得去改一个与本批无关的数学常数。**这是我的验收标准写错了。**

### 裁定一：grep 验收范围收窄

改为：在 **`src/server/portfolio/discipline-source.ts` 与 `src/components/discipline-*.tsx`** 两处，
`230837` / `197422` / `count: 784` / `count: 774` 零命中。

**明确禁止**修改 `src/lib/multiple-testing.ts` 的任何数值——
那是 V1 交付的数学常数，与本批无关，改动它会影响 PSR/DSR 的数值精度。

### 裁定二：授权同步修正文案

`discipline-container.tsx:39` 的「本批核对 W2 的 784/774 回合及两项固定金额」
是描述旧行为的文案，**授权改写**为不含具体数字的表述，
例如「自校验目标由当前账户数据推导」。

### 裁定三：期初现金默认值

执行者顺带提到该文案里还有「期初现金默认 126,200 元」。
**这个默认值同样是账户特定的**，但它与自校验不同——它是一个可被用户覆盖的输入默认值，
不会导致功能对其他账户直接失败。**本批不动它**，记入待办：
后续应改为由"现金不得为负"从当前账户数据反推，而不是写死。

### 其余不变

执行者已确认 `prepare` 内部本就通过 `reviewTrades` 推导 A/B，可直接复用；
只需删除固定目标入参、补 A 的回合数核对、错误信息带两侧实际值。
