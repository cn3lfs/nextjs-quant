# 任务书 R6：让复盘对真实账户真正可用

管理者用真实账户（2776 笔成交、190 笔现金流、2021-01 至 2026-04）做浏览器验收，
复盘能生成，但**核心指标全部不可得**。两个原因，都必须修。

## 1. 零金额、无股份变动的流水让净值从第二天起全断

快照里每一天的净值都是：

```
2021-01-26 neutral 流水缺少可确认的股份变动，后续持仓未知
```

那笔流水是 `代码 799999 / 金额 0 / kind=neutral`——**新股申购的验资配号记录**，
既不动资金也不动股份。类似的还有 `subscription` 的起始配号行
（`708162` / `708020` / `001210` 等，金额均为 0），真实账户里有几十笔。

后果：净值序列从第 2 天起全是 `null`，
**最大回撤、夏普、Sortino、Calmar、TWR 全部不可得**——而这正是用户要的核心功能。

### 要求

- **金额为 0 且不含股份变动证据的流水，不得使持仓与净值作废。**
  它们对现金和持仓都没有影响，跳过即可（在诊断里说明跳过了多少笔、哪几类）。
- 真正会改变股份而数量未知的流水（例如送转到账、无法确认数量的中签入库）
  **仍要保持既有的保守语义**：持仓未知、净值留空。不要把这条一起放宽。
- 判据要基于**证据**（金额是否为 0、是否声称股份变动），
  不要用「kind === neutral」这种类型名硬编码——配号是 `subscription`，同样为零金额。

## 2. ETF 与可转债读不到日线，市值与买卖点全废

`readSnapshot`（`src/server/tdx.ts`）对非股票品种直接抛
`仅支持A股与沪深指数行情`：

```
sh600000: 6388 根，末根 2026-09-11
sh510300: 失败 → 仅支持A股与沪深指数行情
sh113502: 失败 → 仅支持A股与沪深指数行情
sz159915: 失败 → 仅支持A股与沪深指数行情
```

但**文件都在**（`E:/new_tdx64/vipdoc/sh/lday/sh510300.day` 111232 字节等），
格式与股票日线完全相同。用户真实账户里 **ETF 189 笔 + 可转债 207 笔**，
持有期间算不出市值，净值同样断裂。

### 要求

- **不要修改 `readSnapshot` 的品种门禁**——它服务于选股与策略，
  「仅 A 股」是既有语义，放宽会影响所有调用方。
- 在复盘层新增专用的日线读取入口，**复用既有的 `.day` 解析**（不要另写解析器），
  支持 ETF/LOF（15x/16x/51x/56x/58x…）与可转债（11x/12x）。
- **逆回购（204/131）明确排除**并说明理由：它的「价格」是年化利率、
  不存在持仓市值，资金占用已经体现在现金流里。排除要在诊断里可见，不是静默跳过。
- 读不到的品种仍要进「因缺行情无法分析」清单，保持既有的不补造语义。

## 3. 验收标准

修复后，用合成 fixture 构造的账户应满足：

- 含零金额配号流水时，净值序列**连续可得**，不再整体为 `null`；
- 持有 ETF / 可转债期间市值可得（测试用合成 `.day` 字节，不依赖真实目录）；
- 逆回购不参与市值，且诊断里能看到排除说明；
- 真正无法确认股份变动的流水仍使净值留空（这条不能被顺手放宽）。

## 4. 测试

- 零金额流水：构造含 `neutral` 与 `subscription` 零金额行的账户，
  断言净值连续、诊断说明跳过笔数。
- 股份未知流水：构造声称股份变动但数量未知的流水，断言净值仍留空。
- ETF / 可转债日线：用合成 `.day` 字节，断言可读、市值可得。
- 逆回购：断言不参与市值且有排除说明。
- 既有用例全部继续通过；不改 `readSnapshot`、`parseBars` 行为。
