# 任务书 U7a：权重表回测的等价性验证（只读，不替换）

排期里 U7 标的是「待定，不应直接开工」。本批就是它的前置：
**先证明权重表能不能无损表达我们现在的策略，再谈要不要换。**

来源：[wbt](https://github.com/zengbin93/wbt) 的核心主张——
给定 `(dt, symbol, weight, price)`，资金曲线是权重变化与 bar 收益的确定性函数，
所有派生结果「算一次、处处复用」。

## 1. 为什么不直接替换

权重表范式的吸引力是真的：现在双突破、缠论、RPS 过滤各写一套模拟，
结果互相不可比。降维成一张 `(dt, symbol, weight)` 表走同一个回测器，
就能同一套指标横向比较。

但它有一个**前提假设**：目标权重总能达成。而 `researchPortfolio` 的返回里
明明白白有 `unfilled` 和 `excluded`——A 股有 T+1、有涨跌停买不进卖不出、
有停牌、有整手约束、有 `entryMaxWait` 等待窗口、有 `maxPositions` 上限。
这些恰恰是权重表**表达不了**的部分。

所以直接替换的风险是：换完之后数字变好看了，而变好看的原因是
把成交约束偷偷抹掉了。那不是改进，是把已知的困难藏起来。

**本批不替换任何东西**，只回答一个问题：差多少、差在哪。

## 2. 交付

### 2.1 最小权重回测器

新建 `src/lib/weight-backtest.ts`（纯函数，**不接任何页面、不进任何路由**）。

输入 `(dt, symbol, weight)` 长表 + 各标的日收益，输出日度组合收益：

```
组合日收益(t) = Σ_i weight_i(t-1) × 收益_i(t) − 换手成本(t)
换手(t)       = Σ_i |weight_i(t) − weight_i(t-1)|
换手成本(t)   = 换手(t) × 单边费率
```

- 权重按**前一日收盘**生效（`t-1` 的权重吃 `t` 的收益），不得用当日权重吃当日收益——
  那是未来函数，`invariants.md §3` 明令禁止
- 缺收益的标的当日**整体不可得**，不当 0（沿用 U10 已定的处理）
- 费率取 E3 `spec.costs` 的同一口径，不另立参数

### 2.2 把 E3 模拟投影成权重表

新建投影函数：读 `researchPortfolio` 的 `trades` 与 `nav`，
逐交易日算出每标的的持仓市值占净值比例，得到 `(dt, symbol, weight)`。

**这一步只做投影，不做任何修正**——投影不出来的地方如实留空并计数。

### 2.3 逐项比对与差异归因（本批真正的交付物）

比对 **日收益序列**（避开单利/复利口径之争，逐日比较对两种口径都成立）。

**预期结果是不等价。** 不要试图调参数让它们对上——
把差异定位到具体原因才是本批的价值。至少要分别量化以下来源的贡献：

| 差异来源                | 权重表为何表达不了                 |
| ----------------------- | ---------------------------------- |
| T+1                     | 权重表允许当日反向调整             |
| 涨跌停 / 停牌未成交     | `unfilled`：目标权重没达成         |
| `entryMaxWait` 等待窗口 | 信号到成交之间的延迟不在权重语义里 |
| `maxPositions` 上限     | 权重表不知道有持仓数上限           |
| 整手约束（100 股）      | 权重是连续的，股数是离散的         |
| 现金拖累                | 未部署资金的收益差                 |
| 费用口径                | 换手成本 vs 逐笔费用明细           |

输出一份报告（写到 `docs/review/u7a-weight-equivalence.md`）：
每个来源贡献了多少日收益偏差（绝对值均值与最大值）、
剩余无法归因的残差是多少。

**残差是关键指标**：残差接近 0 说明差异已被完全解释，权重表加上这些约束
就能等价；残差大说明还有没搞清的机制，那时**更不能替换**。

### 2.4 结论与建议

报告结尾给一个明确判断，三选一：

- **可替换**：残差在容差内，且所有差异来源都能在权重语义里补回
- **有条件替换**：需要在权重表之外额外携带约束信息（列出具体是哪些）
- **不建议替换**：残差无法解释，或补回约束后权重表已失去「统一简洁」的好处

不要含糊其辞。这份判断是 U7 是否立项的唯一依据。

## 4. 测试

`tests/weight-backtest.test.ts`：

- **手算**：2 标的、3 天、已知权重与收益，逐日手算组合收益与换手，注释写算式。
- **未来函数门禁**：断言 `t` 日收益只用到 `t-1` 及更早的权重；
  构造一个「当日权重突变」的用例，断言它不影响当日收益。
- **缺收益**：某标的某日无收益 → 当日组合收益不可得，不当 0。
- **换手与费用**：全额换仓一次，断言换手为 2.0（卖光买满）而非 1.0。
- **投影往返**：对一个无 `unfilled`/`excluded` 的简单模拟，
  投影成权重表再回测，日收益应与原模拟一致（容差内）。
  这条是投影正确性的锚点——**如果这条都不过，后面的差异归因全部不可信**。
