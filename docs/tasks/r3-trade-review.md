## 1. 真实数据特征（管理者已用用户真实文件核实，务必按此设计）

2775 笔成交、445 个可配对品种：**444 个完全平仓、0 个仍有持仓、1 个负持仓**。
品种构成：股票 2147、ETF/LOF 189、可转债 207，另有 232 笔国债逆回购。

### 1.1 中签建仓：有卖出却没有买入

配债/新股中签得来的持仓，在成交记录里**没有买入行**。
真实例子：`370409 道氏发债` 申购中签 → 上市后以 `123190 道氏转02` 卖出 10 张，
成交记录里只有那一笔卖出。对应的实际付款在**现金流**里：
`新股中签资金扣款，1483新股中签资金扣款`（-1000 元）。

**要求**：配对时接受可选的 `cashFlows`，把 `subscription` 类的**负金额**流水
视为建仓成本来源。能匹配上（同证券或同一发行对应关系可确认）就按实付金额建仓；
**匹配不上就把该回合标为 `openingUnknown`，收益留空，绝不按零成本算成暴利**。

### 1.2 逆回购不是持仓

国债逆回购（`instrument === "reverseRepo"`）成对出现（融出 / 购回），
**不参与回合配对与买卖点分析**，单独汇总为资金占用与利息收入。

### 1.3 仍需处理但真实数据里没有

未平仓持仓、跨除权回合。**代码必须正确处理，测试必须覆盖**，
不能因为这份数据碰巧没有就省略。

## 2. 交付内容

### 2.1 回合配对

按时间（日期 + 时间 + 原始顺序）重放，输出 round-trip，每个回合至少包含：
开仓日、平仓日、持有自然日与交易日数、买入均价、卖出均价、数量、
总费用、净收益（已扣费）、收益率、成本口径、是否跨除权、是否 `openingUnknown`。

- **两种成本口径都要给**：`movingAverage`（与 `positionFor` 一致，默认）与 `fifo`，
  同时返回，供页面对比。不要只实现一种再声称另一种"差不多"。
- **部分平仓**必须正确：一次买入分多次卖出、多次买入一次卖出都要对。
- **未平仓**单列为 `openPositions`，**绝不按零收益进入胜率分母**
  （沿用 `researchTradeStatistics` 的既有语义）。
- 跨除权回合：接受可选的除权事件输入，命中则标注
  「未复权，不代表经济收益」，收益率照算但打标，不静默。

### 2.2 买卖点分析

纯函数，接收每个标的的**未复权日线** `Bar[]`（调用方准备，本函数不读文件）。
缺日线的标的必须返回"数据不可得"，不得跳过或补零。每笔成交给出：

- **日内位置**：成交价在当日 `(low, high)` 中的百分位；当日 `high === low`（一字板）
  时不可算，返回 null 而不是 0.5。
- **区间位置**：成交价相对前 20 / 60 / 250 个交易日高低点的位置；
  历史不足窗口长度时该窗口返回 null。
- **MFE / MAE**：买入日之后至平仓日（未平仓则至末根）区间内，
  相对买入价的最大有利偏移与最大不利偏移（用区间内 high / low，非收盘）。
- **卖后走势**：卖出日之后 T+1 / 5 / 10 / 20 个交易日的收盘相对卖出价的变化；
  日线不足则该档为 null。

### 2.3 汇总统计

把已平仓回合的净收益率喂给 `researchTradeStatistics`，再补充：
`profitFactor`（总盈利 / 总亏损绝对值，无亏损时为 null 不填 Infinity）、
最大连续盈利/亏损串、单笔最大盈亏、**费用占毛利比**。
按标的 / 品种 / 持有期分桶给同样的统计，分组是**描述性**的，不声称因果。

## 3. 硬性正确性要求

- 金额一律用成交记录里的**实际费用**，不要套用 `defaultBacktestCosts`。
- 任何"算不出来"一律 `null` 并给出原因字段，**禁止用 0 或前值填充**
  （`invariants.md` §2）。
- 收益率的分母必须写清楚是哪一个（买入成本含费用），并在测试里手算验证。
- 不得因为某笔数据不合预期就丢弃它——标注并单列。

## 4. 测试要求（`tests/trade-review.test.ts`）

全部用手算可验证的小样本，**不要依赖 fixture 文件**：

1. 单买单卖：手算净收益、收益率、持有交易日数，两种口径结果一致。
2. 一买多卖 / 多买一卖：两种口径**给出不同结果**，各自手算验证
   （这正是要同时给两种口径的原因）。
3. 未平仓：不进胜率分母，单列 `openPositions`。
4. 中签建仓：给一笔卖出 + 一笔 `subscription` 负金额流水 → 成本正确；
   不给流水 → `openingUnknown`、收益为 null。
5. 逆回购：不进回合、不进买卖点，单独汇总。
6. 跨除权：命中事件时打标。
7. 买卖点：一字板日内位置为 null；历史不足时区间位置为 null；
   MFE/MAE 用构造的 K 线手算；缺日线返回数据不可得。
8. `profitFactor` 无亏损样本时为 null。
