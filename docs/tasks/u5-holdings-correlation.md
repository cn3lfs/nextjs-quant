## 1. 问题

U11 给出「等效持仓 8.0」时，看起来是分散的。但如果这 8 只都是同一板块、
日收益相关性 0.9，实际上等于**重仓一个方向**——集中度指标完全看不出来。

赫芬达尔衡量的是**权重分布**，相关性衡量的是**共同运动**。
两者都低才是真分散；只看前者会把「买了 8 只券商股」误读成分散。

## 2. 交付

新建 `src/lib/holdings-correlation.ts`（纯函数）。

### 2.1 输入与口径

- 标的：复盘区间内**曾经持仓**的证券（沿用 U11 的持仓判定，逆回购排除）
- 序列：各标的的**日价格收益**，来自复盘专用日线的收盘价
  （**不要**用 U11 的 `positionValues`——它随买卖改变股数，
  含的是仓位变动不是价格变动，拿它算相关性是错的）
- 相关系数：**Pearson**，逐对计算

### 2.2 缺失处理

- 逐对只用**两边都可得**的交易日（成对完整），并返回该对的 `overlapDays`
- `overlapDays < 20` 时该对返回 `null` + 原因「重叠交易日不足 20，相关性不可靠」，
  **不要**算出一个基于三五天的数字——小样本相关性几乎无意义
- 任一标的全区间无可得收益 → 该标的整行整列留空，不参与平均

### 2.3 输出

```ts
{
  symbols: readonly string[];
  matrix: ReviewValue[][];        // 对称，对角线为 1
  averagePairwise: ReviewValue;   // 所有可得对的均值（不含对角线）
  pairCount: { available: number; insufficient: number };
}
```

`averagePairwise` 是最实用的一个数：接近 0 说明确实分散，
接近 1 说明持仓只是同一笔押注的不同写法。

### 2.4 与 U11 并列展示

`/trade-review` 的「持仓集中度」区块内追加相关性，**和 `effectivePositions` 放在一起**，
并写一句固定说明：

> 等效持仓只数衡量权重是否分散，平均相关性衡量它们是否同向运动；
> 两者都低才是真分散。

矩阵用 `DataTable`；标的数可能上百，**行必须服务端分页**
（沿用 U2/U3/U10/U11 模式）。列过多时只展示当前页标的与其余标的的相关性，
不要一次性渲染 N×N。

颜色用 token；**不新增色阶机制**（那是被砍掉的原 U5 内容）。

## 3. 测试

`tests/holdings-correlation.test.ts`：

- **手算**：3 标的、完全正相关 / 完全负相关 / 不相关各一对，
  注释写出算式，断言 1 / −1 / ≈0。
- **对角线**为 1，矩阵**对称**。
- **成对完整**：A 缺某几天时，A-B 只用两边都有的日子，
  断言 `overlapDays` 正确且结果等于「先剔除再算」。
- **样本门槛**：`overlapDays` 19 / 20 / 21 三个边界。
- **不可用 `positionValues`**：写一条注释说明理由即可，
  但要断言实现读的是收盘价序列而非仓位市值
  （例如：同一价格序列下改变持仓股数，相关性不变）。
- 逆回购不进入标的集合。
