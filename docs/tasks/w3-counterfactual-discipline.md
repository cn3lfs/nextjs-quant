# 任务书 W3：仓位与持有纪律的反事实对照

W 系列第 3 批。触发依据：[W2 复盘追查](../review/w2-real-account-review-2026-09-13.md)。

## 1. 问题

真实账户 784 个有效回合的证据：

- **开仓即重仓**：亏损回合投入均值 30,811、中位 12,978，比盈利回合高 28% / 30%；
  最大投入 820,162 对 288,902。四个分位一致偏移，不是极端值造成
- **处置效应**：盈利中位持有 1 天，亏损均值 5 天、p90 12 天
- 胜率 50.89%，但金额口径净亏 230,837，利润因子 0.53

结论是"亏损来自仓位与持有纪律，不在信号层"。**但这只是相关性。**
要判断它是不是可改的，得回答一个反事实问题：
**如果当初对仓位和持有期加一条纪律，同一批交易决策会变成什么结果？**

本批把这个问题变成可计算的对照，**不上线任何风控**。

## 2. 最重要的一条：本批产出的是对历史的重新解释，不是策略

参数是在看过结果之后选的，**任何"最优参数"都必然过拟合**。因此：

- **必须扫描参数网格并报告全部结果**，不许只报最优点
- **必须经 V5 的 `recordResearchUsage` 记账**，`candidateCount` 为网格点数
- 页面与导出的结论文案里必须有一句固定的话：
  **「参数在已知结果后选定，本对照不构成可交易结论」**
- **不要**据此给"建议仓位上限"或"建议止损线"这类推荐值

## 3. 交付

### 3.1 `src/lib/discipline-counterfactual.ts`（新建，纯函数）

输入：真实成交序列（复用 `reviewTradeNav` 的入参形态）+ 规则参数 + 日线行情。
输出：反事实净值序列与逐回合对照。

**规则 A：等额开仓（检验"仓位选择本身是否有害"）**

每个回合的开仓金额统一为 `equalWeightAmount`（绝对金额，来自网格），
其余成交按同一回合的比例缩放。**不改变任何买卖时点与标的选择**——
本规则只回答"如果每笔下同样多的钱会怎样"。

若某回合原始投入小于该金额，**按原始投入执行、不放大**
（放大等于虚构一笔当时没有的资金，且会与真实现金约束冲突）。

**规则 B：持有期止损（检验处置效应的代价）**

对每个回合，自开仓次日起逐日以**收盘价**检查浮动盈亏；
跌破 `stopLossPct` 时，在**下一交易日开盘**平仓（不许当日收盘价平仓——
那是用当日收盘信息在当日成交，属前视）。

平仓后该回合结束；原始序列中该回合剩余的买卖**全部作废**，不顺延、不替换。

**规则 C：A + B 同时施加**

### 3.2 硬约束（前视与自洽）

- 止损判定只能用**截至判定日已完成**的行情，成交发生在其后的开盘
- 缺当日行情（停牌）→ 该日不判定，顺延到下一个有行情日，**不猜价格**
- 跨除权回合（`crossesExRights`）→ 该回合**整体排除**并计数，不做近似
- 反事实改变了现金曲线，后续回合的可用资金随之变化：
  **若某回合在反事实里资金不足，按可用资金买入整手；不足一手则该回合不发生并计数**
- 逆回购回合（`instrument === "reverseRepo"`）不参与两条规则，原样保留

### 3.3 网格与输出

- `equalWeightAmount`：5,000 / 10,000 / 20,000 / 30,000 / 50,000
- `stopLossPct`：3% / 5% / 8% / 10% / 不启用
- 组合共 5 × 5 = 25 个网格点（含"两条都不启用"= 实际基线，用于自校验）

每个网格点输出：净盈亏、回合数、胜率、盈亏比、利润因子、最大回撤、
被止损平仓的回合数、因资金不足未发生的回合数、被排除的跨除权回合数。

**自校验（必须有）**：网格里"不启用等额 + 不启用止损"那一点的净盈亏，
必须与 W2 实测的 **−230,837** 在 1 元内一致。对不上说明重放器与既有复盘口径不一致，
**先停下报告，不要调参数凑数**。

### 3.4 展示

`/trade-review` 新增「纪律反事实」区块：25 点网格表格 + §2 的固定文案。
不画热力图（本批不引图表新形态）。不高亮"最优"格子——高亮就是在推荐。

## 4. 测试（`tests/discipline-counterfactual.test.ts` 新建）

- **基线自校验**：合成 fixture 上，两条规则都不启用时结果与 `reviewTradeNav` 逐项相等
- **等额缩放手算**：2 个回合、已知投入与收益，手算反事实盈亏，注释写算式
- **不放大**：原始投入小于等额金额时按原始投入执行，有断言
- **止损时点**：构造第 3 日收盘跌破阈值的回合，断言在**第 4 日开盘**平仓，
  且断言不是第 3 日收盘价成交——**这条是防前视的锚点**
- **停牌顺延**：判定日无行情 → 顺延到下一有行情日，不猜价格
- **止损后作废**：原回合后续买卖不再发生，有断言
- **资金不足**：反事实现金不够买一手 → 该回合不发生且计数
- **跨除权排除**：`crossesExRights` 回合整体排除并计数
- **逆回购**：不参与规则，原样保留
- **网格完整**：25 点全部产出，无静默失败

## 6. 管理者裁定（2026-09-13，回应执行者的三条阻断）

执行者按"不成立就停"拒绝实现，三条全部成立，**其中第三条推翻了本批的触发依据**。
更正见 [W2 更正节](../review/w2-real-account-review-2026-09-13.md)。以本节为准。

### 采纳三条

1. **网格自相矛盾**：五个 `equalWeightAmount` 全部启用规则 A，25 点里
   不存在"双不启用"基线，§3.3 的自校验无处落脚。**是任务书的错。**
2. **除权证据缺失**：W2 调用未传 `exRightsEvents`，784 个回合的
   `crossesExRights` **全部是 null（未知）**，不是 false。不能把未知当假。
3. **触发依据推断过强**：W2 的"投入"是全回合累计买入金额而非开仓金额；
   成交笔数混算了买卖两侧。重算后**「开仓即重仓」不成立**——
   首笔买入盈亏回合只差 3–5%，累计差 28–30%，差额来自**加仓**
   （多次买入占比 36.1% vs 30.6%，首笔占累计比 0.800 vs 0.817）。

### 裁定一：规则 A 改为「加仓限制」，不再是「等额开仓」

原规则 A 建立在"开仓仓位有差异"之上，而事实是首笔几乎相同，**它测不到东西**。
改为直接针对已证实的机制：

**规则 A′：加仓上限 `maxAddOns` ∈ {0, 1, 2, 不限}**
——一个回合内允许的**追加买入次数**上限。超出上限的买入**不发生**，
该笔资金留在现金里；后续卖出按实际持有量成比例缩减。
首笔买入一律照原样执行（首笔没有证据支持要改）。

### 裁定二：网格与基线

- `maxAddOns`：0 / 1 / 2 / 不限（4 档）
- `stopLossPct`：3% / 5% / 8% / 10% / 不启用（5 档）
- 共 **20 点**，其中 **「不限 + 不启用」就是真实历史**，自校验落在这一点

自校验目标值改为：该点的**有效已平仓回合净利润合计**等于 **−230,837 元**（±1 元）。
执行者已指出这个数**不是账户净值差**（还受逆回购利息、分红、未匹配现金流与
期初资金反推影响），任务书原先的措辞不准，这里一并改正。

### 裁定三：必须传入除权证据

调用方从 GBBQ 读取并传 `exRightsEvents`，使 `crossesExRights` 有真值。
**若某回合仍为 null（事件覆盖不到），该回合整体排除并单独计数**，
与 true 的排除分开统计——"已知跨除权"和"不知道是否跨除权"是两件事。

### 裁定四：结论文案同步收窄

§2 的固定文案保留，另加一句：
**「本对照针对加仓与止损，不涉及开仓决策；首笔买入在盈亏回合间无显著差异」**。

其余（防前视、停牌顺延、资金不足处理、逆回购不参与、V5 记账、
不高亮最优、不给建议参数）全部照旧。§4 测试里"等额缩放手算""不放大"两条
相应改为加仓上限的手算用例：构造一个 3 次买入的回合，
断言 `maxAddOns=1` 时第 3 笔不发生、现金留存、卖出量按实际持有缩减。
