## 1. 必须先解决的两个前提

### 1.1 现金流缺少时间字段

`ParsedCashFlow` 只有 `flowDate`，没有时间。但银证转账流水导出里**有「委托时间」列**
（已被列映射识别为 `tradeTime`），成交也有成交时间。

**要求**：给 `ParsedCashFlow` 增加 `flowTime: string | null`，
沿用 `parseDeliveryTime` 解析，取不到就是 `null`。

### 1.2 同日事件必须按时间排序，否则现金会假性为负

管理者用真实数据验证过：只按日期排序时，2022-11-09 当天的买入被排到卖出之前，
现金一度出现 `-50451`。按 `日期 + 时间` 排序后该问题消失。

**要求**：现金重放必须按 `(日期, 时间, 原始顺序)` 排序。
时间缺失的事件排在当日**已知时间的事件之后**（不能当成 00:00 抢到最前面），
并在诊断里说明有多少事件缺时间。

## 2. 交付内容

### 2.1 每日现金重放

输入：`ParsedFill[]`、`ParsedCashFlow[]`（可来自多个文件，调用方已合并）、
可选 `openingCash`（默认 0）、交易日历。

- 现金变动一律用**实际资金变动**：成交用 `netAmount`，
  取不到才退回 `金额 ± 费用` 并标注（与 R3b 的费用口径保持一致，不要另立一套）。
- 输出每个交易日的现金余额，以及**最低现金及其日期**。
- 若最低现金为负，说明期初资金不为 0 或流水不完整：
  **明确报告，不要自动上调期初值去掩盖**。

### 2.2 每日持仓与市值

- 按 `(日期, 时间)` 重放成交得到每日收盘后持仓（按标的）。
- 市值 = 持仓数量 × 当日收盘价，收盘价由调用方以 `bars` 传入（本函数不读文件）。
- **任一持仓标的当日无收盘价 → 当日市值不可得 → 当日净值为 `null`**，
  给出原因（哪个标的、哪天）。**禁止**用前一日价格、零或成本价填充。
- 停牌日的处理：没有 bar 就是没有，按上一条处理，不要自行推断停牌。

### 2.3 净值与风险指标

净值 = 现金 + 持仓市值。在**连续可得的净值区间**上计算：

- 复用 `researchNavStatistics`：最大回撤、总收益、夏普（252 年化、显式无风险利率，
  默认 2%，可配）。
- 新增：**Sortino**（下行标准差，用同一无风险利率）、
  **Calmar**（年化收益 / 最大回撤）、
  **回撤区间明细**（峰值日、谷底日、恢复日、水下交易日数；未恢复的标明未恢复）、
  **月度收益表**。
- **资金加权与时间加权要分清**：账户有大额出入金，
  简单的「期末/期初 - 1」是错的。至少给出**时间加权收益率（TWR）**，
  按每次现金流切段连乘；若你也给资金加权（IRR/XIRR），必须与 TWR 分开标注，
  不得混为一谈。这是本任务最容易出错的地方。
- **硬约束**：净值序列中只要有一天不可得，该段即中断；
  夏普与回撤只在连续段上计算，并报告实际使用了多少个交易日、跳过了哪些区间。
  沿用既有口径「没有每日净值就不计算夏普」。

### 2.4 基准对比（可选输入）

调用方可传入基准日线（如 `sh000300`）。给出同期基准收益、超额收益、
以及相对基准的回撤。基准缺数据时该项为 `null` 并说明，不影响主指标。

## 3. 硬性正确性要求

- 任何算不出来的量一律 `null` + 原因，**禁止用 0 或前值填充**（`invariants.md` §2）。
- 不得因为某天数据缺失就悄悄跳过该天继续连乘收益率——那等于伪造连续性。
- 所有比率明确分母口径并在测试里手算验证。

## 4. 测试要求（`tests/trade-review-nav.test.ts`）

全部用手算可验证的小样本，不依赖 fixture：

1. 纯现金账户（只有转入转出，无成交）：净值曲线 = 现金曲线，回撤为 0。
2. 一买一卖 + 行情：逐日净值手算，最大回撤手算。
3. **同日先卖后买**：只按日期排序会出现负现金，按时间排序不会——两种排序各断言一次，
   证明时间排序生效。
4. 缺收盘价：该日净值为 `null` 且给出原因；该段不计夏普；
   报告实际使用的交易日数。
5. **大额入金后收益率**：构造一个「期初 1 万赚 1 千，随后入金 100 万不赚不亏」的账户，
   断言 TWR 约 10%，而「期末/期初-1」会得出荒谬值——用测试把这个区别钉死。
6. Sortino / Calmar / 回撤区间（峰值、谷底、恢复日、未恢复）各一例手算。
7. 月度收益表跨月边界正确。
