# 任务书 W9：货币基金往来纳入现金流

依据：[资金对账诊断](../review/w9-cash-reconciliation-2026-09-14.md)（先读它）。

## 1. 问题

成交明细里**没有 007864 的记录**（场内货币基金申购/赎回）。对账单有 48 条，
净额仅 **+114.13 元**，但过程中资金先流出、后流回。缺了这些记录，
中间时点的现金曲线会塌到 **−126,150.68**（2024-01-12）。

**总额是对的**（成交 + 银证 与对账单只差 296.80 元），**过程是错的**。

W5b 目前把这类记录留在 `unresolved`（其中 23 条申购扣款合计 −387,800）。

## 2. 已核实的事实

- 摘要形态：`202107150010020300000324037202[007864]申购`
  ——前缀是流水号，方括号内是基金代码，结尾是「申购」或「赎回」
- **操作列不可信**：与 [W8](w8-repo-direction.md) 的逆回购同一类问题，
  007864 的记录标「卖出」而金额为负。**方向一律以发生金额符号为准**
- 48 条记录净额 +114.13 元（即持有期收益）
- 另有 370409 一条，净额 0.00

## 3. 交付

### 3.1 独立成类，不要并进银证转账

新增一个现金流类别（如 `cashManagement`），**不要**按金额符号归入
`transferIn` / `transferOut`——它们不是银证转账，而是账户内部的现金管理。
混进去会污染「净入金」口径，让 22.8 万的真实净入金变成错的。

同理**不要**归入 `subscription`（那是新股申购）。两者要能分开统计。

### 3.2 与新股申购区分

新股申购的摘要形如「新股中签资金扣款」「XX配号」，
货币基金形如 `[代码]申购` / `[代码]赎回`。**靠结构区分，不要只匹配「申购」二字**
——W5b 刚因为关键词匹配把逆回购当成利息，教训在 `decisions.md` 里。

无法明确归类的一律留 `unresolved` 并计数。

### 3.3 方向

发生金额为负 → 流出（申购），为正 → 流入（赎回）。
`netAmount` 为 null / 非有限 / 为零 → 不猜，计入"方向不可判"。

与 W8 一致：**操作列与金额方向冲突时要留痕**，不要静默修正。

## 5. 测试

- 结构区分：`[007864]申购` 与「新股中签资金扣款」各一条，断言归入不同类别
- 方向：金额为负归流出、为正归流入，与操作列无关
- 冲突留痕：操作列标「卖出」而金额为负的一条，断言 warnings 有说明
- 不可判：`netAmount` 为 null 的一条，计入"方向不可判"并计数
- 不污染：断言货币基金记录**不出现在** `transferIn` / `transferOut` / `subscription` 里
- 无法归类：构造一条摘要不匹配任何模式的，断言留 `unresolved`
- 既有导入测试全部保持通过
