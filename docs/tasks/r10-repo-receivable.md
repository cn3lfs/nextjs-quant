# 任务书 R10：逆回购债权必须计入净值（管理者前序判断错误）

## 0. 先说清楚这是管理者的错

R6 任务书里管理者写了：

> **逆回购（204/131）明确排除**并说明理由：它的「价格」是年化利率、
> 不存在持仓市值，资金占用已经体现在现金流里。

**这个判断是错的。** 执行者在 R6 与 R9 的报告里两次提示
「未计入未到期回购债权，可能影响收益解释」，管理者两次都没有采纳。
本任务纠正它。

## 1. 现象与根因

真实账户出现荒谬的分段指标（R9 修了 TWR 口径也没消除）：

```
2023-12-29  现金    712.05   净值    712.05
2024-01-02  现金 116978.87   净值 126698.87   日收益 17693%
```

那天没有任何银证转账，只有两笔成交：

```
行1460 buy 002587 奥拓电子  净额  -9888.94   余额  -9176.89
行1461 buy 131801 Ｒ-007    净额 +126155.76  余额 116978.87
```

`131801 R-007` 是深市 7 天期国债逆回购，这笔是**到期回款**。
更清楚的一对：

```
2025-05-29 sell 204001 GC001 量99 净额  -99000.99  ← 融出资金
2025-05-30 buy  204001 GC001 量99 净额  +99016.71  ← 到期回款（含利息 15.72）
```

因为逆回购的资产被排除，**融出当日现金减少 9.9 万而没有任何资产对冲，
净值凭空蒸发；回款当日又凭空增加**。于是产生 17693% 的日收益、
99.97% 的「回撤」——那根本不是回撤，是被抹掉的债权回来了。

日收益最极端的 6 天全部是这个成因（净值从几十元跳到几十万）。

## 2. 正确口径

逆回购融出的资金变成**未到期债权**，是账户资产的一部分：

```
净值 = 现金 + 证券市值 + 未到期逆回购本金
```

- **融出**（`204xxx`/`131xxx` 的 `sell`，净额为负）：
  现金 `-= |净额|`，未到期本金 `+= 成交金额`。
  （例：成交金额 99000、净额 -99000.99，费用 0.99 是当期成本。）
- **到期回款**（同代码 `buy`，净额为正）：
  未到期本金 `-= 成交金额`，现金 `+= 净额`。
  差额（例中 `99016.71 - 99000 = 16.71`）是利息收入。
- 本金用**成交金额**，不要用净额——净额含费用与利息。

## 3. 要求

- 净值中计入未到期逆回购本金，使融出/回款当日净值**连续**。
- **仍然不要**给逆回购算「持仓市值」——它没有行情价格，
  按**本金成本计价**即可；应计利息可以不计（在 `basis` 里说明口径）。
- 未到期本金出现负数（回款多于融出、或记录不全）→
  **报告异常并留空，不要静默取 0**。
- `basis` 里写明：逆回购按本金成本计入资产，利息在回款日确认为收益。
- 不要改动逆回购**不参与回合配对与买卖点分析**的既有语义（R3 已定）。

## 4. 验收目标（管理者用真实账户复验）

- 日收益不再出现万倍级数字；
- 分段 `totalReturn > 1000%` 的段数为 **0**（当前 4 段）；
- 最大回撤最大值从 **99.97%** 降到合理量级
  （该账户 5 年净投入 22.8 万、净亏 22.8 万）；
- Calmar 不再出现 8 位数；
- 净值可得率保持 **1265/1265**，残差保持 **295.90**。

## 5. 测试

- **融出与回款净值连续**：构造「现金 10 万 → 融出 9.9 万 → 次日回款 9.9 万 + 利息」，
  断言融出当日净值**不变**（现金减少、债权增加），
  回款当日净值只增加利息。这是本任务的核心用例。
- 未到期本金跨多日：断言持有期间每日净值都包含该本金。
- 本金为负：断言报告异常并留空。
- 既有用例全部继续通过，逆回购不进回合配对的语义不变。
