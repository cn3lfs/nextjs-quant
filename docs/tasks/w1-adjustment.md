# 任务书 W1：研究路径的复权口径

W 系列第 1 批。触发依据：[两项前置排查](../review/w-prechecks-2026-09-13.md)。

## 1. 问题

sh600000 绝对值最大的 5 个日收益全部落在 GBBQ 除权日，−33.10% / −30.30% /
−25.95% / −23.62% / −16.42%。**A 股主板日跌幅上限 10%，这些在物理上不可能是
市场波动。** 其余极值都是 ±10.0x% 涨跌停，属于真实行情。

`README` 与 `backtest` 的 assumptions 早已声明"不复权、跨除权事件不能用于正式
收益评价"，但那描述的是收益偏差。实际后果更广：

- 假暴跌进净值 → 最大回撤被高估
- 进日收益的三阶四阶矩 → 偏度、峰度严重失真（该标的策略净值峰度 93.62）
- **峰度直接进 PSR 分母 `1 − γ₃·SR̂ + (γ₄−1)/4·SR̂²`，V1 的紧缩夏普被污染**
- 均线窗口跨越除权日 → 信号本身失真，不只是事后评价失真

## 3. 设计（四条口径，缺一不自洽）

| 环节 | 用什么价 | 理由 |
| --- | --- | --- |
| 指标 / 信号 | **后复权** | 均线窗口不能跨除权跳空；后复权因子只增不减，历史不会因新事件被改写，回测可复现 |
| 成交价 | **原始价** | 成交必须发生在当时真实可成交的价格上，否则整手与资金约束失真 |
| 估值 | **原始价 × 当时股数** | 与成交口径一致 |
| 持仓股数 | 除权日按**送转比例**调整 | 送转不改变持仓价值，股数必须跟着变，否则净值假跌 |
| 现金分红 | 沿用 `DividendLedger` | 已有实现，**不要重复计入股数** |

**不要用复权因子直接调整股数**：因子里同时含送转与分红两部分，
用它调股数会把现金分红也算成股数增加，与 `DividendLedger` 重复计算。
股数只跟送转走，现金只走分红账。这条是本批最容易做错的地方。

前复权**不要用于回测**：它每次除权都改写全部历史，同一天的历史价今天和明天不同，
回测不可复现；且早期价格被压得极小，会制造"低价股"前视偏差。
仅允许在展示层临时换算（既有注释已是这个约定）。

**配股**（`rightsRatio > 0`）需要股东出资，现有账簿没有这条路径。
本批**不建模配股**：遇到含配股的事件，该标的整段研究结果标记为不可用 + 原因，
**不要假装配股没发生，也不要当作送转处理**。

## 4. 交付

### 4.1 `backtest` 新增复权模式，默认行为一行不变

`backtest(...)` 增加可选入参（如 `adjustment: "none" | "backward"`，默认 `"none"`）。
`"none"` 时**现有全部路径与数值完全不变**——既有测试一条都不许改。

`"backward"` 时：
- `signalBars` 用后复权序列（沿用 `cash-adjusted-signals.ts` 已确立的
  "信号用调整价、成交与估值用原始价"结构，不要另造一套）
- 除权日按送转比例调整 `shares`；调整产生的碎股按**向下取整到整股**处理，
  余股折现计入现金并单独计数（不要静默丢弃）
- `assumptions` 追加本模式的口径与限制，含"配股不建模"

### 4.2 `walkForward` 透传

`walkForwardSchema` 增加同名可选项并透传给 `backtest` 与 `candidateTrialMatrix`，
默认仍是 `"none"`。**候选矩阵与各 fold 必须使用同一模式**，不许一边复权一边不复权。

### 4.3 页面回显

滚动检验与回测结果显示当前复权口径。`"none"` 时保留既有免责文案；
`"backward"` 时文案改为说明该模式处理了什么、**没处理什么**（配股、退市、
成交量不复权、历史税制）。不要让用户以为复权 = 结果可信。

### 4.4 诊断输出

`backtest` 的 `diagnostics` 增加：`exDividendDays`（区间内除权日数）、
`shareAdjustments`（实际调整股数的次数）、`fractionalShares`（碎股折现次数）、
`rightsIssuesBlocked`（因配股被拒的事件数）。这些数字是验收本批是否真的生效的依据。

## 5. 测试（`tests/backtest-adjustment.test.ts` 新建）

- **手算送转**：10 送 10，持仓 1000 股、价格 20 → 除权后 2000 股、价格 10，
  **净值不变**，注释写出算式。这是本批的核心锚点
- **现金分红不进股数**：只有现金分红的事件，断言 `shares` 不变、
  现金按 `DividendLedger` 入账，且**没有被重复计算**
- **送转 + 分红同日**：断言股数只按送转变、现金只按分红入，两者不互相污染
- **碎股**：10 送 3、持仓 100 股 → 130 股（整数）；构造能产生碎股的比例，
  断言向下取整且余股折现被计数
- **配股拒绝**：含 `rightsRatio > 0` 的事件 → 该段结果不可用 + 原因，
  断言**不会被当作送转处理**
- **默认不变**：`"none"` 模式下，用既有 fixture 断言结果与改动前逐项相等
  （特征化快照，硬编码期望值）
- **信号口径**：构造一个"原始价跨除权日会误触发均线信号、后复权价不会"的用例，
  断言两种模式给出不同信号——证明信号侧真的换了序列
- **因子对齐**：断言复权序列长度与 bars 一致、首日因子为 1

## 6. 验收

- 默认 `"none"` 行为零变化，有特征化断言
- 股数只跟送转、现金只跟分红，有专门用例证明不重复计算
- 配股被明确拒绝而不是误当送转
- 四项诊断计数输出
- 不新增依赖、不新增迁移
- `decisions.md` 记一条：为什么回测用后复权而不是前复权
- `invariants.md` 补一条：四条口径（信号后复权、成交估值原始价、股数跟送转、
  现金跟分红）与配股不建模
- `pnpm typecheck` / `pnpm test` / 改动文件 prettier 通过

## 8. 管理者裁定（2026-09-13，回应执行者的阻断报告）

执行者按 §2 完成四项核实后停止实现，报告了一个真实阻断。四项结论采纳：

1. `category` 共 14 类（1 除权除息、2 送配股上市、3 非流通股上市、4 未知股本变动、
   5 股本变化、6 增发新股、7 股份回购、8 增发新股上市、9 转配股上市、
   10 可转债上市、11 扩缩股、12 非流通股缩股、13 送认购权证、14 送认沽权证）。
   **原任务书只让拒绝配股，覆盖不足。**
2. 单位：`dividend` 元/原股，`bonusRatio` / `rightsRatio` 新增股/原股，
   `rightsPrice` 元/配股股。
3. 配股确实未被 `DividendLedger` 处理。
4. `applyAdjustment` 只校验长度，不校验日期对齐。

**阻断项成立**：GBBQ 没有登记日与派息日，而 `cash-dividends.ts` 的分红计划契约
要求登记日、派息日、公告日、税率与对账哈希，现有计划生成器还会拒绝送转混合事件。
执行者没有用除权日伪造登记日，这个判断是对的。

### 裁定一：本批只处理送转，现金分红两边都不处理

理由是量级。除权假暴跌是 **−33%**，现金分红漏计是每年 **1–3%** 股息率量级，
**差两个数量级，且方向已知**（系统性低估收益，非高估）。为后者接入新数据源
或绕过账簿校验，代价与收益不成比例。分红建模需要分红日程数据源，另行立项。

### 裁定二：信号侧改用"只含送转"的因子，不用完整后复权

原 §3 让信号用完整后复权（因子含分红），而持仓只调送转——**两者口径不一致**，
等于信号假设分红再投资、净值却没有。改为：

- 新增只按送转计算的因子：除权价公式的分母只保留 `10 + bonus×10`，
  **不含 cash、不含 rights**
- 信号、持仓、净值全部走这一套口径

代价：信号仍会看到除息那部分约 1–2% 的跳空。**这个残余偏差必须写进 assumptions
与页面文案**，不许省略。口径一致优先于消除全部偏差。

### 裁定三：拒绝清单补全

以下任一情形出现在研究区间内，该标的整段结果标记不可用 + 原因，
**不猜、不当作送转、不忽略**：

- `category === 1` 且 `rightsRatio > 0`（配股，需股东出资）
- `category === 11`（扩缩股）、`category === 12`（非流通股缩股）
- `category === 13` / `14`（送认购/认沽权证：股东获得额外资产，本批不建模）

其余类别（2/3/4/5/6/7/8/9/10）改变的是总股本而非个人持股数，不影响本批口径，
**但要在 assumptions 里写明这个判断依据**，以便日后被推翻时能找到出处。

### 裁定四：因子表述修正

任务书原文"后复权因子只增不减、历史不会因新事件被改写"是设计意图，
不是函数保证——历史输入被修订时因子会变。改为：
"在历史输入不变的前提下，追加未来事件不改写已有因子"。

### 其余不变

§3 的价格与股数分离（信号用调整价、成交与估值用原始价、股数跟送转）成立，
执行者已确认。§4 交付、§5 测试、§6 验收除下列调整外照旧：

- §4.1 的现金分红一条删除；`diagnostics` 增加 `dividendsIgnored`
  （区间内被忽略的现金分红事件数）与 `blockedEvents`（按裁定三被拒的事件数及类别）
- §5 的"现金分红不进股数""送转+分红同日"两条测试改为：
  **断言现金分红事件不改变股数、也不改变现金**，并断言 `dividendsIgnored` 计数正确
- §5 增加：`category` 11/12/13/14 各一条拒绝用例
