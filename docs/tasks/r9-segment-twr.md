# 任务书 R9：分段指标必须剔除资金流（当前数字失真）

R8 后真实账户净值**100% 可得（1265/1265 天）**，残差稳定在 `295.90`。
但分段风险指标出来的数字是荒谬的：

```
2023-12-21~2024-03-20  58日  总收益 74.7943   最大回撤 0.9992  Calmar 204322969.948
2025-03-24~2025-06-20  60日  总收益 -0.1489   最大回撤 0.9997  Sortino 2121.471
2024-03-21~2024-06-20  60日  总收益  0.0045   最大回撤 0.8712  夏普 3.291
```

## 1. 根因

`nav.segments` 的 `totalReturn` / `maxDrawdown` / `sharpe` / `sortino` / `calmar`
是按**净值绝对值**算的，没有剔除段内的外部资金流入流出。

真实账户在 5 年里多次几乎清空又重新入金（净投入 22.8 万，
累计转入 101.7 万、转出 79.0 万）。于是：

- 段首净值只有几十元、段内入金十几万 → `totalReturn` 变成 **7479%**；
- 一次**转账出金**被当成 **87%～99.97% 的回撤**——那是提款，不是亏损；
- Calmar = 年化收益 / 最大回撤，两个错误值相除，得到 2 亿。

`nav.basis` 里已经写明 TWR 的正确口径
（「逐次外部转入/转出前估值除以上次流后估值，连乘至收盘」），
主口径 TWR 实现是对的，**但分段指标没有走同一套口径**。

R4 任务书 §2.3 已经要求过「资金加权与时间加权要分清，
简单的『期末/期初 - 1』是错的」，并给了对应测试。这条要求在分段上落空了。

## 2. 要求

- **分段内的所有指标一律基于剔除资金流后的日度收益序列**，
  不得使用净值绝对值的首末比值：
  - `totalReturn` = 段内日度 TWR 收益连乘 - 1；
  - `maxDrawdown` = 在**剔除资金流的累计收益曲线**上计算，
    **出入金不得产生回撤**；
  - `sharpe` / `sortino` / `calmar` 全部基于同一条收益序列。
- 日度收益的定义要写进 `basis` 并在测试里固化。
  推荐：当日外部净流入发生在收盘前时，
  `r = (期末净值 - 净流入) / 期初净值 - 1`；
  若无法确定流入时点，按既有「缺少出入金前账户估值」语义留空该日，
  **不要用近似值蒙混**。
- 期初净值为 0 或负的段，收益率无定义 → 该段指标留空并给原因，
  **不要**产生上千倍的数字。
- 已有的「净值 100% 可得」不能退化。

## 3. 顺带核查：月度收益只有 18/64 可得

`monthlyReturns` 64 个月里只有 18 个有值，绝大多数因为
「缺少出入金前账户估值」。净值现在已经 100% 可得，
请重新检查这个判定是否仍然必要——如果日度收益可得，月度就应该可得。
若确实不可得，原因要具体到哪一天、缺什么。

## 4. 验收目标（管理者用真实账户复验）

- 不再出现 `totalReturn > 10`（1000%）这类数字；
- 出入金当日**不产生回撤**；
- 最大回撤落在合理区间（这个账户 5 年净亏 22.8 万、净投入 22.8 万，
  真实回撤应当是几十个百分点量级，不可能是 99.97%）；
- Calmar 不再出现 8 位数；
- 月度收益可得数显著提升。

## 5. 测试

- **出入金不产生回撤**：构造「净值 10 万 → 出金 5 万 → 之后不涨不跌」的账户，
  断言最大回撤为 0、收益为 0。这是本任务的核心用例。
- **入金不产生收益**：构造「1 万赚 1 千 → 入金 100 万 → 不赚不亏」，
  断言 TWR 与分段收益都约 10%，而不是几十倍。
- 期初净值为 0 的段：断言指标留空且有原因。
- 既有用例全部继续通过。
