# 已知测试失败登记

`verify:batch` 精确比较实际失败与下方 JSON 的 `(file, assertion)` 集合；新增失败、登记失败消失、文件加载错误都使验证失败。不得用登记文件跳过测试。空数组表示要求零失败。

每条登记必须包含 `file`、`line`、`assertion`、`reason`、`reviewWhen`。只登记经裁定保留的守卫；夹具或过期基线须修复。

```json
[]
```

E0 的 CRLF 字节夹具、替换未发生与状态指纹过期均按根因修正，不作为豁免。
