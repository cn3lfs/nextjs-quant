# 执行者常备说明

本文件约定任务执行与交接方式，适用于独立执行和已获授权的代理协作。执行边界与验证原则以根 [AGENTS.md](../AGENTS.md) 为准；当前范围见 [roadmap](roadmap.md) 和 [next-plan](next-plan.md)，工程命令见 [conventions](conventions.md)。历史计划提供背景与证据，不自动恢复旧命令、代理角色、数据窗口或权限。

## 接手与拆分

- 先读当前任务及相关差异、交付记录，确认已有能力和有效证据；不为建立信心重跑历史全套。
- 派单只给本轮目标、文件归属、输入、验收行为、关键风险和权限边界。能从现有入口查到的信息不重复抄写；协作规则不绑定具体 CLI 或代理名称。
- 按一条用户可用路径拆任务。共享能力先复用，必要重构只做到支撑当前路径；不因方法目录庞大而逐项复制实现、测试或报告。
- 数据或外部能力不确定时，先查最小代表样本的来源、时点及关键字段，明确可做与阻断范围，再扩展计算。
- 原始数据与冻结研究输入保持只读，不为检查通过改写快照、来源身份或隐含规则；来源歧义和数据窗口按当前任务明确记录。

## 实现与验证

- 开工时简述预期行为、必要证据和停止条件；简单改动可直接写在任务说明中，不另建计划或检查脚本。
- 开发期执行受影响的定向检查；共享契约只在归属层验证，功能补特有规则与接线，页面验证集中于关键交互。静态渲染和合成数据不能宣称真实业务链路通过。
- 完整门禁集中到约定的集成交付点，由当次任务明确负责人；先看命令包含哪些步骤，已覆盖的测试与构建不单独再跑。交接、提交或切换执行者不触发全量。
- 复用仍匹配相关代码、输入、依赖和环境的证据与构建；只有发现证据缺失、相关变化或具体新增风险时才补验，说明原因与范围。
- 失败先分类、定位，再复验受影响部分；没有新线索就停止重复尝试并处理独立工作。保留原失败记录，分步补验不改写原命令退出状态。
- 公式用少量独立手算和边界例；不重复实现整套系统作为验证器，不以字节、措辞或无关材料变化推断经济结果错误，也不因此撤销真实的来源身份失败。

## 复核与结束

- 复核者检查差异、关键业务风险及证据适用范围；只有无法回答的具体问题才追加执行，不默认重演执行过程。
- 功能可用、关键风险已覆盖、约定门禁有有效证据即可收口。记录非阻断问题，不为理论上的完美持续扩展验收范围。
- 工程、研究与自然运行观察分别下结论。数据缺口不能补造，亏损或样本不足不等于程序错误；自然时间与外部授权未满足时写明触发条件，不以重复回放代替等待。
- 不为得到全绿降低断言或研究准入；无足够证据时明确未验证或阻断，不能把定向通过写成整套通过。

## 记录与收尾

复用当前任务已有记录，保留一个当前状态入口和一个证据索引。交接只写：交付行为与改动入口、必要检查及结果、复用证据与适用范围、未完成项及下一步触发条件、临时资源与清理状态。命令、角色、数据窗口和产物路径由当前任务给出，不固定在通用提示词里。

涉及真实缺陷、规则取舍或与预期不符的事实时更新 [decisions](decisions.md)；普通检查过程留在任务记录，不扩散到路线图和多份计划。清理前核对目标归属、路径、进程与保留项；批量或不可逆删除可先预演，用户指定手动执行时照办；不把已交接写成已删除。
