# 交易状态核验与新信号检查

2026-09-09，原方案 A/H 的当前状态与信号入口增量。

## 行为

新增精确证券查询：`hithink-market-query` 返回的完整唯一股票代码，必须与证券一致。`交易状态[YYYYMMDD]` 和 `停牌[YYYYMMDD]` 两个字段要求当日一致日期、唯一列、对应源指标名，以及 STR / BOOLEAN 类型。

- `交易` + `false` 才是来源的交易观察。
- `停牌` + `true` 为停牌观察。
- 缺字段、字符串布尔值、冲突、未识别值及旧日期均不能作为交易通过依据。

来源观察独立保存证券、日期、查询时间、字段证据和指纹；单证券请求合并，有效日期结果缓存 60 秒。来源失败保留旧观察，但过期记录不能通过新信号检查。页面主动核验和监控调用使用同一入口，页面展示明确称“上次状态核验”，不把旧观察称为实时状态。

规则新信号唯一生成入口 `runtime.tick` 在原有基线/时间/日历通过后才查状态，不逐只对全市场扫描请求远端。未知、停牌、过期、身份错误或失败时暂停该证券新信号，并保留前一基线供后续有效核验重试。核验返回后重新检查订阅启用、策略/周期/来源/证券，以及行情是否仍新鲜。状态证据随新信号及订阅保存；原始信号档案不补写今天的观察。

订阅页已说明新信号需要问财交易状态核验。没有问财凭证时，该核验失败，新信号暂停并显示错误；不是静默跳过检查。此行为是原方案要求未知证券不进入可触发信号池的一部分。

## 验证

- 真实精确查询 `600519.SH 股票代码 交易状态 停牌状态 最新交易日` 返回 2026-09-09 的交易/false，记录在 `output/security-status-live.json` 和 `tests/fixtures/security-status-live.json`。
- 反例探测 `今日停牌股票 股票代码 交易状态 停牌状态` 宣称 5569 条，只返回当前页 100 条，停牌 true 为 0。没有采用其筛选条件，也没有把它视作完整停牌名单，见 `output/security-status-suspended.json`。
- 8 项状态测试覆盖真实重放、日期/身份/字段语义、布尔类型、冲突、60秒边界、请求合并与缓存、失败保留。
- 监控集成新增 8 项：未知/停牌/过期/错日期/失败均无信号和投递，之后重试仍可生成；核验过程中停用、改策略、行情过期均不投递。测试 `enqueue` 为 mock，不发送消息。
- 全量 145 文件 702 测试、类型检查、runtime/生产构建、桌面准备和冒烟通过。桌面临时库 `quant-desktop-T8bXmx`，源行情不变。
- 独立库 `quant-status-ui-qe53Q7` 页面真实核验：`output/playwright/security-status-before.txt`、`security-status-after.txt`、`security-status-evidence.txt`。HTTP 校验来源指纹、主档关联和60秒内缓存不重写，见 `output/security-status-http-verification.json`。
- 停用订阅及两份固定展示信号验证：`output/playwright/security-status-signals.txt`。新记录展示证据，缺证据旧记录明确显示缺失；记录深度比对不变，报告/投递为 0，见 `output/security-status-display-verification.json`。这些信号是显示样本，不是一次真实规则触发。

## 尚未证明

来源交易状态不保证可成交；不覆盖盘中停牌公告时点、逐笔交易状态、涨跌停排队或历史回测状态。停牌 true 使用受控样本验证，本轮未取得真实当日停牌正样本。当前交易状态也不能用于回填历史证券池或替代批次行情健康审计。A–H 整体目标仍未完成。

本轮未调用研究模型、启用测试订阅、真实推送消息或打包 EXE。
