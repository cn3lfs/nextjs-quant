# 2026-11-19 交易参考单点优化计划

本批唯一计划。基线 `68716a8`。从九篇第三方参考中取工作流，在观澜现有设计内做三轮单点优化，不重建已具备的市场总览、持仓和情报能力。

## 共用边界

沿用现有数据源、读取流程和存储结构。验证使用隔离数据或模拟接口。视觉沿用 `DESIGN.md` 的浅色规范与现有导航。每轮按「产品定义 → 独立 Claude UI 审阅 → 另一 Claude 开发 → 管理者复核 → 本地提交」推进，提交后再以新 HEAD 细化下一轮。

## R1 今日自选卡片排序

已实施。现有排序状态仅作用于当前面板。行情刷新失败时保留保存顺序并提示。

市场与数据总览的自选面板增加「保存顺序」「涨幅优先」「跌幅优先」，默认保存顺序。涨幅从高到低，跌幅从低到高。并列和未知各自保持保存顺序，未知排在最后。卡片沿用同一批报价和原图表链接。

排序测试 3 项、类型检查、变动源码 ESLint 与格式检查通过。交互复用已有可换行的分段控件，本轮以代码和排序测试验收，未实机核对窗口尺寸。

## R2 统一持仓直达图表

状态：待 UI 审阅，R1 验收后细化。

可验收行为：A 股持仓行增加独立「图表」入口，在同一标签内打开 `/scan?symbol=<代码>`。原「持仓」详情链接保持不变。数字货币行不显示该入口，不能用 A 股地址误开。入口只用行内已有代码，不新增估值或查询。用浏览器返回后，原筛选、分组和页码仍是离开前的样子。从外部或新标签直达时仍从默认视图开始。

范围：只改统一持仓列表。详情、筛选、分页、账本、风控和图表默认周期都不变。视图恢复用浏览器历史里的前端列表状态，不写数据库，也不加接口。

门槛：定向测试覆盖 A 股有入口、数字货币无入口、详情链接不变。真实浏览器验证返回后筛选、分组和页码一致，图表打开的代码正确。`tsc --noEmit` 与差异检查通过。

## R3 情报匹配标的

状态：待 UI 审阅。源码已确认一次读取同时取回标题和正文，可支持本轮的命中证据。

可验收行为：持仓与计划情报的每条相关新闻显示「匹配标的」，列出名称或代码在标题、正文中真实命中的已保存持仓和未完成计划标的。一条新闻可对应多个标的。同一标的既在持仓又在计划时分别标明。证据只放在展开区，不按命中数量排序，不改变原文链接。原有「只按名称和代码匹配，不表示已核实利好利空」的说明保留。

范围：复用现有一次新闻读取和现有标的集合，不在预览截断文本上判断，也不新增匹配规则、模型判断、第二次读取或跳转筛选。

停止条件：若实现必须扩大读取范围、增加第二次读取，或无法从完整正文判定命中，本轮停在证据确认并记录缺口，不显示猜测标签。

门槛：测试覆盖一条多标的、持仓与计划同时命中、命中只在预览截断之后仍成立、无法归属到标的时不显示。`tsc --noEmit` 与差异检查通过。
