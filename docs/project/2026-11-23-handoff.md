## 3. 交付内容

### 门禁（`scripts/lib/local-check.mjs`、`scripts/check.mjs`）

- 每个 stage 用异步 `spawn`，`stdio: ["ignore","inherit","inherit"]`，避免 watch/交互式子进程等待调用者终端。
- 单步超时默认 15 分钟，`QUANT_CHECK_STEP_TIMEOUT_MS` 可覆盖；超时先 `taskkill /pid <pid> /t /f`（Windows），再 `child.kill()`，5 秒兜底 `finish`，不会让门禁无限挂起。
- `check-result.json` 记录 `stepTimeoutMs`、每步 `elapsedMs`，超时步带 `timedOut: true`。
- 新增定向测试覆盖 stdin、超时、非零退出、启动失败、非法超时、真实进程树终止（Windows）。

### 诊断器（`scripts/backtest-diagnose.ts`、`scripts/lib/backtest-diagnose/*`）

- 支持 5 个 adapter key、`hold` 对照、以及 94 个可构造的 catalog study key（`studyStrategies` 中 `createExtendedStudyRule` 非 null 且不是 `hold`）。
- 参数：`--execution-profile strict|clamp|no-slippage`、`--max-participation (0,1]`、`--capacity-policy clip|reject`、`--plan`、`--limit`、`--data-dir`。
- 单元产物：`summary.json`、`diagnostics.json`、`fills.csv`、`orders.csv`、`rejections.csv`、`equity.csv`、`positions.json`、`run.json`、`report.md`。
- 诊断项：信号漏斗、因果价、订单/成交守恒、费用、现金/权益恒等、公司行动、价格基、容量、GBBQ 数据质量、独立账本重放。

### 引擎与研究适配

- `packages/quant-backtest/src/execution.ts`：滑点 `reject|clamp|none`；停牌/一字/涨跌停仍拒绝。
- `packages/quant-backtest/src/portfolio/order-execution.ts`：参与率裁剪；`capacityClipped` 标记。**普通买入被裁剪后不重试，卖出与目标权重订单按 pending 逐日重试**。

## 4. 运行方式

### 门禁

```powershell
pnpm check          # 约 7 分钟；格式、依赖、runtime、类型、lint、完整测试
pnpm check --build  # 追加生产构建
```

- 只在干净 shell 跑；门禁自己隔离 `QUANT_DATA_DIR` 与 TEMP。
- 卡住时看 `check-result.json` 的 `elapsedMs` 与 `timedOut`，不要直接杀进程后继续用同一隔离目录。

### 诊断矩阵

```powershell
pnpm exec tsx scripts/backtest-diagnose.ts `
  --tdx-root E:/new_tdx64 `
  --symbols "sh600519,sz000001,sh601318,sz000333,sz300750" `
  --strategies "research-volume-price-protected,research-volume-breakout-15" `
  --controls hold --mode both --start auto --end 2026-11-20 `
  --initial 1000000 --cost base `
  --data-dir .test-data/backtest-diagnose/data `
  --out .test-data/backtest-diagnose/<批次> --execution-profile strict
```

- `--data-dir` 必须在仓库 `.test-data` 下；不要指向生产库。
- 先 `--plan` 看单元，再 `--limit 2` 冒烟，最后全量；不同 profile 顺序执行，避免共享缓存竞争。
- 复现命令见各报告末尾：量价、威科夫、执行敏感性。

### 缠论 spike

```powershell
QUANT_DATA_DIR=.test-data/<隔离目录> pnpm exec tsx .test-data/backtest-diagnose/chan-spike/full.mts
```

- 依赖 `runtime/czsc-worker.cjs` 与 `runtime/czsc/CZSC64.dll`（`pnpm runtime:build` 生成）。
- `sh600519` 全历史 5,908 前缀约 87 秒；脚本结束用 `process.exit(0)`，必要时检查残留 `czsc-worker` 进程。

## 6. 已知问题与风险

1. **三个威科夫策略零入场**：`wy-lps`、`wy-reaccumulation`、`wy-trend-pullback` 在五标的全历史没有入场。逐条件计数显示：LPS/再吸筹的 57 根有效回踩日全部量能不合格；趋势回踩 42 个候选的次日量能全部低于 1.5 倍。判定为当前参数下的稀有结构，不是接线或数据错误；是否调整规则未决。
2. **幸存者偏差**：五标的均为当前存续标的；RPS 回填使用当前池。不能外推到全市场。
3. **历史 ST/IPO 未认证**：无本地历史 ST 证据表；不能用当前名称反推。2026-07-06 的 10% 规则只在提供同日证据时生效。
4. **`sz000001` 早期周末 bar**：39 个 1991–1993 年日期不在 `sh000001` 日历；当前删除并披露，未用第二数据源核对。
5. **GBBQ 归因**：归属其他标的的 issue 不再阻断当前标的；无法归属的仍阻断 strict；record-only 跳过并披露两类计数。归因只解决“坏记录连坐”，不证明事件完整。
6. **容量裁剪语义**：普通买入被裁剪后不重试（按已成交量完成），卖出与目标权重订单会 pending 重试；报告必须看 `capacityClipped`。
7. **缠论捕获成本**：约 87 秒/标的（6,000 根前缀），5 标的约 7–8 分钟；尚未接入诊断回放，`study-rule` 不能替代原生观察。
8. **成长 PIT**：strict 可见时点是公告后首个交易日；重述/更正、亏损字段语义未审计。
9. **门禁超时语义**：超时只保证终止进程树（Windows `taskkill`）；若 `taskkill` 不可用，5 秒兜底记录 `timedOut` 但可能留下孤儿进程，需人工检查。
10. **文档日期**：本轮记录统一用 `2026-11-22`（批次开始日），实际提交跨到 2026-11-23。
