## 已批准的持久化与盘中预警决策

Iteration 5 执行一次向后兼容的 `v25 → v26` SQLite 迁移，使已有 v25 库可原地升级并保留历史事实。五张新增表通过同一版本的事务迁移交付，应用版本、启动检查和冒烟断言同步到 `v0.4.0 / v26`。

| 表 | 保存的事实 |
| --- | --- |
| `account_risk_states` | 账户级回撤基准、风控状态及状态推进证据。 |
| `account_sleeve_holdings` | 共用账户内按分仓归属的持仓数量。 |
| `execution_fill_links` | 执行意图到已核实成交的关联与追溯身份。 |
| `intraday_alert_config` | A 股盘中实时预警的启停及运行配置。 |
| `intraday_watch_rules` | 盘中观察对象及可配置的触发规则。 |

盘中预警同步交付配置与查看界面。用户可管理观察对象、触发条件和启停，查看触发时间、报价来源及结果。按 A 股交易日和交易时段处理有效报价，区分陈旧、缺失与达标状态，核对重启和重复报价下的去重。预警默认遵循现有空跑、订阅与正式提醒授权边界，仅生成观察和提醒事实。

## 验收口径

- **数据库**：在隔离 `QUANT_DATA_DIR` 内验证带历史事实的 v25 升级、干净建库、重复打开、失败事务回滚与拒开更高版本。核对已有账户、运行、意图和调仓单仍能读取，迁移无虚构归属或成交。
- **执行与账户**：从默认调度入口复现执行日取价、窗口切换、缺失与误日拒绝、停牌与涨跌停、先卖后买、并发和重启。用共用账户双策略样本核对单分仓清仓、回撤连续性、ETF T+0/T+1 与费用，独立手算资金、持仓及成交归属。未知外部回执保留待核对，图表只画可核实成交并核对账户、时间和价格口径。
- **研究交接与预警**：从冻结回测选择策略、部署、查看运行、回查调仓单，核对版本与快照身份一致，失配有明确反馈。盘中验证停启、缺失或过期报价、去重、交易时段与订阅授权，并以隔离样本完成界面流程。
- **Wave 3 研究证据**：冻结输入快照、数据截止、池、价格与成本口径。`etf-risk-budget` 用旧实证风险关闭档的 `+34.04%`、Sharpe `0.879`、最大回撤 `3.83%` 作对照，沿真实研究到调仓／执行路径核对逐笔流水及指标并解释差异。以同输入三开关组合拆开账户回撤限制、已有仓位减仓与 ATR 定仓的单独和交互影响。对 Alpha Top-10 基线的 `-71.20%` 拆分费用与滑点、换手与拒单机会成本、选股及尾部损失，报告归因方法和残差。独立审计 `.lc5` 来源、时间、成交量单位及与日线的交叉核验，证据不足的分钟窗保留 `null`。
- **集成**：记录定向单测、全量门禁、受影响浏览器用例及桌面启动／生命周期冒烟结果。实机环境不可用时登记仍待验证的原生与数据源项目。工程通过、历史复算结论和自然运行样本分别记录。

## 明确不做

- 不扩策略数，不以结果好坏修改验收门槛或调参掩盖差异。
- 不自动实盘下单，不未经授权向外部投递通知、操作生产库或发布正式包。
- 不补造缺失历史行情、证券池、公司行动、财务披露版本和分钟成交量。通达信及外部 Blocks 仅读。
