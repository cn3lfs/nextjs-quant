# 同花顺 App · 券商账户持仓展示

2026-11-18 收到的同花顺 App 截图，画面选中「交易 → 持仓」，展示人民币账户的 A 股持仓。笔记记录界面和字段结构，账户尾号与具体资产数值留在原图。 [原图](2026-11-18-ths-brokerage-positions/01-brokerage-positions.jpg)

## 画面所见

| 区域 | 可见内容 |
| --- | --- |
| 账户与导航 | 券商名、掩码账号、下拉及刷新图标。上方同排有买入、卖出、撤单、持仓、查询，账户行右侧展示仓位比例。 |
| 资产总览 | 两行三列。第一行为总资产、总盈亏、当日参考盈亏，后者同时显示金额和百分比。第二行为总市值、可用、可取，其中可用旁有「逆回购」、可取旁有「转账」。总资产旁有眼睛图标。 |
| 持仓明细 | 「持仓股」表中的样例为一只 ETF。四组字段依次为证券名称与市值、盈亏金额与比例、持仓数量与可用数量、成本与现价。表下有「查看已清仓股票」。 |
| 操作与信息 | 单独一行提供持仓管理、批量买入、批量卖出、止盈止损，下方另有持仓资讯与资产分析。截图只展示入口。 |

## 可借鉴

- 先展示当前账户、币种和仓位，再列资产汇总与逐标的明细。多账户场景可沿用这条阅读顺序，让用户先确认当前查看的是哪个账户。
- 将「持仓／可用」「成本／现价」各放在同一列的上下两行，减少扫读时的横向跳转。资产区的资金「可用」「可取」和持仓行的可用数量应带各自单位、保持明确标签。
- 总盈亏和当日参考盈亏分别展示。已清仓记录有独立入口，持仓表下另放管理与交易动作，用户可从读数进入相应操作。

## 待确认

- 总盈亏、当日参考盈亏和仓位比例的分母、估值基准与更新时间。成本是否含费，以及部分卖出、转入或分红后怎样计算。
- 资金可用与可取采用的结算口径，持仓数量与可用数量的变化原因及提示方式。
- 眼睛图标的遮挡范围、明细上方图标的用途，以及跨账户切换、空仓和已清仓页的展示。
