# 同花顺 · 概念与行业板块估值百分位

2026-11-18 收到的同花顺「板块掘金」截图。路径为「数据掘金 → 估值水平」。页面同时提供「概念板块」和「行业板块」入口，本图选中「行业板块」，因此下列样例来自行业榜。 [原图](2026-11-18-ths-sector-valuation-percentiles/01-sector-valuation-percentiles.jpg)

## 画面所见

- 「数据掘金」还可见「机构调研数」「净利润增长」两个相邻入口。估值榜展示板块名称与代码、`PE/百分位`、`PB/百分位`、`PE最低股`。
- PE、PB 各用两行显示，上方是倍数，下方是百分位。PE 列显示向上的红色排序箭头，可见行的 PE 百分位从 `0.07%` 递增至 `0.79%`，PE 倍数没有按同一顺序递增，画面顺序与按 PE 百分位升序一致。

## 可借鉴

- 同列放置估值倍数与对应百分位，排序时明确当前按「倍数」还是「百分位」。图里通信设备的 PE 百分位为 `0.07%`，同一板块的 PB 百分位为 `75.28%`，并列展示能让用户看到两种口径给出的不同位置。
- 概念和行业分别浏览，保留板块代码及成分股线索，便于从板块估值继续查看个股。估值百分位的参考样本和比较窗口需要独立标识，可与现有板块 RPS 榜单区分阅读。 [观澜选股与 RPS 模块](../../modules/screening-rps.md)

## 待确认

- 百分位是相对板块自身历史还是其他样本计算，窗口多长、使用何种频率、怎样处理并列与有效样本不足。
- 板块 PE 和 PB 的计算与聚合方法，亏损公司、负净资产、缺财报和成分变更如何处理，估值数据截至何日。
- 「PE 最低股」的有效值范围，是否排除负 PE，是否可以点击下钻。概念榜的实际字段和排序等待选中后的画面补证。
