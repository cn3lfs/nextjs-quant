# 量价关系分析

判断"当前这根 K 线/这段走势的成交量是否支持价格方向"，输出趋势延续或反转的倾向、需要等待的确认信号，以及判断被证伪的条件。

**核心原则**：

1. **量在价先**——成交量是价格的先行与确认变量，但只提高概率，不给必然结论。
2. **位置决定含义**——同一种量价形态在底部、中途、高位的意义可以完全相反；脱离位置谈量价没有意义。
3. **量比价可靠，但量也能造假**——对倒放量、单笔大宗、ETF 申赎均可污染成交量，需交叉验证（见 `references/vp-astock-caveats.md`）。
4. **只给条件计划**，不预测必涨必跌；结论写成"如果……就……"。

**与相邻技能的关系**：

| 需求 | 用哪个 |
|---|---|
| 只判读量价形态、量能状态（本技能） | volume-price-analysis |
| 主力吸筹/派发阶段、Spring/UT/SOS 事件、多周期结构 | `../wyckoff-trader/SKILL.md` |
| 要出具体买卖点、止损、仓位 | `../swing-trader/SKILL.md` |
| 次日开盘持仓应对 | `../opening-price-playbook/SKILL.md` |

本技能是上述技能的量价判据底座；被它们调用时，只需返回"形态 + 位置 + 倾向 + 确认/证伪信号"，不要重复输出交易计划。

## 前置条件

- A股数据优先用 `hithink-market-query`（需要 `IWENCAI_API_KEY`）；未配置时降级 `akshare-one-mcp` 的 `get_hist_data` / `get_realtime_data`。
- 美股/加密可用 `tradingview` MCP 或 `akshare-one-mcp`。
- 无数据源时，要求用户提供最近 20~60 根 K 线的开高低收与成交量；数据不足时用模糊分支表述，**不要伪造精确量值**。

## 工作流

### Phase 1: 取数与基准量

需要的最小数据集：

- 最近 60 根 K 线的 开/高/低/收/成交量（成交额更好，能抵御除权与价格量级差异）。
- 当日：现价、涨跌幅、成交量、量比、换手率、流通市值。
- 均线（20/60/120/250）与量均线（5 日、10 日量均）。

计算基准（判定放缩量的锚）：

- `VMA5`、`VMA10`：近 5/10 日均量。
- `量能比 R = 今日量 / VMA5`。
- 若为盘中，用**量比**（今日每分钟均量 / 过去 5 日每分钟均量）代替 R，或按已过时间线性折算全天量（开盘半小时内折算误差极大，只作方向参考）。

阈值口径（默认，可按品种波动率放宽，见 `references/vp-indicators.md`）：

| R = 今日量 / VMA5 | 判定 |
|---|---|
| ≥ 2.0 | 巨量 |
| 1.5 ~ 2.0 | 明显放量 |
| 0.8 ~ 1.5 | 量平（正常量） |
| 0.5 ~ 0.8 | 缩量 |
| < 0.5 | 极度缩量（地量） |

价格方向口径（A股主板日线，创业板/科创板/北证及加密可放宽 1.5~2 倍）：

| 涨跌幅 | 判定 |
|---|---|
| > +2% | 价涨 |
| -1% ~ +1%（且实体窄） | 价平 |
| < -2% | 价跌 |

`±1%~2%` 为灰色地带，按方向轻微偏强/偏弱处理，不强行归类。

### Phase 2: 定位股价位置

位置是解读的前提，先判定再解读：

| 位置 | 特征 |
|---|---|
| 底部区域 | 长期下跌后横盘，均线走平粘合，量能长期萎缩 |
| 上涨中途 | 20/60 日均线多头排列，高点低点抬高，回调不破关键均线 |
| 高位区域 | 距起涨点涨幅显著（如 ≥50% 或阶段涨幅居前），偏离均线较远，已有滞涨迹象 |
| 下跌中途 | 均线空头排列，高点低点持续下移，反弹不过前高 |
| 区间震荡 | 上下沿清晰，无明确方向 |

位置不清楚时，按**更保守**的一类处理（持仓从严、开仓从紧）。

### Phase 3: 九宫格定形态

用 Phase 1 的两个判定交叉查表，得到基本形态，再读 `references/vp-patterns.md` 取该形态在当前位置下的完整解读。

| | 量增 | 量平 | 量缩 |
|---|---|---|---|
| **价涨** | 价涨量增（量价齐升）：配合，趋势确认 | 价涨量平：动能一般，观察 | 价涨量缩：**背离**，动能不足 |
| **价平** | 价平量增：变盘前兆（吸筹或派发） | 价平量平：无信息，等待 | 价平量缩：观望期，等突破 |
| **价跌** | 价跌量增：**背离/加速**，看位置定多空 | 价跌量平：参与度低，跌势易延续 | 价跌量缩：抛压衰竭，配合式回调 |

⚠️ 九宫格只是入口，两处最易误读，必须按下述口径理解：

- **价跌量缩 ≠ 会涨**。"配合"指的是回调健康、抛压在衰竭，是底部的必要条件而非充分条件；"跌不动"不等于有买盘，须等放量阳线确认。
- **价涨量缩** 在高度控盘股（换手持续 <2%、连续小阳不破 5 日线）属良性，不可一律看空。

两条极端形态单列（不在九宫格内，需优先识别）：

- **天量天价**：高位出现历史级/阶段级巨量（R ≥ 2.5 或创 60 日新高量）且价格冲高。顶部信号权重高于九宫格结论。
- **地量地价**：低位出现阶段最小量（R < 0.5 且创 60 日新低量）。底部信号，但"地量之后还有地量"，必须等放量确认。

**趋势配合度归纳**（用于一句话结论）：

- 量价同向（配合）：价涨量增、价跌量缩 → 原趋势延续概率高。
- 量价背离（警戒）：价涨量缩、价跌量增（高位）、价平量增 → 趋势可靠性下降，等待变盘。

### Phase 4: 背离与陷阱校验

在给结论前，逐条过一遍：

1. **背离位置校验**：价跌量增在**高位**是派发/恐慌加速，在**长期下跌末端 + 长下影**则可能是恐慌见底（放量换手）。方向相反，必须先定位置。
2. **量的真实性**：一字涨跌停的缩量无意义；对倒放量、大宗交易过户、ETF/指数调仓、限售解禁首日均可虚增量能。见 `references/vp-astock-caveats.md`。
3. **连续性优先于单日**：单日量价只是样本，用"最近 3~5 日的量能斜率"（递增/递减/间隔堆量）覆盖单日噪音。
4. **洗盘 vs 出货**：高位放量必须做这一判别，判据表见 `references/vp-patterns.md#洗盘与出货判别`。
5. **换手率交叉验证**：只看成交量易被流通盘变化误导，同步看换手率（换手 = 成交量 / 流通股本）。

### Phase 5: 输出

按以下结构输出，缺数据的字段写"数据不足"，不要编造：

```
【量价快照】
标的 / 周期 / 收盘价 / 涨跌幅
今日量 X 万手，VMA5 Y 万手，R = Z（判定：放量/量平/缩量）
量比 A，换手率 B%

【位置】
底部 / 上涨中途 / 高位 / 下跌中途 / 区间震荡（依据：均线形态 + 阶段涨幅 + 关键位）

【形态判定】
主形态：价__量__（配合 / 背离）
附加形态：天量天价 / 地量地价 / 堆量 / 间隔放量 / 无

【含义】
2~4 句，说明多空双方谁占优、动能是增强还是衰竭。

【条件计划】
- 如果 ______，则 ______（延续方向的操作倾向）
- 如果 ______，则 ______（反转方向的操作倾向）

【确认信号】需要再看到什么才能加大置信
【证伪条件】出现什么就说明本判断已错
【风险提示】量能失真可能性、数据缺口、事件干扰
```

结论一律给概率倾向（偏多 / 偏空 / 中性观望）与置信度（高 / 中 / 低），不给"必涨必跌"。
