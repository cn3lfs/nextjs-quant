# 量价形态详解

每个形态按 **定义 → 常见含义 → 按位置分解 → 确认信号 → 证伪条件** 组织。位置定义见 SKILL.md Phase 2。

---

## 1. 价涨量增（量价齐升）

**定义**：价格上涨（>+2%），成交量较 VMA5 明显放大（R ≥ 1.5）。

**常见含义**：买方力量强劲，新资金进场，上涨获得成交量确认——量价配合的标准形态。

| 位置 | 解读 |
|---|---|
| 底部区域 | 底部放量突破，最佳形态之一；若同时突破颈线/平台上沿且量能 R ≥ 2，反转确立概率高 |
| 上涨中途 | 趋势健康延续，回调后放量新高尤佳 |
| 高位区域 | **需警惕**：可能是最后加速（主升末段），也可能是天量天价。涨幅巨大后的放量上涨，先按派发嫌疑处理 |
| 下跌中途 | 反弹性质，量增但不过前高则仍是下跌中继 |

**确认信号**：次日不放巨量回落，回踩突破位不破且缩量；量能维持在 VMA5 上方。
**证伪条件**：放量上涨后 1~3 日内跌回突破位下方（假突破），或次日放更大量收长上影/阴线。

---

## 2. 价平量增

**定义**：价格横盘（±1% 内、实体窄），成交量明显放大。

**常见含义**：多空分歧显著加大，筹码在换手——**变盘前兆**，方向取决于位置。

| 位置 | 解读 |
|---|---|
| 底部区域 | 主力吸筹嫌疑，横盘承接抛压，后市转强概率偏高 |
| 上涨中途 | 平台换手洗盘，若量能温和且不破关键均线，视为整理 |
| 高位区域 | **派发嫌疑最大**：高位滞涨放量，主力出货的典型早期信号 |
| 下跌中途 | 抵抗性承接，需看能否止跌；单次不足以判底 |

**确认信号**：横盘后放量向上突破区间上沿（吸筹被证实）或放量跌破下沿（派发被证实）。
**证伪条件**：横盘量增持续 2 周以上却始终不选方向 → 降为"无信息"，回到区间震荡处理。

---

## 3. 价涨量缩（量价背离）

**定义**：价格上涨但成交量萎缩（R < 0.8）。

**常见含义**：跟风盘不足，上涨缺乏新资金推动，动能衰竭——**背离形态**。

| 位置 | 解读 |
|---|---|
| 底部区域 | 无量反弹，多为超跌修复，可持续性弱 |
| 上涨中途 | 分两种：①主力高度控盘的缩量上涨（换手极低、K 线连续小阳）可以持续，属良性；②普通个股的缩量上涨多为反弹尾声。用换手率区分：换手持续 <2% 且形态稳健 → 控盘型；否则按动能不足处理 |
| 高位区域 | 危险，滞涨前兆，随时回调 |
| 下跌中途 | 无量反抽，压力位前大概率再度走弱 |

**确认信号（向好）**：缩量上涨中出现一次温和放量突破前高。
**证伪条件（转差）**：出现放量阴线或跌破 20 日均线 → 背离兑现为回调。

---

## 4. 价跌量增

**定义**：价格下跌，成交量放大。

**常见含义**：卖方力量强，但**位置决定这是加速下跌还是恐慌见底**。

| 位置 | 解读 |
|---|---|
| 高位区域 | 派发/出逃，跌势确立，最危险的组合之一 |
| 上涨中途 | 放量回调，若不破关键均线与前低视为洗盘；破位则趋势受损 |
| 下跌中途 | 加速下跌（杀跌段），不接飞刀 |
| 底部区域 / 长期下跌末端 | **可能是恐慌性抛售的最后一跌**：若伴随长下影、收盘拉回、次日缩量止跌，则为放量换手见底信号 |

**确认信号（见底）**：巨量长下影后 2~3 日显著缩量且不创新低，随后放量收复。
**证伪条件**：放量下跌后继续放量创新低 → 不是底，是加速。

---

## 5. 价跌量缩

**定义**：价格下跌，成交量萎缩。

**常见含义**：抛压衰竭，卖方力量减弱——属于**量价配合**的健康回调形态。

| 位置 | 解读 |
|---|---|
| 上涨中途 | 最健康的回调：缩量调整，趋势未坏，回踩均线企稳即可再上 |
| 高位区域 | 初期缩量下跌可能是获利盘轻微兑现，但若后续放量下跌则确认转势 |
| 下跌中途 | 阴跌，动能减弱但无买盘，"跌不动"不等于会涨，需等地量与放量确认 |
| 底部区域 | 接近地量地价，是底部形成的必要条件而非充分条件 |

**确认信号**：缩量下跌后出现放量阳线（需求回归）。
**证伪条件**：缩量下跌途中突然放量破位（补跌）。

---

## 6. 价涨量平

**定义**：价格上涨，成交量与前期基本持平。

**常见含义**：相对少见，属于上涨动能一般。既无新资金大举进场，也无明显撤退。

- 上涨中途：温和推升，可延续但斜率有限。
- 高位区域：滞涨前兆，警惕转为价平量增（派发）。

**处理**：不构成独立信号，需结合下一根 K 线确认（放量走强 → 归入形态 1；缩量 → 归入形态 3）。

---

## 7. 价跌量平

**定义**：价格下跌，成交量持平。

**常见含义**：市场参与度低，无承接意愿，下跌趋势易延续。

- 下跌中途：阴跌延续，观望。
- 底部区域：尚未出现衰竭，底部条件不成熟。

**处理**：同形态 6，作过渡形态，等待量能选择方向。

## 8. 天量天价 / 地量地价

### 8.1 天量天价

**定义**：高价位出现极端成交量（R ≥ 2.5，或创 60 日/历史新高量），当日或随后数日见到阶段最高价。

**含义**：主力借巨量在高位完成筹码转移；顶部信号，优先级高于九宫格结论。

**判别要点**：
- 巨量当天的 K 线形态：长上影、光头阴线、冲高回落 → 派发权重更高。
- 巨量之后量能是否维持：若次日大幅缩量且价格无法再创新高 → 顶部确认度上升。
- "天量之后未必立刻见顶"——高位巨量后可能还有一次缩量新高（背离式二顶），这恰恰是更强的卖出信号。

**证伪条件**：巨量后持续放量上攻并接连创新高（主升加速），则改判为形态 1。

### 8.2 地量地价

**定义**：低价位出现极端萎缩成交量（R < 0.5，或创 60 日新低量）。

**含义**：抛压枯竭，浮筹出清；底部区域信号。

**判别要点**：
- **地量之后还有地量**——地量只说明"不再有人卖"，不说明"有人要买"。
- 底部成立需要"地量 → 温和放量 → 放量突破"的三段过程，缺一段就只是磨底。
- 同步看换手率是否降到历史低位区间（如 <1%），比绝对成交量更可靠。

**证伪条件**：地量后放量下跌破前低（缩量之后是补跌，非见底）。

## 量能形态（多日维度）

单日形态之外，用连续量能形状提高置信：

| 形态 | 特征 | 常见含义 |
|---|---|---|
| 堆量（量堆） | 连续多日量能温和递增，形成小山堆 | 资金持续进场，健康建仓/推升 |
| 间隔放量 | 每隔数日放一根量，其余缩量 | 主力控盘节奏，多见于拉升前后 |
| 单日孤量（独量） | 一日巨量、前后皆缩 | 事件驱动或对倒，可靠性低，需查消息 |
| 递减量（缩量整理） | 量能阶梯下行，价格窄幅 | 变盘临近，方向由突破方向决定 |
| 放量滞涨 | 量创新高但价格涨幅收敛 | 上方抛压沉重，派发嫌疑 |
| 缩量新高 | 价格创新高但量能低于前高点时 | 量价顶背离，动能不足 |

## 洗盘与出货判别

高位或上涨中途放量下跌时，必做的判别（满足越多越偏向该列）：

| 维度 | 偏洗盘 | 偏出货 |
|---|---|---|
| 跌幅与量能 | 放量但幅度可控，量能未创天量 | 巨量长阴，量创阶段新高 |
| 关键位 | 不破 20/60 日均线与前低 | 直接跌破关键均线与平台 |
| 回抽 | 下跌后迅速缩量企稳、快速收复 | 反抽无量且不过前高 |
| 时间 | 短促（1~3 日） | 反复多日，逐级下台阶 |
| 分时 | 早盘急跌尾盘拉回 | 高开低走、尾盘跳水 |
| 筹码/换手 | 换手温和，筹码峰未上移 | 高位换手剧烈，筹码峰在高位密集 |
| 消息面 | 无重大利空 | 伴随利空或业绩不及预期 |

判别不明确时按**出货**处理（保守优先），并明确写出证伪条件。
