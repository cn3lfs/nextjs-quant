# 量能指标口径与阈值

---

## 1. 成交量 vs 成交额

- **成交量（手/股）**：受除权、送转、股本变动影响，跨期比较需复权处理。
- **成交额（元）**：跨期与跨品种比较更稳健，判断"资金规模"时优先用成交额。
- 判定放缩量用成交量或成交额均可，但**同一分析中必须口径统一**。

## 2. 量能均线与量能比 R

```
VMA_n = 最近 n 根 K 线成交量的算术平均
R = 今日成交量 / VMA5
```

推荐同时看 `VMA5`（短期基准）与 `VMA10/VMA20`（中期基准）。`VMA5` 上穿 `VMA10` 视为量能转强。

| R | 判定 | 备注 |
|---|---|---|
| ≥ 2.5 | 巨量 / 天量候选 | 需同时核对是否创 60 日新高量 |
| 1.5 ~ 2.5 | 明显放量 | 标准"放量"口径 |
| 1.2 ~ 1.5 | 温和放量 | 健康推升常见区间 |
| 0.8 ~ 1.2 | 量平 | |
| 0.5 ~ 0.8 | 缩量 | |
| < 0.5 | 极度缩量 / 地量候选 | 需同时核对是否创 60 日新低量 |

**阈值调整**：

| 品种 | 调整 |
|---|---|
| 沪深主板大盘蓝筹 | 用默认值 |
| 创业板 / 科创板 / 北证 | 波动更大，放量阈值上调约 20%（如 1.8 起算明显放量） |
| 小市值、低流通盘 | 单笔即可扰动，需以换手率为主判据 |
| 指数与 ETF | 放量阈值可下调（1.3 即为明显放量） |
| 加密（7×24） | 用同期同时段均量对比，不能直接与日均量比 |

## 3. 量比

```
量比 = 当日每分钟平均成交量 / 过去 5 个交易日每分钟平均成交量
```

- 仅用于**盘中**判断当日活跃度，收盘后价值等同于 R。
- 参考区间：<0.8 缩量清淡；0.8~1.5 正常；1.5~2.5 放量活跃；2.5~5 明显异动；>5 剧烈异动（多有消息或资金介入）。
- **开盘前 30 分钟量比天然偏高**，此时的极端值不可直接外推全天。

## 4. 换手率

```
换手率 = 成交量 / 流通股本 × 100%
```

比成交量更适合**跨股票横向比较**与**跨时间纵向比较**（不受股本量级影响）。

| 日换手率 | 状态 | 解读 |
|---|---|---|
| < 1% | 极度冷清 | 地量特征，无人交易 |
| 1% ~ 3% | 正常 | |
| 3% ~ 7% | 活跃 | 有资金关注 |
| 7% ~ 15% | 高度活跃 | 主力参与明显，需分辨进出方向 |
| > 15% | 剧烈换手 | 底部为吸筹、高位多为派发；必须结合位置判断 |

小盘股换手天然高于大盘股，上述区间对大盘蓝筹应整体下调。

## 5. OBV（能量潮 / On-Balance Volume）

```
收盘价 > 前收：OBV += 今日量
收盘价 < 前收：OBV -= 今日量
持平：OBV 不变
```

用途：把量能累积成一条曲线，看**资金净流向趋势**是否与价格趋势一致。

| 情形 | 含义 |
|---|---|
| 价创新高 + OBV 同步创新高 | 趋势健康 |
| 价创新高 + OBV 未创新高 | **顶背离**，上涨缺乏量能支撑 |
| 价创新低 + OBV 未创新低 | **底背离**，抛压在减弱 |
| 价横盘 + OBV 持续上行 | 悄然吸筹 |
| 价横盘 + OBV 持续下行 | 悄然派发 |

OBV 只看方向与背离，绝对值无意义。

## 6. 其他可选量能工具

| 工具 | 用途 | 注意 |
|---|---|---|
| VOL-MA 交叉 | 量能转强/转弱的机械判据 | 滞后 |
| Volume Profile（成交量分布） | 找密集成交区（支撑压力） | 见 `../../wyckoff-trader/references/wyckoff-volume-profile.md` |
| 筹码分布 / 成本分布 | 看套牢盘与获利盘位置 | A股行情软件常见，判洗盘出货有用 |
| 主力资金净流入（大单/超大单） | 拆解量能的资金结构 | 各家算法不同，只作辅助 |
| 均量线（如 5/10/20 日量均） | 判断量能中枢抬升还是下移 | |

## 7. 计算注意

- **复权**：跨越除权日的历史量价必须用后复权数据，否则量能与价格同时失真。
- **停牌**：停牌日不计入均量窗口。
- **数据窗口**：VMA5 至少需要 6 根 K 线，60 日新高/新低量判定至少需要 60 根；数据不足时降级为"数据不足，仅作方向参考"。
- **周期一致性**：日线量价结论不能直接套到 60 分钟或周线；多周期出现冲突时以大周期为主、小周期定时点。
