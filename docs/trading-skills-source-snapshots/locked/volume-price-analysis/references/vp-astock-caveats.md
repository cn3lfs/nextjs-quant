# A股量能失真场景与应对

量价分析的前提是"成交量真实反映供求"。以下场景会破坏这一前提，判读前必须先排除。

---

## 1. 涨跌停与一字板

| 场景 | 失真表现 | 应对 |
|---|---|---|
| 一字涨停（开盘即封死） | 成交量极小 | **缩量无意义**，不能判为"缩量上涨背离"；应看封单量与开板次数 |
| 一字跌停 | 成交量极小 | 同上，不是"缩量下跌抛压衰竭"，是无人接盘 |
| 涨停打开又封回（换手板） | 放量 | 换手充分，后续持续性强于一字板；量能有效 |
| 天地板 / 地天板 | 巨量 | 量能有效但情绪极端，单日结论置信度低 |

**判据补充**：连板股看"**首板放量、中继换手、加速缩量**"的节奏，比九宫格更有效。炸板后放量长上影，按派发处理。

## 2. T+1 制度

- A股当日买入不可当日卖出，**当日成交量中不含日内回转**（融券与部分 ETF 除外），因此 A股换手率的含义比 T+0 市场更"实"。
- 反过来说，A股的日内量能无法像 T+0 市场那样被日内高频反复放大；跨市场套用美股/加密的换手阈值会高估 A股活跃度。
- 次日开盘的抛压来自前一日买入的被套盘，这是"放量后次日走势"判读的制度基础。

## 3. 除权除息与股本变动

- 送转股、拆股后成交量（手数）会跳变，直接与历史比较必然误判。
- **必须使用后复权价 + 相应调整的量**，或改用**成交额**与**换手率**。
- 大比例定增、限售解禁会改变流通股本，换手率的历史可比性同样断裂。

## 4. 大宗交易与协议转让

- 部分统计口径会把大宗交易计入当日成交额，形成"虚假放量"。
- 特征：盘中分时无明显放量，但收盘统计量骤增。
- **应对**：出现异常单日巨量时，查当日大宗交易与龙虎榜；若量能来自大宗过户，剔除后再判读。

## 5. 指数与 ETF 相关扰动

- 指数成分股调整生效日、ETF 大额申赎、指数基金再平衡，会在收盘集合竞价制造非趋势性巨量。
- 特征：巨量集中在尾盘 3 分钟（14:57~15:00 集合竞价）。
- **应对**：这类量能不代表主动买卖意愿，不作趋势确认依据。

## 6. 新股与次新股

- 上市初期无历史量能基准，VMA5/60 日新高量判定无效。
- 换手率天然极高（首日常 >50%），不能套用常规换手阈值。
- **应对**：上市 60 个交易日内，只做"相对自身上市以来"的量能比较，并明确标注置信度低。

## 7. 停牌与复牌

- 长期停牌后复牌，首日量能与价格均为集中释放，不具备连续性。
- 停牌日不能计入均量窗口（否则 VMA 被摊薄）。
- **应对**：复牌首周的量价形态单独看，等量能回归常态再套用九宫格。

## 8. 对倒与虚假放量

- 主力自买自卖制造成交量，诱导跟风。
- 特征：放量但价格滞涨、买卖盘挂单形态规整、分时成交笔数与成交量不匹配（单笔均量异常大）、无消息面支撑的孤量。
- **应对**：孤量（前后皆缩量的单日巨量）默认降低置信；必须有次日的量能延续才认可。

## 9. 事件性扰动

| 事件 | 影响 |
|---|---|
| 龙虎榜/游资炒作 | 短期量能爆发，与基本面无关，持续性差 |
| 限售解禁首日 | 抛压与量能同时放大，属供给冲击 |
| 重大重组/并购公告 | 量价同时跳变，历史形态参考价值下降 |
| 指数纳入/剔除 | 被动资金一次性买卖 |
| 季末年末 | 机构调仓，量能季节性异常 |

## 10. 排查顺序（照此执行）

1. 今日是否涨跌停/一字板？→ 是则量能判定改用封单与开板节奏。
2. 是否处于除权、股本变动窗口？→ 是则改用复权数据/成交额/换手率。
3. 单日巨量是否来自大宗、尾盘集合竞价、指数调整？→ 是则剔除后再判。
4. 是否新股次新、复牌初期？→ 是则标注置信度低，不套常规阈值。
5. 是否为孤量、量价明显不匹配（对倒嫌疑）？→ 是则等次日确认。
6. 以上均否 → 按 SKILL.md 九宫格正常判读。
