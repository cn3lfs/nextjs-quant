# 仓位管理与纪律

> **止损定位、仓位换算、凯利上限、账户熔断已统一到 `stop-loss` 技能**（风险控制公共层）。
> 本文件只保留 swing-trader 特有的参数取值、加减仓节奏、准入门槛与纪律清单。

## 1. 单笔风险控制（本技能参数）

委托 `Skill(stop-loss, ...)` 计算时，传入以下本技能口径：

| 参数 | 本技能取值 |
|------|-----------|
| 单笔风险比例 | **2%** |
| 单只标的仓位上限 | **30%** |
| 单笔止损幅度上限 | **5%**（超过则不交易，改等更好的入场位）|
| 默认账户基准 | 100 万元（用户未指定时；按自有资金等比换算，比例不变）|

止损方法的选择（固定/结构/ATR/时间/移动/趋势线）、公式推导、计算示例、
R 倍数体系与组合层风险，见 `../../stop-loss/references/position-sizing.md`
与 `../../stop-loss/references/methods.md`，**本技能不另行推导**。

止损越窄风险仓位越大，最终由 30% 上限封顶；止损越宽仓位自动收缩——
这个方向性关系由 stop-loss 的公式自然给出。

## 2. 总仓位控制

### 2.1 仓位上限

| 规则 | 限制 | 说明 |
|------|------|------|
| 单只个股 | ≤ 30% | 集中风险控制 |
| 同时持仓 | ≤ 3 只 | 分散但不过度 |
| 总仓位 | ≤ 60% | 留 40% 现金 |
| 弱市总仓位 | ≤ 30% | 市场不明朗时 |

### 2.2 市场环境与仓位

| 环境 | 评估 | 最大总仓位 |
|------|------|-----------|
| 强势（大盘 MA20 向上，>MA20） | 适合做多 | 60% |
| 中性（大盘在 MA20 附近震荡） | 观望为主 | 30% |
| 弱势（大盘 MA20 向下，<MA20） | 空仓或做空 | 0-30% |

## 3. 加仓与减仓

### 3.1 加仓规则（金字塔加仓）

| 次序 | 比例 | 条件 | 止损调整 |
|------|------|------|---------|
| 首仓 | 50% | 双突破信号确认 | 设定初始止损 |
| 第二次 | 30% | 浮盈 ≥ 1R（1 倍止损空间） | 整体止损上移至保本 |
| 第三次 | 20% | 浮盈 ≥ 2R | 止损上移至首仓成本 |

### 3.2 加仓铁律

- **只在盈利头寸上加仓**，永远不在亏损头寸上加仓
- 每次加仓量递减（金字塔形）
- 加仓后整体止损必须上移
- 加仓后总仓位不超过 60%

### 3.3 减仓规则

| 触发条件 | 操作 |
|---------|------|
| 达到第一目标（1:1 风险回报比） | 减仓 1/3 |
| 达到第二目标（1:2 风险回报比） | 再减 1/3 |
| 趋势线反向突破 | 全部出场 |
| 重大利空/利好兑现 | 全部出场 |
| 时间止损（5 天无进展） | 全部出场 |

## 4. 止盈与止损

### 4.1 止盈策略（分批出场）

```
入场价: 50 元
止损价: 48.5 元（止损 3%）
第一目标: 51.5 元（+3%，1:1 风险回报比）→ 减 1/3
第二目标: 53 元（+6%，1:2 风险回报比）→ 再减 1/3
剩余 1/3: 移动止损至 51.5 元跟踪
```

### 4.2 止损（委托）

止损类型选择与铁律见 `stop-loss` 技能：方法族见其 `references/methods.md`，
移动与分批管理见 `references/management.md`，常见错误见 `references/pitfalls.md`。

本技能只负责把**入场价与结构位**（趋势线、前低/前高、突破颈线）交给它作为定位依据。

## 5. 胜率/风险回报比准入标准

### 5.1 最低准入门槛

| 条件 | 标准 | 说明 |
|------|------|------|
| 风险回报比 | ≥ 1:2 | 止损空间的 2 倍以上盈利空间（口径固定为 `1 : X`，X = 收益/风险） |
| 胜率预估 | ≥ 45% | 基于历史类似形态统计 |
| 期望值 | > 0 | P×W - (1-P)×L > 0 |
| 信号质量 | ≥ 3/5 | 趋势线+压力位+放量+指标+形态 |

### 5.2 期望值计算

```
E = P × W - (1-P) × L

P = 预估胜率
W = 平均盈利（R 的倍数）
L = 平均亏损（= 1R）

示例：
P = 50%, W = 2R, L = 1R
E = 0.5 × 2 - 0.5 × 1 = 0.5R（正期望，可出手）

示例：
P = 40%, W = 3R, L = 1R
E = 0.4 × 3 - 0.6 × 1 = 0.6R（正期望，可出手）

示例：
P = 60%, W = 1R, L = 1R
E = 0.6 × 1 - 0.4 × 1 = 0.2R（边际，减仓操作）
```

### 5.3 准入决策表

| 期望值 | 操作 |
|--------|------|
| E > 0.5R | 标准仓位入场 |
| E 在 0.2-0.5R | 半仓入场 |
| E 在 0-0.2R | 观望或极小仓位 |
| E ≤ 0 | 不交易 |

### 5.4 凯利公式仓位（委托）

公式、分数凯利规则、胜率取值表与计算流程见
`../../stop-loss/references/kelly-sizing.md`（公共实现）。

本技能传入的参数：单笔风险比例 **2%**、总仓位上限 **30%**、
b = 第 4 节的「第二目标空间 / 止损空间」。

输出"建议仓位"时须同时列出风险仓位、半凯利仓位、最终取值，并注明是哪一项在约束。

## 6. 纪律执行

### 6.1 交易前检查清单

- [ ] 市场环境是否适合交易？
- [ ] 是否有明确的双突破信号？
- [ ] 风险回报比是否 ≥ 1:2？
- [ ] 止损位是否已设定？
- [ ] 仓位是否符合 2% 风险规则？
- [ ] 是否在重大事件窗口？
- [ ] 情绪状态是否正常？

### 6.2 交易后复盘

- 记录入场价、止损价、目标价
- 记录入场理由（技术信号）
- 记录情绪状态
- 统计风险回报比是否符合预期
- 分析做得好和做得差的地方

### 6.3 月度统计

| 指标 | 目标 | 停止交易线 |
|------|------|-----------|
| 胜率 | ≥ 45% | < 35% 连续 2 个月 |
| 风险回报比 | ≥ 1:2 | < 1:1.5 连续 2 个月 |
| 最大回撤 | < 10% | > 15% 立即停止 |
| 连续亏损 | ≤ 3 笔 | 3 笔后强制休息 |
| 月度收益 | 正 | 连续 3 个月负收益停止 |

### 6.4 紧急停止条件

出现以下情况，**立即停止交易，休息至少 1 周**：
1. 单日亏损超过总资金 5%
2. 连续 5 笔亏损
3. 情绪失控（愤怒/恐惧/贪婪明显影响决策）
4. 违反任何一条纪律（移动止损、不设止损等）
5. 总回撤超过 15%
