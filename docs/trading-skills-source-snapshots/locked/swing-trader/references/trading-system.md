# 交易体系核心规则

## 1. 双突破策略

### 1.1 做多条件（三要素同时满足）

1. **趋势线突破**：价格向上突破下降趋势线（阳线实体收盘价突破，非影线）
2. **压力位突破**：价格突破近期压力位（前期高点/平台/密集成交区上沿）
3. **成交量确认**：突破日成交量 ≥ 20 日均量的 1.5 倍

### 1.2 做空条件（三要素同时满足）

1. **趋势线跌破**：价格向下跌破上升趋势线（阴线实体收盘价跌破，非影线）
2. **支撑位跌破**：价格跌破近期支撑位（前期低点/平台/密集成交区下沿）
3. **成交量确认**：跌破日成交量 ≥ 20 日均量的 1.5 倍

### 1.3 信号强度分级

| 等级 | 条件 | 操作 |
|------|------|------|
| 强信号 | 三要素全部满足 + ≥3 个指标确认 | 标准仓位入场 |
| 中信号 | 三要素满足 + 2 个指标确认 | 半仓入场 |
| 弱信号 | 仅趋势线+压力位突破，量能不足 | 观望，等待回踩确认 |
| 无信号 | 条件不满足 | 不交易 |

## 2. 趋势线画法

### 2.1 下降趋势线

- 连接至少 **2 个波段高点**（高点依次降低）
- 第三个触及点确认趋势线有效
- 触及次数越多（≥3 次），趋势线越可靠
- **有效突破**：阳线实体收盘价站上趋势线，非盘中影线穿越

### 2.2 上升趋势线

- 连接至少 **2 个波段低点**（低点依次抬高）
- 第三个触及点确认趋势线有效
- 触及次数越多（≥3 次），趋势线越可靠
- **有效跌破**：阴线实体收盘价跌破趋势线，非盘中影线穿越

### 2.3 趋势线有效性判断

| 标准 | 强趋势线 | 弱趋势线 |
|------|---------|---------|
| 触及次数 | ≥3 次 | 2 次 |
| 时间跨度 | ≥20 个交易日 | <20 个交易日 |
| 角度 | 30-60 度 | 过陡或过平 |
| 突破方式 | 放量长阳/长阴突破 | 缩量小K线穿越 |

## 3. 支撑与压力位识别

### 3.1 压力位（从强到弱）

1. **前期波段高点**：最可靠的压力位
2. **缩量整理平台上沿**：多次触及未突破的价格区间上沿
3. **放量长阴线收盘价**：大量套牢筹码集中位
4. **整数关口**：心理价位（如 100、50、20 元）
5. **均线位置**：MA60（中期）、MA120（长期）
6. **前期跳空缺口上沿**

### 3.2 支撑位（从强到弱）

1. **前期波段低点**：最可靠的支撑位
2. **缩量整理平台下沿**：多次获支撑的价格区间下沿
3. **放量长阳线收盘价**：大量获利筹码成本位
4. **整数关口**：心理价位
5. **均线位置**：MA20（短期）、MA60（中期）
6. **前期跳空缺口下沿**

### 3.3 支撑压力互换

- 压力位被有效突破后变为支撑位
- 支撑位被有效跌破后变为压力位
- 互换的可靠性取决于原压力/支撑的强度

## 4. K 线形态清单

### 4.1 反转形态（看多）

| 形态 | 特征 | 可靠性 |
|------|------|--------|
| 锤子线 | 下影线 ≥ 实体 2 倍，无上影或极短 | 高（在下跌末端） |
| 启明星 | 三根K线：阴线+小实体+阳线，中间跳空 | 高 |
| 看涨吞没 | 阳线实体完全包住前一根阴线 | 高 |
| 早晨之星 | 类似启明星，中间十字星 | 中 |
| 底部十字星 | 下跌末端出现十字星 | 中 |

### 4.2 反转形态（看空）

| 形态 | 特征 | 可靠性 |
|------|------|--------|
| 射击之星 | 上影线 ≥ 实体 2 倍，无下影或极短 | 高（在上涨末端） |
| 黄昏之星 | 三根K线：阳线+小实体+阴线，中间跳空 | 高 |
| 看跌吞没 | 阴线实体完全包住前一根阳线 | 高 |
| 乌云盖顶 | 阳线后高开低走阴线，收盘入阳线实体 50% 以上 | 中 |
| 顶部十字星 | 上涨末端出现十字星 | 中 |

### 4.3 持续形态

| 形态 | 含义 | 持续时间 |
|------|------|---------|
| 上升三法 | 大阳线后几根小阴线，再大阳线突破 | 5-7 根 K 线 |
| 下降三法 | 大阴线后几根小阳线，再大阴线跌破 | 5-7 根 K 线 |
| 旗形整理 | 快速走势后的平行四边形整理 | 10-20 根 K 线 |
| 三角形收敛 | 高点降低+低点抬高，等待方向选择 | 15-30 根 K 线 |

## 5. 市场环境过滤

### 5.1 适合交易的环境

- 大盘 MA20 向上且价格在 MA20 之上 → **偏多操作**
- 大盘 MA20 向下且价格在 MA20 之下 → **偏空操作或空仓**
- 布林带收口后方向选择 → 关注突破方向
- 市场涨跌比 > 1.5:1 → 偏多环境
- 市场涨跌比 < 0.7:1 → 偏空环境

### 5.2 不适合交易的环境（应空仓等待）

- 大盘在 MA20 附近反复穿越（震荡市）
- 市场连续 3 天涨跌比在 0.8-1.2 之间（无方向）
- 波动率突然飙升（恐慌情绪）
- 重大政策/事件前 1-2 天（不确定性高）
- 节假日前 2 个交易日（流动性下降）

### 5.3 大盘环境评估表

| 信号 | 偏多 | 中性 | 偏空 |
|------|------|------|------|
| 价格 vs MA20 | 价格 > MA20 | 价格 ≈ MA20 | 价格 < MA20 |
| MA20 方向 | 向上 | 走平 | 向下 |
| MACD | 金叉/红柱 | 临界 | 死叉/绿柱 |
| 涨跌比 | >1.5:1 | 0.8-1.2:1 | <0.7:1 |
| 成交量 | 放量上涨 | 平量 | 放量下跌 |

## 6. 入场与出场规则

### 6.1 入场方式

- **突破确认入场**：突破日收盘前 30 分钟入场（确认实体突破）
- **回踩确认入场**：突破次日回踩不破突破位时入场（更安全）
- **分批入场**：首仓 50%，回踩确认后加仓 50%

### 6.2 止盈分批出场

| 目标 | 位置 | 操作 |
|------|------|------|
| 第一目标 | 1:1 风险回报比 | 减仓 1/3 |
| 第二目标 | 1:2 风险回报比 | 再减 1/3 |
| 剩余 | 移动止损跟踪 | 回撤到前一目标位出场 |
| 全部出场 | 趋势线反向突破 | 清仓 |

### 6.3 止损规则（无条件执行）

| 类型 | 规则 | 说明 |
|------|------|------|
| 固定止损 | 入场价 ±2-3% | 根据品种波动率调整 |
| 结构止损 | 突破前低点/高点 | 跌破则突破失败 |
| 时间止损 | 5 个交易日无进展 | 横盘消耗时间成本 |
| **铁律** | **止损不得向亏损方向移动** | **只能向盈利方向移动** |

## 7. 无条件纪律清单

### 7.1 绝对禁止

1. ❌ 移动止损向亏损方向（只能向盈利方向移动）
2. ❌ 单笔亏损超过总资金 3%
3. ❌ 不设止损就入场
4. ❌ 亏损后报复性加仓（摊薄成本）
5. ❌ 连续 3 笔亏损后不休息（强制冷静 1-2 个交易日）
6. ❌ 风险回报比 < 1:2 的交易
7. ❌ 在重大事件窗口（财报、政策）前新建仓位
8. ❌ 情绪化交易（愤怒、贪婪、恐惧时不做决策）

### 7.2 必须执行

1. ✅ 每笔交易前写下入场理由和止损位
2. ✅ 每日复盘记录（买卖点、理由、情绪状态）
3. ✅ 严格执行仓位计算公式
4. ✅ 信号不明确时选择"不交易"
5. ✅ 月度统计胜率、风险回报比、最大回撤
