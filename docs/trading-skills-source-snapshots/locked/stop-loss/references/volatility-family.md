# 波动率止损族

所有成员共用一个模板：

```
止损 = 价格锚点 ∓ (波动度量 × 安全倍数)
```

三个变量的可选项决定了整个家族：

- **波动度量**：ATR / 标准差 / 简单区间(H−L) / 方向性运动(DM) / Beta
- **安全倍数**：1~3.6，越大越宽松
- **价格锚点**：入场价 / 收盘价 / 持仓期最高价 / 均线 / 前一根 K 线高低点

---

## 八个具名成员

### 1. Chandelier Exit（吊灯止损，Chuck LeBeau）
```
做多止损 = 最近 22 根 K 线最高价 − 3 × ATR(22)
```
锚点是**持仓期最高价**，所以天然只升不降，是移动止损的标准实现。适合趋势跟随。倍数 3 较宽松，短线可降至 2。

### 2. 布林带下轨
```
止损 = MA(20) − 2 × StdDev(20)
```
波动度量用标准差而非 ATR，锚点是均线。趋势中价格常沿上轨运行，跌破中轨往往比跌破下轨更早也更有效——**多数情况下用中轨而非下轨**。

### 3. Keltner 通道
与布林同构，把标准差换成 ATR，抗极端值更好，通道更平滑，假信号少于布林。

### 4. Kase DevStop（Cynthia Kase）
波动度量 = **2 根 K 线真实波幅的标准差**，并对区间偏度做修正。设 4 条线：预警线 + 1/2/3 sigma，安全倍数 1~3.6。

价值在于「分级」——不是一个止损点，而是一组递进的风险等级，可配合分批减仓。

### 5. Kaufman 波动止损
波动度量用简单平均区间（High − Low），锚点用近期价格极值。比 ATR 简单（不含跳空），在缺口频繁的市场里反而不如 ATR。

### 6. Elder SafeZone（Alexander Elder）
用**方向性运动 DM** 而非 ATR。核心洞察：**ATR 是方向中性的，但顺势波动与逆势波动的性质完全不同**——上升趋势里真正该防的只是「向下穿透」的幅度。

```
上升趋势止损 = 今日最低价 − 系数 × 近 N 日平均向下穿透幅度
```
默认系数 2、回看 10 日。Elder 的要求：用 22 日 EMA 斜率先定趋势方向；上下趋势分别计算；回看期不得跨越上一个重要转折点。

这是本族里理论上最贴合「排除噪音」原意的一个。

### 7. Bulkowski Beta 调整止损
用 Beta 作为相对波动度量，按 Beta 与价格的组合查表定止损距离。优点是把个股相对大盘的波动放大效应纳入，适合股票组合统一口径。

### 8. Parabolic SAR
唯一同时含**时间**维度：加速因子（默认 0.02，上限 0.2）随趋势延续递增，止损加速逼近价格。

- 强趋势中表现好，能在趋势末段快速收紧
- 震荡市中被反复打脸，是本族里假信号最多的
- **只能在明确趋势中使用**，需配趋势过滤器（如 ADX > 25）

## 选用建议

| 需求 | 选择 |
|---|---|
| 通用初始止损 | ATR，k=1.5~2.0，锚入场价 |
| 趋势移动止损 | Chandelier（3×ATR(22)） |
| 想区分顺逆势波动 | Elder SafeZone |
| 想要分级减仓 | Kase DevStop |
| 均值回归/通道交易 | Keltner 中线或对侧轨 |
| 强趋势末段快速收紧 | Parabolic SAR + 趋势过滤 |
| 股票组合统一风险口径 | Beta 调整 |

**统一原则**：无论选哪个，安全倍数最终应由 MAE 统计（见 `mae-validation.md`）校准，而不是照抄默认值。默认值只是起点。

---

## 共同缺陷

1. **滞后**：波动度量都是历史窗口的平均，波动率跳升时止损宽度扩张滞后一到几根 K 线，恰在最危险时最紧。
2. **窗口敏感**：ATR(10) 与 ATR(20) 可能给出差异 30% 以上的止损距离。参数需固定并回测，不可临场挑。
3. **不认结构**：波动率止损可能正好落在一个明显的支撑位上方，被扫后立刻反弹。**与结构位取更远者**可缓解。
4. **跳空无效**：任何价位型止损都不覆盖跳空，需靠仓位和期权兜底。
