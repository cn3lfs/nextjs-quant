# 执行层：订单、滑点与 A股特有约束

止损位算得再好，下不出去等于没有。这一层是原始资料缺失最多的部分。

## 止损单类型

| 类型 | 行为 | 风险 |
|---|---|---|
| 止损市价单 | 触发后按市价成交 | 一定成交，价格不确定，跳空时滑点巨大 |
| 止损限价单 | 触发后挂限价 | 价格可控，急跌时可能**完全不成交** |
| 心理止损（手动） | 到价手动下单 | 零技术风险，全部是执行力风险 |
| 条件单/预埋单 | 券商端触发 | 依赖券商实现，注意是否只在交易时段生效 |

**默认建议**：止损用市价（保证离场），止盈用限价（保证价格）。原则是「离场的确定性 > 价格的优化」。

只有在流动性极差的标的上，才用带较宽缓冲的止损限价单（如触发价下方 1% 挂单）以防瞬时插针成交。

## 滑点与跳空

止损**不保证**在止损价成交。必须承认两类超额亏损：

1. **滑点**：急跌中市价单成交价低于触发价，通常 0.1%~0.5%，小盘股更大
2. **跳空**：隔夜利空直接低开在止损价下方，实际亏损可能是 2R、3R

应对：
- 单笔风险比例留出余量（这也是不建议超过 2% 的原因之一）
- 财报、重大事件、长假前减仓或对冲，而不是依赖止损
- 用「灾难止损」概念：假设最坏跳空 −10%，检查此时账户是否仍可承受

## A股特有约束（关键）

### T+1
当日买入当日不可卖。**日内止损对当天买入的股票无效。**

应对：
- 当日买入后若逻辑破坏，只能记录并在次日开盘处理（参考 `opening-price-playbook`）
- 想保留日内纠错能力，需事先持有底仓，用「T+0 回转」方式操作（卖旧买新）
- 由此推论：A股日内追高的容错成本远高于美股，止损纪律必须前移到**入场筛选**

### 涨跌停板
跌停封死时无法成交，止损单形同虚设。ST 股 ±5%、创业板/科创板 ±20% 各不相同。

应对：
- 一字跌停：次日集合竞价挂跌停价排队，能否出局取决于封单量
- 持仓中出现跌停且伴随利空公告，优先考虑「不惜价出局」而非等反弹
- 高位股仓位应主动限制在「一个跌停仍可承受」的规模内

### 停牌
重大资产重组、核查停牌期间完全无法离场，复牌可能连续跌停。这是纯粹的**事前风险**：对有停牌传闻/重组预期的标的，直接降低仓位上限，止损方法解决不了这个问题。

### 竞价与临停
- 集合竞价（9:15–9:25，9:20 前可撤单）是唯一能在开盘前调整止损的窗口
- 科创板/创业板盘中临时停牌会中断执行

## 交易时段外风险

- A股：隔夜与周末外盘、政策、公告
- 美股/港股：盘前盘后波动大，止损单通常只在常规时段有效，需确认券商设置
- 加密：7×24，止损单必须挂在交易所端而非本地程序

## 执行检查清单

下单前逐条确认：

- [ ] 止损价已写下并知道触发后做什么
- [ ] 订单类型选定，且知道该类型在跳空时的行为
- [ ] 该标的今日可卖数量（T+1 检查）
- [ ] 最坏情况（跌停/跳空 −10%）下的亏损仍在可承受范围
- [ ] 未来 5 个交易日内是否有财报、解禁、重大事件
- [ ] 组合当前总在险金额加上这笔后是否仍在上限内
