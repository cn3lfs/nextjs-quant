# 仓位换算与 R 倍数体系

## 基本公式

```
单笔风险金额 R$ = 账户权益 × 单笔风险比例
止损距离 D     = |入场价 − 止损价|
理论股数 Q     = R$ / D
实际股数       = floor(Q / 最小单位) × 最小单位
实际风险       = 实际股数 × D
```

含成本的严格版（短线频繁交易必须计入）：

```
实际风险 = 实际股数 × (D + 预估滑点) + 双边手续费与税费
```

A股卖出印花税 0.05%、双边佣金约 0.02%~0.03%，短线止损 3% 时，成本可占单笔风险的 3%~5%，不致命但需在期望值统计中扣除。

## 单笔风险比例怎么选

| 账户/风格 | 建议比例 | 说明 |
|---|---|---|
| 新手、验证期策略 | 0.25%~0.5% | 目标是活到样本量够 |
| 成熟波段策略 | 1% | 行业默认值 |
| 高胜率、低频、强信号 | 1.5%~2% | 上限，不建议再高 |
| 任何情况 | 不超过 2% | 连续 10 次止损即 −20% |

连亏时按权益自动缩小（用当前权益而非初始权益计算），这本身就是一种降杠杆机制。

## 集中度上限

三条约束同时生效，取最小值：

1. 风险约束：`R$ / D` 股
2. 市值约束：单标的市值 ≤ 组合 15%~20%
3. 流动性约束：仓位 ≤ 该股近 20 日平均成交额的 1%（否则自己就是滑点来源）

## R 倍数体系

以初始风险 1R 为单位记录所有结果：

- 止损出局 = −1R；保本出局 = 0R；在 2R 目标离场 = +2R
- 期望值 `E = 胜率 × 平均盈利R − (1−胜率) × 平均亏损R`
- E > 0.2R 的策略才值得放大仓位

用 R 记录的好处：不同价格、不同仓位的交易可以横向比较，能直接回答「我的止损是不是太紧」——若大量交易在 −1R 后回到 +2R 区域，说明止损过紧或入场过晚。

## 计算示例

**统一以账户总资金 100 万元为基准**（使用者按自有资金等比换算：50 万账户所有金额 ×0.5，200 万 ×2，占比不变）。账户 1,000,000，单笔 1% = 10,000。

| 标的 | 入场 | 止损 | 距离 | 距离% | 理论股数 | 取整(100) | 实际风险 | 市值 | 占比 |
|---|---|---|---|---|---|---|---|---|---|
| A | 80 | 75.8 | 4.2 | 5.25% | 2381 | 2300 | 9,660 | 184,000 | 18.4% |
| B | 25 | 24.4 | 0.6 | 2.4% | 16666 | 16600 | 9,960 | 415,000 | 41.5% ❌ |

B 触发市值上限（20% = 200,000），须降至 8,000 股，实际风险降为 4,800（0.48%）。**这是正确的**——低波动标的用满风险额度会造成过度集中。

## 组合层风险

```
组合在险金额 = Σ 各持仓实际风险
```

上限建议 4%~6%。同板块持仓相关性接近 1，应按「合并为一笔」计算：三只光伏股各 1% 风险 = 实际约 3% 的单一风险敞口，而非 3 笔独立风险。

日/周亏损熔断：单日 −3%、单周 −6% 触及即停止开新仓，只管理存量。这是防止「报复性交易」的机械开关，不依赖当时的自控力。
