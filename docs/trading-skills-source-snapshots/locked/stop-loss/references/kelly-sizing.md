# 凯利公式仓位（优势定权重）

> **公共实现**。原先在 `swing-trader/references/position-management.md`、
> `canslim-analyst/references/entry-exit-rules.md`、
> `sepa-strategy-analyst/references/entry-exit-rules.md` 三处逐字重复，现统一到此。
> 各技能只保留自己的**单笔风险比例**与**回报倍数 b 的取法**，公式与分数凯利规则读本文件。

`position-sizing.md` 的固定风险比例规则回答"单笔亏多少"，凯利公式回答"有多大优势就下多重"。
二者**配合使用**：凯利按统计优势给出仓位上限，风险规则按止损距离给出仓位，
**最终取两者及总仓位上限的最小值**。

## 公式

```
f* = (b × p − q) / b = (p(b+1) − 1) / b
```

- p = 胜率，q = 1 − p
- b = 回报倍数（目标空间 / 止损空间，即风险回报比 1:b 中的 b）
- **f* ≤ 0 → 无正期望，不开仓**（凯利第一原则：没有优势不下注）

## 实盘必须用分数凯利

波段标配 **半凯利 f*/2**，样本不足或参数不确定时用 **1/4 凯利**：

- 胜率与回报倍数都是历史估计、未来会漂移，**高估参数导致的过度下注，危害远大于保守**
- 半凯利保留约 75% 的理论增长率，波动却降约一半
- **绝不超过 1 倍凯利**——超过 2 倍凯利时长期增长率转负，这是爆仓的数学根源

## 胜率 p 的取值

有 ≥30 笔同策略记录时用实测胜率（配合 `mae-validation.md` 校准）。
样本不足时用信号质量作保守代理：

| 信号质量 | 经验胜率 p |
|---------|-----------|
| 5/5 | 0.55 |
| 4/5 | 0.50 |
| 3/5 | 0.45 |
| ≤2/5 | 不交易 |

## 计算流程

```
1. f*        = (b·p − q) / b            # f* ≤ 0 → 不开仓
2. f_kelly   = max(f*, 0) × 0.5          # 半凯利
3. 凯利仓位  = T × f_kelly
4. 风险仓位  = (T × 单笔风险比例) / 止损百分比    # 比例见调用方策略
5. 建议仓位  = MIN(凯利仓位, 风险仓位, 总仓位上限)
```

**示例**：T=100 万，信号质量 4/5（p=0.50），b=2（风险回报比 1:2），止损 5%，
单笔风险比例 2%，总仓位上限 30%：

- f* = (2×0.50 − 0.50)/2 = 0.25 → 半凯利 12.5% → 凯利仓位 12.5 万
- 风险仓位 = (100万 × 2%) / 5% = 40 万
- 建议仓位 = MIN(12.5万, 40万, 30万) = **12.5 万**
  （此例凯利更严，说明优势不足以支撑大仓）

## 输出要求

报告"建议仓位"时须同时列出：**风险仓位、半凯利仓位、最终取值，并注明是哪一项在约束**。

样本量不足（同策略历史交易 <30 笔）、参数非平稳、或标的有黑天鹅肥尾风险时，
凯利值不可尽信，应进一步压缩至 1/4 凯利。

## 各调用方的参数差异

| 技能 | 单笔风险比例 | 总仓位上限 | b 的取法 |
|---|---|---|---|
| `swing-trader` | 2% | 30% | 第二目标空间 / 止损空间 |
| `canslim-analyst` | 1.5% | 25% | (目标价−买入价)/(买入价−止损价)，要求 b ≥ 2.5 |
| `sepa-strategy-analyst` | 见其 entry-exit-rules 第 5 节 | 同左 | 枢纽点目标 / 初始止损距离 |
| 通用/未指定 | 1%（见 `position-sizing.md`） | 组合在险 4%~6% | 由用户给定 |
