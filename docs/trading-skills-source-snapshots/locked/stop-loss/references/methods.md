# 止损方法总目录

## 先分清四个正交维度

多数教程把不同维度的东西并列成「N 种止损法」，这是混乱的根源。一个完整的止损定义需要在四个维度上各选一项：

| 维度 | 回答的问题 | 选项 |
|---|---|---|
| **A. 定位** | 止损放在哪个价位 | 结构位 / 波动率 / 指标 / 百分比 / MAE 统计 / 逻辑证伪 |
| **B. 触发** | 什么条件算触发 | 盘中触碰 / 收盘确认 / 连续两根收盘 / 时间到期 |
| **C. 规模** | 亏多少钱 | 资金风险法（由 A 的距离反推仓位） |
| **D. 演化** | 持仓中如何调整 | 不动 / 保本移动 / 移动止损 / 回撤止损 / 分批 |

在这四层之外，还有一层**不属于单笔交易**的风控：

| **E. 账户层** | 什么时候整体停手 | 日/周/月亏损上限、连亏计数、回撤熔断、equity-curve 开关 |
| **F. 替代/补充** | 不用止损时怎么控风险 | 保护性看跌、领口、降仓、分散 |

Van Tharp 的关键区分：**money management stop（最大损失止损，属 C/E 层）** 与 **技术止损（属 A 层）** 是两回事，很多人只做前者而忽略后者，或反之。

# A 层：定位方法

## A1. 百分比止损

`止损 = 入场 × (1 ∓ p)`。日内 1%~2%，波段 3%~8%。

**适用**：新手建立纪律、自动化系统、标的多无法逐个看图。
**缺陷**：完全无视波动率与结构，止损常落在噪音区内。
**改进**：按 ATR/价格 分档（>3% 用 8%，<1.5% 用 3%），本质上退化为 A2。

## A2. 波动率止损族（重点，原始资料严重简化）

统一公式：**`止损 = 价格锚点 ∓ (波动度量 × 安全倍数)`**

三个变量各自可换，组合出整个家族。八个具名成员与选用建议见 `volatility-family.md`。

最常用两个：
- **初始止损**：`入场价 − k × ATR(14)`，k 取 1.5~2.0（波段）
- **移动止损（Chandelier Exit）**：`持仓期最高价 − 3 × ATR(22)`

**关键区分（原文未强调）**：初始止损锚点是入场价，移动止损锚点是持仓最高价，公式不同，不可混用。

**共同失效模式**：ATR 滞后于波动率突变，在最需要放宽时才放宽。

## A3. 结构止损（摆动高低点）

放在最近有效摆动低点（做多）下方，跌破即上升结构被破坏、入场逻辑证伪。

- **缓冲**：低点下方 0.3~0.5×ATR 或 0.3%~0.8%，避免精准被扫
- **周期一致**：日线波段用日线摆动低点，不用 5 分钟的
- **距离过远时**：正确动作是**放弃这笔交易或等更好入场**，绝不缩小止损凑仓位

这是价格行为交易者的默认方法，因为它是唯一直接对应「我为什么买」的方法。

## A4. 指标止损

20EMA、60/120 日均线、布林中轨、Keltner 中线、SAR、缠论结构线。通常用**收盘跌破**而非盘中触碰。

**前提检验**：用之前必须回看该标的历史上是否真的沿这条线运行。不同标的对同一条均线的「尊重程度」差别巨大。

## A5. MAE 统计止损（原始资料缺失，价值最高）

John Sweeney 在《Campaign Trading》提出。**最大不利偏移（MAE）= 一笔交易平仓前经历的最大浮亏。**

做法：
1. 记录 100 笔以上同策略交易的 MAE 与最终盈亏
2. 以 MAE 为横轴、最终 P&L 为纵轴散点
3. 最终盈利的交易，其 MAE 会聚集在某个阈值以下；亏损交易的 MAE 显著超出
4. 这个分界就是**用你自己的数据算出的止损宽度**

**为什么它是独立大类**：A1~A4 都是先验假设，只有 A5 是后验证据。它的正确用法不是取代其他方法，而是**校验**——用 MAE 检查你的 k 值、缓冲、百分比是不是真的合适。详见 `mae-validation.md`。

**代价**：需要足够样本，且策略必须稳定；样本不足时不适用。

## A6. 逻辑证伪止损（非价格触发）

不看价位，看假设是否成立：业绩证伪、政策转向、竞争格局变化、产品失败、管理层变动。

**适用**：中长线持仓、事件驱动、基本面驱动仓位。
**风险**：极易被亏损厌恶劫持，变成「我还相信它」的托词。
**约束**：必须在入场时**书面写下**「什么事实出现即证伪」，事后不得新增解释。同时保留一条灾难止损兜底。

# B 层：触发方式（正交维度，常被忽略）

同一个价位，三种触发方式的实际结果差别极大：

| 方式 | 特点 | 适合 |
|---|---|---|
| 盘中触碰 | 执行确定，被噪音扫出概率最高 | 日内、高杠杆、可预埋单 |
| 收盘确认 | 过滤插针，但当日亏损可能远超止损位 | 波段、趋势跟随 |
| 连续两根收盘破位 | 过滤更强，滞后更大 | 长周期、低频 |
| 时间到期（时间止损） | 与价格无关，见 D 层 | 动量、事件驱动 |

**必须在入场前写死用哪种**，事后切换等于取消止损。用收盘确认时，仓位应按「最坏收盘价」而非止损价计算风险。

# C 层：规模（资金风险法）

不是「第七种止损位」，而是与 A 层正交的一层：**先定亏多少钱，由 A 层给出的距离反推仓位。**

```
股数 = (账户权益 × 单笔风险比例) / |入场价 − 止损价|
```

价值：止损位由市场逻辑决定，不被资金规模扭曲；波动大→仓位自动变小；所有结果可用 R 倍数统一衡量。

必须叠加单标的市值上限与流动性上限。完整内容见 `position-sizing.md`。

**灾难止损（Maximum Loss Stop）**：在技术止损之外另设一条绝对亏损线（如单笔 −2R 或 −3%），用于跳空、停牌、系统故障等技术止损失效的场景。它不参与仓位计算，是兜底。

# D 层：演化方式

## D1. 一次设定不动
## D2. 保本移动（+1R 且结构确认后）
## D3. 移动止损（固定距离 / 百分比 / ATR / 结构性）
## D4. 回撤止损（Retracement Stop，Tharp，原文缺失）

按**回吐已有利润的百分比**分级收紧，而非按价格距离：

| 已达 | 允许回吐 |
|---|---|
| 2R | 30% |
| 3R | 25% |
| 4R | 20% |
| 7R | 5% |

与 D3 的区别：D3 距离恒定，D4 随盈利增长而按比例收紧，更贴合「让利润奔跑但越到后期越保守」。

## D5. 时间止损

约定时间内未达预期进展即离场（日内 30 分钟未走出 0.5R；波段 5 日仍原地震荡）。这是**期望止损**，不替代价格止损，两者并存。趋势跟踪不宜用紧时间止损。

## D6. 分批减仓 + 逐级抬升

详见 `management.md`。

**铁律**：止损只能朝减少风险方向移动。

# E 层：账户与组合熔断（原始资料完全缺失）

单笔止损做对，组合仍可能被同向持仓一起打穿。Elder 的经典规则：

- **2% 规则**：单笔风险不超过账户 2%
- **6% 规则**：当月累计回撤达 6%，本月停止开新仓

扩展的四道闸：

| 层级 | 阈值参考 | 触发动作 |
|---|---|---|
| 单日亏损 | −2%~−3% | 当日停止开新仓 |
| 单周/单月 | −6% | 当期只管理存量 |
| 连亏计数 | 连续 5~6 笔止损 | 减半仓位直到重回正 R |
| 峰谷回撤 | −10%~−15% | 降杠杆或全面复盘 |

另有 **equity-curve 开关**（权益曲线跌破自身均线即停手）。注意：这是「交易策略的策略」，实证效果不稳定，Build Alpha 的案例中它反而加深了回撤——**列在这里是为了知道它存在且需谨慎，不是推荐**。

同板块/高相关持仓必须合并计算敞口：三只同板块股各 1% 风险 ≈ 3% 的单一风险，不是 3 笔独立风险。

# F 层：替代与补充手段

止损不是唯一的风险控制方式，某些场景下不是最好的：

| 手段 | 解决什么 | 代价 |
|---|---|---|
| 保护性看跌期权 | **跳空**——止损唯一无法覆盖的风险 | 权利金；高波动期更贵 |
| 领口（买put卖call） | 零成本获得下方保护 | 放弃上方收益 |
| 直接降仓 | 所有风险按比例缩小 | 收益同比缩小，但最可靠 |
| 分散与再平衡 | 单一标的风险 | 稀释 alpha |

**理论视角**：设止损在期权上等价于卖出一个下方看跌——你把下行保护免费让渡给了市场。这解释了为什么统计套利、均值回归类策略常常刻意不设单笔止损（止损会摧毁其统计边际），改用组合对冲与仓位控制。

**判断准则**：止损适用于「单笔结果重要、且不利偏移确实预示逻辑失败」的策略。若不利偏移是策略的正常组成部分（均值回归），单笔止损会直接杀死边际，应改用 C/E/F 层控制。

# 组合使用范式（波段股票，修正版）

1. **定位**（A3+A2）：结构止损 = 摆动低点 − 0.3×ATR；若该距离 > 2×ATR，说明入场太差 → 放弃或等回调
2. **触发**（B）：日线收盘跌破才执行；预埋条件单作为盘中崩塌的备份
3. **规模**（C）：单笔 1% ÷ 止损距离，受市值 20% 与流动性 1% 上限约束；另设 −2R 灾难止损
4. **演化**（D）：+1R 移保本 → +2R 减半并移至 +1R → 其后 3×ATR(22) Chandelier 跟随；10 日无进展则时间止损
5. **账户**（E）：单周 −3R 停手；连亏 5 笔减半仓位
6. **校验**（A5）：每 100 笔用 MAE 分布回头检查第 1 步的缓冲与 k 值是否合适
7. **例外**（F）：财报与重大事件前，改用减仓或保护性看跌，不依赖止损
