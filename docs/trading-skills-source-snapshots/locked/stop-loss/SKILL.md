# 止损策略手册

止损的本质不是「亏了就卖」，而是**先定义交易逻辑在什么价位被证伪，再由这个距离反推仓位**。价位来自市场结构，亏损金额来自账户规则，两者不能互相迁就。

核心口诀：**先定失效点 → 再定单笔风险金额 → 最后算仓位。** 仓位是因变量，不是自变量。

## 输出要求

给出止损建议时必须包含四项，缺一不可：

1. **止损价位**（或触发条件，如「日线收盘跌破 X」）
2. **止损理由**（跌破它意味着什么逻辑被证伪）
3. **仓位/股数**（由单笔风险金额 ÷ 止损距离算出）
4. **触发后的动作**（清仓 / 减半 / 只减不加）

不要给「大概跌 5% 就止损」这种脱离结构和账户的答案。数据不足时说明缺什么，用条件式表述，不要编造精确价位。

## 第一步：确认前置信息

- 品种与市场（A股/港股/美股/期货/加密），涨跌停与 T+0/T+1 规则
- 账户规模、单笔可承受亏损比例、当前总持仓与已用风险
- 交易周期（日内 / 波段数日至数周 / 趋势数月）
- 入场逻辑（突破 / 回调 / 反转 / 事件驱动）——止损必须锚定这个逻辑
- 最近波动率（ATR）、关键结构位（前低、平台下沿、缺口、均线）

缺账户信息时，**默认账户总资金 100 万元、单笔风险 1%**，并明确说明这是假设。所有金额按 100 万基准给出，使用者按自己资金等比换算即可（如 50 万账户所有金额 ×0.5）。

## 第二步：按六层框架组装

止损不是「选一种方法」，而是在六个层次上各做一次选择。完整目录见 `references/methods.md`。

| 层 | 回答 | 选项 |
|---|---|---|
| **A 定位** | 价位放哪 | 结构位 / 波动率族 / 指标 / 百分比 / MAE统计 / 逻辑证伪 |
| **B 触发** | 什么算触发 | 盘中触碰 / 收盘确认 / 连续两根收盘 |
| **C 规模** | 亏多少钱 | 资金风险法 + 灾难止损兜底 |
| **D 演化** | 持仓中怎么调 | 不动 / 保本移动 / 移动止损 / 回撤止损 / 分批 |
| **E 账户** | 何时整体停手 | 2%/6%规则、日周亏损上限、连亏计数、回撤熔断 |
| **F 替代** | 止损覆盖不了时 | 保护性看跌 / 领口 / 降仓 / 分散 |

A 层快速选择：

| 场景 | 首选 | 备选 |
|---|---|---|
| 趋势回调买入 | 结构位（摆动低点 − 0.3×ATR） | 1.5~2×ATR |
| 突破买入 | 平台上沿下方 / 突破K线低点 | 1.5×ATR |
| 高波动、结构模糊 | ATR（k=1.5~2.5） | Keltner 中线 |
| 日内动量 | 分时结构位 + 时间止损 | 固定点数 |
| 趋势持仓浮盈保护 | Chandelier（3×ATR(22)） | 回撤止损 / 20EMA |
| 中长线/基本面仓位 | 逻辑证伪 + 灾难止损兜底 | 保护性看跌 |
| 自动化/新手/无法看盘 | 百分比（纪律优先） | — |
| 已有 100 笔以上交易记录 | **MAE 统计校准以上任一** | — |

**方法可叠加，但只能有一个最终触发价。** 多套逻辑并存时取最保守（离场最早）的那个，并写清楚理由。

波动率止损族的八个具名成员（Chandelier、布林、Keltner、Kase DevStop、Kaufman、Elder SafeZone、Beta 调整、Parabolic SAR）及选用建议见 `references/volatility-family.md`。

## 第三步：仓位换算（不可跳过）

```
单笔风险金额 = 账户权益 × 单笔风险比例（常用 0.5%~2%）
止损距离     = 入场价 − 止损价
股数         = 单笔风险金额 ÷ 止损距离
```

再用两个约束修正：单一标的市值不超过组合上限；股数需符合最小交易单位（A股 100 股整数倍，取下整）。

`scripts/stop_loss_calc.py` 可直接计算并给出百分比/ATR/结构位三套方案对照、R 倍数目标与滑点后的实际亏损。用法：

```bash
python scripts/stop_loss_calc.py --equity 1000000 --risk-pct 1 --entry 80 --stop 76 --lot 100
python scripts/stop_loss_calc.py --equity 1000000 --risk-pct 1 --entry 80 --atr 2.5 --k 1.5 --target 92
```

仓位与 R 倍数体系细节见 `references/position-sizing.md`。

上式按**止损距离**定仓位。当调用方还能给出胜率与风险回报比时，再叠加一层
**凯利上限**（`references/kelly-sizing.md`）：最终仓位取「风险仓位、半凯利仓位、
总仓位上限」三者的最小值，并注明是哪一项在约束。凯利是本技能的公共实现，
`swing-trader`、`canslim-analyst`、`sepa-strategy-analyst` 均引用此文件，
各自只保留单笔风险比例与 b 的取法差异。

## 第四步：管理方式

三种风格（一次设定不动 / 保本移动 / 分批减仓 + 移动止损）的取舍、触发阈值与完整示例见 `references/management.md`。

铁律：**止损只能朝减少风险的方向移动。** 做多时止损只上移不下移；「再给它一点空间」是最常见的爆仓路径。

## 第五步：账户熔断与执行约束

单笔止损做对了，组合仍可能被同向持仓一起打穿。必须叠加（Elder 2%/6% 规则为基准）：

- 同板块/高相关持仓合并计算风险敞口
- 单笔 ≤2%，单日 −3% 停开新仓，当月累计 −6% 只管理存量
- 连续 5~6 笔止损自动减半仓位；峰谷回撤 −10%~−15% 降杠杆复盘

执行层面：止损单类型（限价/市价/条件单）、跳空与滑点、A股涨跌停与 T+1 导致「想止损卖不掉」的处理，见 `references/execution.md`（含 A股专章）。

## 第六步：校准（有交易记录时必做）

参数不该照抄默认值。累积 100 笔以上同策略交易后，用 MAE（最大不利偏移）分布反推止损宽度，并诊断「止损过紧 / 过宽 / 根本没有区分度」。方法与判读规则见 `references/mae-validation.md`，含最小可行记录表。

## 常见错误

`references/pitfalls.md` 列出十类高频错误及其纠正动作。最需要当场纠正的三条：

1. **先定仓位再找止损位** —— 顺序反了，止损必然被塞进不合理的位置。
2. **止损设在整数关口或明显前低正下方** —— 那里是流动性密集区，容易被扫。留缓冲（如前低下方 0.3~0.5×ATR）。
3. **频繁被扫后放宽止损** —— 先检查是不是入场太晚、周期与止损宽度不匹配，而不是加大止损。

## 边界

本技能只处理风险控制的方法论与计算，不预测行情、不做个股推荐。涉及具体标的的买卖判断时，交由 `swing-trader`、`opening-price-playbook` 等技能，本技能负责给出其中的止损与仓位部分。

作为**风险控制公共层**被调用时，只返回「止损价 + 理由 + 股数 + 触发后动作」四件套，
不重复输出交易计划、不判断标的好坏。
