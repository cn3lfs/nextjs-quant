# 入场/出场/止损规则（T+1 适配）

本文件定义基于欧奈尔体系的入场确认、止损铁律、止盈策略和 T+1 操作规则。

---

## 1. 五步入场确认清单

| 步骤 | 条件 | 类型 | 判定方法 |
|------|------|------|---------|
| 1 | 收盘价 > 突破点 × 1.01 | 必须 | 当日收盘价确认突破 |
| 2 | 成交量 ≥ 20日均量 × 1.5 | 必须 | 放量突破确认买盘力量 |
| 3 | 价格 ≤ 突破点 × 1.05 | 必须 | 超过为追高，禁止买入 |
| 4 | 大盘确认 | 重要 | 沪深300 当日非大跌（跌幅 < 2%） |
| 5 | 催化剂确认 | 加分 | 近期有盈利超预期/研报上调/机构调研 |

**判定逻辑**：
- 步骤 1-3 全部通过 + 步骤 4 或 5 至少一项 → **BUY**
- 步骤 1-3 全部通过 + 步骤 4 和 5 均未通过 → **WATCH**
- 步骤 1-3 任一未通过 → **PASS**

## 3. 止损铁律（欧奈尔 7-8% 法则）

### 3.1 止损价计算

```
止损价 = 买入价 × 0.92
```

**含义**：买入后下跌 7-8%，无论任何理由必须止损出场。

**绝对规则**：
- 不允许主观判断覆盖止损规则
- 不允许"再等等看"的侥幸心理
- 不允许向下调整止损位
- 止损触发后必须在次日开盘执行

### 3.2 止损价验证

**止损价 vs 突破点**：
- 如止损价 < 突破点 × 0.92：以突破点 × 0.92 为准（更严格）
- 如止损价 > 突破点 × 0.92：以买入价 × 0.92 为准

```
实际止损价 = MAX(买入价 × 0.92, 突破点 × 0.92)
```

### 3.3 止损示例

假设：
- 突破点 = 50.00 元
- 买入价 = 51.00 元（突破点 +2%）
- 止损价 = MAX(51.00 × 0.92, 50.00 × 0.92) = MAX(46.92, 46.00) = 46.92 元
- 实际亏损 = (51.00 - 46.92) / 51.00 = 8.0%

## 4. 止盈策略（阶梯止盈）

### 4.1 两阶段止盈

| 阶段 | 触发条件 | 操作 | 止损调整 |
|------|---------|------|---------|
| 第一目标 | 盈利 ≥ 20% | 卖出 50% | 剩余仓位止损上移至成本价 |
| 第二目标 | 盈利 ≥ 25% | 卖出剩余 50% | 全部出场 |

### 4.2 止盈后的止损调整

| 情形 | 止损调整 |
|------|---------|
| 盈利 < 15% | 维持原止损价 |
| 盈利 ≥ 15% 且 < 20% | 止损上移至成本价（保本止损） |
| 盈利 ≥ 20%（已卖出 50%） | 剩余仓位止损上移至 +10% |
| 盈利 ≥ 25%（触发第二目标） | 全部出场 |

### 4.3 异常情况止盈

| 信号 | 操作 |
|------|------|
| 出现明显放量下跌（机构出货信号） | 及时减仓，不等目标价 |
| 大盘出现连续分布日（≥ 5 个） | 主动降低持仓比例 |
| 周线跌破 10MA | 减仓 50% |
| 入场后 4 周无进展（涨幅 < 5%） | 强制出场 |

## 5. 仓位管理

### 5.1 仓位计算公式

以 100 万元账户为例：

**步骤 1** — 确定单笔最大风险：
```
单笔最大风险 = 账户总资金 × 1.5% = 1,000,000 × 1.5% = 15,000 元
```

**步骤 2** — 确定止损百分比：
```
止损百分比 = (买入价 - 止损价) / 买入价 = 8%
```

**步骤 3** — 计算最大持仓金额：
```
最大持仓金额 = 单笔最大风险 / 止损百分比 = 15,000 / 8% = 187,500 元
```

**步骤 4** — 确定仓位上限：
```
单笔仓位上限 = 账户总资金 × 25% = 1,000,000 × 25% = 250,000 元
```

**步骤 5** — 取较小值：
```
实际仓位 = MIN(最大持仓金额, 单笔仓位上限) = MIN(187,500, 250,000) = 187,500 元
```

### 5.2 分批建仓

| 策略 | 操作 | 适用场景 |
|------|------|---------|
| 一次性建仓 | 买入 100% 目标仓位 | 突破确认度高，大盘配合 |
| 分批建仓 | 先买 50%，确认后补仓 | 突破确认度一般，大盘震荡 |

**分批建仓确认条件**：
- 第一批买入后，股价上涨 2%-3%
- 成交量维持在 20日均量以上
- 大盘未出现异常波动

### 5.3 凯利公式仓位（委托）

公式、分数凯利规则、胜率取值表与计算流程见
`../../stop-loss/references/kelly-sizing.md`（公共实现）。

本技能传入的参数：单笔风险比例 **1.5%**、总仓位上限 **25%**、
b = 第 8 节的 (目标价−买入价)/(买入价−止损价)，CANSLIM 要求 **b ≥ 2.5**。

输出"建议仓位"时须同时列出风险仓位、半凯利仓位、最终取值，并注明是哪一项在约束。

## 6. T+1 次日出场预案

由于 A 股 T+1 制度，买入当日无法卖出。次日开盘的 5 种场景及应对：

| 情形 | 开盘操作 | 盘中操作 | 说明 |
|------|---------|---------|------|
| 跳空高开 > 3% | 持有 | 止损上移至成本价 | 趋势确认，保护利润 |
| 平开或小幅波动 | 持有 | 观察量能，不破止损持有 | 正常走势 |
| 跳空低开 1-3% | 持有观察 | 盘中不破止损价则持有 | 可能是洗盘 |
| 跳空低开 > 3% | 减仓 50% | 盘中确认跌破止损则全部出场 | 趋势可能反转 |
| 大阴线（跌 > 4% 放量） | — | 次日开盘全部出场 | 强烈出货信号 |

## 7. 绝对禁止事项

1. **禁止** 在没有预设止损价的情况下买入
2. **禁止** 在止损触发后"再等等看"
3. **禁止** 向下调整止损位
4. **禁止** 在涨停板追高买入
5. **禁止** 在 ST 股票上使用本策略
6. **禁止** 在大盘熊市（M 因子 < 6）时做多
7. **禁止** 单笔仓位超过账户总资金的 25%
8. **禁止** 在财报发布前 5 个交易日内买入
9. **禁止** 风险回报比 < 1:2.5 的交易
10. **禁止** 报复性交易（止损后立即买入同一只股票）

## 8. 风险回报比验证

### 8.1 计算公式

```
X（回报倍数） = (目标价 - 买入价) / (买入价 - 止损价)
风险回报比 = 1 : X
```

### 8.2 最低要求

- 风险回报比 ≥ 1:2.5（即 X ≥ 2.5）
- 如风险回报比 < 1:2.5，不执行交易

> 口径固定为 `1 : X`：左边 1 是风险（一份止损空间），右边 X 是回报倍数。公式算出的是 X，不是比值本身。

### 8.3 示例

假设：
- 买入价 = 51.00 元
- 止损价 = 46.92 元（-8%）
- 第一目标价 = 61.20 元（+20%）

```
X = (61.20 - 51.00) / (51.00 - 46.92) = 10.20 / 4.08 = 2.5
风险回报比 = 1 : 2.5 ✓（达到 CANSLIM 门槛）
```

## 9. 持仓管理时间表

| 时间点 | 检查内容 | 操作 |
|--------|---------|------|
| 每日开盘 | 检查止损是否触发 | 触发则执行止损 |
| 每日 14:30 | 检查当日走势 | 异常则次日减仓 |
| 每周五收盘 | 检查周线走势 | 周线跌破10MA减仓50% |
| 买入后第 4 周 | 检查涨幅 | 涨幅 < 5% 强制出场 |
| 盈利 15% | 止损调整 | 止损上移至成本价 |
| 盈利 20% | 部分止盈 | 卖出 50%，止损上移至 +10% |
| 盈利 25% | 全部止盈 | 卖出剩余 50% |
