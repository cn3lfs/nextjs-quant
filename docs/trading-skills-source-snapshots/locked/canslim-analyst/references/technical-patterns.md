# 技术形态识别规则

本文件定义欧奈尔体系中的三种核心买入形态：杯柄形态（Cup and Handle）、平台突破（Flat Base）、平底形态（Saucer）。每种形态的量化识别参数和评分标准。

---

## 1. 杯柄形态（Cup and Handle）— 欧奈尔经典形态

### 1.1 形态定义

杯柄形态是欧奈尔最推崇的买入形态，由"杯形"和"柄部"两部分组成。

```
        杯沿           杯沿
         /\             /\
        /  \           /  \
       /    \    柄部  /    \
      /      \  /\/\  /      \
     /        \/    \/        \
    /         杯底            \
   /                           \
```

### 1.2 杯形识别参数

| 参数 | 标准 | 边界处理 |
|------|------|---------|
| 杯深度 | 12%-33% | < 12% 太浅（整理不充分）；> 33% 太深（趋势破坏） |
| 杯周期 | 35-325 个交易日（7-65 周） | < 35 日太短；> 325 日太长 |
| 杯形形状 | U 形（底部圆润） | V 形扣分（底部尖锐，整理不充分） |
| 杯沿高度 | 左右杯沿基本等高 | 右杯沿可略低于左杯沿（≤ 5%） |

**杯形质量评分**：
- U 形（底部圆润，有 2-4 周的底部盘整）：3 分
- W 形（底部双底）：2 分
- V 形（底部尖锐，快速反弹）：1 分
- 不规则形（无法识别）：0 分

**杯深度评分**：
- 15%-30%（最佳区间）：2 分
- 12%-15% 或 30%-33%：1 分
- < 12% 或 > 33%：0 分

### 1.3 柄部识别参数

| 参数 | 标准 | 边界处理 |
|------|------|---------|
| 柄部位置 | 杯的上半部（柄部低点 > 杯深 50%） | 柄部太低说明卖压重 |
| 柄部回调 | ≤ 杯深的 1/3 | 回调过深说明整理不充分 |
| 柄部周期 | ≥ 5 个交易日 | < 5 日太短，不足以消化卖压 |
| 柄部量能 | 持续萎缩 | 放量说明卖压未消 |

**柄部质量评分**：
- 回调 ≤ 杯深 1/3，量能持续萎缩：2 分
- 回调 ≤ 杯深 1/2，量能平稳：1 分
- 回调 > 杯深 1/2：0 分

**量能萎缩评分**：
- 柄部平均成交量 < 杯部平均成交量 × 60%：2 分
- 柄部平均成交量 < 杯部平均成交量 × 80%：1 分
- 柄部平均成交量 ≥ 杯部平均成交量 × 80%：0 分

**周期合理性评分**：
- 杯形周期在 7-65 周范围内：1 分
- 超出范围：0 分

### 1.4 突破点确认

**突破点** = 右杯沿的最高点（即柄部开始的位置）

**突破确认条件**：
1. 收盘价 > 突破点
2. 成交量 ≥ 20日均量 × 1.5
3. 突破后 3 个交易日内不跌破突破点

**突破确认价** = 突破点 × 1.01

**最优买入上限** = 突破点 × 1.05（超过此价为追高）

### 1.5 杯柄形态综合评分（0-10）

| 项目 | 分值 | 评分标准 |
|------|------|---------|
| 杯形质量 | 3 | U形3分，W形2分，V形1分 |
| 杯深度 | 2 | 15-30%得2分，12-15%或30-33%得1分 |
| 柄部质量 | 2 | 回调≤杯深1/3得2分，≤1/2得1分 |
| 量能萎缩 | 2 | 柄部量<杯部量60%得2分，<80%得1分 |
| 周期合理 | 1 | 7-65周得1分 |
| **总分** | **10** | ≥6分确认形态 |

## 2. 平台突破（Flat Base）

### 2.1 形态定义

平台突破是杯柄形态的变体，通常出现在杯柄形态突破后的第二阶段整理。

```
                    突破点
    ───────────────────/\
    平台整理区间      /  \
    ─────────────────/    \
```

### 2.2 识别参数

| 参数 | 标准 | 边界处理 |
|------|------|---------|
| 整理周期 | ≥ 15 个交易日 | < 15 日太短 |
| 整理振幅 | ≤ 15% | > 15% 算正常回调，非平台 |
| 成交量 | 整理期间持续萎缩 | 放量整理说明卖压重 |
| 整理位置 | 在前高附近（距前高 ≤ 15%） | 离前高太远说明趋势弱 |

### 2.3 评分标准（0-10）

| 项目 | 分值 | 评分标准 |
|------|------|---------|
| 整理周期 | 2 | ≥ 20日得2分，15-20日得1分 |
| 振幅控制 | 3 | ≤ 10%得3分，10-15%得2分 |
| 量能萎缩 | 3 | 整理量<前期量50%得3分，<70%得2分 |
| 位置合理 | 2 | 距前高≤10%得2分，≤15%得1分 |
| **总分** | **10** | ≥6分确认形态 |

## 3. 平底形态（Saucer /碟形）

### 3.1 形态定义

平底形态是浅而宽的 U 形整理，通常出现在长期上涨趋势中。

```
    前高            前高
     /\             /\
    /  \           /  \
   /    \         /    \
  /      \_______/      \
         底部盘整
```

### 3.2 识别参数

| 参数 | 标准 | 边界处理 |
|------|------|---------|
| 整理深度 | ≤ 15% | > 15% 算杯形，非平底 |
| 整理周期 | ≥ 25 个交易日 | < 25 日太短 |
| 底部形状 | 圆弧形 | 尖底不算平底 |
| 量能 | 底部区域量能萎缩 | 放量不算有效整理 |

### 3.3 评分标准（0-10）

| 项目 | 分值 | 评分标准 |
|------|------|---------|
| 整理深度 | 3 | ≤ 10%得3分，10-15%得2分 |
| 整理周期 | 2 | ≥ 30日得2分，25-30日得1分 |
| 底部形状 | 2 | 圆弧形得2分，W形得1分 |
| 量能萎缩 | 3 | 底部量<前期量40%得3分，<60%得2分 |
| **总分** | **10** | ≥6分确认形态 |

---

## 4. 形态选择优先级

当多种形态同时存在时，按以下优先级选择：

1. **杯柄形态**（最优先）— 欧奈尔经典形态，成功率最高
2. **平台突破**（次优）— 通常出现在强势股的第二阶段整理
3. **平底形态**（备选）— 适合长期趋势中的补充整理

**形态冲突处理**：
- 如果杯柄形态评分 < 6 但平台突破评分 ≥ 6：使用平台突破
- 如果所有形态评分均 < 6：PASS，不建议买入
- 如果形态不明确：降级为 WATCH

---

## 5. 形态失败的常见原因

| 失败模式 | 表现 | 应对 |
|---------|------|------|
| 杯形太深 | 杯深 > 33% | 趋势破坏，不参与 |
| 柄部回调太深 | 回调 > 杯深 1/2 | 卖压重，不参与 |
| 突破无量 | 突破日量 < 20日均量 | 假突破风险高，等待确认 |
| 突破后快速回落 | 3日内跌回突破点下方 | 突破失败，止损 |
| 整理时间过长 | 杯形 > 65 周 | 趋势已变，不参与 |
| 大盘环境差 | M 因子 < 6 | 个股形态再好也不参与 |

---

## 6. A 股适配注意事项

- **涨跌停限制**：涨停板缩量突破不算有效突破（量能受限）
- **T+1 制度**：突破当日买入后无法当日卖出，需更严格的确认
- **板块效应**：A 股板块联动性强，形态突破需板块配合
- **游资影响**：中小盘股可能受游资短线炒作影响，形态可靠性降低
- **财报窗口**：财报发布前后的形态突破需额外谨慎
