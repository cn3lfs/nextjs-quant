# CANSLIM 量化选股分析师

基于威廉·欧奈尔（William O'Neil）的 CANSLIM 成长股选股体系，对 A 股进行系统性分析，输出 BUY / WATCH / PASS 三级交易决策。

**核心策略**：7 因子全量评分（116分制）→ 杯柄形态分析 → 入场信号评估 → 综合决策。所有阶段全部执行，不存在提前终止。

**因子权重**：C(20%) + A(20%) + N(15%) + S(15%) + L(15%) + I(5%) + M(10%，实际优先级第一)

**风控纪律**：单笔亏损 ≤ 7-8%、风险回报比 ≥ 1:2.5、账户风险 ≤ 1.5%、T+1 次日预案

**数据来源**：同花顺问财（hithink-* 系列技能）

## 前置条件

需要 `IWENCAI_API_KEY` 环境变量。如未设置，参考 hithink-finance-query 技能的配置指引。

## 工作流

### Phase 1: 市场环境评估（M 因子评分）

从用户参数 `$ARGUMENTS` 中提取股票名称或代码。

**步骤 1.1** — 获取大盘指数数据（并行执行）：

```
Skill(hithink-zhishu-query, "沪深300 最新价 涨跌幅 成交量 MA20 MA60 MA120 MA250")
Skill(hithink-zhishu-query, "上证指数 最新价 涨跌幅 MA20 MA60 MA120 近20日涨跌幅")
```

**步骤 1.2** — 获取市场宽度与板块轮动（与 1.1 并行）：

```
Skill(hithink-sector-selector, "近5日涨幅排名前10的板块 涨跌幅")
Skill(hithink-macro-query, "最新GDP同比 CPI同比 PPI同比 PMI")
```

**步骤 1.3** — M 因子评分（满分 23 分）：

读取 `references/canslim-scoring.md` 第 7 节，按以下规则评分：

| 条件 | 分值 | 判定方法 |
|------|------|---------|
| 大盘站上 200 日均线 | 10 | 沪深300 最新价 > MA250 |
| 近期有跟进日信号 | 8 | 近 10 个交易日内，指数放量上涨 ≥ 1.5%（成交量 > 前一日 × 1.5） |
| 分布日 < 5 个 | 5 | 近 20 个交易日内，指数下跌且成交量 > 前一日的天数 < 5 |

**M 因子市场环境判定**（不阻断流程，仅标注风险等级）：

| M 因子得分 | 判定 | 影响 |
|-----------|------|------|
| ≥ 18 分 | ✅ 牛市确认 | 正常评分，后续因子不受影响 |
| 12-17 分 | 🟢 牛市初期 | 正常评分，报告中标注市场环境一般 |
| 6-11 分 | 🟡 震荡市 | 报告中标注风险，后续评分保留但置信度降低 |
| < 6 分 | 🔴 熊市 | 报告中醒目警告"市场环境不适合做多"，后续分析照常进行 |

**无论 M 因子得分多少，后续 Phase 2-6 流程全部执行。** 最终判断中综合考量所有因子，M 因子低分会在总分和置信度中体现。

如无法识别股票，向用户确认。如上市日期不满 1 年，在报告中标注数据可信度较低。

### Phase 4: 杯柄形态识别（Gate 2）

读取 `references/technical-patterns.md`。

**数据采集**：

```
Skill(hithink-market-query, "{stock} 最近120个交易日 开盘价 收盘价 最高价 最低价 成交量")
Skill(hithink-market-query, "{stock} 20日平均成交量 60日平均成交量")
Skill(hithink-market-query, "{stock} 近10日 日内振幅")
```

**杯柄形态识别流程**：

1. **识别杯形**：
   - 在 120 个交易日数据中寻找"先跌后涨"的 U 形走势
   - 杯深度 = (杯沿价格 - 杯底价格) / 杯沿价格，应在 12%-33%
   - 杯形周期 = 从左杯沿到右杯沿的交易日数，应在 35-325 个交易日（7-65 周）
   - 杯形应呈 U 形（底部圆润），非 V 形（尖底）

2. **识别柄部**：
   - 柄部在杯的上半部形成（柄部低点 > 杯深的 50% 位置）
   - 柄部回调幅度 ≤ 杯深的 1/3
   - 柄部持续时间 ≥ 5 个交易日
   - 柄部成交量持续萎缩

3. **确认突破点**：
   - 突破点 = 右杯沿的最高点（即杯柄连接处的高点）
   - 突破确认价 = 突破点 × 1.01

**形态评分（0-10）**：

| 项目 | 分值 | 评分标准 |
|------|------|---------|
| 杯形质量 | 3 | U形3分，W形2分，V形1分 |
| 杯深度 | 2 | 15-30%得2分，12-15%或30-33%得1分 |
| 柄部质量 | 2 | 回调≤杯深1/3得2分，≤1/2得1分 |
| 量能萎缩 | 2 | 柄部量<杯部量60%得2分，<80%得1分 |
| 周期合理 | 1 | 7-65周得1分 |

**Gate 2 判定**（不阻断流程，始终进入 Phase 5）：
- 评分 ≥ 6 → 形态确认，入场信号参考价值高
- 评分 4-5 → 形态不成熟，入场信号参考价值降低
- 评分 < 4 或无杯柄形态 → 检查平台突破/平底形态作为替代（见 `references/technical-patterns.md`）
- 无任何有效形态 → 报告中标注"无有效技术形态"，后续照常分析

**无论形态评分多少，Phase 5 入场信号确认照常执行。** 形态结论在最终判断中作为技术面的权重参考。

### Phase 5: 入场信号确认与风控管理

读取 `references/entry-exit-rules.md`。

**5 步入场确认**：

| 步骤 | 条件 | 必须/加分 | 判定方法 |
|------|------|----------|---------|
| 1 | 收盘价 > 突破点 × 1.01 | 必须 | 当日收盘价确认 |
| 2 | 成交量 ≥ 20日均量 × 1.5 | 必须 | 当日成交量确认 |
| 3 | 价格 ≤ 突破点 × 1.05 | 必须 | 超过为追高，禁止买入 |
| 4 | 大盘确认 | 重要 | 沪深300当日非大跌（跌幅 < 2%） |
| 5 | 催化剂确认 | 加分 | 近期有盈利超预期/研报上调/机构调研 |

**入场信号评估**（不阻断流程，始终输出完整报告）：
- 步骤 1-3 全部通过 + 步骤 4 或 5 至少一项 → 入场信号强，偏向 **BUY**
- 步骤 1-3 全部通过 + 步骤 4 和 5 均未通过 → 入场信号中等，偏向 **WATCH**
- 步骤 1-3 任一未通过 → 入场信号弱，偏向 **WATCH** 或观望

**入场信号评估仅影响最终判断倾向，不阻断 Phase 6 完整报告输出。**

**T+1 适配检查**：

| 检查项 | 标准 | 不满足时操作 |
|--------|------|------------|
| 入场时段 | 14:00-14:30 优先 | 其他时段需更严格确认 |
| 当日涨幅 | < 8% | ≥ 8% 禁止买入 |
| 财报窗口 | 距最近财报 > 5 个交易日 | 在窗口期内建议等待 |
| ST 股票 | 非 ST | ST 股禁止买入 |
| 次新股 | 上市 ≥ 60 个交易日 | 次新股标注风险 |

**风控参数计算**：

读取 `references/entry-exit-rules.md` 第 5 节仓位计算公式（含 **5.3 凯利公式仓位**）：

0. **账户总资金 T 统一以 100 万元计**（用户未指定时的默认基准，便于换算：50 万账户所有金额 ×0.5，300 万 ×3，比例不变）
1. 止损价 = 买入价 × 0.92（7-8% 止损，欧奈尔铁律）
2. 单笔最大风险 = 账户总资金 × 1.5% = 1.5 万元
3. 最大持仓金额（风险仓位）= 单笔最大风险 / 止损百分比
4. 单笔仓位上限 = 账户总资金 × 25%
5. **凯利仓位**：委托 `stop-loss`（公式见其 `references/kelly-sizing.md`）。传入本技能口径：p 由 CANSLIM 综合质量映射（高分达标+强信号→0.55，基本达标→0.48，部分达标→0.40），b = 回报倍数（风险回报比 1:b 中的 b，CANSLIM 要求 ≥2.5）
6. 实际仓位 = MIN(风险仓位, 半凯利仓位, 单笔仓位上限)；报告列出三者与约束项，M 因子熊市不做多

**优先用脚本精确计算**（quality 取 high/basic/partial）：
```bash
python ../stop-loss/scripts/kelly.py --profile canslim --quality basic -b <回报倍数≥2.5> --stop 8
# 默认单笔风险 1.5%、单只上限 25%、账户 100 万；追加 --json 供解析
```

**止盈策略**：
- 第一目标：买入价 × 1.20（+20%），卖出 50%
- 第二目标：买入价 × 1.25（+25%），卖出剩余仓位
- 风险回报比验证：X = 目标收益 / 止损损失 ≥ 2.5，即风险回报比 ≥ 1:2.5

## 错误处理

- **API Key 缺失**：输出 hithink-finance-query 的 API Key 配置指引
- **股票无法识别**：向用户确认股票名称或代码
- **财务数据缺失**（无法判断 C/A 因子）：该项得 0 分，降低总分和置信度
- **行情数据缺失**（无法判断趋势）：记录为数据缺失，在报告中标注"行情数据不可用"，继续分析
- **K 线数据不足**（无法识别杯柄）：继续分析，在报告中标注数据不足，形态评分降级
- **技能调用失败**：每条查询最多重试 2 次，失败后记录并继续
- **上市不满 1 年**：MA250 数据不可靠，在报告中标注数据可信度较低
