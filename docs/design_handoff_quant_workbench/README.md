# Handoff：观澜量化工作台（全部页面）

目标仓库：`cn3lfs/nextjs-quant`（master）

## 关于设计文件
`观澜主面板.dc.html`（今日总览）与 `观澜工作台.dc.html`（其余 15 页，左侧导航可切换）是 **HTML 设计参考**，不是生产代码。请在现有 Next.js + React 代码中按仓库既有模式重建，**复用现有数据接口与业务逻辑，只改布局与样式**。浏览器直接打开即可预览（依赖同目录 `support.js` 与 `_ds/`）。

所有数据均为示例数据；实现时接入仓库现有 API。

保真度：高保真（颜色、字号、间距、文案为最终值）。页面内容以仓库真实功能为准——设计中若出现仓库没有的字段，保留占位或省略，不要编造后端。

## 全局结构
- 根布局：左侧导航 206px（sticky，满高）+ 主区 `flex:1`
- 顶栏 sticky：面包屑（分组名）+ 页标题 15px/500 + 副标题 + 右侧搜索（Ctrl K）与时段胶囊
- 主区：12 列 grid，gap 14px，padding 18px 22px；视口 < 1240px 时所有面板整行
- 替换 `navigation.ts` 中 tab 与路由两套并行的导航，统一为一层分组侧边栏

## 面板类型（所有页面由这 8 种组合而成）
通用外壳：bg #1f2130，1px #3f424d，圆角 8px，padding 14px 16px，标题行 = 图标(#9184d9) + 13px/500 标题 + 可选 tag 胶囊 + 灰色 meta + 右侧分段控件/描边按钮。可选底注 11px #75798c。
1. **Stats**：`auto-fit minmax(130px,1fr)` 指标卡，数值 17px tabular-nums；异常卡边框换语义色暗阶
2. **Table**：grid 行，表头 10.5px #75798c，行 12px，分隔 #232532，hover #232532；证券列 = 名称(500) + 代码副行；窄屏横向滚动
3. **List**：行卡（图标 + 标题/副标题 + 状态胶囊 + 可选按钮），标题与副标题单行省略
4. **Form**：`auto-fit minmax(170px,1fr)` 字段，输入框 bg #1b1d2c、1px #3f424d；勾选项；按钮组
5. **Bars**：名称 + 5px 进度条 + 数值（RPS / 主题热度）
6. **Kline**：报价头 + K 线（沿用仓库现有图表库，仅套配色）
7. **Equity**：净值曲线（同上）
8. **Report**：结论标题 + 摘要 + 分阶段证据卡（证据支持 / 存在反证 / 证据不足）

主操作为描边按钮（1px #9184d9、字 #d2cefd、透明底，hover #2b2741），次操作边框 #3f424d。

## 各页要点
- **今日总览**：见 `观澜主面板.dc.html`；调度时间轴、5 张健康卡、下一步、今日信号、盘中预选、RPS、自选；内容随时段（盘前/午盘前/尾盘前/收盘后）派生
- **行情图表**：K 线 9 列 + 右侧快照操作（证据分析 / 回测 / 建立监控）3 列；RPS 4 列 + 自选表 8 列
- **条件选股**：入口分段（通达信公式 / 自然语言草案 / 本地可复现条件）→ 条件表单 → 本次运行统计 → 候选表（含 AI 快评列）
- **信号与通知**：今日统计 → 信号记录（核验/投递状态分列）+ 订阅列表 → 投递历史
- **任务中心**：队列统计 → 全部任务表
- **数据与连接**：本地行情统计 → 路径表单 + 研究模型表单 → 推送渠道列表
- **盘中预选**：批次分段（11:20 / 14:40）→ 参数表单 + 候选与收盘确认表
- **财联社复盘 / RPS / 信号台账 / 持仓与交易日志 / 证据分析 / 策略实验 / 策略样本研究 / 新闻主题 / 研究档案**：结构见设计文件 logic 中 `screens()` 的对应键

⚠ 信号台账、持仓与交易日志、新闻/主题三页设计时未读到完整源码，按组件名推断；实现前以仓库现有功能为准调整。
