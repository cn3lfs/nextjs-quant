## 本批结果

统一目录 91 项：56 项日线规则/对照、25 项目标权重预设、4 项研究、6 项数据缺口。分类仍为 15 类，既有方法登记 695 项。七个 RPS 周期属于同一个策略家族的预设；这些数字不能解释为 91 个独立有效 alpha。

- 整文件迁移累计 120 个路径（119 TS、1 JSON），由[精确映射](../../../strategy-module-migration.json)核对原路径不存在和目标唯一。包括因子、风险、条件查询、CANSLIM/SEPA 形态和评分。旧 `research-execution` 纯转发层删除，直接使用执行包真实接口。
- 风险修复与纪律政策从账户回放中拆出；固定指标从公式 DSL 中拆出；初始止损和人工覆盖计算从应用配置中拆出。费用、可买/可卖数量和账本变化通过真实执行器函数注入，不在策略包复制撮合逻辑。
- 供应商中文字段、列单位/时间、`status_code/datas` 解析保留实际应用适配器；流通市值、机构、行业观察评分与 SEPA 财务阈值使用包内 typed series。共享 ISO 周、证券类别严格代码识别归核心包，原始交割单清洗仍归导入器。
- 包内 CANSLIM/SEPA 入场诊断显式接收时钟；回放以各历史收盘的固定时点计算，不能依赖机器当前日期。策略源依赖守卫覆盖静态、类型、动态导入及 re-export。

## 新接入与恢复执行

新增[四项财务组合](../../../data-sources/portfolio-classics/README.md)：毛利/资产盈利能力、现金应计质量、保守资产增长、盈利能力与价值融合。复用已有财务数学和统一排名；年度资产分母、TTM 组成期、报告同比与披露后可见规则保持明确。上游脚本为固定版本参考资料，未复制到运行包。

新增[本地候选池 RPS 七周期](../../../data-sources/portfolio-rps/README.md)：1/3/5/10/20/50/120 日。利用相同候选池收益排序与 RPS 同序的关系复用排名器，不复制 `quant-rps`。此基线使用未复权本地价格及明确候选集合，不等同主 RPS 的后复权、证券资格和全市场结果。

新增[协方差风险平价](../../../data-sources/portfolio-risk-parity/README.md)：严格对齐的 60 日简单收益、样本协方差和固定微小对角正则，求只做多等风险贡献权重。纯求解器与手工 API 均在矩阵分配前限制最多 200 个候选，普通排序保留自身上限。未收敛则失败，不替换为反波动。原论文与 MIT 开源参考、固定版本许可均可追溯。

恢复五个已有代表 ID 的实际日线执行：`research-breakout`、`research-indicator-confluence`、`research-volume-price`、`research-wyckoff`、`research-growth`。调用现有规则，保留实际退出；成长新高价量基线明确采用既有默认五交易日持有退出，不能称为完整 CANSLIM。日线定义、API 枚举、任务和回放共用同一目录，不保留只在页面标“已实现”的假入口。

候选适配统一七项历史百分数输出为 ratio：动量、短期收益、波动率、利润增长、E/P、B/P、CF/P。底层原始因子单位不改；排名及反波动相对权重不因同比缩放改变，冻结候选数值与元数据单位一致。

策略中心来源仅 HTTP(S) 渲染为外链，技能相对路径作为来源标识显示。风险平价手工输入保留 `returns` 字段，真实本地取数与历史任务冻结对应行情、收益和财务组成期。权重结果绑定原请求的策略 ID 与截至日；手动选择、搜索自动选择或晚到响应均不能把一项策略的权重显示到另一项策略卡片。

## 未关闭范围

总体目标继续有效。混合成长因子/证据编排、财务分析服务中的规则数学仍需继续收拢；原生缠论需要实际确认结构与 DLL 版本的统一任务适配。价值、情绪、产业链研究依赖各自带时点证据和明确执行规则，不能以 `structure` 统一代替所有依赖。借券、多腿合约、盘口及训练样本缺口保留具体原因。

ETF 轮动已有行情来源，但当前统一任务限制沪深股票代码，品种、费用和执行模型仍需扩展；这属于执行适配缺口，不能笼统登记为缺行情数据。

现有历史证券池、公司行动、数据修订及交易模型限制保持披露；本批没有据程序测试追认任何可信策略业绩。
